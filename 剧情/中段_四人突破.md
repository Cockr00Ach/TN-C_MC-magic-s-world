## 一、熙永槐 —— 「铁冢」⇒ ★ 天赋「**重铸**」

| 项 | 【提案】 |
|---|---|
| **遗迹** | ★ 一处埋在旧战场底下的废矿/大铁匠坑 —— 名字叫「**铁冢**」：里面全是折断的兵器、没人收的残铁，堆到顶 |
| **守关者** | ★ **一具用废铁把自己拼起来的"炉守"** —— 它**不追人**，它把进来的东西**熔掉、钉进墙里**；⇒ ★ 所以这一仗**硬挡没有用**（挡住了也会被熔），只能**就地取材** |
| **拿到** | ★★ **「重铸」** —— 他能**当场把任何铁重打一遍**：断刀、碎甲、嵌在墙里的旧铁，都变成他要的形状 |
| **战场上的变化** | ★★ 他的盾**不再"碎"** —— 裂了就当铁料，**当场再打一遍**；⇒ ★ 从"一面打到烂的盾"变成"**越打越有的盾**" |
| **试招（收尾那一波）** | ★ 盾被凿穿 → 他**不退、不换**，把碎的那块**当场打成一支楔子**钉进地面，把冲上来的那一波卡在门口 |
| **★ 二周目** | ★ 他知道铁冢在哪、知道炉守先动哪一只手 ⇒ ★★ **一周目他是"找到它"，二周目他是"知道这块铁值什么"** |

## 二、庄鹊让 —— 「不借之卷」⇒ ★ 技能「**不借**」

| 项 | 【提案】 |
|---|---|
| **遗迹** | ★ 一座**塌掉的私人藏书楼** —— 原主把书当命，谁借书不还，他记一辈子；楼塌之后水漫进来，成了一潭**死水** |
| **守关者** | ★ **那潭水本身** —— 它认一个字：「**借**」。⇒ ★ 动过不属于自己的东西的人，水就压谁；★ 让第一次进去是**被水放过的**（她一辈子在管别人的东西） |
| **拿到** | ★★ **「不借」** —— 她能让一片水**当场不流动**；⇒ ★★ 效果**不是减速，是禁止移动**：被那片水罩住的，动不了（不是"慢"，是"**不被允许**"） |
| **她自己的说法** | ★「**这次不外借。**」（★ 对应她的档案/藏书身份，也接豫让那口气） |
| **战场上的变化** | ★ 她不再只是"让战斗停下来" —— 她**按住整片场地**（水、湿地、河沟都行），把路**封成墙** |
| **试招（收尾那一波）** | ★ 一波冲到半路 → 她不挡，只把中间那片水按住：⇒ ★ **怪物撞在上面像撞在墙上，一只都没到人** |
| **★ 二周目** | ★ 她知道卷在哪、知道那水认什么 ⇒ ★★ **一周目她是"被水放过的人"，二周目她知道要"让水认谁"** |

## 三、周坐望 —— 他自己的**旧居** ⇒ ★ 技能「**回头**」

> ★ 位置：【提案】**他入队之后**（前面三人在遇他之前）—— 这是**他"第一次自己下场"**的那一场。

| 项 | 【提案】 |
|---|---|
| **遗迹/地点** | ★ **他自己上山求真理之前住的那间屋子** —— 灯、书、没带走的旧东西都还在；★ 他一直绕开这个地方 |
| **守关者** | ★ **不是怪，是"必须他自己上"的局面** —— 队伍里只有他的光能进去，别人进不去（★ 呼应他一贯"只出主意、不下场"的老毛病）|
| **拿到** | ★★ **「回头」** —— 他的光**不只是照亮，还能"照穿"**：★ 他能看见**别人半拍之后要做什么** |
| **这条最有用** | ★★ 它解释了最终战两件事：★ 他为什么看得出**衍的右手会慢半拍**；★ 他为什么看得出 **Chiller Lynn 习惯先迈右脚** |
| **试招（收尾那一波）** | ★ 他第一次**不照队友、照自己** —— 知道对方下一步往哪走，就**站到对方下一步的位置上** |
| **★ 二周目** | ★★ 他**开场就会「回头」** ⇒ ★ 但二周目他照见的第一个人是**归** —— 他知道归会怎么选、也知道结果；★★ **他这一世最难的事，是装作不知道** |

## 四、吴归衡 —— ★ 这条要你定

> ⚠️ **归是主角，他的突破我不能自己编** —— 两个方向你挑：

| 方案 | 内容 | 好处 |
|---|---|---|
| **A（推荐）** | ★ 契机：【提案】中段清过一处**两种元素互相打架的裂隙**；他在这里**第一次把两样叠进一个动作里**（雷裹在风里、火藏在土里）<br>⇒ ★★ **「叠」** —— 他后来"七样都强"的**起点** | ★ 与"均衡=容器"咬合；★ 不需要新设定；★ 二周目可写成"他会得更多" |
| **B** | ★ 拿到**「第七件」** —— 一件让他能站在任何领域里不被压的东西 | ★ 很酷，**但得先定"领域"的规则** ⇒ ⚠️ **现在写不了**（等你那边魔法设定定稿）|

> ⇒ ★ **我倾向 A**：它是归**唯一一条属于自己的成长线**（他此前一直"够得着但不成器"），
> 而且**不与任何已有设定冲突**。★ A 的"试招"：一波怪他一样一样打都打不动，**叠上第二样就破了防**。
