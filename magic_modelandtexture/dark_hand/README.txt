================================================

★★ 2026-10-10 晚起：**这份 .bbmodel 是模型与贴图的唯一来源** ✓
作者交给我们的是**导出的**模型与重画过的贴图（原话：「我现在更新了一下，你依照我的更新更新吧」）✓
⚠️ **模型不是作者做的** ✗ —— 作者原话：「手的模型不是我做的啊，我帮你导出了」✓
   ⇒ **原作者与授权/署名待确认**（本仓规矩：分发前逐个确认授权）——
      文档/注释里请写"作者提供（导出）"，不要写成"作者自制/手改" ✗。

改完之后，用下面这一条命令导回模组（会覆盖 jar 里的模型 JSON 与贴图 PNG）：

        python tools/import_dark_hand_bbmodel.py

它会：① 逐条卡住加载器硬约束（分辨率 32x32 / from-to 在 −16..32 / 旋转只能单轴且角度合法 /
UV 在图内）；② 把 bbox **居中到原点**（引擎与渲染器都按这个前提工作）；③ 打印
**模型半高**该填的值 —— 照着填进 `TNNightGripEntity.MODEL_HALF_HEIGHT_UNITS` ✓
（作者这版是 12.5 单位 = 0.78125 格 ✓）。
⚠️ **别再跑 `tools/gen_dark_hand_model.py`** ✗ —— 那是旧的程序化生成器（按它自己的调色板重画贴图、
按老坐标重建 31 个方块），跑一次你的活就没了 ✓。它文件头也写了这条警告 ✓。

这个文件夹是"黑夜之手"道具模型的 Blockbench 工作副本。
用法见下面，两分钟能上手。

【dark_hand.json 是什么（作者放到这里的）】
  这是模型的**原始导出**（Blockbench 直接导出的 Java 模型，42 方块、坐标与 .bbmodel 完全一致 ✓）。
  ⚠️ 两处**不能直接拿去发货** ✗：
    · `"textures": {"0": "dark_hand"}` —— 没命名空间 ⇒ 游戏会去找 `minecraft:dark_hand` ✗
      （发货那份必须是 `tnc:spell_projectile/dark_hand` ✓）
    · `"texture_size": [32,32]` ＋ UV 是**半分辨率**（例：down `(3,10,4,11)`，而发货那份是 `(6,20,8,22)`）
      ⇒ 直接把这份丢进 jar，模型只会取到贴图的**左上四分之一** ✗
  它就当**来源留档**看 ✓；真正发货的模型由 `tools/import_dark_hand_bbmodel.py` 从 .bbmodel 生成（UV 与
  32x32 贴图自洽 ✓）。
  ⚠️ `credit` 只写了 "Made with Blockbench" —— **里面没有任何作者信息** ✗ ⇒ 原作者与授权仍**待确认** ✓
     （已登记在 docs/法术专题_交接.md 的待办里 ✓）。

【要打开的文件】
  dark_hand.bbmodel   ← 双击 / Blockbench 里 File > Open Model
                        **贴图已经内嵌在里面**，打开就能直接在 Paint 模式刷图
  dark_hand.png       ← 同一张贴图的独立副本（想在 Photoshop / Paint.NET 里改也行）

【模型是什么】
  31 个方块，分辨率 32x32，按材质分成了 9 个组（左侧 Outliner 里能整组点选）：
      wrist x1   palm x1   back x2   knuckle x1
      digit_0 x3   digit_1 x4   digit_2 x7   claw x9   aura x3
  朝向约定（**别改**，两个渲染器都靠它）：
      +Z = 掌心（朝着敌人 / 天降时朝着正下方）
      +Y = 上（手指朝上）
      -Z = 手腕
  改**几何**之前先说一声 —— 模型的"贴地锚点"是按 y 跨度算的（±13 单位 ⇒ 半高 13/16 格），
  几何一改那个常数也要跟着改。

【贴图图集对照表】（32x32，每一块就是一个材质，按像素坐标；**这次整张重排过，坐标全变了** ✗）
      palm      x  0..12   y  0..11    (13x12)   ← ★ **掌心**那一面（south = +Z）
      palm_back x 13..25   y  0..11    (13x12)   ← ★ **手背**那一面（north = -Z）
      claw      x  0..7    y 12..19    (8x8)     ← 爪尖：全图唯一的暖色（干血红）
      aura      x  8..13   y 12..17    (6x6)     ← 灵光碎片
      wrist     x 14..21   y 12..19    (8x8)     ← 手腕
      back      x 22..29   y 12..19    (8x8)     ← 掌根 / 掌垫
      digit_0   x  0..5    y 20..23    (6x4)     ← 手指三段
      digit_1   x  6..11   y 20..23    (6x4)
      digit_2   x 12..17   y 20..23    (6x4)
      knuckle   x 18..23   y 20..23    (6x4)     ← 掌指关节横条
      tether    x 24..31   y 20..27    (8x8)     ← **现在没有方块用它**（黑带已删）✓ 备用区域
      y 24..31 其余区域：空的，以后要加材质可以用 ✓

  ★★ 2026-10-10 重要变更：掌心 / 手背现在是**两块独立贴图**，各 13x12 ✓
      以前掌板两个大面共用同一块 12x12（手心手背长得一模一样，谁也认不出哪面是掌心 ✗）。
      现在：
        · `palm`(掌心, x 0..12) 与 `palm_back`(手背, x 13..25) **各 13x12** ——
          正好等于掌板那个大面的尺寸（13 宽 x 12 高）⇒ 画上去 **1:1 不拉伸** ✓；
        · 想验证"这两块是分开的"：打开模型转一圈，**手背那面明显比掌心黑**（实测平均亮度 23 vs 5）✓；
        · 这两块的默认亮度差是**故意拉大的**（不是最终配色）—— 就是为了让你一眼看出哪面是掌心，
          随后你把自己的画覆盖上去即可 ✓；
        · ★ **现在掌心上直接画了一个临时记号**：血红的"封印"（一个环 ＋ 三道掌纹），**手背留空** ✓ ——
          在 Blockbench 里转一圈、或游戏里放一次，都是**一眼**的事 ✓。
          ⚠️ 这是**临时记号，不是最终美术** ✗（作者的原话是"这个没变啊" —— 因为形状本来就没变、
            两块又都是近黑，光靠调色说不清 ✗）⇒ 你把自己的画**整块覆盖**上去就行 ✓。

  ★ 图集**任何两块都不重叠**（生成器里有断言，重叠会当场报错 ✓）——
    以前 `palm`/`claw`/`digit_*` 是叠在一起的：那样你画爪子会同时改到手背 ✓（已修）。

  想更快看懂：在 Blockbench 里点某一块方块 → 右侧 UV 面板会高亮它用的是图集哪一块。

【改完贴图怎么回到游戏】（★ 这一步必须照做，不然看不到变化）
  1. 在 Blockbench 的 Textures 面板里对 dark_hand.png 右键 → **Save As / Export Texture**；
  2. 覆盖到：
        src/main/resources/assets/tnc/textures/spell_projectile/dark_hand.png
     ⚠️ 分辨率必须还是 **32x32** —— 模型的 UV 是按这张图集逐像素写的，改尺寸会让所有 UV 错位；
  3. 告诉我 → 我重编译 ＋ 装机（装机前要关游戏）。

【⚠️ 别让谁再跑一次生成器】
  tools/gen_dark_hand_model.py 会**按它自己的调色板重画整张贴图**，把你手绘的这张覆盖掉。
  这个模型和贴图本来就是那个脚本生成的（所以仓库里原先没有 .bbmodel）。
  如果你更想"手绘为准"，说一声，我把你画好的 PNG 反向烘进生成器 ⇒ 以后重跑也不会丢。

【这个 .bbmodel 是怎么来的】
  python tools/gen_dark_hand_bbmodel.py
  （它读 models/projectile/dark_hand.json ＋ 贴图 PNG，把几何和内嵌贴图一起写成 .bbmodel；
    方块名字是按 UV 落在图集哪一块自动命名的，重新生成也不会变。）

【当前配色（2026-10-10 改过一版）】
  旧版：亮紫肉质 ＋ **洋红爪尖 ＋ 近白高光** ⇒ 作者反馈"太花了"，
        量化对照：最亮像素 240.7 → **47.1**，亮度>120 的像素占比 4.9% → **0.0%**。
  现版：焦黑的碳 ＋ 冷紫极窄描边，唯一的暖色留给**爪尖的干血红**。
