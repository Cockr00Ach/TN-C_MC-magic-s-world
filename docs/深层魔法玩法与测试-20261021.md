# 深层魔法：玩法与测试

这轮把炼药、农牧、能源、个人养成和出行串在同一套魔力网络里。相关任务在「魔药学」与新增「深层魔法 · 世界的回响」；原有作者与玩家任务页不重排。天空岛建筑、队友内饰和存档地形不改。

## 先试这条路线

药釜倒水 → 三味药材与焰蕊盐 → 火法点燃 → F8观察热环 → 分三次搅拌 → 封魔盖收汁 → 玻璃瓶盛药。

成熟魔植与合适魔兽靠近 → 集露盏/集息器 → 晶纤 → 储池 → 喷灌、温泉、锯台、温养祭坛或天路。前期三种储池不会过载。

## 1. 炼药：控制温度，观察漩涡

右键药釜持书打开药典，查二十三种配方；真正制作在世界中完成。水桶倒一次水供三剂。药材可手持右键投入，也可由玩家Q键丢入锅口；一份配方三味，另需焰蕊盐。普通火、岩浆和打火石不能点燃。

火法命中釜体点燃并提升温度；水法命中降温220。冰霜类投射物也接入降温事件。360～620为甜点区，热环翠绿；过冷暗蓝，过热红色。燃烧会持续升温，所以不能放着不管。超过800并持续五秒会炸出毒气与废液，不破坏地形。

打开魔力视后空手或搅拌棒右键搅拌，共三次，分别推进三段融合；过早重复搅拌无效。三色漩涡向中心重合：未达60%就盖釜为次品，60%以上为标准；达到100%后的一点五秒内盖釜为大师药。继续加热错过黄金帧则药性解离，成为废液。

手持封魔盖右键，或潜行持法杖右键，均需要开启魔力视。盖好后用玻璃瓶盛取。大师药剂药效和持续时间提高；次品弱但淤积高。废液可右键除草或腐蚀小怪。

## 3. 农用魔药与变异

同样使用药釜配方。手持药水右键自己的植物或动物。魔力农田喷灌塔供魔后，每五秒对9×9内一株施用一瓶药，消耗10M；空瓶留在装置中，潜行空手取回。

- 狂躁透支：成熟产魔株两分钟内产能+400%，随后枯死掉魔力灰烬；需要足够的收集吞吐。灰烬与两份骨粉可制作三份异兽骨粉。
- 巨人/微缩：魔植和魔兽体型改变。巨株采收获得带原品种记录的巨果，送入魔导锯台才切出八份该种产物；不会把任意植物变成同一种高价果。巨型魔兽的输出带重型来源属性。
- 属性扭曲：镜莲、霜铃及露系魔植有50%烧毁，50%变成蒸气魔莲；蒸气魔莲可留下种子继续培育。
- 分裂：成年镜翅蛾、守望螳螂或小史莱姆；另外消耗一份糖。每只每天一次，附近同种上限十二只。
- 缩水捕捉：用于普通怪物，生命低于25%、最大生命不超过250。地下城守关Boss与虚空巨兽不能抓。标记十秒内手持空生态拘束笼右键捕获。

## 4. 淤积与温泉

次品/标准/大师药每剂增加25/10/2淤积。超过50点时新药效减半、轻微迟缓；超过80点不能继续喝药，并会间歇干扰自己五格内的机器。F8内视显示数值，背包人物区域会显示经脉与紫黑淤积。

地热核心接魔力，投入舒缓浴盐，在五格内建源水池。泡在源水中每秒消耗1M，降低2点淤积。清零后一个世界日内回魔+50%，魔力视不增加精神过载。温泉房屋留给玩家装修，不生成替代建筑。

## 5. 精神过载与高维契约

连续开魔力视三分钟后开始增加精神压力；凝视太阳或高阶容器更快。关闭后缓慢下降。压力增加会出现色散、呼吸式视野和钟鸣。

超过80%时，16～32格附近可能出现高维魔灵，只在过载魔力视中可见。走到八格内右键：用90%当前生命、3级经验、完整献祭一把未附魔普通武器，或100%融合大师共鸣酊交换棱镜、古卷、寄生种、星界杖心。同一选项每日一次。先留出背包位置，装不下不会扣代价。

攻击魔灵会被清空魔力并送到百米高空，附带缓落保护。高维棱镜沿用检流尺配对，必须两端已加载；不强行加载整张地图。

## 6. 高阶聚能与灾难

深渊塔在魔力锻炉制作，需先阅读禁忌古卷。核心占3×3×3底部中央，四周八格每层铺聚能砖，共二十四砖；中央上方两格留空。容量一百万M。外壳各方向可接同属一个玩家的魔力网络。

| 过载 | 状态 |
|---|---|
| 0～40% | 蓝绿平稳；输入持续超过320M/s才增长 |
| 40～75% | 橙金热流；连接锻炉、锯台效率+50% |
| 75～100% | 红色临界流、心跳；32格内少量草地异变，附近普通动物狂躁 |
| 100% | 不破坏建筑的冲击波，召出魔力吞噬者 |

泄压阀放在塔三格内，潜行空手右键，抽出5000M、降低20点过载，并降下舒缓魔力雨。不要在珍贵草坪旁测试临界阶段。

巨兽优先吸食塔主机器的真实魔力回血，不会凭空回复，也不会啃坏建筑。击杀掉落坍缩魔力奇点，用于制作奇点核心。核心采用64位实存加工作缓冲，实际容量极大，但不是数学意义上的无限数值。

## 7. 天体魔力与极光

日镜露天放在高于海平面16格的位置，白天产24M/s；月盘夜间产16M/s，乘原版月相系数，满月三倍、新月0.2倍。来源类型会随网络真实传递。

每五至八个世界日出现一次极光夜，观星台可预测。普通视野见微光，魔力视中见天穹彩色极光帘。收集效率提高500%，产出星界魔力。

极光羽翼和星界杖心要求读过古卷、极光当晚、锻炉露天，并从旁边同主设备实际扣除200星界魔力；同时消耗正常锻炉材料与魔力。羽翼手持长按右键消耗8M/s飞行，结束有防摔宽限。

## 8. 活体装甲与器灵

寄生种可锻出三个全身装甲分支，拥有各自穿戴模型。首次扎根扣1生命，随后每秒消耗微量魔力维持活性；无魔力时消耗饱食。

- 荆棘暴君藤：四格内自动抽打、击退最多三只怪；不会自动攻击高维魔灵、已拘束魔物和友方。
- 翡翠生命苔：储魔抵挡伤害，站草地上恢复生命。
- 捕食者花苞：吞食附近经验球和腐肉、骨头、线、火药，转换成魔力；不吞珍贵物品。

王级及以上法杖右键插入温养祭坛，投入大师魔药或Boss核心。每份需要100同属性、太阴或星界魔力。大师魔药加20成长，核心加100；达到100觉醒真实陨星回响或治疗波词条。法术命中后有概率触发，独立冷却十秒并消耗15魔力。F8能看见杖上器灵虚影。

## 9. 九宫餐盘

雕花餐盘表面九个位置对应九格，手持食物对准位置右键摆盘。五种属性为火、水、风、土和中和。火水直接相邻会冲突；用史莱姆布丁、月光蜂蜜糕等中和食材隔开。

九格摆满且五味齐全、无冲突，F8可见金色阵光。空手食用整盘，消耗九份真实料理，获得十五分钟微型太阳：自己施法不再消耗可承载范围内的魔力，并向附近自有机器供魔与加速。乱吃冲突餐盘会受伤、击退、混乱。

## 10. 魔物车间

缩水捕捉后得到带魔物记录的拘束笼，放下还原真实魔物。服务器捕捉账本防止复制笼子生成多只怪。笼子每秒消耗3M维持，断供十秒会越狱。

史莱姆：笼下铺压电踏板，实际落地一次产20土魔力；对笼喂糖增加高跳次数。烈焰人：旁边喷水挑衅器有邻接水、供魔并激怒，吸魔罩收24火魔力/秒。暗影类：白天用邻接露天镜照射，在吸魔罩下产暗影魔力并定期结晶。

拘束期间不会向玩家家里乱射破坏性火球。拆笼或断供会释放，不会把怪物当作永久无敌摆设。

## 11. 天空魔力之路

用星路标记杖先点发射环，再依次点中继环建立单向路径；每段不超过二十格，可转弯、上坡、下坡，最多十六段。潜行空手清除去向。发射端每段每秒消耗8M。

跳入直径两格的流中即被托举，潜行离开。顺风魔导靴是全身衣装的升级件：穿着衣装、手持导靴右键装入，不占已经取消的独立鞋槽。

自己Q键丢出的物品会沿路成为气泡物流。末环下方一到两格或上方放箱子/漏斗收货；箱满保留物品，不吞货。只处理已加载路线，不强制加载远处区块。所有节点与收货位置都遵守玩家权限。

## 当前表现与边界

淤积用粒子、背包人物上的经脉与结晶表达；精神过载已有色散边缘、呼吸式视野和钟鸣，普通生物变成透明线稿的表现尚未加入。古怪废液目前通过右键施用，实际造成魔法伤害和虚弱；抛掷弹体与独立护甲腐蚀效果尚未加入。新增装甲、魔灵和巨兽使用独立原生几何模型，当前是可测试的首版外观。

高维棱镜和天空路只连接已经加载的区块，不替玩家永久加载远方地图；奇点核心以64位真实余额替代数学上的无限容量。温泉建筑继续由玩家装修，已实现核心、浴盐与源水理疗逻辑。
