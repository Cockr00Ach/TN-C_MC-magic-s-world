## 二、"会飞"改了三处（缺一处就会变成"飘着走路"✗）

在 `light/TNFightingAngelEntity` 的构造函数与 `createNavigation`：

1. `setNoGravity(true)` —— 不往下掉（不然一起飞就被重力拽回地面 ✗）；
2. `this.moveControl = new FlyingMoveControl(this, 20, true)` —— 位移变**三轴**，会自己升降到目标高度 ✓
   （取代原版走路用的 `MoveControl`）；
3. `createNavigation` 返回 `FlyingPathNavigation` —— 寻路可以**穿空气** ✓
   （原来的 `GroundPathNavigation` 只会沿地面绕路：你一飞高，它就在下面仰头卡住 ✗）。

配套的两件事：

* **跟随是三维的** ✓：主人飞上天，天使升空悬停在主人斜上方 1.8 格（`aiStep` 里用
  `getMoveControl().setWantedPosition(...)` 每 tick 给落点 ✓）；超过 16 格直接瞬移到主人身边 ✓。
* **打怪会俯冲** ✓：目标在地面时给一点向下的速度助力（`Mth.clamp(dy * 0.05, ±0.14)` ✓），
  不然它会悬在目标头顶够不着 ✗。

## 三、动作（`animations/entity/fightingangel.animation.json`）

| 动作 | 何时播 | 说明 |
|---|---|---|
| `idle` | 静止悬停 | 慢速扇翅 + 身体起伏 + 光环自转（4 秒循环 ✓） |
| **`fly`** | **空中移动** | 飞行专用：翅拍 **0.4 秒一次、幅度 −14°↔−48°**，身体前倾 14°、袍子被风带向后 ✓ |
| `walk` | 贴地移动 | 这套模型没有腿，所以是原位起伏 + 扇翅 ✓ |
| `attack` | 攻击（每 20 tick 一次） | 右臂劈下 + 身体前冲 + 翅膀一收 ✓ |
| `cast` | 触发式（留给以后的天使技能 ✓） | 双臂上举 + 光环放大 + 双翼展开 ✓ |
| `death` | 死亡 | 前扑 + 光环绕暗 + 翅膀垂下 ✓ |

生成器：`tools/gen_fightingangel_animation.py`（改完跑一次 `python tools/gen_fightingangel_animation.py` ✓）。

## 五、调试

```
/summon tnc:fighting_angel          # 原地放一只（没有主人 ⇒ 原地悬停、不会消散 ✓，专门用来试飞与看动作 ✓）
/tnc spell give ...                 # 学满五档后按档位放，看数量/个头/血伤 ✓
```

* 没有主人时它**不动也不消散** ✓ —— 这是故意的：`/summon` 出来的那只就是"活动靶子/展示品" ✓。
* 想验"会飞"最快的一条：`/summon tnc:fighting_angel` + 创造模式飞高，再放一次 t3 法术，
  三只天使会跟着你升空 ✓（如果它们只会贴地绕圈 ⇒ 说明飞行三件套有一处没生效 ✗）。
