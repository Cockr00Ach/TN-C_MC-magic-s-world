# 风系 Boss（苍岚）的魔法：审了一遍，然后跟上玩家侧

2026-11-15 · 作者：「我们的风系魔法更新过了，那风系boss手里的魔法有更新过吗」

## 一、审计结论：只跟上了一半

玩家风法这十几轮换了三代：

| 玩家侧 | 现在长什么样 |
| --- | --- |
| 龙卷风 | 螺旋折线（`WindTornadoLines` + `TornadoLineShape`），两层、根部收窄 |
| 风刃 | 战士剑气式光带（`WindBladeQi`），不自转、直射 |
| 风球 | 漩涡漏斗线（`WindBallLines`，三倍数量 + 渐变） |
| 风灵 | 分档出手 + 吸力有画面 + 命中炸开 |

Boss 侧对了一遍，**只有风刃被动跟着换了**（因为 `WindWardenCombat` 用的是同一个
`TNWindBladeEntity`，渲染器一换它自动变）✓；其余都没跟：

| Boss 侧 | 之前 | 状态 |
| --- | --- | --- |
| 苍岚旋风 `CanglanTempestEntity` / `CanglanTempestRenderer` | 烘焙模型（7 层薄板），只有"轻推"没有吸力 | ✗ 这次补上 |
| 风刃（波＋投矛） | 26°/tick 在打转 | ✗ 这次统一成直射 |
| 风刃波（非旋风模式） | 模型刀光 | ✓ 保留（那是"一片横着飞的刀光"，和玩家的风刃本来不同形状） |
| 风球 / 风灵 | Boss 不用这两样 | — |
| `WindEarthVisualMechanics` 的旧几何 | 旧代风/土表现 | 待定（见文末） |

## 二、这次改了什么

### 1. 旋风换成"线"，和玩家同一套

`CanglanTempestRenderer`：

- `tornado()` 模式 ⇒ 直接调用 `WindTornadoLines.draw(...)`（就是玩家龙卷风那个渲染器用的同一个方法）
- 尺寸按 Boss 的 `renderScale` 放大：半径 = `2.7 × renderScale × 0.92`（略小于伤害半径，线不会飘到判定外）、
  高度 = 半径 × 2.6、根部 0.42 倍（和玩家那个漏斗同一个收口比例）
- 自转沿用 28°/tick（和原来 Boss 的转速一致）
- **非旋风模式（风刃波）保留原模型** ✓

### 2. 旋风有了"强力吸力"

`CanglanTempestEntity` 新增 `swirlNearby()`（每 tick）：

- 半径 = `max(3, 2.7 × visualScale × 1.15)`、高度 = `max(3, 2.7 × visualScale × 2.6)`
- 速度全部走玩家的 `TornadoSwirlRules.velocity(...)`：切向转 + 向内收 + 往上升，上限 1.5 格/tick
- **乘 0.9**：Boss 的吸力比玩家收一点，不至于把玩家一直甩在空中没法操作
- 清 `fallDistance` ⇒ 掉下来不摔死
- 不吸自己（`CanglanWarlordEntity` 排除）

### 3. 风刃统一"直射"

`WindWardenCombat` 的两发风刃（横扫波 `blade` 与投矛 `spear`）都改成 `setSpinRate(0.0F)`，
和玩家风刃一致 ⇒ 同一片刀光不再"一边转一边飞"✗。

## 三、闸门

新增 `CanglanWindUpdateTest`（3 条）：

- Boss 旋风必须走 `WindTornadoLines.draw(...)`，且**不再引用** `projectile/wind_tornado` 模型；
  风刃波的 `projectile/windblade` 还在 ✓
- Boss 吸力必须走 `TornadoSwirlRules.velocity(...)`、有 0.9 倍系数、清 `fallDistance`、
  半径/高度跟着 `visualScale`
- `WindWardenCombat` 里不许再有 `setSpinRate(26.0F)`，且两发风刃都必须是 0 ✓

回归：`world.wind.*` + `boss.*` + `magic.*` **329 用例** 全绿（中途 `mana_shield` 缺冷却让
`SpellBalanceTest` 红，补成 12 秒 ✓）。

## 五、进游戏要验

1. 打苍岚，等它放**旋风**：应该是一束螺旋折线（和玩家龙卷风同一个画风），不是薄板模型
2. 站进旋风：会被**拽向轴心并卷起来**（转圈 + 上升），不是只被轻轻推一下
3. 风刃（横扫/投矛）：直着飞，不自己打转
4. 旋风与非旋风两种状态切换时，画面不要闪（一个是线、一个是模型刀光，这是有意的）

## 六、还没跟的（等你定）

# 第二轮（作者「改啊」）：把没跟的都跟完

## 1. 风刃波 → 玩家同款剑气

`CanglanTempestRenderer` 的非旋风分支不再画烘焙模型 `projectile/windblade`，
改成调用 **`WindBladeQi.draw(...)`** —— 就是玩家风刃那套「四层渐隐弯月 + 残影 + 刃口」✓：

- 朝向：实体 YRot 就是飞行方向 ⇒ 只绕 Y 转一次，弯月法线对着飞行方向 ✓
- 尺寸：`2.2 × renderScale`（按 Boss 体型放大）
- 淡出：按寿命 `1 − age/20` 渐隐 ✓

## 2. 风系自身的光环：旧视觉保留 ＋ 叠漩涡线

`WindEarthVisualRenderer` 的 `kind == 0`（风场 / 风之翼 / 风神降临这些**自己身上**的风系技能）
仍然先画原来的 `WindSolidModels.flight(...)` ✓，**再叠一层** `WindBallLines.vortex(...)` 的螺旋线 ✓：

- 半径 `1.15 + 0.16×档位`（t1 1.31 → t5 1.95 格），跟着档位变大 ✓
- 和风球/龙卷风共用同一份几何 ⇒ 风系内部统一 ✓
- 透明度只有 `envelope × 0.35 × 每根线自己的 alpha`（很淡，只当外圈气流）
- **顺序有闸门**：必须先 `WindSolidModels.flight`、后 `windAuraLines` ✓（不替换，只叠加）

## 3. 连招语言

Boss 现在三样都是玩家同款：
- 旋风 = `WindTornadoLines`（螺旋折线）
- 风刃波 / 投矛 = `WindBladeQi`（弯月剑气）
- 自身风场 = 旧模型 ＋ `WindBallLines` 漩涡线

⇒ 和玩家风法、风球、风灵是同一套线条语言 ✓（动画节拍本身没动）

## 4. 还没做的（需要你点头，工作量大）

`WindEarthVisualRules` 里 **35 个法术**（风 8 个 + 土 27 个）的旧几何还在用
`WindEarthGeometry`（21KB 的生成器，土系那套是"岩石/泥沼/地刺"的形体模型）。
把它们全部换成线条语言是一次大改（土系那批跟"土"的形体强相关，换了可能反而更难看）——
建议只换**风系那 8 个**，土系保持。要动的话我按"风系 8 个 + 保留土系"来做。

## 5. 闸门（4 条）

- 旋风走 `WindTornadoLines.draw`、不再引用 `projectile/wind_tornado`；风刃波走 `WindBladeQi.draw`、**不再引用** `projectile/windblade`
- 吸力走 `TornadoSwirlRules.velocity` ＋ 0.9 倍 ＋ 清 `fallDistance`
- 风场：必须**同时**有 `WindSolidModels.flight(` 和 `WindBallLines.vortex(`，且顺序是先旧后新 ✓
- 两发风刃都是 `setSpinRate(0.0F)` ✓

回归：`world.wind.*` + `boss.*` + `magic.*` + `client.*` **432 用例 / 96 套件全绿**。

# 第三轮（作者「全部改完优化一下」）：风系 8 个法术全部带上线条 ＋ 距离剔除

## 2. 优化（性能）

新增两处 **48 格距离剔除 + 距离线性衰减**：

```java
if (distSqr > 48.0D * 48.0D) return;              // 远处不画（27 根线在 48 格外看不出是线）
float distFade = max(0, 1 - sqrt(distSqr) / 48);  // 近处实、远处淡
```

- 风场光环（kind 0）：原本每个玩家身上 15~27 根线 × 18 段，远处白烧 ⇒ 现在 48 格直接跳过 ✓
- 召唤小阵 / 狂风波（kind 1/2）：同样加剔除 ✓
- 狂风波只在 `waveAlpha > 0.01` 时才画剑气（淡到看不见就不发顶点）✓

粗算：满屏 10 个风系视觉实体在 48 格外时，每帧少发约 **2~3 万个加色顶点** ✓

## 3. 闸门（4 条 → 保持 4 条，断言加严）

`WindBladeQi.draw` 在 ✓、**必须有 `48.0D*48.0D` 的距离剔除** ✓
