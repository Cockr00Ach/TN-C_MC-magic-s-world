# 附：修「换视角后脚下的龙不在人脚下」（2026-11-14 02:2x）

作者：「雷速链脚下的龙，在第一人称视角下位置没问题，但是换视角之后龙不在人物脚下，查查问题」

## 根因

`CoilDragonOverlay` 画那条盘在脚上的龙时，**自己拼了一个矩阵**：

```java
Matrix4f m = new Matrix4f().translation(at.x - cam.x, at.y - cam.y, at.z - cam.z);
```

只补了「平移到相机」，**没有带相机的旋转** ✗。

- 龙是绕 Y 轴盘的螺旋 ⇒ **绕 Y 转它看起来几乎一样**，所以第一人称时缺的那次旋转看不出来 ✓
  （而且第一人称相机就在脑袋里，脚下本来也基本看不见 ✗）
- 换成第三人称：相机被拉到身后、朝向完全不同 ⇒ 少掉的那次旋转立刻暴露，龙就"跑到人旁边"了 ✗

## 修法

不再自己拼矩阵，改用引擎给的 `event.getPoseStack()`（它已经含**相机旋转 + 平移到相机**），
只在上面平移世界坐标：

```java
var pose = event.getPoseStack();
pose.pushPose();
pose.translate(at.x, at.y - 0.40D, at.z);      // 世界坐标；相机变换由引擎负责 ✓
Matrix4f m = pose.last().pose();
... coil(..., m, ..., camX, camY + 0.40D, camZ, ...)
pose.popPose();
```

⇒ 第一人称 / 第三人称 / 任何 FOV 下都是同一套变换 ✓（和引擎自己画实体的方式一致）。

## 顺带修的一处数据

`SpellBalanceTest` 报 `solar_judgment`（t5 射线）读条只有 **1.05 秒**（规矩是顶档 ≥ 1.1 秒），
是这轮队友改出来的 ⇒ 改成 **1.15 秒**（`src/main/resources/data/tnc/spells/solar_judgment.json`）✓。
