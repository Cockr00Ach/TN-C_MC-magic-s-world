# 苍岚战将：风系重装 Boss，一阶段持剑、二阶段持矛

苍岚战将（`tnc:canglan_warlord`）是风系的重装 Boss，与翠岚武尊同域，代码放在 `com.tnc.tnc.world.wind`。整体沿用原来战神的高大体态：五十根骨骼、四百二十四个方块、十点二万个顶点，身高一百零八单位（六格七五），肩宽六十点八单位（三格八零）。模型朝向 `-Z`，一单位等于二点七五个像素。

## 兵器：不建模，直接借用风系兵器库

Boss 模型里没有任何武器几何。右拳上只留一个空的 `weapon_1` 锚点（父级 `hand_1`，子级 `weapon_tip_1`），渲染器在锚点上直接绘制玩家风系法术同一套兵器库模型：

- 一阶段画 `tnc:wind/arsenal/sword`（`FORM_SWORD = 1`），二阶段换 `spear`（`FORM_SPEAR = 2`）；
- 缩放二点一零 / 二点四零，绕 Z 轴负八度 / 正四度，绕 X 轴负七十六度 / 负八十度，沿矛杆前移零点二五 / 零点五五格，让拳头握在杆上而不是握在杆尾；
- 因此模型配色直接取自兵器库的遗物金属（板岩钢 `#102030`、蓝灰 `#306070`、青色 `#60B0B0`、白雾 `#E0F0F0`），Boss 与它的兵器是同一块料。

腕部关键帧是按画出来的剑反解的：离线脚本把兵器库模型真正摆到锚点上，量出剑尖朝向（零度朝后、负九十度朝上、正负一百八十度朝前）再挑关键帧，所以每一刀的落点在游戏里和预演图一致。

### 锚点坐标系（2026-10-21 修）

GeckoLib 的 `renderRecursively` 会**先压栈、应用这个骨骼自己的变换、画完它和它的子骨骼、再弹栈**；渲染器在 `super.renderRecursively(...)` 之后拿到的姿势是**父骨骼**的坐标系，不是锚点自己的。原来两位风系 Boss 的渲染器都在这个位置上直接画武器，后果是：锚点的位移（这里零点一七格）和**锚点的动画**全部丢失——十三段动画的腕部关键帧在游戏里一点作用都没有，剑只跟着 `hand_1` 走。

修法是先把姿势重新坐回锚点轴心（`WindConstructModels.atBone`：`T(pos)·T(pivot)·Rz·Ry·Rx·scale`，与 GeckoLib 的顺序一致），再叠握持角度。修前修后的差别（命中帧实测）：

| 招式 | 剑尖位移 | 朝向 |
|---|---|---|
| `cleave_left` 0.5s | 三点五五格 | 负八十二度 → 正一百六十四度（目标正一百六十） |
| `thrust` 0.6s | 五点零二格 | 负二十六度 → 正一百八十度（目标正一百八十） |
| `overhead` 0.8s | 三点六五格 | 负六十九度 → 正一百六十六度（目标正一百六十八） |

翠岚武尊的 `weapon_1` 在全部片段里都没有动画，所以它只受那个零点二四格的轴心位移影响，一并修了。

十三段动画的腕部角度集中放在生成器的 `WEAPON_KEYS` 表里，由 `tools/solve_wrist.py` 负责求解：它把每一段按 0.05 秒逐帧重建骨骼矩阵，把真正的兵器模型摆到锚点上，只要有任何剑体顶点落进头盔或胸腔就继续调腕角，直到整段干净；命中帧还要额外守住朝向容差，不会为了避让把刀口调歪。每段动画首尾都压在待机腕角上，招式播完切回 `idle` 时刀不会从肩膀里弹出来。求解结果：十三段全部零穿透（头盔、胸腔最差只剩四十五个顶点级别的贴柄摩擦，拳套本来就在肩甲盒里，肩甲不计入判定）。

## 造型按风元素重做

石板甲配雾岚缎带：布质披风与头冠改用雾色、刃色、狂风色四个象限，肩甲各加两片风羽，手背贴风符，盾牌换成圆形风盾——八片凸面盾板加边框、风纹、顶冠风羽和雾色束带。头盔双角与垂布保留，眼睛骨骼仍走全亮，暗处也能看见面甲。

## 动画

十三段 GeckoLib 动画，秒数与服务端 tick 数严格一致（一秒 = 二十 tick）：

| 片段 | 时长 | 用途 |
| --- | --- | --- |
| `idle` / `walk` | 四秒 / 二秒（循环） | 待机与行走 |
| `cleave_left` / `cleave_right` | 一秒 | 一阶段左右横扫 |
| `overhead` | 一点四秒 | 一阶段双手过顶下劈 |
| `shield_bash` | 一点一秒 | 贴身盾击，两阶段都能用 |
| `thrust` | 一点二秒 | 二阶段突刺，带前冲 |
| `sweep` | 一点七秒 | 二阶段三百六十度旋身扫击，两段判定 |
| `spear_throw` | 一点五秒 | 二阶段掷矛，长矛整根脱手 |
| `war_cry` | 二点二秒 | 狂风怒吼 |
| `phase_shift` | 二点六秒 | 半血换相：剑换成矛 |
| `spawn` / `death` | 二点六秒 / 二点四秒 | 出场与倒地 |

伤害窗口与片段对齐：横扫十 tick、过顶十六 tick、突刺十二 tick、旋扫十二与二十 tick、盾击十 tick、掷矛十二 tick、怒吼二十四 tick。

## 战斗

生命一千二、攻击二十八、护甲十六、韧性十、移速零点二六、击退抗性零点九，经验一千二。半血触发换相：播放 `phase_shift`、把武器从剑换成矛、把周围玩家推开，之后进入长矛阶段——收招更短、每击额外一成伤害。

| 招式 | 阶段 | 判定距离 | 半锥角 | 伤害倍率 | 击退 |
| --- | --- | --- | --- | --- | --- |
| 左/右横扫 | 剑 | 四点二格 | 一百零五度 | 零点八零 | 零点四零 |
| 过顶下劈 | 剑 | 四点八格 | 五十五度 | 一点三零 | 零点三零 |
| 盾击 | 双 | 三点二格 | 七十五度 | 零点五五 | 一点一五 |
| 突刺 | 矛 | 五点六格 | 三十五度 | 一点一五 | 零点六零 |
| 旋身扫击 | 矛 | 四点八格 | 一百六十五度 | 零点六零 | 零点五五 |
| 掷矛 | 矛 | 二十六格内 | — | 一点零零 | 零点二五 |
| 狂风怒吼 | 双 | 六点四格 | 一百八十度 | 零点三零 | 一点二五 |

掷矛复用风系已有的 `TNWindBladeEntity.shoot`（速度二点零、尺寸四点四、不自旋），命中规则与玩家法术完全一致。怒吼给自身加速与力量，把周围推开，并进入二百四十 tick 的冷却。

所有伤害只在服务端结算，并用「目标 UUID + 窗口」记账，同一窗口不会重复命中；死亡、重载、换维度都会把状态清干净。目标太远时不会原地挥空，`choose` 会返回 `IDLE` 让 Boss 先走近，掷矛与怒吼则是远程选项。

## 验证

- 离线审计 `tools/audit_canglan_warlord.py`：`PASS canglan warlord rig audit`，含骨骼层级、四象限贴图、循环标记、片段长度、左右镜像、落地贴合、锚点为空且在拳上；每个命中帧把真正的兵器模型摆上去量剑尖朝向与外伸距离（三格六五至六格一五）；逐段逐帧扫描，确认画出来的刀在整段动画里都不会穿进头盔或胸腔；并且把渲染器里的握持常数（缩放/前移/俯仰/侧倾）与 `wind_blade.GEAR` 逐项对齐、确认渲染器走了 `atBone` 锚点坐标系——两边一旦漂移，上面这些离线测量就不再描述游戏里画的东西。
- 腕角求解 `tools/solve_wrist.py`：逐帧搜索腕角并写回生成器的 `WEAPON_KEYS` 表，支持 `--check` 只报告不修改、`--prune` 删掉多余的转向关键帧。
- 单元测试 `CanglanWarlordAttackRulesTest`、`CanglanWarlordModelTest`：片段长度与规则逐条对齐、每阶段只能选本阶段的招式、半血换相、掷矛释放帧、锚点空骨骼、语言键、四象限图集。
