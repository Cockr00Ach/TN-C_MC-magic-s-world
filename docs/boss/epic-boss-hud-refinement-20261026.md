# Boss 血条细化

按用户反馈重画火山巨龟之外的十二套血条，保留巨龟上一版的完整绘制分支。

## 造型调整

上一版的公共菱形徽章、连续锯齿、满幅重复装饰和粗发光外框取消。新版本把金属边框收为细线和暗槽，血槽由 10/8 GUI 像素调整为 7/5，装饰集中在两端，给中间读数留出空间。阶段标记改为小刻痕，文字降低装饰占比。

十二套左端轮廓分别重画：日轮羽饰、角盔锁链、风化岩面、鳞冠水兽、破冠面具、枪旗、羽冠鸟首、战盔长矛、盘螭、长颈墨鹤、圆润虎面和分叉角须龙首。没有公用的外徽章轮廓。各自两端使用卷草、锁链、岩层、水涡、咒丝、旗缎、羽枝、枪刃、墨笔、鹤羽、窗棂和祥云。

水墨使用有粗细变化的曲线、确定性的飞白纹理和局部墨点；没有增加粒子或世界实体。风系使用分叉羽轴、羽枝和飘带，光系使用金属圆环与羽缘。下方读数移到羽饰、云纹下方，保留原有行距；血量滞留残影、实际实体绑定和阶段数据保持原逻辑。

主要实现：`src/main/java/com/tnc/tnc/bosshud/client/BossBarEngraving.java`。`EpicBossBarArt` 仅增加分流，火山巨龟继续执行全部旧代码。
