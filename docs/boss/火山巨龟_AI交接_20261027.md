## 5. Boss 设计现状

### 阶段

- 一阶段：`HITBOX 5.4×4.3`，模型 `phase1`，无 `plate_l/plate_r/jaw` 变形。
- 二阶段：`HITBOX 6.6×6.4`，模型 `phase2`，`transition` 3.4s（68 tick），岩甲外掀到 ±22° 并保持。
- 阶段切换走 `ACTION_TRANSITION`，期间普通技能不触发。

### 技能表（二阶段权重）

| 技能 | ACTION | 距离 | 说明 |
| --- | --- | --- | --- |
| 撕咬 `bite` | 1 | < 8.5 | 20 tick，命中 tick 10（0.5s 闭嘴帧） |
| 重踏火环 `slam` | 2 | < 7.1 | 72 tick，24 tick 落地，火环 0→22 格 30 tick，击退 0.6 |
| 大地震波 `quake` | 5 | < 9.9 | 72 tick，地面副本抬升，伤害默认 0（`-Dtnc.tortoise.quake.damage`） |
| 喷吐火球 `spit` | 6 | 7–30 | 蓄力 24–32 tick，72% 处锁定，嘴前 1.55 水平偏移出膛 |
| 熔岩之柱 `pillar` | 7 | 6–22 | 预警 36 tick，5–7 根，每 4 tick 一根，伤害半径 1.6 / 高 8 格 |
| 火山喷发 `eruption` | 3 | 8–28 | 3 批 × 7 颗，落区 8–24 格环形，爆炸半径 2.5 |

二阶段新技能（spit/pillar/eruption）权重合计约 **68%**，旧技能 32%；连续两次大范围技能时重复项 ×0.30。

### 狂暴 / 虚弱

- 血量 **≤20%** 触发一次（`ENRAGE_THRESHOLD=0.20F`），NBT 持久化，每场一次。
- 与转阶段冲突时转阶段优先，狂暴排队。
- 狂暴 200 tick：攻击冷却减半（`ENRAGE_COOLDOWN_SCALE=0.5`，实际约 1.8–2 倍频率）、`damageScale()` 全部伤害 ×2、清空负面并拒绝新增负面。
- 登场时立刻放一次**大喷发**：5 批 × 12 颗、外径 34 格、`MEGA_DAMAGE_SCALE=0.42`。
- 结束进入 160 tick 虚弱：Weakness + 受到伤害 ×2。
- 调试：`/tnc_enrage`、`/tnc_enrage weak`、`/tnc_enrage off`。

### 伤害规则（全部服务端权威）

- 统一入口 `damageScale()`（阶段 ×1.35、狂暴 ×2 只乘一次）。
- 投射物发射时快照伤害；`castHits` / `hitOnce` / `mortarLastHit` / `fieldHits` 各自去重。
- 同一次施法同一目标最多一次主伤害；燃烧区同 Boss 跨区域共享 10 tick 间隔。
- 不破坏地形、不点火、不生成 FallingBlock。

## 6. 血条

- 只在客户端 `CustomizeGuiOverlayEvent.BossEventProgress` 里接管，`setCanceled(true)`。
- 识别方式：实体同步 `DATA_BAR_ID`（`CompoundTag` 存 `Most`/`Least`）写入 `bossEvent.getId()`，客户端遍历 `level.entitiesForRendering()` 比对 UUID。**不要改回按译名匹配**。
- 布局：`UI_SCALE=0.5` → 血条 180×13（三段拼接：左框 78 / 火山 35 / 右框 78，`ART_W=191`）；名字在血条下方 4px、`#FF5A24` 带阴影；整条上移 6px；居中自算 `(guiScaledWidth - ART_W)/2`。
- 熔岩矩形由内槽反算再内缩：`round(6*sx)+2`、`round(73*sy)+1`、`round(364*sx)-4`、`round(51*sy)-2`。
- 多 Boss：非第一条从 `CROP_TOP=34` 裁掉火山上半段。

## 7. 这个整合包里的渲染坑（血泪，务必先读）

1. **Oculus 会把 `mc.renderBuffers().bufferSource()` 换成 no-op 的缓冲**：自己建 `MultiBufferSource.immediate(new BufferBuilder(n))`，否则画什么都看不见（`PortalRitualRenderer` 是参照实现）。
2. **`AFTER_WEATHER` 阶段**最稳：只叠 `new Matrix4f().translation(-camera)`，不要再用事件给 PoseStack（会双重平移）。
3. **实体渲染器必须注册**，哪怕不画：删掉渲染器不给替代，Forge 的 `EntityRenderDispatcher` 返回 `null` → `LevelRenderer` 空指针崩溃。用 `shouldRender=false` 的空渲染器占位。
4. **新增粒子类型必须补 `assets/tnc/particles/<name>.json`**，否则 sprite set 为空，`setSpriteFromAge` 空指针。
5. **`GuiGraphics.blit` 用十参数重载**（目标 w/h 与源矩形分开），九参数顺序极易错。
6. **1.20.1 `ServerBossEvent` 没有 UUID 构造**，只能靠实体同步数据传 UUID。
7. **`ModelEvent.RegisterAdditional` + `#standalone` 在本整合包不稳**，方块模型可能不烘焙（紫黑）。火球已改为**直绘网格**（`FireballCoreMesh`，84→102 面顶点表 + 直连纹理）。
8. **方块模型 JSON 三条硬限制**：不能写 `texture_size`；旋转只能 0/±22.5/±45；uv 空间固定 0..16。
9. 粒子 `overrideLimiter=true` + `addAlwaysVisibleParticle` 可绕过"粒子最少"裁剪；危险预警一律用独立几何，不要依赖粒子。
10. `Set-Content -Encoding UTF8` 改中文源码会 GBK 乱码 + 吞换行 + 加 BOM；**改 Java 源码用编辑器/写入工具，不要用 PowerShell 文本替换**。
