# User-authored Canglan spear pose and attacks

The user's Blockbench model and animation file are preserved byte-for-byte under `model-source/canglan_warlord/user-animation-20261022/`. The editable files in `exports/` are never regenerated by the importer.

The authored arm and weapon base rotations are imported into both the boss and echo geometry. Editor-only spear pieces are removed from runtime geometry, preserving the existing independently rendered wind spear and 256px body texture. Previous animation arm/wrist offsets are rebased from the old idle grip to this authored grip.

| User animation | Runtime clip | Duration | Gameplay timing |
| --- | --- | --- | --- |
| 突刺 | thrust | 1.7083 s / 34 ticks | swept collision-aware dash over first second, final strike at tick 24 |
| 横扫 | sweep | 4 s / 80 ticks | sweep at ticks 60 and 66 |
| 释放武器链t4t5 | sky_arsenal | 2.2917 s / 46 ticks | existing T4/T5 formation released at tick 30 |

The thrust root-Z track moves 492 model units (30.75 blocks) in one second. This track is extracted into authoritative entity movement, with normal block collision, loaded-chunk checks and a per-attack hit set. It is removed from only the runtime animation so the mesh stays on its hitbox. Original author files retain the track. The remaining authored tracks and timing are imported unchanged.

`python tools/import_canglan_authored_animation.py` rebuilds runtime assets from the author snapshot and the preserved previous runtime animation baseline. Do not run the older animation-kit exporter over the user's edited files.

Wind steps and spell dodges travel five times their previous distance (up to 75 and 50 blocks respectively), using the same six movement ticks with swept block collision and loaded-chunk checks. Anchors share the boss geometry/texture/animation resources, render at full brightness with a stronger translucent body, and have explicit 512-block draw and tracking ranges instead of inheriting the 0.1-block marker hitbox culling distance.

Cyclones from spinning attacks and anchor recalls pursue the current target, stop at target contact or a wall, and remain active for their bounded original lifetime. Nearby cyclones from the same boss fuse into one entity; cross-sectional area is added, model scale eases to the larger size, damage/reach grow with it, and fusion cannot create an endless lifetime. Other bosses’ cyclones and wave slashes remain separate.
