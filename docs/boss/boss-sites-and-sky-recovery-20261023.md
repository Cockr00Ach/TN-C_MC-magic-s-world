# 首领场景刷新与天空岛选址修复

## 已确认的天空岛根因

正式整合包 `logs/latest.log` 中，新世界在 2026-10-23 02:14:57 进入 `SkyIslandManager.chooseGroundPortal` 异常：出生点附近没有足够净空的安全候选地，`SURVEY` 失败。不是已经确认的末地浮岛碰撞问题，因此没有任意移动既有末地群岛。

原逻辑只扫描出生点附近 16 个传送阵候选。现在保留原候选，并将备用选址分环扩大到 256、384、640、1024、1536 格，共 56 处；每 tick 只检查一个位置。继续调用原来的 `PortalArchitecture.prepare`，保留容器、建筑和玩家改造保护、边界与高度限制，不通过清空建筑强行建阵。

原失败存档在更新后再次登录时，走现有检查点恢复流程继续选址，不需要删存档或重建世界。极端情况下全部 56 处受阻仍会明确暂停并保留现状，不声称任意地形必定可生成。

## Boss 位置

|---|---|---|
| 阿波罗 | 哥特大教堂 | 玩家接近该建筑时检查已加载的内部落脚点，自动刷新 |
| 暗巨人 | 主世界的末地群岛 `end_pvp_island` | 按 24 格宽、56 格高的真实碰撞箱寻找完整支撑与净空；必要时补专用承台 |

| 土系首领 | 土系战场 | 保留原遭遇系统 |
| 鹤、翼虎、墨龙 | 水墨世界 | 保留三阶段遭遇系统 |
| 公孙衍、火系首领 | 不安排 | 遵照本次用户指定，不自动放置 |

刷新身份按每一座建筑实例保存，不按每位玩家反复生成。只有 `addFreshEntity` 成功才保存 UUID。净空受阻或区块未加载时保留待重试；已知首领区块卸载时等待原实体，不复制一只新的。击败结果保存，不会马上补刷。可接管场景里原有的未绑定同类首领。

和平难度不生成，切换难度后重试。活着的首领被明确清理时可重试，正常区块卸载则不清除身份。旧存档以已完成施工日志中的最终坐标为准，支持选址期间移位过的浮岛；不会仅凭重新推算的种子位置，在旧世界空地上刷出首领。

真实末地群岛源模板中央没有满足暗巨人完整支撑条件的原生落脚点。后备承台为半径 19 格的末地石砖圆台，紫珀外缘；位于中央区域最高表面上方，仅向预先检查过的空气写入。不拆建筑、容器或植被，不强制加载建筑远处区块。已有承台会被安全落点搜索复用。若高度、边界或加载条件不足，仍保留待重试状态，不记录虚假刷新成功。

`/tnc boss_sites` 查看已发现场景的坐标、刷新与等待状态。建筑没有被加载/接近前不会凭空生成整座遗迹或提前刷出首领。
