# Boss 血条主体材质细化

保留用户认可的十二枚头像，对火山巨龟之外的血条主体重新制作材质与边框。火山巨龟继续走最初的完整绘制代码。

## 改动

- 使用带倒角、表面纹理和嵌槽的静态浮雕图集替换逐线绘制。头像右缘与血条之间使用配套衔接件，远端各有独立收尾。
- 光系金属、暗系铁甲、岩层裂隙、蓝金水纹、血红刃饰、风系织纹/羽纹/钢纹，以及水墨纸纹/鹤羽/虎窗/龙云使用十二种表面和端饰。
- 原血槽厚度、头像大小与位置、标题、阶段和血量数字位置保持不变。填充端部增加细微边缘高光、缓慢掠光，受伤残影继续使用既有血量平滑数据。
- 边框用三段切片绘制，端饰比例固定，中间随窗口伸缩。空血槽以透明开口显示下层材质，不使用一张不透明装饰遮盖生命值。没有新增实体、模型渲染或粒子。

生成器：`tools/bake_boss_bar_materials.py`。源图与排版参数：`art/boss-bar-materials-20261026/`。游戏图集：`assets/tnc/textures/gui/boss_hud/materials_v1.png`，1024×2048 RGBA、722688 字节。渲染器：`BossBarMaterials`，由 `BossBarEngraving.draw` 调用。

## 验证

原生客户端最终报告 `failures=[]`，实际绘制 2032 次；外部普通血条未被拦截，实体离场后缓存清零。十三位 Boss 图库、小分辨率和实际双 Boss 同屏共四张截图逐张检查，血量填充、透明空槽、头像衔接、阶段文字和端饰无重叠。

`tools/verify_boss_bar_materials.py` 检查图集十二格均不同、空槽透明，确认十二枚头像的所有不透明核心像素与用户认可版本完全一致（十二项差异均为 0）。火山巨龟完整一行逐像素一致。报告：`work/boss-bar-materials-client-20261026/verified.json`。截图：该目录 `screenshots/`。

最终合并包 97 个相关类、1136 个方法通过 ASM 检查。
