# 苍岚横扫镜头与处决修复（2026-10-23）

旧版镜头根据动画头部朝向每 tick 绕 Boss 旋转，同时推近；横扫根骨骼快速旋转会带着摄像机大幅转动。新版在镜头开始时固定拍摄侧，直接采样实际脸部和矛尖渲染坐标，以脸为主、长矛为辅平滑取景；取消快速绕圈和推近，并在特写期间覆盖震屏产生的相机角度。保留潜行跳过及所有视角恢复条件。

普通横扫原本在第 60 和 66 tick 都判定伤害，基础攻击力为 28，足以击杀原版 20 生命玩家。现在只在第 66 tick 判定一次，普通横扫伤害上限为目标最大生命的 45%，仍受通常护甲和无敌帧规则影响。

处决必须在蓄力开始时和命中时都严格低于半血，判定计入吸收生命（金色生命）。刚好半血不满足处决；普通横扫不会因为蓄力过程中目标掉血而升级成处决。回血、远离、失去视线、无敌、创造或旁观状态均不能触发终结。命中前回血的目标按普通横扫结算。普通镜头明确标为“横扫（普通攻击）”。

## 验证

- 风系 Boss 专用单元检查通过，15 项服务端 GameTest 全通过。
- 新增满血、51%、50%、吸收生命、蓄力中降血、回血取消以及 20 最大生命满血目标不会被普通横扫秒杀的检查。
- 原生客户端实际 S2C 镜头运行，9 张截图；最大单 tick 转向 1.0061°，相机恢复正常、检查失败列表为空。创造模式只预览处决构图，伤害由服务端独立验证。
