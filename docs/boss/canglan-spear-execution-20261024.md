# 苍岚战将：穿身挑举、掷落处决

新增独立动作 `execution_impale`（move 15，112 tick），不覆盖玩家原先制作的 `sweep`、`thrust`、`sky_arsenal` 轨道。

动作顺序：

1. 收矛蓄势、向目标刺入；第 22 tick 接触时再次校验生命、距离、视线与可用空间。
2. 命中后将目标躯干固定到实际长矛尖端，举至头顶，短暂停顿。绑定为服务端实际位置约束，不只是镜头幻觉；客户端同步锁住移动和使用动作。
3. 第 72 tick 解除绑定，施加向前向上的抛掷速度；镜头从 Boss/受害者双主体构图切换为持续追踪飞出的玩家。
4. 抛出后落地或第 100 tick 才结算终结伤害，避免刺中瞬间死亡导致挑举、甩飞完全看不到。

自动触发条件沿用之前的半血处决：生命加吸收生命严格低于最大生命的一半；创造、旁观、无敌及已有乘骑状态不参与。满血和半血整的横扫仍是普通攻击，不切镜头。接触之前逃离或回血可使处决落空，绑定期间外部回血到半血及以上也会解除处决。

近距离测试：生存模式、生命低于半血时 `/tnc canglan attack execution`；`/tnc canglan stop` 取消，`/tnc canglan resume` 恢复正常 AI。潜行键只跳过镜头，不解除服务端的矛尖绑定。

安全处理：绑定存在超时，地形碰撞、世界边界、高度及区块检查；取消、Boss 移除、目标死亡、退出、换维度或服务器停止会清理绑定，保留原先的重力状态。绑定期间不打开玩家的 NoGravity 标志，避免中途保存或异常退出把该标志写入存档；通过服务端位置约束与速度清零固定目标。不写入永久玩家 NBT、不修改永久移动属性。只有处决期间使用新姿态，其他动画与模型贴图不变。

同一份姿态数据 `assets/tnc/poses/canglan_execution.json` 用于服务端矛尖位置和客户端骨骼变换；独立 GeckoLib 动画可在原动画文件中编辑，但修改后应同步姿态数据的关键帧。姿态数据不放在 GeckoLib 自动扫描的 animations 目录内。
