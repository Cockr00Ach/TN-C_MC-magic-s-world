# 地核战场入口恢复

当前工作区停留在较早的源码版本，正式包缺少 `world/eartharena` 模块、
`tnc:earth_arena` 维度数据和生成器，以及地形依赖的元素符文石建材。
Boss 本体仍在，因此表现为 Boss 能保留，但战场区域和传送命令一起消失。

从 Git 中恢复已经完成的战场实现，包括黄色天空的山地、双色石环竞技场、
地形保护、旧区块迁移和中央守卫遭遇。沿用原维度 ID，不删除或重置玩家存档。
恢复原 `/tnc eartharena`，同时增加等价快捷命令 `/tnc earth`；再次使用会返回原位置。
原有地核钥石也保留，命令权限与原实现一致。

恢复战场依赖的元素符文石注册和全部材质，避免维度虽然存在但生成时缺少方块。
发布时只合入战场、相关建材及守卫锚定逻辑，语言条目、挖掘标签与必要 Mixin 按键合并，保留安装包中的其他更新。
发布检查新增必需战场类和维度资源的存在性检查，阻止此类缺失包通过校验。

验证：3 项地形单元测试、3 项独立服务器测试通过，覆盖命令和维度注册、山地生成、
旧区块升级、守卫进入唤醒/离开重置和地形防破坏。实际恢复包的 231 处 TN-C 成员引用检查通过。
已备份后安装到工作区与 PCL2，完整发布校验通过。
最终包只新增 337 个恢复条目并合并 5 个相关条目，其余已安装内容逐字节一致。
