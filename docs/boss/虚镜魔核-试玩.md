# 虚镜魔核试玩

在 PCL 的「元素觉醒1.4.3-魔改版-20260915」进入自己的世界，在地下城外输入 `/dungeon mirror`。传送到镜厅中央的石地后，镜像会自行起身。你可以直接疾跑、跳跃和侧闪。

正常路线是「星眠幻庭」第 30 层的新守关房。整队到场后，任一人踏入中央石纹即可唤醒镜像。镜像读取魔法石两页装配和背包中的独立法术容器。进场时可以空手。新学的技能会自动填入第一个空装配槽；如果槽位已满，进场前手动装上想测试的那招。试玩和正式闯关使用同一份装配规则。没有学过技能且没有独立法术容器时，镜像会近身普攻。

单人房主可以直接使用。多人试玩由有指令权限的队长在星眠幻庭入口大厅集合全队后使用。创意或旁观模式会在本次试玩期间临时切为生存，击碎镜心或离开试玩后恢复。

| 想看什么 | 怎么试 |
| --- | --- |
| 技能与外观复制 | 两人用不同皮肤、护甲与技能进场，各自观察与自己同名的镜像。等它举杖锁定方向再横移，重法术收势后近身。 |
| 双方换装 | 所有一阶段镜像倒下后留在房内。水银回流、静默生效，玩家和镜像同时换上全套铁甲、铁剑和盾。玩家热栏里还有水桶、镐、弓等反制工具。原装备在二阶段结束时归还。 |
| 破盾与跳劈 | 在石地上近距离持续正面举盾，观察换斧、抬肩和下劈；看到斧举过头顶再侧闪。随后在中距离横移躲钩，观察它追上后跳起、下降出剑。 |
| 放网与跑路 | 跟它贴身拉扯，或连续命中它制造压力。留意镜像是否先在脚下放网、再换岩浆桶抬手。岩浆落下前割网侧闪，或用水桶凝固岩浆。放出的水会逐格扩散，收回水源会一起退掉，最迟 30 秒自动消失。 |
| 搭高与追击 | 在平地贴住镜像，留意它后撤到空地、搭四格柱并居高连续射箭。也可借断柱取得高差。拉开到 12–20 格，或在它上方保持视线，留意抬手掷出的末影珍珠。镜像有 64 颗珍珠和 64 个金苹果，珍珠要落在安全地面才能传送。玩家二阶段各借用 10 个。用镐敲最底下带银纹的支撑石，柱身随之消散。 |
| 残血与落地水 | 低于四成血时追到掩体后打断吃果；把它打离高台后留意低头换桶、落地、收水的反击窗口。 |
| 最后一拳 | 所有二阶段镜像倒下后，等两道金环停转、岩板完全打开。走到低托前，空手击碎小镜，再到对面的终点石结算楼层。 |

中途重连到原来的试玩房间后，输入 `/dungeon mirror` 即可继续；地下城原有的 `/dungeon resume` 也能确认恢复。查看试装归还时，可在入场前给一件装备改名，记下原快捷栏位置。无需拿自己的正式存档做物品还原测试。

开发回归使用 `gradlew.bat -PdungeonMobTests -PechoMirrorTests runGameTestServer`。组合参数载入地下城实体依赖，并选择虚镜专项。首通的「无相镜片」逐人发放，满包时存入地下城邮件。
