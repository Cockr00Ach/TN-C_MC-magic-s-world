## 召唤

```
/summon tnc:volcanic_tortoise ~ ~ ~
```

刷怪蛋：`tnc:volcanic_tortoise_spawn_egg`（在创造模式物品栏的 TN-C 页）。
强制进二阶段（把血打到半血以下等价）：

```
/data modify entity @e[type=tnc:volcanic_tortoise,limit=1,sort=nearest] Health set value 400f
```

## 外观

轮廓约 **5.9 × 4.75 × 8.9 格**（比首版放大约 1.5 倍）：低伏的椭圆龟壳（壳缘 → 两级穹顶）、
壳背正中一座**六级火山锥**，锥顶是**两级环形火山口**（厚口沿 + 内部凹陷 + 井底岩浆 + 口沿溢流），
四条熔岩沟从锥腰向下淌到壳缘；粗短四腿、前伸低垂的龟头、短尾。

- 贴图 1024×1024，岩石用**分层的深灰/灰褐**（岩层带、鳞片格、苔藓块都画进基础色），
  最深一档只到 `(84, 78, 72)`，**没有大面积近黑** —— 这是按"关闭光影也要看得清"的要求重烘的。
- **一阶段**：火山岩壳、暗红裂缝、口沿冒烟。
- **二阶段**：同一副骨架，裂缝灌满岩浆、火山口岩浆池变亮、壳缘与头顶长出岩刺、眼睛发红光。
- 两阶段各有一张 `_glow.png` 发光层（火山口 + 熔岩裂纹），走 `entityTranslucentEmissive`，
  与光照无关 ⇒ 关光影也亮；身体其余部分照常吃环境光。

## 行为

| 技能 | 触发 | 判定 |
|---|---|---|
| 撕咬 | 目标进入 8.5 格 | 动作第 5 tick 结算一次，单体伤害 |
| 重踏 | 目标进入 7.1 格、冷却好 | 第 13 tick 结算，半径 9.5 格内全部吃伤害并被掀起 0.42 |
| 火山弹（仅二阶段） | 目标 18 格内、冷却好 | 第 1 tick 在目标周围撒 3 个落点并画预警环，第 26 tick 一起爆（每个半径 2.5 格，落点散布 8 格） |

节奏：撕咬冷却 22/14 tick（一/二阶段），重踏 130/90 tick，火山弹 300/200 tick。

**所有伤害都在固定 tick 结算一次**，不看客户端动画事件、不每 tick 结算。

## 阶段

- 血量 ≤ 50% 时触发一次转阶段：44 tick 的 `transition` 动画，期间 **无敌 + 停手**，播咆哮与岩浆粒子。
- 转阶段只改 `DATA_PHASE`（同步 + `TortoisePhase` 写进 NBT），**不改属性**；
  二阶段伤害是读阶段算出来的系数（`damageScale()`）⇒ 存档重载不会叠乘。
- 模型与贴图由 `GeoModel` 按 `phase()` 现取，晚进场的玩家也能看到正确外观。

## 体量与渲染校准（2026-10-19 放大版）

| 项 | 值 |
|---|---|
| 碰撞箱 | `HITBOX_WIDTH = 5.4` / `HITBOX_HEIGHT = 4.3` |
| 撕咬距离 | `BITE_RANGE = 8.5` |
| 重踏半径 | `SLAM_RADIUS = 9.5` |
| 火山弹散布 | `ERUPTION_SPREAD = 8.0` |
| 阴影半径 | `shadowRadius = 3.4F` |
| 渲染裁剪盒 | `getBoundingBoxForCulling().inflate(3.2, 2.2, 3.2)` |

模型改大改小之后这几个数要跟着改，否则会出现"打不到"或"隔空咬人"。
Blockbench 工程与导出步骤见 `docs/boss/火山巨龟_模型编辑说明.md`。

## 实机验证清单

1. `/summon tnc:volcanic_tortoise ~ ~ ~` 能出现、朝向正确、贴地。
2. 走两步：`walk` 动画、四腿对角摆动，不穿地。
3. 靠近：会转向、会咬；站在侧面会被重踏。
4. 打到半血：转阶段动画 + 无敌 + 模型/贴图当场换成二阶段。
5. 二阶段：火山弹预警圈 → 爆炸伤害。
6. `Ctrl+S` 退出重进：仍是二阶段、血量不回满、伤害没有翻倍。
7. 两个客户端同时在场：都能看到阶段与动画。
