# Boss 脱战距离：专属维度里"几乎不脱战"

2026-11-15 · 作者：「每个boss在自己专属的维度里，战斗距离也就是玩家离开多少格才会脱战，应该非常的远」

## 一、机制：脱战距离 = `FOLLOW_RANGE`

原版 Mob 靠 `Attributes.FOLLOW_RANGE`（跟随范围）决定"能咬住多远的玩家"：
玩家一旦跑出这个半径，`TargetGoal` 就不再续用 ⇒ `getTarget()` 被清空 ⇒ 脱战。
所以"玩家离开多少格才脱战" 差不多就是这个属性 ✓

> 另外两个会影响"玩家跑了还回不回来"的点，一并确认过：
> - `removeWhenFarAway(...)`：这些 Boss 全都已经 `return false`（不会因为玩家跑远被刷掉）✓
> - `setPersistenceRequired()`：专属维度 Boss 都设了 ✓

## 三、现在：统一 512 格

新增 `boss/BossLeash`：

- `ARENA_FOLLOW_RANGE = 512`（脱战距离）
- `ARENA_CHASE_RANGE = 448`（追到这个距离就守在原地看着，但**不清目标** ⇒ 不脱战）
- `stillEngaged(distance)` / `shouldChase(distance)` 两个纯函数

十个 Boss 的属性构造器全部改成 `BossLeash.ARENA_FOLLOW_RANGE`：

阿波罗 / 衍 / 利维坦 / 火山龟 / 石枪 / 巨兽人（`TNDarkGiantSpells.FOLLOW_RANGE`，黑魔法师共用）/
墨鹤 / 墨翼虎 / 墨天龙 / 苍岚 ✓

专属维度一般就几百格见方 ⇒ 实际效果是「**只要人还在这个维度里，就不会脱战**」✓

## 四、闸门

新增 `BossLeashTest`（3 条）：

- 512 > 之前最远的 400；500 格仍算在战斗里、600 格算脱战；追击上限 < 脱战距离
- 十个 Boss 文件都必须引用 `BossLeash.ARENA_FOLLOW_RANGE`（漏一个就红）
- 有 `removeWhenFarAway` 的 Boss 必须是 `return false`（不然玩家跑远会被刷掉，脱战距离再远也没用）

石枪的旧游戏测试断言从 `==400` 放宽到 `>=400`（保持原意）✓

## 五、进游戏怎么验

1. 进任一专属维度，打 Boss 到半血，然后**跑到维度另一头**（几百格）：Boss 应该还在战斗状态（血条还在、会继续追/放远程技能）✓
2. 只有当你**离开这个维度**（传送回主世界），才算真正脱战 ✓
3. 顺带确认：Boss 不会因为你跑远而被刷掉（`removeWhenFARAWAY=false`）✓

## 六、待定

1. `ARENA_CHASE_RANGE = 448` 是否合适（Boss 追到 448 格就停在原地远程打你 —— 想让它一路追到底就把这个值提到 512）
2. 是否要给每个维度加"进了维度就锁门"的机制（现在只是"不脱战"，玩家还是能跑出去）
