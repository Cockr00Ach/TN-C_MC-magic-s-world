# 火山巨龟 · 模型编辑与导出说明

这份说明对应仓库里当前实装的版本，目的是你能直接在 Blockbench 里改模型、改完按这里导出回仓库。

## 一、文件在哪

| 文件 | 作用 |
|---|---|
| `art/volcanic_tortoise/volcanic_tortoise_phase1.bbmodel` | 一阶段可编辑工程（贴图已内嵌） |
| `art/volcanic_tortoise/volcanic_tortoise_phase2.bbmodel` | 二阶段可编辑工程（贴图已内嵌） |
| `src/main/resources/assets/tnc/geo/entity/volcanic_tortoise_phase1.geo.json` | 一阶段实际加载的几何 |
| `src/main/resources/assets/tnc/geo/entity/volcanic_tortoise_phase2.geo.json` | 二阶段实际加载的几何 |
| `src/main/resources/assets/tnc/animations/entity/volcanic_tortoise.animation.json` | 两阶段共用的动画 |
| `src/main/resources/assets/tnc/textures/entity/volcanic_tortoise_phase1.png` | 一阶段贴图 1024×1024 |
| `src/main/resources/assets/tnc/textures/entity/volcanic_tortoise_phase2.png` | 二阶段贴图 1024×1024 |
| `src/main/resources/assets/tnc/textures/entity/volcanic_tortoise_phase1_glow.png` | 一阶段发光层（黑底，只有裂缝亮） |
| `src/main/resources/assets/tnc/textures/entity/volcanic_tortoise_phase2_glow.png` | 二阶段发光层 |
| `tools/gen_volcanic_tortoise_art.py` | 生成上面全部美术的脚本（几何/贴图/动画/bbmodel 一次出） |

两条路线，选一条：

- **改 bbmodel 再导回 geo.json**（推荐，所见即所得，见下面第三节）。
- 改 `tools/gen_volcanic_tortoise_art.py` 里的 `CUBES_P1` / `CUBES_P2` / `THEMES` / `ROCK`，跑一次脚本全部重出。贴图是程序画的，只有走这条路才能连贴图一起改。

## 二、单位与朝向约定

- 1 单位 = 1/16 格，**地面 `y = 0`**，**前方是 `-Z`**，`+X` 是它的右侧（玩家的左）。
- 当前轮廓：宽 94、高 76、长 142（单位）≈ **5.9 × 4.75 × 8.9 格**。
- 碰撞箱 `HITBOX_WIDTH = 5.4` / `HITBOX_HEIGHT = 4.3`（比模型略小，正常做法），在
  `VolcanicTortoiseEntity` 里；`BITE_RANGE = 8.5`、`SLAM_RADIUS = 9.5`、`ERUPTION_SPREAD = 8.0`
  都按这个体型配过。**如果你把模型明显改大改小，这几个数要跟着改**，否则会出现"打不到"或"隔空咬人"。
- 阴影半径 `VolcanicTortoiseRenderer.shadowRadius = 3.4F`，渲染裁剪盒
  `getBoundingBoxForCulling().inflate(3.2, 2.2, 3.2)`。

## 三、骨骼名字（**不要改**）

```
root
└─ body
   ├─ shell            ← 壳缘、穹顶、火山锥、沟槽、火山口
   │  └─ whorl         ← 火山口里的岩浆（idle 里慢慢自转）
   ├─ neck
   │  └─ head
   ├─ tail
   ├─ leg_fl / leg_fr  ← 前腿
   └─ leg_bl / leg_br  ← 后腿
```

动画是按这些名字绑的，改名会让 `idle / walk / bite / slam / transition / death` 直接失效。
新加的方块挂到上面任意一根骨骼下都没问题；要加新骨骼也可以，但**不要动已有名字**。

## 四、动画

两阶段共用 `volcanic_tortoise.animation.json`，六段：

| 名称 | 时长 | 谁触发 |
|---|---|---|
| `idle` | 2.6s 循环 | 控制器 `move`（站着时） |
| `walk` | 1.0s 循环 | 控制器 `move`（移动时，对角腿摆动） |
| `bite` | 0.6s | `triggerAnim`，命中在第 5 tick |
| `slam` | 1.4s | `triggerAnim`，命中在第 13 tick |
| `transition` | 2.0s | 半血转二阶段，44 tick 无敌 |
| `death` | 1.8s | `die()`，`deathTime` 提前 16 tick 让它播完 |

**注意**：命中判定在服务端按 tick 数走（`BITE_HIT_TICK` / `SLAM_HIT_TICK` / `ERUPTION_HIT_TICK`），
你把动画节奏改长了，要把实体里那几个常量一起改，不然会出现"动作还没砸下去就已经吃伤害"。

## 五、Blockbench 导出步骤

1. 打开 `art/volcanic_tortoise/volcanic_tortoise_phase1.bbmodel`（贴图已内嵌，不用另外找）。
2. 改模型。改完确认 **`File → Project → Format` 是 `Geckolib Animated Model`**（工程本来就是）。
3. `File → Export → Geckolib Model`，得到 `.geo.json`：
   - 重命名成 `volcanic_tortoise_phase1.geo.json`，覆盖
     `src/main/resources/assets/tnc/geo/entity/` 下同名文件。
   - 二阶段同样操作，导出成 `volcanic_tortoise_phase2.geo.json`。
4. 贴图：在 Blockbench 里改完，`File → Export → Texture` 存成同名 PNG（1024×1024），覆盖
   `textures/entity/volcanic_tortoise_phase1.png` / `_phase2.png`。
5. 发光层（裂纹自发光）：它必须是**黑底 + 只有亮的裂缝/岩浆**。改完基础贴图后，如果裂纹位置变了，
   要么重跑 `tools/gen_volcanic_tortoise_art.py`（会按新几何重画发光层），要么手工把
   `_glow.png` 里对应的像素补上。发光层用的是 `entityTranslucentEmissive`，亮度与光照无关，
   所以关光影时也能看见。
6. 动画：`File → Export → Geckolib animations`，覆盖
   `animations/entity/volcanic_tortoise.animation.json`。
7. 构建 + 装机验证：

```powershell
$env:JAVA_HOME='D:\software\PyCharm 2024.1.4\jbr'
$env:GRADLE_USER_HOME='<workspace>\.gradle-home'
.\gradlew.bat build --console=plain --no-daemon --offline '-Dnet.minecraftforge.gradle.check.certs=false'
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install-to-pack.ps1
```

> 注意 `-Dnet.minecraftforge.gradle.check.certs=false` 在 PowerShell 里**必须加单引号**，
> 否则会被当成 task 名。

## 六、导出的 geo.json 要满足的几条

- `description.texture_width` / `texture_height` = 1024。
- `visible_bounds_width` ≈ 13、`visible_bounds_height` ≈ 8、`visible_bounds_offset` ≈ `[0, 4.5, 0]`
  —— 这三个只是渲染裁剪用的包围盒，模型改大要跟着放大，否则远处会被裁掉。
- `identifier` 保持 `geometry.tnc.volcanic_tortoise_phase1` / `_phase2`。
- 方块原点用整数、尺寸用整数最稳（本工程全是整数，贴图 UV 才能贴着像素）。

## 七、关光影下"不发黑"的几条约定

- 基础色最深只到 `ROCK["basalt"] = (84, 78, 72)`，没有大面积近黑；
  岩层（每 4 行一条 ±10% 明暗带）、鳞片格（每 6 像素一道 0.88 暗线）、苔藓块都画进基础贴图。
- 代码里**没有**任何颜色乘数：`RenderType.entityCutoutNoCull` + 默认着色，`packedLight` 走环境光。
  所以如果实机还是偏黑，先看贴图本身，不要怀疑渲染器。
- 发光层只叠在裂缝/岩浆上，身体照常吃环境光。

## 共面偏移（避免密集条纹/闪烁）

生成器在输出前跑一遍 `_fix_coplanar()`：只要两个方块的某个面**正好落在同一平面**
且在该平面上有重叠，就把体积较小的那个沿该轴往较大方块的中心推 **0.02 单位**。
一阶段原本有 110 处这样的共面（壳缘顶面 vs 甲片底面、腹甲侧面 vs 大腿侧面等），
修复后只剩 2 处（都在山体内部的遮挡块，看不见）。

在 Blockbench 里手动加方块时也要注意：**不要让两块的面正好齐平**，
错开 0.02 以上即可，否则关光影下会看到条纹/闪烁。

## 二阶段独立模型（2026-10-20，作者第二轮要求）

二阶段不再由一阶段派生，是一套**独立几何 + 独立贴图**，由 `tools/gen_volcanic_tortoise_art.py` 里的
`P2_SCALE / BONES_P2 / ROT_P2 / P2_CUBES` 定义。

- 体量：**7.62 × 7.75 × 11.23 格**（一阶段 5.88 × 4.88 × 8.88），即整体 1.2 倍；立方体 103 个、贴图 1024×1024。
- **新增骨骼**（原有 11 根骨骼名与动画名全部不变）：
  - `jaw` —— 下颌（含三颗粗短岩石獠牙），转阶段末拍张嘴咆哮用；
  - `plate_l` / `plate_r` —— 壳侧外掀的大岩甲（前肩与后胯各一块，共四块立方体），转阶段第三拍向外掀起。
- **带旋转的立方体** 11 个（`rotation.origin/axis/angle`）：四块岩甲绕 z 掀起、五组断裂岩脊（`rg1/2/5` 绕 z、`rg3/4` 绕 x）、眉脊与下颌各绕 x 微倾。
- 火山：五级锥 `vb_1 → vm_1 → vu_1 → vw_1` + 断裂口沿 `cw_b/l/r/f`（**正面右侧整段缺失**）+ 口内 `lava_core / lava_deep / lava_spill`；正山面与两侧各一组熔岩通道，末端被 `oc1/oc2` 岩块遮挡。
- 贴图打包**必须用缩放后的立方体尺寸**（`build_texture` 里 `int(round(size * scale))`），否则 box-UV 六面错位（表现为大片纯黑 + 错图）。
- 转阶段动画 `transition` 从 2.0s 改成 **3.4s 四拍**（停步低头 → 下沉震动 → 岩甲掀开 → 口部喷发），`TRANSITION_TICKS = 68`；动画里同时驱动 `plate_l/plate_r/jaw`（一阶段模型没有这几根骨骼，通道会被忽略，不会报错）。
- 实体碰撞箱按阶段切换：`getDimensions(Pose)` 返回 5.4×4.3 / 6.6×6.4，`beginPhaseTwo()` 里调 `refreshDimensions()`；渲染裁剪 `inflate(4.2, 3.6, 4.2)`。
- 发光层沿用 `VolcanicTortoiseEmissiveLayer`，只覆盖熔岩色像素（`volcanic_tortoise_phase2_glow.png` 24 KB），岩石保持正常受光。
