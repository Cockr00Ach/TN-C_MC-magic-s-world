# 风、水棋盘战场与水墨落点修复（2026-10-23）

- `/tnc wind`：进入苍岚柱阵，再次执行返回原位置；`/tnc wind boss` 在战场中央召唤苍岚战将。
- `/tnc water`：进入水渊棋境，再次执行返回原位置；`/tnc water boss` 在水下中央召唤水系巨兽。
- 指令需要管理员权限。战场不会自动反复刷 Boss，召唤指令每次生成一只。

两个维度均为超平坦方格地面，基本地面 Y=32，8×8 格交错。风系中央另有 768×768 格的抬高战台，抬高 8 格至 Y=40，宽度大于 Boss 索敌直径 512 格（半径 256）；四周以 8 级台阶连接原平面，不加装饰边框，Boss 在中心生成。水系地面仍为 Y=32。柱阵以 48 格为间距，中央半径 72 格不放柱，外围采用有底座、削角和腰箍的实体柱，柱高 44～60 格。两座棋盘均使用全部八阶配色，按地面与柱体部位分工，避免随机混色；地面仅作无边框的连续方格平铺。场景为普通区块方块，无常驻装饰实体、逐帧场景模型或全维度粒子。

风系最终采用 imagegen 新绘的建筑材质套件：玉白石、暗青石、翠玉石、风暴板岩、香槟金、卷风徽石、槽柱石和金线墨石。图集与完整提示词保存在 `art/generated/element_boss_blocks/wind_architecture_atlas.png`、`art/prompts/wind_architecture_20261023.txt`，按 4×2 网格机械提取为八张 128×128 贴图，全部加入创造栏。

地面仅使用连续的大方格平铺，没有棋盘外框、边线、节点或围边；少量相近色阶以大片区变化，避免满地高频纹样和八色随机混铺。柱身采用连续槽纹，柱脚和外扩柱头分层收束，少量金色作柱头收边，卷风徽记仅用于个别节点。水系使用原有八阶蓝金纹石，按同样的建筑分工排色，深蓝和浅蓝保持棋盘对比。

水面 Y=128，棋盘地面位于水下约 96 格；维度内持续恢复空气，不覆盖玩家药水。仅此维度的水下雾视距放宽至 112 格。

传送先等待目标区块完成加载，风、水入口根据 OCEAN_FLOOR 高度贴地放置，水系不会错误传到水面，入口受阻时拒绝传送。每个战场分别保存来源维度、位置和视角，服务器退出清理待传送记录。

水墨原落点使用 `getHeight(...) + 1`，比可站立高度多出一格，而且没有先确保区块已生成。修复为先加载区块，再取实际碰撞表面顶点，检查脚下、头顶空间与液体；原点受阻时在 8 格内搜索，找不到安全位置时返回失败，不把玩家丢到空中。其他已安装水墨进入/返回逻辑保持原样。

验证：服务端真实生成两个维度，检查正负坐标棋盘、柱顶、固体及水面高度图；另以未加载的新水墨区块检查玩家贴地和无碰撞，共 2 项 GameTest 通过。原生客户端检查方块资源、两座场景及水系返回风系的位置流程；截图随文保存。未做完整整合包帧率基准测试。
