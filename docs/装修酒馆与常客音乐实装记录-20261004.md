# 装修酒馆、坐席常客与两首音乐

源内饰：`RouchNao-内饰试玩-第一版-20261003`。沿用用户同伙完成的酒馆，提取为独立装修补丁；保留原始压缩包。后续美术继续沿用用户认可的生态版本。

## 游玩效果

- 酒馆共有75个椅凳和软垫座位，安排49位固定坐着的常客，占65.3%，留26席给玩家。
- 常客按楼层与桌组分布，有各自姓名与一句简短日常对话；右键打开原有对话面板。使用不同原生村民衣装与专用坐姿模型，低软垫的腿部姿势单独处理。
- SELF在酒馆内可站立的位置；协会接待员与委托栏迁到可用位置。保留NPC身份、剧情进度及原委托栏内容，空槽补充城镇委托。
- 连续进入酒馆室内10秒后，等概率选中用户提供的两首BGM之一，同曲循环至离开。重新进入重新计时、重新选择。静音、暂停、退出存档和跨维度均处理；战斗音乐优先。
- 游戏内音乐音量设置可以控制酒馆BGM。MP3原文件未修改，JAR内使用OGG流式播放。
