# 四条生活路线：实装与测试说明

这份说明对应 20261007 的整套实装。四页任务放在「RouchNao · 生活与魔导」分组：四时农圃、魔植花园、异兽牧场、魔导工坊。共 409 个节点，跨季作物另有 56 个共用完成记录的入口。原有其他章节保留。

## 十分钟测试入口

1. 更新后重启游戏，创建新世界。在自己的野外地块测试即可；天空岛的公共地块仍受保护。
2. 先看四页最上面的说明任务，领取对应手册。手册右键展开为游戏内书籍；厨房手册较长，会分卷发放。
3. JEI 搜索「注能台」。配方为一玻璃、两铜锭、三石头。放下后潜行右键开面板，把玻璃瓶放进第一个输入格；空手对台长按右键，每秒注入自身 5 魔力。也可在面板中点击注能，持续五秒。
4. 注入 100 魔力生成一个满瓶；八泥土与满瓶做魔法土源。放在泥土区，同高度 9×9 内获准修改的泥土在十秒后转化。不会转草地、铺路或建筑。
5. 用注能台向空桶注入 400 魔力，得到流动魔力桶。也可用四个独立满瓶加一空桶合成。把流动魔力放在田边，八格内的魔法土与土源都可以直接种魔植，无需再锄。缺灌溉暂停生长，不会杀死植株。
6. 种下翠脉枝或新供魔植物。把集露盏放在成熟供魔株的 3×3×3 范围，依次接相邻魔导丝、浅魔池、魔导锯台。先用注能台供能也能验证加工，再换花园供魔。
7. 找到一只低阶异兽，喂其喜食，再用灵纹笼持续捕获。放出、继续照料，牧务杖选兽后右键自己的栖居标记设窝；附近放食槽并装真实饲料。
8. 给饰品充能台接线，把饰品或魔道机甲放输入格，观察每秒最多 16 魔力实际转入物品。它不会凭空充满。

创造模式测试可以用 JEI 取物，但「拿到魔力瓶」不会凭空写入服务端余额，测试能源请仍用注能台。行为任务须实际种植、捕获、设窝、采收或加工；持有一个物品不等于完成这些操作。

## 四时农圃

现有原版与模组植物盘点为 94 个任务条目、137 个明确方块 ID；多种生长方块会归在同一条目。每季七个游戏日，二十八日一年。应季正常生长，相邻季六成、反季四分之一，不会换季枯死。睡觉推进季节；作物自身成长依然需要已加载世界运行。

普通作物继续使用原模组的土、水、架子和种法。菌菇、水生和异境植物保留自己的规则。护候灯每秒消耗 0.4 魔力，在完整封闭的 9×9 温室内恢复应季速度。厨房手册列出原模组配方例，当前实际合成以 JEI 为准。

## 魔植花园

人工魔植统一需要魔法土/土源及八格内流动魔力，不按四季限制，也不要求某群系才能种。供魔种类的日光、音符、雨水等条件决定特殊产能，不能把「能种」与「正在供魔」混为一谈。

成熟果实类的产物可以直接种回；根芽类用普通剪刀取种源；拔掉植株会返回种源。无需旧采样工具。正常成长与复产需要运行时间，未加载地块不补算产能。

普通魔法土使用蓝灰土质与细青绿纹，低密度微光；土源的纹路与溢出更明显。流动魔力同样采用青蓝色。世界里的流动魔力仅灌溉，不能反复抽回网络制造能源。

## 异兽牧场

灵纹笼、曜纹笼、星髓笼使用灵纹铁、曜纹金、星髓晶制造，分别持续捕获三、五、八秒，高级笼兼容低级目标。先喂喜食建立短暂信任，III 级目标还要安抚；受伤、距离拉开或松手会中断。每个笼装一只真实个体，放出后笼可复用。

窝点限制的是身体边界：地面 9×9，飞行 9×9×9。明确安排的运输、跟随、巡逻可以例外。食槽真正消耗饲料；饥饿停产停工，不会饿死。肉用、活取、服务、储魔与供魔动物分别有用途，特殊的蓄魔鲸、纸帆鳐、牵线蜥放在任务页下方。

曳彩角羚和鼓腹砂獭拥有独立模型与不同配色。角羚喜欢的色靶由个体确定，染料右键切靶色，无遮挡时收集不伤人、不破地形的真实能量；砂獭等运动供魔按真实行动计算，瞬移不会算成运动产能。集息器须用牧务杖绑定自己的动物，潜行空手右键切取魔/充能。鲸每秒上限 32、蜥 8、貂 25；物品装瓶与网络共用余额。

## 魔导工坊

本轮采用纯魔力单位 M；没有 FE 放大转换。三级线路共享带宽为 8 / 32 / 128 M 每秒，储池容量为 1000 / 8000 / 32000。多个来源经过同一根线，合计受同一带宽限制。折光镜沿六轴对齐，普通十二格、远折二十四格，需要无遮挡；分流阀接红石信号可关断。检流尺查看实际输入、输出与状态。

魔力炉继续使用 3×3×3 四材料结构：下层九砖；中层外围砖、前正中炉口、中心核心；上层外围砖、中心排烟口。灵纹铁消耗一铁锭与 60 魔力，曜纹金一金锭与 180，星髓晶一钻石与 600。实体炉口 GUI 的配方与实际进度为准。

加工装置有四个输入格、两个输出格。堵塞输出不会吞材料。纸皮压机需要相邻清水；注能台、充能台的容器会显示在装置上方。所有新装置只在已加载区块中工作，权限改变会暂停。

- 魔导灯与庭院明灯：分别 0.05 / 0.1 M 每秒；守望铃发现九格内敌意生物时耗 2 M 响铃并输出短暂红石信号。

饰品充能台连接上述网络，每秒实际转入最多 16 M。归途缎带容量 300，安全回自己买下的房屋需 120 M、脱战十秒；缓降羽饰容量 200，副手下降时耗 2 M / 秒；探矿耳坠容量 200，15 M 提示八格内矿物方向；守露护符容量 300，副手减伤有耗魔与冷却。

魔道机甲穿胸甲位，容量 6000 M，有独立穿戴模型；走路免费，冲刺耗魔增速。符文弩为手持器具，每发消耗真实箭与 25 M。法术机枪模块必须穿机甲使用，每发消耗箭与机甲 20 M，最多连射八秒，冷却四秒。营造尺普通五格直线、潜行三格框，逐格消耗玩家实际方块和 3 M。当前射击使用实体箭；额外的高阶法术弹与机甲飞行尚未加入。

## 委托、交易与协作安装

新增十一种供货材料接入酒馆可选委托及商店交易，包含九株新产物和两兽产物。农业与牧养服务于生活、赚钱与工程供料，不以全收集卡主线。

仓库不保存第三方模组 JAR。合伙人拉取本次提交后需要构建 TN-C，再安装运行文件，不能只凭 Git 中的源码变化期待游戏自动更新。使用项目要求的 JDK 17，在仓库运行：

```powershell
./gradlew.bat test build runGameTestServer -PlifeRoutesTests -PbuildingGameTests --offline --console=plain *> work/life-routes-final.log
./gradlew.bat runClient -PlifeRoutesVisualAudit -PbuildingGameTests --offline --console=plain *> work/life-routes-client-final.log
python tools/verify_life_routes.py
python tools/prepare_route_ftb_loading.py --live "你的整合包版本目录"
./gradlew.bat runGameTestServer -PlifeRoutesTests -PbuildingGameTests -PftbQuestLoadTests --offline --console=plain *> work/ftb-real-loading.log
python tools/install_life_routes.py --live "你的整合包版本目录" --apply
```

安装器先检查测试和游戏进程，备份运行 JAR、这四章、章节分组和本轮合伙人的法术覆盖文件。只更换本轮自己的四章，校验其他章节内容不变；不触碰存档、天空岛或酒馆模板。

`integrate_life_routes.py`、`finish_route_runtime.py`、`complete_route_details.py`、`finalize_route_details.py` 是开发过程的一次性迁移辅助，不要当作安装器重复执行。

## 与原提案的具体差异

- 影漏兰用真实运行日的日影时段结算，尚未模拟客户端的动态阴影几何。旋页蕨读真实讲台页并耗纸，矿眠苔按天然矿点区块共享额度。
- 晨晖盘葵白天蓄光，已有缓冲也可在白天供出，未强制限制成只在夜间释放。
- 雷纹冠仅接受自然雷，人工雷暂不实现付费八成转存。
- 定量投料盘当前为真实饲料分盘；营造尺实现直线/框；聚能弩座当前采用手持符文弩。机枪当前采用真实箭弹，还没有独立符片弹匣与高阶法术弹。
- 高阶机甲已有充能、穿戴、冲刺和机枪联动，飞跃/飞行尚未加入。上述条目在后续细调时可继续完善，不能据此宣称所有提案表现均已原样落地。

## 验证范围

数据检查覆盖四章、唯一 ID、依赖、行为进度引用、图标和资源镜像。服务端集成检查真实合成、捕获防复制、余额守恒、网络限流、充能、流体保护、孵育及真实营造耗材。客户端使用独立开发世界检查模型、植物四阶段、土壤、两只新异兽和工作 GUI，并生成八张实际渲染截图。

完整 PCL 中的 FTB 排版、全部野外发现节奏和经济平衡仍需要玩家游玩测试，不能将上述开发环境验收当成完整整合包通关测试。具体计数与安装结果另见同目录验证记录。
