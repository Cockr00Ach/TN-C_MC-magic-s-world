# 地下城第一版：进入、游玩与继续制作

四主题各30层：黄沙遗庭（desert）、锁钟地牢（crypt）、沉潮回廊（tide）、星眠幻庭（astral）。独角兽门对应星眠幻庭。独立维度为 `tnc:rift_dungeons`，与城堡维度和土系首领场景分别独立。

## 怎么进去

正常流程：在酒馆委托栏**潜行右键**，领取手册和寻找野外大门的指引；进入对应大门的门幕，到入口大厅选择五层段。新世界与新探索区块可自然生成入口，原有世界建筑不会被自动替换。

测试不用跑图，打开作弊后：

```text
/dungeon enter desert
/dungeon enter crypt
/dungeon enter tide
/dungeon enter astral
```

这是直接进入大厅的测试命令。若要看完整的大门建筑，在主世界空旷位置使用 `/dungeon buildgate desert`（或其他主题）。该命令会在面前建造大型建筑，须预留约100×100空间。寻找自然入口用 `/dungeon locate desert` 等命令。

## 一次挑战怎么玩

每层八间房，沿真实走廊连接，每间总共1～3个门。清场后开门，可以回头；找到下层界碑即可前进，不强迫清完所有岔路。宝匣、行商、许愿灯、测绘员、补给挑战、旧门环和归途石碑会改变探索收益。

每五层为一段。第5／10／15／20／25／30层有基础守关试炼，完成后保存进度与遗币，解锁下一段。入口可选择已解锁的1／6／11／16／21／26层。正常撤离保留原挑战；主动放弃后重新随机开段。

**当前守关者是明确标注的基础版，专属Boss模型与机制按用户要求后续制作。** 不把放大的杂兵称作已经完成的独立Boss。四种主题材料目前用于收集和行商交易，后续再接具体工坊配方。

### 倒地规则

- 单人：每个五层段有一次倒地自救机会，按住原有救援键自救。普通下层、重登和正常撤离均不会补次数；进入下一个五层段才补充。
- 多人：每人可以反复倒地，不能自救，只能让未倒地的队友靠近并按住救援键。全员同时倒地才失败。
- 失败保留装备、背包和经验，仅扣**本段尚未结算遗币的20%，向下取整**；例如30扣6，银行铜币与存款不受影响。
- 战斗中不能撤离。安全时用 `/dungeon leave` 暂停原挑战；确认放弃使用 `/dungeon abandon confirm`，采用同样的遗币损失规则。
- 断线重连不会刷新宝箱和自救次数。未倒地玩家进入确认保护状态，点击聊天提示或输入 `/dungeon resume` 才继续战斗；倒地玩家重连仍须等待救援。
- 如果队友在你掉线期间已经前进，会恢复到队伍当前楼层；已倒地者只移动位置，不自动复活。退出会取消尚未完成的恢复传送。

### 联机

最多4人。队员先来到同一个野外大门，或分别进入该主题大厅。队长输入 `/dungeon invite 玩家名`，对方输入 `/dungeon accept`。全员到大厅，由队长选择所有队员均已解锁的段首。不同队伍有独立实例和救援分组。

怪物强度按房间开战时登记的人数固定，途中掉线不降低后续波次难度。守关参与者即使掉线，解锁、遗币和酒馆报告奖励仍会记账；满包纪念物保留待领取。回酒馆委托栏潜行右键交付报告获得铜币。

## 怪物与模型源文件

共10类、28变种：哥布林4、骷髅3、史莱姆4、触手2、兽人3、蛤蟆2、蜥蜴2、蜥蜴人3、恶魔3、宝箱怪2。可在TN-C创造页找中文刷怪蛋，或 `/summon tnc:goblin_mage` 等。

可编辑的Blockbench工程位于 `model-source/dungeon/*.bbmodel`，包含对应贴图与骨骼。游戏几何位于 `src/main/resources/assets/tnc/dungeon_models/`；材质在 `textures/entity/dungeon/`。素材生成源为 `tools/build_dungeon_assets.py`，手工改完bbmodel后不要直接重跑生成器覆盖修改。

## 队友怎样拿到一致的版本

仓库包含代码、原创模型、任务章节与导入工具。**只pull代码不会替换PCL里的JAR。** 本机另备有 `work/dungeons-collaborator-update-20261019.zip`，解压后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\apply_dungeon_update.ps1 -Pack '你的PCL版本目录'
```

先完全关闭游戏。补丁只替换TN-C JAR和新增地下城章节，带哈希核对与旧文件备份，不覆盖存档及其他任务章节。也可以直接发更新后的整个PCL版本压缩包。

四座入口建筑来自用户提供的MazaVili蓝图。第三方建筑原件及转换后的NBT不上传公开Git，随本地测试运行包使用；公开发布前按原作者许可处理。开发者有源ZIP时运行 `tools/import_dungeon_gates.py`；已有更新后的TN-C JAR时可用 `--from-jar 路径` 恢复本地构建缓存。没有入口素材的开发构建仅提供小型测试门，正式安装检查会拒绝缺少完整素材的JAR。

## 本轮保护范围

不改天空岛模板、家庭系统、用户世界建筑或原有FTB章节。独立新增 `tnc_dungeons.snbt` 一章。队友的48种符文建筑方块、土系首领维度与此前火法等成果均合并保留。

## 验证范围与限制

本轮277项单元测试、16项地下城及原有救援兼容服务端测试通过；完整PCL副本实际完成连续五层，清理29只登记怪物、解锁第6层，并核对失败扣币与背包保留。客户端界面、模型、四主题房间和完整入口使用原生截图检查。

另尝试了原有 `tnc` 全命名空间混跑，有36项失败，**没有计作通过**：其中包括仍要求普通泥土种魔植的旧测试、缺少专用世界生成环境的地标测试，以及部分既有法术测试。本轮没有通过改旧测试断言来隐藏这些结果；具体失败名单保存在 `release/dungeons-validation-20261019.json`。因此本次通过结论限于上面列出的单元、地下城、救援兼容及实际客户端范围。

当前尚未做真人四人长时间联机压测；专属Boss、进阶词缀、主题工坊配方、收藏的独立摆件模型及种养奖励扩展都不列为本轮已完成内容。
