# 陆地坐骑体验版

在创造模式“刷怪蛋”中搜索彩虹独角兽、高山山羊、雪狼；也可用 /summon tnc:rainbow_unicorn、tnc:mountain_goat、tnc:snow_wolf。
成年坐骑空手右键即可驯服并骑乘，直接免鞍骑乘，不生成鞍物品，不提供马匹装备界面。WASD 移动，空格蓄力跳跃，Shift 下马。暂不设置自然生成、合成和繁殖，避免把体验入口当成最终获取方案。
独角兽移动属性0.34、山羊0.27、雪狼0.30；跳跃强度依次0.65、1.0、0.55。山羊额外容忍5格落差；雪狼可走细雪、免冻结，补偿冰面惯性并允许水中骑乘。数值为体验初值。
资源使用v17腿型与无鞍版本，保留黑棕角、加快后的步频和尾巴动作，并重新适配四种步态。GeckoLib 4.8.4，原版马承担移动输入和跳跃同步。步态按实际位移速度切换并适配播放速度。
尚待用户验收：坐姿贴合、过渡与转弯、上坡/冰面及水中手感、模型接缝与多人同步。没有攻击和状态效果，不影响Boss阶段保护。
