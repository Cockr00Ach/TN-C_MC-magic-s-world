## 一、为什么该换：整合包里那份不是官方构建

| | 整合包原文件 | 官方 1.6.0（Modrinth） |
|---|---|---|
| 文件名 | `ConquestReforged-forge-1.20.1-1.6.0.jar` | 同名 |
| 大小 | **107,870,881（102.9 MB）** | **230,528,362（219.8 MB）** |
| SHA1 | `5cbb2b81057e00f3773f26760cbaf865e7d6e8c3` | `b46ea18d34626910b5c47b850a39bf578328dd82` |

**文件名一样、版本号一样，但内容只有官方的 46.8%、哈希完全不同** ✗ ⇒ 那份是**被删过的重打包版**
（不是压缩率问题：Conquest 的内容绝大部分是已压缩的 PNG）。
这就解释了日志里那些 `FileNotFoundException` ✓。
