# RouchNao 小镇内饰交接

给内饰制作者的实际工作单。优先把一座可以生活的小镇做完整，先不用给全部41栋塞满家具。

## 交付方式

1. 用本整合包开一个专用的新测试世界。进入天空岛后等待地形与建筑都完成，备份存档，再开创造模式。
2. 修改这座岛的内饰即可。保持房号、外墙、屋顶、楼梯、道路及岛的整体地形。新增家具用创造模式，生存制作家具已禁用。
3. 完成后退出游戏，压缩**完整存档文件夹**，附上修改过的房号、使用的模组和几张室内截图。只发截图或某个region文件无法完整交付方块实体与家具数据。
4. 将压缩包交给作者。随后由程序侧从副本提取已改房屋的分块结构和方块实体，形成新的版本化岛模板；新世界使用新版本。已经卖给玩家的房屋、土地和后续装修要保留，不能拿成品岛整片覆盖旧世界。

当前「新的世界」记录的岛原点为 **X=-36、Y=90、Z=524**。这只用于当前世界；下表全部给**岛内偏移**，实际位置=原点+偏移。新的测试世界以游戏银行的看房指引和门牌为准。

## 装饰方向

小镇以木材、石材、铜件和暖灯为主，魔法器具作为生活的一部分。酒馆有杯碗、商行有收货篮、银行有房源告示、居民家有各自的习惯；这些差别比所有房间摆同一套豪华家具更有用。
