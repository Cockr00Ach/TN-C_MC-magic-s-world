## 实施注意（血的教训）

1. **顺序必须是"先引擎 JSON、后目录"** —— 目录里加了、引擎里没有的法术会**学得到但放不出**，
   而且法杖槽位会**空一格** ✗（风系当时就是这样：目录 15 条、JSON 只有 5 个）。
   → 计划中的修法：学法术之前先问引擎 `SpellRegistry.getSpell(id) != null`，
   不存在就不给学（防呆闸门，待实现）。
2. **学派名要对**：火=`FIRE`、雷=`LIGHTNING`、风=**`AIR`**（不是 WIND）、水=`WATER`、
   土=`EARTH`、光=`HEALING`、暗=`SOUL`（对应 `spell_power` 属性 `water/fire/lightning/air/earth/healing/soul`）。
3. **音效 id 要查**：引擎自带的只有 `spell_engine:generic_<school>_casting/release` 那一套，
   而且**风系只有 `generic_wind_charging`**（没有 casting/release）—— 写错就是静音 ✗。
4. 文档里还有 **特殊魔法（§12.F）**：规则魔法、无法升级、只与亲和力有关 —— 独立机制，待做。
