# 自己编辑任务书：直接在游戏里做

你现在这版使用 FTB Quests Forge 2001.4.22。下面的编辑命令、右键菜单、中键移动、图片字段和保存目录已按本机安装的模组核对。

## 先准备

先退出游戏，备份下面这个完整文件夹。这里保存的是任务书的章节和内容，会影响使用这份整合包的所有世界；不是某个玩家的完成进度。

```text
D:\垃圾桶\PCL 正式版 2.9.3\.minecraft\versions\元素觉醒1.4.3-魔改版-20260915\config\ftbquests\quests
```

然后进入一个专门编辑用的测试存档。单人游戏可使用编辑命令；服务器需要管理员或任务编辑权限。如果命令被权限拒绝，单人可在“对局域网开放”里临时允许作弊，服务器则让管理员给权限。

输入：

```mcfunction
/ftbquests editing_mode true
```

按 E，点背包左上角任务书按钮。现在右键章节、任务或空白处就可以编辑了。

## 修改已有页面

- **修改章节名称、图标和章节属性**：右键左侧对应章节，选择编辑。章节就是你所说的“第一页、主线页、地图页”。
- **修改一个人物的介绍**：右键这个人物的任务节点，打开“编辑”或任务属性，改标题、图标和任务描述。描述编辑器支持多行，Shift+Enter 保存并退出该描述编辑器。
- **移动位置**：右键任务选择移动，或中键点击任务进入移动状态，再在目标位置点击落下。不要按删除后重建来代替移动。
- **大小与形状**：在任务属性中改大小、形状；位置也可以在属性中改 X/Y。图标填实际物品，例如 `minecraft:book`、`tnc:water_wand_1`、`tnc:self_spawn_egg`。
- **新建说明节点**：在章节空白处右键，选择勾选类任务。它适合人物介绍、世界观与说明；你可以自己写标题和描述，不需要我给每一段文字写代码。
- **新建玩法目标**：空白处右键选物品任务或进度任务。物品任务检测携带材料；进度任务可检测我已经接入的上岛、登记、制杖等实际行为。想新增代码中没有的行为时，再告诉我，我来接触发逻辑。

已有的章节、任务和任务项 ID 保留。可以自由改文字、图标、位置、大小与外观；保留 ID 能让旧存档继续认出同一个任务。正式玩法节点如果删掉重建，会变成新任务。

## 你的“歸”页可以这样编

先移动中央主角节点，改成你想写的吴归衡介绍。下面的人物介绍可以逐个右键编辑，再用中键移动摆成三列。上方“歸”是章节图片，右键图片可以修改它的位置和尺寸。

你不必遵循我排的顺序，也不必保留我写的介绍文字。后面任务书的文案与布局由你决定。

## 增加图片和地图

目前已经能直接使用的图片资源：

```text
tnc:textures/guide/gui_world_title.png    上方的繁体“歸”
tnc:textures/guide/town_atlas.png         你发的天空岛地图
tnc:textures/guide/water_focus_1.png      水系冒险者法杖
tnc:textures/guide/water_staff_2.png      水系二阶
tnc:textures/guide/water_staff_3.png      水系三阶
tnc:textures/guide/water_staff_4.png      水系四阶
tnc:textures/guide/water_staff_5.png      水系神杖
```

在章节空白处右键，选“图片”，图片资源填写上面的资源名，再改 X、Y、宽度、高度、层级。地图图片层级放在节点下方，节点才能显示在地图上。别把 Windows 文件路径填进图片资源栏。

你自己新增的 PNG 放在这里，文件名使用小写英文字母、数字和下划线：

```text
D:\垃圾桶\PCL 正式版 2.9.3\.minecraft\versions\元素觉醒1.4.3-魔改版-20260915\kubejs\assets\tnc\textures\guide
```

例如保存为 `my_world.png`，任务书里填写 `tnc:textures/guide/my_world.png`。添加文件后重启游戏再选图片最稳妥；已加载的图片资源也可用 F3+T 重新加载。

当前地图章节宽29.325、高25.55，对应你提供的1173×1022底图。只改图标大小和介绍文字，不需要改宽高。换底图或裁切范围时，建筑标记位置也需要重新对齐。

## 主线任务怎么接起来

右键目标任务，在依赖/前置任务菜单里连接已有节点；箭头表示先完成前一个，再做后一个。你先定好“上岛→酒馆→四个去处”等内容和排版，我保留下面的实际行为触发供你使用。

| 实际行为 | 进度资源名 |
| --- | --- |
| 找到天空岛 | `tnc:onboarding/arrived` |
| 与Self交谈 | `tnc:onboarding/met_self` |
| 领取Self给的材料 | `tnc:onboarding/self_materials` |
| 协会登记 | `tnc:onboarding/registered` |
| 领取第一根法杖 | `tnc:onboarding/forged` |
| 领取第一件铁装备 | `tnc:onboarding/armored` |
| 全款买下开放房源 | `tnc:onboarding/home_bought` |
| 到访茶灯会馆 | `tnc:onboarding/visited_entertainment` |

进度任务选择对应资源名即可。已有同目标节点可以直接改文字和摆放，不需要再新建一份。城镇委托和商家已经结算金币/物品；给同一个目标另加金钱或装备奖励时会再发一次，设计时记住这个区别。

## 保存、交给我和以后更新

编辑完成后关闭编辑窗口，退出任务书，输入：

```mcfunction
/ftbquests editing_mode false
```

最后“保存并退出”世界。FTB 在世界关闭时保存任务定义。重新进入查看一次，再退出，把前面 `config/ftbquests/quests` **整个文件夹**压缩留存，或把其路径告诉我。

任务完成进度则保存在 `saves/<存档名>/ftbquests` 下；一般编辑内容时不需要交这部分，也不需要删除它。新增图片另外把 `kubejs/assets/tnc/textures/guide` 一起交回。

我会把你编辑的任务书作为新的内容母版，检查编号和行为连接，并接回开发仓库。直接编辑后的章节可能是原生 SNBT 格式，转换和工程验证由我处理，你不用手动改回 JSON。

本次更新不会重排、重写你的任务书。安装脚本以后默认保留任务书、章节组和 KubeJS 指南图片；只有明确要发布新的任务书内容时才使用 `-UpdateQuestbook`。不要运行旧的 `gen-ftb-guide`、`gen-town-progression`、`gen-main-atlas` 等生成脚本，它们会重新生成自己的章节。

仓库现有参考源位于 `questbook/ftbquests/chapters`，你实际在游戏里编辑的是 D 盘版本目录里的任务书。以你编辑并交回的版本为准。
