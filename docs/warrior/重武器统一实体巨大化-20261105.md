# 重武器统一实体巨大化

## 范围和行为

`GREATSWORD` 与 `HAMMER` 家族彻底停止提交武器虚影，覆盖重剑、赤霄斩马刀、收割巨镰、战锤和裂地战锤，以及同标签的其他物品。虚影禁用是按武器家族决定，站立、切招、架势或收招时也不会回退到旧虚影。

普通左/右/横斩、重劈、横扫、抡击、短促前顶和巨镰攻击，统一使用真实持物模型从 1 倍逐渐长到 3 倍，攻击过程中维持，收招平滑回到原大小。不同招式有各自的起手截止时刻；连续旋转类攻击较晚进入缩小阶段。原有战锤下砸的上举巨大化继续保留。

原版挥手作为尚未收到动作包时的视觉补充，同样驱动实体放大。防御架势、闪避与保持蓄力不放大。第一、第三人称与左右手共享放大规则和握柄补偿；装饰和刀光沿实际放大后的武器采样，不再额外叠加磨砺虚影尺寸。

长剑、长枪、弓的现有表现不变。服务端伤害、命中范围和连招判定不变。
