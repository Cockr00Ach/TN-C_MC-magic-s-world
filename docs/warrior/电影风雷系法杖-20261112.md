# 电影风雷系法杖

重制现有 lightning_wand_1～5 的手持立体模型，不增加物品ID、不改法术和数值、保留背包原图。五款依次为雷击古木、白银枝冠、黑曜雷笼、风暴星环、雷王冠冕。

参考：[Weta 灰袍甘道夫木杖](https://www.wetanz.com/us/pipe-staff-of-gandalf-the-grey)、[白袍甘道夫法杖](https://www.wetanz.com/us/shop/staff-of-gandalf-the-white)、[哈利波特电影魔杖设计](https://www.harrypotter.com/features/designing-harry-potter-wands)。采用自然木质、纤细镂空结构和雕刻金属的设计思路，雷晶与星环为原创组合。

沿用 botanical_mesh、握点、材质分区和发光贴图，每款1522～2254面；导出可编辑Blockbench文件。生成工具 tools/cinematic_lightning_staves.py；几何预览 docs/previews/cinematic_lightning_staves.png。已检查有限坐标、握点、面数，并查看离线预览；未做游戏内验收。

## 方块雕刻版修订

依照反馈重新制作五款：阶梯杖冠、方柱镂空、分层晶簇、方形包角、嵌入雷纹、凹槽与铆钉。保留握点与物品接口。预览：docs/previews/block_lightning_staves.png；复现工具 tools/preview_block_lightning_staves.py。新版模型低于1000面/款，几何验证通过；实际实例已备份并安装，哈希一致。未实机验收。

## 贴图面细化

材质图集提升至512×512，每种材质两套128像素面板，UV按零件分配。增加分区明暗、倒角亮边、凹刻雷纹、拉丝、木纹和细小磨损；雷晶采用深蓝分面与窄发光裂隙。移除整面glow标记，保留发光贴图。模型几何不变。新增真实UV三角光栅预览，纠正旧预览每面只取一个颜色的问题。预览 docs/previews/textured_lightning_staves.png，生成工具 tools/lightning_staff_materials.py。
