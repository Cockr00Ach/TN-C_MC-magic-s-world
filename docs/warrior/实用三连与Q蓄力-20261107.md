# 实用三连与 Q 蓄力（2026-11-07）

## 操作

磨砺已加入、手持战士武器时，连续短按三次 Z 或连续点击三次左键触发该武器第一槽主攻。主攻沿用原解锁要求与同族技能冷却，冷却最多三秒，减少击退，不强制冲进 Boss 身体。原 QZE 主攻仍可作为备用输入；EQE（末 E 长按）振刀、EQZ 破振刀和特色招式保留。

Q 短按松手仍出左斩；长按半秒进入蓄力，继续按住蓄势，松手出招。按下时不先造成一次伤害。受击、换武器、步法中断、打开界面或失焦会取消蓄力。旧 Z 蓄力入口保留。

## 武器表现

- 剑、重剑：逐渐放大并直立提起，松手过顶重劈。
- 柳叶刀、环首刀、太刀、青铜刀：侧身收刃，松手横向拔斩。
- 长枪：压枪蓄势，松手向前破军直刺。
- 方天戟、齐眉棍：蓄势后大幅横扫／抡棍压顶。
- 月牙铲：沉身蓄势，松手推铲压进。
- 偃月刀：拖刀提刃，松手断岳重劈。
- 铁锏、锤：沉腰举起，松手破甲砸击／震地。
- 镰刀：蓄势回镰，松手环身收割。
- 青铜双刃：成套蓄势合斩，仍只有一份伤害与耐久。
- 弓：拉弦蓄力，松手发射，沿用箭矢与弹药规则。

近战实体模型按蓄力时间逐渐放大，三秒达到八倍上限，释放后随收势缩回。第一人称和第三人称共用服务端广播的蓄势起点，保留握持锚点。伤害沿用现有蓄力规则；视觉八倍上限独立于伤害增长。
