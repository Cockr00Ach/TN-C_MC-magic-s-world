# 重武器磨砺成长，十倍上限

攻击时实体武器的峰值倍率改为：`3 + 7 × clamp(磨砺值, 0, 10000) / 10000`。

| 实际磨砺值 | 攻击峰值倍率 |
| --- | --- |
| 0 | 3 |
| 1000 | 3.7 |
| 3000 | 5.1 |
| 5000 | 6.5 |
| 8000 | 8.6 |
| 10000 | 10 |

使用绝对磨砺值，而不是当前天赋上限的完成比例。成长上限按全局 10000 点计算，提升天赋上限不会导致同样磨砺值的武器变小。站立和收招结束仍为 1 倍；上举/起手逐渐变大、攻击时保持峰值、收招缩回。重剑和战锤家族继续禁用武器虚影，刀光跟随实际模型。第一、第三人称使用相同倍率，握柄固定规则覆盖 10 倍。

## 同步

原跟踪玩家数据只有按天赋上限归一化的旧虚影倍率，无法据此还原实际磨砺值。因此 `WarriorPhantomPacket` 增加实际磨砺点数，登录、开始跟踪、重生、换维度及磨砺变化均沿既有同步入口下发。客户端为每个 UUID 缓存自身点数，退出时清空。原有轻武器虚影与伤害范围成长逻辑保持不变。

同步格式已变化，网络协议从 28 提升到 29；联机双方必须更新到同版 JAR。新解码器拒绝越界点数，旧虚影倍率仍维持原来的 1～1.9 校验范围。
