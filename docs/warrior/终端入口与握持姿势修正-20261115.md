# 演武场迁移与握持姿势修正

## 演武场迁移

当前「新的世界 (3)」的天空岛原点为 `(-260,90,-260)`。整座 61×61 演武场使用岛内偏移 `(466,86,236)`，中央终端落在 **`(206,177,-24)`**，维度为 `tnc:skyhaven`。四个训练位、教官、J 任务指引和 `/tempering ground` 随场地迁移。南侧入口的台阶按地表高度接到林地。

加载存档后先建设新场，再退役有备案的旧终端和训练位。旧石台作为遗址保留。迁移沿用玩家的修习记录与教程进度。新址施工范围内如有箱子等方块实体，会等待方块移除后继续。

## 教官握剑

GeckoLib 的骨骼回调已经包含动画变换，旧手持层重复添加枢轴和旋转，导致装备随动画偏到身后。现在在现有动画矩阵中只回到一次手部枢轴，并读取武器 `tnc_grip` 握点。

原版二维剑的斜轴与新三维剑的纵轴分别归一化，随后补偿 ItemRenderer 的模型中心偏移。普通教官和教学教官共用修正后的手持层，两套动画均适用。

握腕角随实际抬臂幅度平滑调整。手臂伸出时剑尖沿前臂延伸，待机时保持自然斜握，整个动作的剑柄始终跟着拳心。

## 玩家持杖

36 款法杖仅调整 `display` 变换，保留几何、贴图、UV、材料、发光和装饰动画。第三人称按原版完整持物挂载链校正至掌心，配合单手持杖姿势抵消手臂前举造成的向后倾斜；第一人称移除旧平面图的脱手偏移。

左右手均已校正。施法、使用物品、潜行、游泳、飞行和睡眠继续使用各自动作。生成工具复用 `tools/staff_hold_pose.py`，后续重新生成法杖也会保留新握点。
