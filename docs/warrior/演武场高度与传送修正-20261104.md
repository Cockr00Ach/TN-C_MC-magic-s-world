# 演武场高度与传送修正

> 后续修正：天空岛现已使用独立维度。本记录中“主世界正式场地”的实现已被 `SkyIslandWorlds.island(server)` 路由取代，见「命中斩光与怪物振刀-20261104.md」。不能再把建场／传送维度写死为主世界；新维度存档必须在新维度建场。

用户反馈 `/tempering ground` 到达的地点不在天空岛，也没有教官。读取正式实例当前「新的世界 (1)」存档得到：

- 天空岛 `ORIGIN=(-260,90,-260)`，`ARRIVAL=(-51,180,164)`，生成状态 COMPLETE。
- 演武场旧记录 `minecraft:overworld (-176,105,-4)`，确实在岛下地面高度。

原因是 `PracticeArena.site` 只用于取得 X/Z，`build` 用自然地表 heightmap 定台面，岛西空白区域落到地面；`ensure` 见到任意旧记录即返回，后续不会纠正。另外传送使用玩家当前维度，可能在其他维度套用同一坐标。

修复：正式演武场台面由岛抵达点高度减一确定；ensure 核对主世界正式 X/Y/Z，旧地面记录不再阻止正确建场；旧台与玩家记录保留。传送明确到主世界正确台面，不采用最后登记的其他场地。到场自动打开教官选择面板并提示选择教官、点击开始练习。

当前存档修复后目标台心 `(-176,179,-4)`，传送落脚 `(-175.5,180,23.5)`。不直接修改运行中存档；新包下次启动后自动补建天空岛台面。
