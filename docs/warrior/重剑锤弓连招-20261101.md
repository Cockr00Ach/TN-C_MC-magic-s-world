# 战士 · 重剑 / 战锤 / 长弓连招（2026-11-01）

> 2026-11-04：槽位及按键已统一，前三槽固定为攻击／振刀／破振刀。旧操作示例由 [统一前三槽与招式辨识](统一前三槽与招式辨识-20261104.md) 取代；历史制作说明保留。

长剑之后的三把正式武器。每把三条链，按武器特性改写"突击"的表现：
**重剑与战锤的突击链不位移**（用范围压制代替突进），**长弓三条链都是射击**，
其中突击链是突进射、闪避链是无敌后跃射。

2026-11-01 下午补的第二次改动：重剑和战锤各加了第四招**架势**（壁立 / 沉渊），
于是三把近战武器都齐了 `进攻 / 架势 / 破架` 三种对拼定位；同时四把武器的四招都有
Blockbench 关键帧（见本文§五），不再吃长剑那套程序化动作。

判定层与长剑完全共用：`WarriorSkill` 上的 `dash / backstep / evadeTicks / ranged /
interrupt / staggerTicks / animation` 决定表现，`WarriorComboService` 没有为哪把武器
写分支。新武器只要填目录、图鉴和标签。

## 三 表现与判定

- **重剑/战锤不位移**：突击链 `dash=0`，靠更大半径/扇形压制；位移只出现在长剑突击链
  （1.35 格）和长弓突击链（1 格）。
- **弓的射击**：`ranged=true` 的终结技走 `shoot()`，以玩家攻击力 × 倍率生成箭。
  **每条弓连招都消耗一支箭**（背包或副手里任意 `ArrowItem`，优先取第一摞）；
  没有箭时整段不发动，提示"弓弦空了"，不扣耐久、不进冷却、不做位移，
  所以不会出现"人已经后跃出去、箭却没射出来"。
  创造模式或弓带无限附魔时不消耗，此时射出的箭拾取为 `CREATIVE_ONLY`（不刷背包）；
  正常消耗的那一箭拾取为 `ALLOWED`，和原版一样可以捡回来。
- **闪避链**：`evadeTicks=10` 给玩家 0.5 秒无敌帧，`backstep=2.5` 沿视线反方向弹开；
  动作 `弓ZE`（后仰收腿 + 空中放箭）。
- **破架（铁壁 / 断招）**：命中打断目标的施法/使用、清空对方连招缓冲、压出僵直；
  打到正在摆架势的人（振刀 / 壁立 / 沉渊）会**打散架势并压 2 秒僵直**。
- **架势（壁立 / 沉渊）**：放出后 `guardTicks` 内（1.8 s / 2 s）把自己标成"正在架势"，
  同时拿到抗性。这段时间里被对方的攻击链/突击链打到，会把对方**架住**：
  这一下不掉血，对方连招作废并僵直 1 秒。
- **动作**：三把武器十招各有一条 Blockbench 关键帧（见§五），起手是静止姿势、
  结束回到 0，文件和服务器广播时长必须一致（`clipLengthMatchesTheBroadcastDuration`）。

## 四 测试

- 单元测试：`weaponTraitsAreExpressedByTheChains`（重剑/锤各四条、弓三条、重剑/锤不位移、
  弓全远程且闪避带无敌+后撤）、`everyMeleeWeaponHasAStanceOfItsOwn`（壁立/沉渊是架势、
  另外四招是进攻、两招架势都有窗口）、`everyComboHasAnImplementedCodexEntry`（家族→页签映射）、
  以及原有的前缀/槽位/解锁约束。
- GameTest：
  - `eachWeaponFamilyAcceptsItsOwnItems`：四种武器各拿各的首段输入，都能进缓冲。
  - `greatswordAssaultHitsWideWithoutDisplacement`：破阵斩命中且玩家不被向前推。
  - `bowAttackFiresAnArrowAndEvadeBacksteps`：穿云箭真的生成箭并扣掉 1 支箭（5→4）；
    后跃射把玩家向后推、给无敌，再扣 1 支（4→3）。
  - `bowWithoutArrowsFiresNothingAndStaysOffCooldown`：背包没有箭时不生成箭、
    不占冷却（补完箭立刻能放）。
  - `stanceWindowOpensWhenTheParryFires`：重剑 Q E E 放出壁立后，架势窗口 ≥1.5 秒、
    同时拿到抗性——窗口和抗性少一样，"架住"就永远触发不了。
- 图鉴：重武器页签新增"重剑连招/锤连招"两列，弓页签新增"弓连招"列；页签总数仍是 6，
  UI 审计的 9 个界面/6 页签检查继续通过。重剑/锤各 4 条，弓 3 条。

## 五 四把武器的关键帧

四份文件都放在 `assets/tnc/animations/entity/战士连招/`，Blockbench 1.8.0 直接导出，
骨骼名和 `self.geo.json` 一致（`bone / head / armLeft / armRight / legLeft / legRight`）。
自己动手做下一把武器的动作时按 [连招动画制作说明-20261101.md](连招动画制作说明-20261101.md) 走。
现已接入 15 条：

| 文件 | 动画名 | 时长 | 用在 |
|---|---|---|---|
| `长剑连招.json` | `长剑QZE` / `长剑QEQZZZ` / `长剑QE长Z` / `长剑ZZQQEE` | 0.875 / 0.75 / 1.0 / 1.25 s | 长剑四招 |
| `重剑连招.json` | `重剑ZQE` / `重剑QQZ` / `重剑EQZ` / `重剑QEE` | 0.90 / 1.10 / 0.85 / 1.00 s | 重剑四招 |
| `战锤连招.json` | `锤QZZ` / `锤EEZ` / `锤ZQQ` / `锤QEQ` | 0.95 / 1.15 / 0.80 / 1.00 s | 战锤四招 |
| `长弓连招.json` | `弓QZ` / `弓EQ` / `弓ZE` | 0.90 / 0.70 / 0.85 s | 长弓三招 |

- 剑/锤的动作是"双手握持"的写法：两条手臂都动；锤的砸地是蹲身 + 双臂过顶。
- 弓的动作不转身体，只动两条手臂（左手推弓、右手拉弦 + 松弦回弹），
  所以第三人称能看清"拉—放"两拍。
- 加载：`WarriorComboAnimations` 按 classpath 读四份文件后合并（中文路径不能用
  `ResourceLocation`），读不到时再走 Forge 的 `ModFile#findResource` 兜底；少一份只影响
  那一把武器，其余照常。进游戏后 `logs/latest.log` 会有一行 `TN-C: 连招关键帧 15 条`。
- 采样：线性插值，超出首尾取端值；`position` 关键帧故意忽略（服务端已经真的推过人了）。
- 缺文件 / 解析失败时，`WarriorPoseMath` 会退回最接近的程序化动作，不会 T 字。
