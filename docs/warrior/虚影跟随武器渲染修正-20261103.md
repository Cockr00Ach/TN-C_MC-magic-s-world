# 虚影跟随武器渲染修正

针对双手握持时虚影错位的反馈，虚影从独立的玩家刀光层移到 `ItemInHandRenderer.renderItem` 的实际武器绘制调用。接收本次绘制的物品、左右手标记、显示上下文与姿态矩阵，不再重建主手手臂变换。

虚影采用与原物品相同的模型种子（实体 ID 加显示上下文），围绕模型的真实握柄进行放大。旧的 `WarriorTrailLayer` 虚影入口已移除，避免重复绘制。第一人称和非武器物品不会新增虚影。

新增 `WarriorHeldWeaponMixin`，并同步注册配置、生产环境 refmap 和发布包类检查。武器外观仍为用户指定的 1:32 版本。

验证包括模型握柄、数据包回归、实际 Minecraft 目标方法字节码签名，以及不同武器挂载变换下的握柄重合检查。构建包检查确认新 Mixin、配置和 refmap 均存在，未包含开发预览的 SpellCloud 临时类。

本次未启动完整整合包做双手握持实机验收，未安装游戏实例。后续重点目测重剑、战锤、长枪的静止、挥击和架势保持，以及左右手切换。
