# 战锤上举巨大化

## 表现

战锤的碎骨、震地、崩山轮砸，以及通用过顶重劈/震地下砸动作，在上举过程中由 1 倍平滑长到 3 倍，保持最大尺寸完成下砸，在收招阶段缩回。普通挥锤、前顶、架势和保持蓄力不套用这条巨大化曲线。

增长按实际姿势时间采样，与上一轮重武器时间曲线保持一致；碎骨和震地分别在各自动画的最高举锤关键帧达到最大。通用下砸原本没有上举阶段，本次补上先抬起再下砸的姿势，避免在下落途中才开始长大。

缩放作用于真实持物模型，围绕经过当前物品显示变换后的握柄补偿；手臂不随物品放大。第一、第三人称及左右手走同一套增长规则。武器装饰、刀光采样继承同一变换。巨大化招式暂时不再叠加磨砺虚影的二次放大，避免多层大锤遮住真实轮廓。

本次属于客户端视觉表现；伤害、命中范围、击退和冷却沿用现有规则。取消动作、切换武器或结束播放后不保留放大状态。
