# 战士系统内容与测试清单

整理日期：2026 年 10 月 29 日。适用于当前工程中的 `com.tnc.tnc.warrior` 系统；整合包里的其他职业书不等于本系统的天赋入口。

> **2026-10-30 变更**：训练场已从自建虚空维度迁到天空岛西侧的**共用演武场**（本地坐标 `(84, 256)`），入口改为场内正中的**演武终端**：右键终端 → 面板选教官（陪练/洛克/莉娅/岚）→「开始练习」，教官当场显形并开课。**冒险者协会与艾琳入口已取消**，`/tempering ground` 现在只是把角色送到演武场。教官从尸壳换成 GeckoLib 独立模型（17 骨骼、四张皮肤、六条动画）。协议升至 14。详见 `天空岛演武场与教官终端-20261030.md`；本文中「个人训练场/进入个人训练场/协会」相关条目按该变更理解。

当前可玩的循环是：管理员配置天赋 → 加入磨砺 → 近战成长、守势反击 → 个人训练场及专项练习 → 炉台风灌注 → 使用风刃。另有九套战技外观。以下复选框均为待实机验收项目，不能视为已经测试通过。

## 一 测试准备与推荐顺序

使用测试存档，准备管理员权限、铁剑或铁斧、副手盾牌、食物；炉台测试另准备完整魔力炉及供能、8 羽毛、4 紫水晶碎片、1 幻翼膜。正式操作训练使用生存模式。

管理员按顺序执行：

```text
/tempering talent set @s 4
/tempering join
/tempering set 200
/tempering talent
```

这会得到天赋 4、磨砺 200 的测试角色；首次训练奖励测试应另用未毕业角色，并留出磨砺空间。直接设置磨砺不会清除首次训练领取记录。

推荐先测 K 面板和训练场，再测三档守势反击、三位教官，最后做灌注、风刃、特效与存档回归。自然成长与首次领奖需在管理员设值测试之外单独验证。

## 三 天赋与磨砺

| 天赋 | 成长倍率 | 有效磨砺上限 |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0.5 倍 | 200 |
| 2 | 1 倍 | 1000 |
| 3 | 1.5 倍 | 3000 |
| 4 | 2 倍 | 6000 |
| 5 | 2.5 倍 | 8000 |
| 6 | 3 倍 | 10000 |

天赋不会被普通练习提高，新角色和旧档缺失天赋字段时默认 0。当前由权限等级 2 的管理员配置，角色创建与剧情自动赋予尚未接入。

| 勾选 | 怎么测 | 应有结果 |
| --- | --- | --- |
| [ ] | 天赋设为 0，尝试 join、训练、进入训练场 | 拒绝修习；无磨砺成长、战士减伤或风刃资格 |
| [ ] | 普通玩家尝试 talent set 和 set | 无权修改天赋或磨砺 |
| [ ] | 有天赋后 join 两次 | 正常启用，第二次不清空数据 |
| [ ] | 生存模式持剑斧直接近战击杀普通敌对怪 | 获得基础 2 至 20 点，再乘天赋倍率；提示与磨砺条更新 |
| [ ] | 分别试空挥、挨打、杀动物、弓箭或法术击杀、创造模式击杀 | 不应获得这项近战磨砺奖励 |
| [ ] | 天赋 1 击杀两只最大生命 30 的有效敌对怪 | 每只基础 3 点，两次合计 3 点；半点余数不被逐笔丢弃 |
| [ ] | 接近个人上限时击杀或领奖 | 只补到上限，提示到顶；管理员不能设置超过个人上限的值 |
| [ ] | 调低天赋后再调高 | 低天赋时有效值受限；原始磨砺记录保留，不因降天赋直接抹掉 |
| [ ] | 重登、死亡复活、换维度 | 磨砺和天赋仍在，HUD 正确同步 |

基础击杀奖励为 `floor(敌人最大生命 / 10)`，限制在 2 至 20；敌人必须实现 `Enemy`，武器必须继承 `SwordItem` 或 `AxeItem`，因此其他模组武器和 Boss 要逐个确认兼容。

额外减伤为 `0.30 × 有效磨砺 / (有效磨砺 + 2000)`，在护甲、抗性、吸收之后结算，不消耗磨砺。

| 阶段 | 磨砺 | 额外减伤 |
| --- | --- | --- |
| 初习 | 0 | 0% |
| 扎根 | 200 | 约 2.73% |
| 坚韧 | 1000 | 10% |
| 百炼 | 3000 | 18% |
| 久战 | 10000 | 25% |

- [ ] 同装备同攻击源，对比 0、1000、10000 磨砺受伤量；需要天赋 6 才能设置满磨砺。护甲等结算后原为 40 点时，后两者应约为 36、30 点。
- [ ] 对比摔落等环境伤害，应无这层减伤；友方、生物来源缺失、绕甲或绕过无敌的伤害也不适用。

| [ ] | 场内挨打、盾挡和持剑攻击 | 保护生命；陪练盾挡不损盾；武器攻击仍正常消耗耐久 |

| [ ] | 场内退出再登录、失去天赋、跨维度离开 | 按恢复或资格规则退出；教官与临时训练被清理，永久成果保留 |

训练场的教官使用原版生物外观、南瓜头和彩色装备区分，当前没有独立定制的战士教官模型。

## 五 守势反击和三档纪录

按 K 开始训练，近身面向主陪练举盾，读粒子和声音前摇。盾挡击退后向前补位；完成三次有效盾挡，再持剑斧命中最后被挡住的敌人。开始训练后面板关闭。

| 难度 | 出招间隔 | 前摇 | 反击窗口 |
| --- | --- | --- | --- |
| 入门 | 2.5 秒 | 0.75 秒 | 4 秒 |
| 进阶 | 2 秒 | 0.6 秒 | 3 秒 |
| 试炼 | 1.5 秒 | 0.5 秒 | 2 秒 |

| 勾选 | 怎么测 | 应有结果 |
| --- | --- | --- |
| [ ] | 每档完成一次三挡一反 | 显示计数、反击窗口和完成反馈，结算该档纪录 |
| [ ] | 反击超时后再盾挡一次 | 提示窗口过期；新有效格挡刷新窗口 |
| [ ] | 攻击别的敌人、用法术反击或无有效伤害的格挡 | 不应误判完成；格挡计数最少间隔 10 tick |
| [ ] | 训练中再次点开始或尝试切难度 | 重复开始不重置进度，难度锁定；取消或完成后才能切换 |
| [ ] | 未毕业且天赋 4、磨砺有空间时首次完成 | 获得基础 120 × 2 = 240 磨砺，受剩余上限限制 |
| [ ] | 换难度再完成、重登或死亡后再完成 | 不重复发首次磨砺；分档完成次数和纪录继续更新 |
| [ ] | 故意漏挡一次后快速有效反击 | 生命受保护，但计漏挡；分数至多 85，随后随反击耗时下降 |
| [ ] | 重新开始、重登、重启后查各档纪录 | 每档分别保存完成次数、最高分和最快反击；两项最佳可来自不同场次 |
| [ ] | 训练中倒地、死亡、转创造/旁观、天赋归零或换维度 | 终止临时训练，不清除永久磨砺和领奖标记 |

评分：`max(0, 100 - 漏挡次数 × 15 - floor(反击耗时tick / 2))`。90 起炉火纯青、75 起稳健、50 起合格，其余仍需磨练。

野外仍可 `/tempering train`，使用入门节奏；野外照常受伤、倒地和死亡，不能套用训练场生命保护。

## 六 三位专项教官

右键对应教官开始，潜行右键取消，每次限时 45 秒；头顶显示进度和剩余秒数。专项训练与原守势反击互相停止。

| 勾选 | 教官和外观 | 怎么测 | 应有结果 |
| --- | --- | --- | --- |
| [ ] | 洛克，蓝色地台、蓝甲、盾 | 副手盾，面向教官完成五次真实盾挡 | 逐次计数至 5，保存盾卫完成次数；没带副手盾拒绝开始 |
| [ ] | 莉娅，金色地台、金色甲、剑 | 剑斧攻击蓄力至少 85%，有效命中五次；插入几次急挥 | 满蓄命中计数；急挥不计并提示；保存剑术完成次数 |
| [ ] | 岚，青色地台、青甲、羽毛 | 风灌注剑斧、有效磨砺至少 200；距其 4 至 6 格，遵守 8 秒冷却命中三次 | 距离至少 3 格的实际风刃命中才计数，保存风刃完成次数 |
| [ ] | 任意教官 | 超时、取消、离场再回来 | 临时进度结束，重新开始；已完成次数保留 |
| [ ] | 任意教官 | 连续完成两次并对照磨砺 | 只更新次数，不额外给磨砺，也不占用或重发守势反击首次奖励 |

风刃练习时对空右键，避免贴着岚操作：潜行右键实体会触发取消交互。陪练不发击杀磨砺、掉落或原版经验。

## 七 风元素灌注和风刃

魔力炉「用品」选择风元素灌注，四格分别放：一把可灌注剑斧、8 羽毛、4 紫水晶碎片、1 幻翼膜，顺序不限。需要 120 炉内魔力，基础 160 tick（20 TPS 时 8 秒），受现有工坊加速影响。

| 勾选 | 怎么测 | 应有结果 |
| --- | --- | --- |
| [ ] | 给有名称、附魔和已损耐久的剑斧灌注 | 取回原武器类型，原名称、附魔、耐久和其他 NBT 保留，新增风元素 |
| [ ] | 材料不足、魔力不足、输出堵塞，分别尝试加工 | 暂停，不吞武器和材料；成功结束才统一扣料扣能量 |
| [ ] | 已有元素武器再次灌注 | 拒绝重复或覆盖 |
| [ ] | 查看灌注武器说明 | 显示潜行对空右键、200 磨砺门槛、4 伤害、6 格射程、8 秒冷却 |
| [ ] | 磨砺 199 与 200 时分别潜行对空右键 | 199 拒绝；200 且已 join 时释放风刃 |
| [ ] | 对准前方敌对怪释放 | 通常射程 6 格，命中轨迹最近的合格敌人；青色双螺旋轨迹可见 |
| [ ] | 目标之间放实心墙；另试玩家、普通动物、同队目标 | 墙体阻挡且不破坏地形；不攻击玩家、动物和队友 |
| [ ] | 在真正的 `tnc:wind_arena` 内重复距离测试 | 射程延伸至 9 格；其他维度不自动获得加成 |
| [ ] | 成功释放后换武器、重登、死亡或换维度再尝试 | 共用玩家冷却，不能重置；冷却按世界 tick 推进 |
| [ ] | 对空、对墙、冷却中分别释放并对照耐久 | 成功释放即耗 1 耐久，挥空和被挡也耗；资格不足、倒地、旁观或冷却中不扣 |
| [ ] | 对照释放前后磨砺、武器攻击力和击杀成长 | 风刃不消耗永久磨砺；基础伤害 4，服从抗性和无敌帧，不叠加普攻攻击力，不作为近战击杀磨砺 |

默认支持原版六档剑斧和 `tnc:sword`；其他武器需要标签支持且仍满足剑斧继承条件。风刃目前是瞬时服务器射线攻击加粒子轨迹。

## 八 九套战技特效

执行 `/tempering effects` 查看，执行 `/tempering effects fire` 等选择。可用 ID：`steel`、`fire`、`water`、`ice`、`lightning`、`wind`、`earth`、`light`、`dark`。

| 配色 | 应看到的主要内容 |
| --- | --- |
| 钢 | 银色挥砍轨迹 |
| 火 | 上扬炽色弧、火星 |
| 水 | 波动水弧、溅水 |
| 冰 | 霜白刀弧、冰晶短线 |
| 雷 | 折线电弧、电火花 |
| 风 | 青色双层刀弧、云絮 |
| 土 | 低平厚弧、砂岩碎屑 |
| 光 | 金色刀光、盾面内层光点 |
| 暗 | 反向紫弧、暗色碎光 |

- [ ] 每种配色都用普通剑空挥、命中、举盾、实际格挡检查一次；有天赋的生存角色应看到对应粒子和声音。
- [ ] 连续挥动有交替斜向弧线；停手超过一秒后，从首段重新开始。
- [ ] 举盾就绪有一次盾面轮廓，实际挡伤有冲击环；举盾生效后至第 10 tick 内的快速格挡追加亮闪和晶体音，亮闪最多每秒一次。
- [ ] 格挡后 2 秒内首次有效近战命中刚才攻击者，追加反击碎光和暴击音；不加伤害，不自动等于训练完成。
- [ ] 选火配色再拿风灌注武器，显示优先采用武器风元素；换回普通剑可验证个人选择。
- [ ] 重登验证配色保留；退出、换维度和重生后无残留临时状态；另一名玩家可看到广播特效，粒子设置低时显示量会变少。
- [ ] 对照生命、磨砺、伤害和耐久：配色选择及特效发送本身不改变这些数值；普通攻击和风刃原有成本照常结算。

冰属于水系视觉变体。除风灌注外，其余配色没有因此获得元素能力，火光不附带点燃、雷光不附带麻痹。

## 九 尚未落地的内容

不要把旧提案里的下列内容列为应有功能：

- 读招闪避、连续实战等独立挑战，以及击败导师化身学习剑招。
- 压服、返锋或通用投射物反弹；精准格挡目前只是表现反馈。
- 火、土等其他实际灌注路线、多元素融合、龙魂附魔、风刃命中后的风旋。
- 刷怪来源识别、挑战收益衰减、多人辅助贡献结算。
- 自动角色天赋发放与完整职业互斥；特殊双修角色目前可由管理员明确配置。

整合包中 `warrior_tutorial.json` 的制作盾牌任务目前为 `enabled: false`，不应当作本系统已经启用的剧情入口。

powershell -File tools/test-warrior.ps1
powershell -File tools/test-warrior-ui.ps1

2026 年 10 月 28 日文档记载：16 项规则测试、18 项服务端 GameTest 通过，专项教官及特效已安装。此次清单整理核对了代码和记录，未重新运行这些测试，也未启动正式整合包；当前安装包是否仍与该批相同需要另行核验。正式客户端重点补测右键冲突、九套特效观感、全模组共存和多人场景。
