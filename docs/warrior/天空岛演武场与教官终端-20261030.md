# 天空岛演武场与教官终端（2026-10-30）

取代旧的「个人训练场」：不再有独立虚空维度 `tnc:training_ground`，也不再需要去冒险者协会找艾琳。
演武场是天空岛上的一块石台，走过去、右键中央的**演武终端**，选一位教官，练习当场开始。

## 一 场地在哪

- 天空岛**西侧**，本地坐标 `(84, 256)`（岛原点 `ORIGIN` + 该偏移），台面 61×61。
- 选址在「风之林」以南、农场以北的岛西空地；建台前用 `landscape.nbt` 的 72 万个作者方块核对过，这块 61×61 没有任何作者地形/建筑，只有自然地表。
- 台子由代码一次性砌出（`PracticeArena.build`）：先按 `MOTION_BLOCKING_NO_LEAVES` 找平地形，台面比最高点高一格，下面用石砖补到地面；四周矮墙（南侧留五格入口）、四角灯柱、南侧五级台阶。
- 台面花纹：外圈抛光黑石、四条石环、四角演武位、中央 3×3 台基。
- 台子建好后写入 `tnc_training_ground_v1` 的 `Arena` 标记；`PracticeArena.ensure` 每 40 tick 检查一次，岛一生成完就补建，不需要存档预置。

## 二 演武终端

- 方块 `tnc:practice_terminal`（金框 + 深板岩底座 + 发光核心，亮度 7，不可破坏）。
- 右键只做一件事：把修习面板推给客户端（`TemperingEvents.sync(p, true)`）。
- 面板下半张是终端界面：四个按钮 `陪练 / 洛克 / 莉娅 / 岚`（选中的带 ▶，在场的带「· 在场」），下面是「陪练难度」「开始练习 / 结束练习 / 返回」。
- 点「开始练习」发 `SUMMON(role)`；服务端复核后：占一个空演武位 → 把玩家传到该位 → 召出教官 → 自动开课。
- 「结束练习」发 `DISMISS`：收教官、停训练、释放演武位。

## 三 四个演武位

- 四角 `(±17, ±17)`，各 13×13，中央 5×5 徽记（陪练=铁、洛克=青金、莉娅=金、岚=海晶灯）。
- 同一座台子供四人同时用：`TrainingGroundData.claim` 按 0..3 顺序发空位，满员返回 -1，提示「四个演武位都有人在用」。
- 走远（离开台面范围）或退出游戏会自动释放，不会一直占位。

## 四 教官

- 实体 `tnc:instructor`，一个实体类型 + 一个变体字段（0 陪练 / 1 洛克 / 2 莉娅 / 3 岚）。
- 只在该玩家名下的演武位显形，`TncPracticeOwner` 记归属，`TncSpecialist` 记角色；不自然消失、不掉落、不给经验、不烧不淹不摔。
- 陪练（counter）走原有「守势反击」节拍：站桩、面向玩家、按难度周期挥击；三次盾挡后的反击窗口不变。
- 洛克/莉娅/岚走原有专项课：五次有效盾挡、五次蓄满剑击、三格外三次风刃命中，限时 45 秒，潜行右键取消。
- 场内保护：玩家不掉血、盾不耗耐久、方块不可破坏/放置、只允许武器/盾/食物；教官只吃所属玩家的正面一击，其他来源一律取消。

## 十 手持剑盾（2026-10-31 02:20）

之前教官是**空手**的：`InstructorEntity` 没配装备，`GeoEntityRenderer` 也不会自动画装备（它只画 geo 里的方块），
所以 `attack` 是空手挥、`block` 是空手架臂。现在改成真手持。

| 角色 | 主手 | 副手 |
| --- | --- | --- |
| 陪练（counter） | 木剑 | — |
| 洛克（guard） | 铁剑 | 盾 |
| 莉娅（blade） | 铁剑 | — |
| 岚（wind） | 风刃（`WindInfusion.infuse` 过的铁剑） | — |

实现分三块：

1. **装备**：`InstructorEntity.equipForRole()` 往 `MAINHAND` / `OFFHAND` 塞真 `ItemStack`，
   `TrainingGround.spawnTutor` 召出时调用。耐久、附魔、风刃的元素标记都跟着物品走，
   所以岚手里那把和学员要拿的是同一种东西。
2. **挂点**：`InstructorHeldItemLayer extends BlockAndItemGeoLayer`，主手挂 `forearm_r`、
   副手挂 `forearm_l`。骨骼原点在**肘**（模型 y=18），握点在 y=12，所以层里沿骨骼局部 -Y
   挪 6 px（`GRIP_DROP`）到拳头；挪的是局部坐标，手臂一抬剑跟着抬。
   不需要额外加 `hand_*` 骨骼。
3. **朝向自己算，不走原版 thirdperson 显示变换**：那套变换是给"原点在肩膀"的人形手臂标定的
   （`ItemInHandLayer` 里那串 0.0625/0.125/0.625 是整条手臂的魔数），套到手腕骨骼上，
   剑会浮在拳头上方约 6 px、后面 3 px —— 肉眼可见的"飘"。所以层里显式给：
   握把挪到原点（精灵图 8,1 px）→ **只绕 X 转 -55°**（刀身从"顺着手臂向上"倒向角色正前方，
   物品 +Y 映射到 `(0, 0.574, -0.819)`）→ 0.85 缩放，显示变换用 `ItemDisplayContext.NONE`。

   **为什么只允许一个轴**（这是踩过的第二个坑）：欧拉角的合成顺序不是统一的——
   Blockbench 用 three.js，方块按 `Rx·Ry·Rz` 合成；Bedrock/GeckoLib 按 `Rz·Ry·Rx` 合成。
   一开始用了 `(-90, -35, 90)` 这组等价于原版 `rotationXYZ(0,-90,55)` 的三轴角，
   游戏里是对的，但在 Blockbench 里同一组数字被按另一种顺序合成，剑就被摆到了**背侧**。
   单轴旋转在两种顺序下结果相同，所以 `GRIP_ROT_X` 是旋转的全部内容，
   Blockbench 里看到的就是游戏里的。叉刃（+X）不受影响，护手仍然横在刀身两侧。

为什么用 GeckoLib 的层而不是自己往 `renderRecursively` 里画：`super.renderRecursively`
返回时栈里是**父骨骼**的坐标系，直接画会让武器钉在肩膀上、而且完全不跟动画
（`WindConstructModels.atBone` 的注释就是那次踩坑写的）。`BlockAndItemGeoLayer`
是引擎按骨骼矩阵压栈后再回调的，天然跟动画。

调参入口：角度改 `InstructorHeldItemLayer.GRIP_ROT_X`（同时重跑作者用模型脚本，见下节），
握点高低改 `GRIP_DROP`。**要保持单轴**——真要斜着摆，先把需求说清楚，
得同时改渲染器与作者模型两处的合成顺序，并让 `InstructorGripModelTest` 跟着变。

测试：`terminalSummonsOnlyTheChosenInstructorAndDismissClears` 现在把四个角色各召一次，
断言主手是什么、副手有没有盾（仍然在 19 个用例内，没有新增批次）。
另有一个单元测试 `InstructorGripModelTest`（`gradlew test --tests '*InstructorGripModelTest*'`）：
一条断言"单轴旋转在 XYZ 与 ZYX 下结果相同、刀身朝上偏前、护手横着"，
一条断言"作者模型里剑方块的旋转/握点 = 渲染器常量"，防止两边再次漂移。

## 十一 在 Blockbench 里 K 动画（武器可见）

游戏里的武器是**装备**，不是几何体，所以 Blockbench 打开 `assets/tnc/geo/entity/instructor.geo.json`
只会看到空手。为了能对着武器摆姿势，另外生成一份**作者用模型**：

```
python tools/build_instructor_authoring.py
→ model-source/instructor/instructor-blockbench.geo.json   （17 骨 / 20 方块）
→ work/instructor-preview/authoring-weapon.png             （正面/前左/侧面/背面 + 两帧挥砍）
```

要点：

- **骨骼一根没多**。剑的三个方块（刃/护手/握把）直接焊在 `forearm_r` 里，
  盾的方块焊在 `forearm_l` 里。所以你在 Blockbench 里 K 出来的动画通道仍然只有那 17 根骨骼，
  导出的 `instructor.animation.json` 可以直接替换 `assets/tnc/animations/entity/instructor.animation.json`。
- **武器位置和游戏里一致**：方块 pivot 就是拳头（`(-6, 12, 0)` / `(6, 12, 0)`），
  旋转只有 `x = -55°`（`y = z = 0`），与 `InstructorHeldItemLayer.GRIP_ROT_X` 是同一个常量，
  由 `InstructorGripModelTest` 守着；单轴也保证了两边的合成顺序差异不会造成偏差。
- **UV 故意指向贴图里接近纯色的金属/木料区域**（`flat_patch` 自动挑的低方差小块），
  所以剑盾在 Blockbench 里是"纯色但有正确形状"的参考物，不用为它改 `instructor_*.png`。
  想让它好看，自己把 UV 挪到空白处再画一格就行。
- **别从这个文件导出模型**。正式 geo 由 `tools/build_instructor_model.py` 生成（带 UV 占位校验、
  骨骼层级校验、贴图校验）；这里只导出动画。
- 打开方式：Blockbench → New Project → Bedrock Model → 导入该 geo → 贴图选
  `assets/tnc/textures/entity/instructor_<variant>.png`（四套皮形状一样）。
