# 武器特色动作第二轮

> 2026-11-04：槽位及按键已统一，前三槽固定为攻击／振刀／破振刀。旧操作示例由 [统一前三槽与招式辨识](统一前三槽与招式辨识-20261104.md) 取代；历史制作说明保留。

本轮重新编排现有连招动作，不新增按键串或独立技能。29 条连招与镰刀六招各自使用明确的转身轨迹；持续拉弓姿态保留。

| 武器 | 新动作编排 |
| --- | --- |
| 长剑 | 退步藏刃后反斩、抬臂反身燕返、连旋与短促架刀分开表现 |
| 重剑 | 短步拖刀、贴地起势反撩、双手过顶重劈、横剑迎撞；重劈偏竖直，横扫偏转腰 |
| 战锤 | 原地沉腰砸地、绕身轮砸、沉肩前顶；不再全部共用同一段大抡锤 |
| 长枪 | 舞花探刺、转身望肩回马枪、整圈回身扫、双手盘架；长刺与回马枪松开副手 |
| 镰刀 | 扑身劈落、低身连续收割、先甩出后逆向回钩、抬镰处决、连续猎杀转圈 |
| 长弓 | 定射、前滑快拉、后仰收腿、侧滑侧倾、转身射分别编排；头和持弓手抵消转体保持瞄准方向 |

起手和收势加入烘焙缓入缓出采样，每根骨骼由原来 8 帧扩展到 29 帧，蓄力由 5 帧扩展到 17 帧。重剑和锤关键姿势继续使用双手腕汇合计算。修复作者脚本共享初始姿势字典导致跨动作污染的风险，所有动作在编辑前独立复制。

新增回归比较实际轨迹，防止仅有不同动画名称却共用同一条转身曲线。未改伤害、命中时机、冷却、位移冲量或解锁规则。近战仍沿用现有即时命中结算，不能把这些预演当作伤害帧同步证明。
