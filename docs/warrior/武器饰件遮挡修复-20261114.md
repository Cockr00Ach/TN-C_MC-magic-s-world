# 武器饰件遮挡修复（2026-11-14）

晨星细剑圆环、龙之剑等实体饰件共用了半透明刀光材质。原材质只写颜色，不写深度；第一人称中饰件缓冲先提交、剑身固定缓冲后提交时，剑身会覆盖本应位于前面的圆环。这不是模型缺失，也不是圆环挂载位置错误。

新增独立的实体饰件层：不透明、LEQUAL 深度测试、颜色和深度写入、主渲染目标；使用标准实体 Cutout shader、满亮顶点光照与正常雾色，绑定 LIGHTMAP 和 OVERLAY。实体饰件 alpha 为 1；共享方块绘制函数的箭尾调用仍保留原来的 .96。大招辉光层另补 OVERLAY 绑定，混合方式与目标保持原状。

共用修复的 11 把武器：龙之剑、霜月太刀、晨星细剑、赤霄斩马刀、收割巨镰、裂地战锤、破天戟、长弓、弦月长弓、逐风战弓、烬羽重弓。手持变换、左右手、放大与动作继续使用原来的挂载矩阵。

验证：`WarriorOrnamentDepthTest` 的 3 项测试读取已编译材质及原版材质字节码，不初始化游戏；根据真实写深度标记验证前后饰件的两种提交顺序，并重现旧版丢失前方圆环的情况。`WarriorWeaponOrnamentsTest` 的 1 项测试覆盖全部 11 把武器的装饰几何与动画边界。共 4 项通过。

增量包只替换 3 个客户端类，基于当前实际实例 JAR 保留其他条目。构建、CRC、依赖、未改条目逐字节核对、安装副本哈希及备份信息记录在 `work/weapon-ornament-depth-release-20261114/receipt.json`。本次没有拉取或推送提交。
