# 测试木桩、命中声音与全武器蓄力

## 测试入口

执行 `/tempering ground`，在演武终端点击「测试木桩」。需要加入磨砺、在场内且为生存模式；会结束自己的教官课程，并使用本人的演武位。

- 木桩使用独立木制靶标模型，不追人、不攻击、不被推走。
- 名牌显示本次／累计伤害；动作栏显示命中次数、累计与 DPS。DPS 按首末攻击时间计算，至少以一秒为分母。
- 右键清零；潜行右键收起；终端的「结束练习」也能收起。换教官、离场或退出时清理本人木桩，不占着演武位。
- 同一 tick 的连续命中也能统计，取消普通受击无敌帧。
- 统计读取护甲等处理后的伤害，在木桩保命截断之前记录，所以十万、万亿级的伤害也能记录；木桩自身生命不会归零，不发经验、掉落或磨砺奖励。
- 可用管理员命令 `/summon tnc:test_dummy` 在其他地方放无归属木桩；终端召出的木桩只允许本人使用。

## 命中声音

只在有效命中时于目标位置发声：轻武器为较清脆的金属碰撞，重剑为低沉铁砧碰撞，锤更低、更重，枪用尖锐的刺击声，箭使用箭矢命中声。按攻击者限流：轻武器 3 tick、重剑 4 tick、锤 5 tick，群攻不会每只怪叠一声。木桩可用于听音，包括创造模式下的普通武器命中。

## 长按 Z

这是专用键盘 Z（控制设置可改绑）的蓄力；鼠标左键保持普通攻击。

1. 按下 Z 立即登记准备状态，阻止普通攻击；没有初始伤害。
2. 不足半秒即松手：作为一次短按横斩输入，仍可组成 QZE 等统一连招。
3. 按住半秒以上：进入武器专属蓄势动作。持续按住只续状态，绝不会自动普攻或循环攻击。
4. 松开 Z：出手一次；重复松手包不能再攻击。
5. 准备阶段或蓄力中受到实际伤害、被僵直、按步法中断、切换武器／维度、退出或长时间断开续包都会取消。被打断后，迟到的长按包不能恢复蓄力，松手也不补攻击；需要重新按下。

倍率为 `1 + 按住秒数`，例如 1 秒为 2×、10 秒为 11×、60 秒为 61×，**不设玩法伤害上限**。长剑斩击、重剑下劈、锤震击、枪前刺、镰刀回旋、弓射出震荡箭；攻击仍检查距离、角度和墙体，近战蓄力攻击沿用振刀对拼规则。

Z 蓄力箭单独在受伤结算中使用浮点蓄力伤害，避开原版箭矢内部的整数伤害上限。箭的飞行速度和聚拢特效亮度保持可控，伤害继续增长；震荡范围伤害也随蓄力增长。弓仍消耗一支箭，创造／无限按现有规则处理。弓 Q／E 旧的短期蓄力模式保留。

木桩不会攻击；受伤中断可在场外对敌测试，场内免伤保护保留。主动中断可直接用战斗步法键测试。

网络协议 26，联机双方须同版。武器外观、统一前三槽及旧训练记录保留。
