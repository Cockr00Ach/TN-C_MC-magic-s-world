# 战士天赋与发布

用户确认：没有天赋就练不动；天赋越高，相同练习成长越快。不能让任意法师通过加入命令获得完整战士成长。

## 已采用的规则

天赋是独立、持久化的角色属性，普通练习不改变天赋。第一版使用单独的战士天赋 0–6；暂不凭空拆出力量、灵巧等多个轴。

| 战士天赋 | 磨砺获取倍率 | 有效磨砺上限 |
|---|---:|---:|
| 0 | 0 | 0 |
| 1 | 0.5 | 200 |
| 2 | 1 | 1000 |
| 3 | 1.5 | 3000 |
| 4 | 2 | 6000 |
| 5 | 2.5 | 8000 |
| 6 | 3 | 10000 |

倍率及上限为可调的实现初值。击杀成长和首次训练奖励均使用相同倍率，按整数向下取整。零天赋不能加入、获得磨砺、完成训练或获得战士减伤/风刃资格。

新增角色及旧版缺失天赋字段的角色默认 0，不因魔法亲和力或旧磨砺数据自动获赠天赋。旧磨砺原始记录保留，但有效值被天赋上限约束：零天赋时不生效。赋予/调整天赋后立即同步并取消当前训练。

`/tempering talent` 查看天赋、倍率、上限与有效磨砺。

权限等级 2 的管理员可通过 `/tempering talent set <玩家或选择器> <0–6>` 配置角色。例如 `/tempering talent set @s 4`。普通玩家没有自选、重掷或改写天赋的入口。管理员测试磨砺 `/tempering set` 也不能超出天赋上限。

角色创建/剧情 NPC 自动赋天赋尚未接入；当前角色配置入口是上述管理员命令。没有强制清空已有魔法亲和力；只有明确赋予战士天赋的角色才具备战士成长资格，因此可由剧情明确配置特殊双修人物。

客户端剑形磨砺条使用个人天赋上限，协议升级到 10，客户端和服务端须一起更新。

## 发布检查

规则测试新增零天赋、成长倍率递增、成长上限递增；隔离服务端新增旧数据绕过防护、零天赋不减伤/不成长、赋予天赋后按倍率成长的验证。安装与 Git 同步结果在发布完成后补记。
