# 战士入门教程与 J 任务追踪

## 玩家入口

进入世界后，在 J 任务书的「战士入门」章节追踪「莉娅的第一堂课」。已命名的玩家会自动接取；已有其他追踪任务时保留原追踪，由玩家自行切换。

在演武场找到「莉娅 · 战士入门」，右键开始。实操需生存模式，且已在人物档案选择战士天赋。首次开始赠送一把白蜡木练剑。

## 教学顺序

1. 教官以长剑演示九次交错穿刺、地面剑痕、收剑与直立落雷。
2. 介绍台中央的演武终端，玩家右键终端进入实操。
3. 主攻：ZZZ，或连续三次左键，必须实际命中木桩。
4. 振刀：E、Q、按住 E，架开教官的一记轻击。
5. 破振刀：E、Q、Z，必须实际命中木桩。
6. 总结兵器特色、一级至五级的连招数量、蓄力攻击与大招条件。

显示的按键会随玩家配键变化。一级武器开放前三招，每升一级增加一招；大招需要三级及以上武器，磨砺严格大于 3000，磨砺上限仍受天赋限制。

镜头使用教官近景、手部、木桩、终端、玩家肩后和演示全景。空格或左键推进对话，潜行键或 ESC 跳过镜头；长剑动作演示至少运行到结尾才进入下一阶段。实操阶段默认 R 重看本课，可重新配键。

## 进度与退出

七个 J 任务目标随服务端真实教学阶段同步，客户端不能用完成消息跳过实操。使用独立的个人任务，不共享队伍进度，不修改已有 FTB 任务。

死亡、离开演武场、换维度、断线或教学超时会释放个人教官、木桩和演武位，并恢复自有镜头。实操中断保留检查点，再找莉娅可继续；练剑不会重复发放。教学演示不造成战斗伤害、额外磨砺或地形破坏。
