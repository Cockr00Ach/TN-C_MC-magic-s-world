# 刀光渐变与重武器重量感

## 颜色

刀光壳体现在沿刃长插值顶点颜色：剑尖侧保留武器原色，向内侧过渡到冷白；巨镰和暗属性武器改为近黑色内侧。内侧仍保持半透明，尾迹继续按寿命消散。最外侧另有窄亮边，颜色只轻微混白，透明度最高限制为 0.92；亮边位置跟随磨砺放大后的真实剑尖。

保持原有七片/段的几何预算、两面绘制、深度测试及半透明自发光实体管线。没有增加粒子或新的全屏后处理。

## 重量感

`WarriorHeavyMotion` 为重剑家族、战锤家族的攻击提供统一时间采样。原始总时长不变，起手更迟缓、挥出更快，结束挥砍后短暂沉住再回收。第三人称关键帧、程序化姿势、根部转身以及第一人称武器读取同一条时间曲线。第三人称增加躯干承重、头部补偿及前后腿支撑；第一人称增加武器下坠和适度扩大挥动幅度，不旋转镜头。

防御、蓄势保持、闪避和轻武器不使用重武器时间曲线。服务端攻击判定、伤害和连招时长均未改变。主观重量感与命中观感仍需实际试玩。
