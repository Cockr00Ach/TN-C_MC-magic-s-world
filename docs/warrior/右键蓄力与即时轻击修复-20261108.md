# 右键蓄力与即时轻击修复（2026-11-08）

Q 与 Z 改为按下事件直接发送轻击，不再等待松手或半秒阈值，快速按下又抬起也不会被 tick 轮询漏掉。Q 不再拥有蓄力状态；E 原有长按振刀保留。

普通鼠标右键在物品使用事件中准备蓄力，按住半秒后蓄势，松手释放；原版方块／实体成功交互优先，因此箱子与交易不被对空蓄力接管。潜行右键继续保留风刃、人偶召唤和原物品交互。原 Z 长按蓄力入口撤除，Z 与左键都即时记录横斩。

蓄力状态由独立的 `WarriorRightChargeInput` 管理。Q、E、左键和步法可取消蓄力；右键仍未松开时不自动重启。失焦或打开界面发送取消，松手不补攻击。服务端修正了待蓄力、受击取消、换武器后第一下轻击被吞的问题；不再把 Q／E 的 HOLD 当作蓄力入口。原版弓使用由服务端一并拦截，避免原版与战士释放各发一次。

K 操作说明及 Z 的按键名称同步更新。尺寸上限、各武器蓄力表现和伤害规则沿用原实现。
