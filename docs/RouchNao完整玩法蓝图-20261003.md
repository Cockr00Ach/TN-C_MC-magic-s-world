## 一、这个世界每天能玩什么

玩法中心不是「刷完 Boss 得下一把武器」，而是**出门观察一个会回应人的世界，再把见闻带回小镇变成生活**。六条路线可并行，也可只做其中一条：

1. **远行与发现**：酒馆传闻或野外地标给线索。玩家亲眼见到植物或动物的特殊行为，带回样本；第一次研究给图鉴记录和少量报酬，但必须保留能续种/繁殖的起点。已有存档用野外采集、交换或补给线获得替代种源，不能因新区块已生成而绝版。
2. **培育与牧养**：天空岛的购买地提供归属感和安全空间；普通野外只要有方块编辑权和合适生态，也能开田、种所有魔法作物、围栏养动物。不同作物需要光、雨、水、安静、热源、回家或玩家亲自注魔，不用每天上线打卡。动物分肉食供给、活采生产、元素魔能与生活协作，屠宰料理和周期采集各有独立价值。
3. **餐桌与小镇关系**：收成可做旅食、宴席、居民礼物和家具材料。MCA 居民对节日、晚饭、归家和送信有可见回应；婚恋/孩子仍由玩家选择。家不是主线准入证。
4. **工坊与能源**：多个工序各司其职。野外营火/便携炊具和厨房做食物，纺织台做布，铁匠/3×3×3魔法炉处理金属与魔导件；玩家魔力、蓄魔根和成熟绿脉枝提供可计量能源，导线把 Forge Energy 送去蓄能匣、灯和兼容设备。没有能量守恒证据的「魔法发电」不发布。
5. **酒馆、商行、银行**：41号酒馆原生 Bountiful 栏接可交物的普通供货；巡夜、勘查和特别调查从同一栏的行为委托页登记，由服务端记录阶段。32号织夏的商行收可再生货、卖家具；19号米洛的银行管存款、日薪、贷款、房田牧地分期；28号铎恩管炉与装备；29号莉娅管法杖。玩家不必到 Self 处办所有事。
6. **遗迹与首领**：一个首领委托先有去处与调查，再有可选的生活补给和真实参战，最后把消息带回镇里，让公共订单、对话或店货发生小变化。黑暗潮、公孙衍、终局仍按正史；农业不成为救人的强制钥匙。

完整循环的示例：在旧驿道发现路铃麦与带铃响的野羊 → 收一粒种、一份样本 → 酒馆研究后保留种源 → 在野外营地或自家地种麦、做饲料 → 活剪响绒 → 自用做远行保暖毡、把多余的卖商行 → 用工资/订单收入买窗帘与灯 → 下次远行带上毡和路签。另一个玩家完全可以不种麦，接讨伐、买补给、交调查，也能体验正史。

### 地权与种植的明确边界

|位置|允许|禁止与原因|
|---|---|---|
|天空岛公共路、店铺、他人家/待售房|通行、交互、看房|普通挖放、锄地、偷采、喂/剪别人牲畜及向其机器抽能；合伙人内饰不受系统植物覆盖|
|天空岛**标明的公共试种圃**|播种、照料、采自己种的魔法植物，供新手试机制|改道路、墙、容器、装饰和他人植株；现成耕地供需要耕地的作物试种|
|自己房屋、农田、牧场|编辑、种植、收获、畜牧、加工；可授权朋友|跨界自动化不得吸走邻地资源|
|普通野外自然地|按生存规则开荒、种植、采集、围栏牧养；不要求购地|仍尊重别的模组领地、结构/机关和服务器事件取消|
|遗迹/专用保护结构|明确允许的调查、机关、可再生样本采集|不能借播种/机器/动物绕过解谜或拆建筑|

这要从右键点击位、最终放置位、采收、施肥、浇水、喂养、剪毛、自动抽能全部一致判断。当前代码有先拦 BlockItem 种子、BushBlock 例外缺失、归巢花硬性要求自有住宅等问题；这些是已定位的返工对象，不把「野外理论上可种」当成玩家已能种的证据。

植物的「魔法」不是凭空给战斗属性。图鉴按回应方式分为**迎人/守护、昼夜/天候、共生/牧养、记录/旅途、蓄能/工坊、奇观**六页；玩家能从轮廓、声音、动作猜规律。野外样株只在经检查的空气位、远离天空岛与作者建筑；旧存档可通过对应野外采样获得种源。任何首报任务都不收掉唯一一粒种子。各物种的成熟收获至少保留一次繁殖可能，世界卸载不饿死植株。

### 六个有魔法味道的实景片段

- 雨后在河边，雨书莓叶纹像写满水线；听潮苇轻响，雾织棉散开。玩家采一份作路签和浇灌壶，下雨不是只改变天空颜色。
- 半夜回营，钟眠草卷合；自己种的脉舞铃花认出主人，花茎开始跳。晨起钟眠草打开一片静叶，归巢花只因玩家真的回来才开放。
- 废工坊里，绿脉枝叶脉按储魔量明暗起伏。接上发电座后**绿光朝机器流动、植物储量减少、灯真的亮**；缺光时逐渐停机，蓄能匣让夜灯多撑一会儿。
- 洞穴里投出远照果，照亮可到达的路线20秒。警路苔对近敌发亮，缄声蕈因奔跑合伞；玩家据这些自然反应作决定，而不是靠任务坐标箭头。
- 高坡晴夜，星露藤结果，星憩蕊放出三只真实花灵。玩家可吃一颗果救急，花灵不跟随打架；守候它们回花才能取得做家灯的露。
- 数日后野外望天蔓长出第二层枝台，玩家沿支架与藤筋上爬，取纤维做长绳；它是一件远方地标，不是天空岛模板旁突然长出的破坏性方块柱。

## 五、魔法锻炉、魔力电与有限自动化

「冰火传说」仅作交互层次参考：读说明、按图搭建、结构唤醒、开界面、看能量与制作反馈。按作者最新纠正，锻炉外包络固定为 **3×3×3**，有真实内部炉膛，不能再做同层九格。方向可转四向，炉芯在正面中层保留旧 ID；耐火炉砖15、刻铜炉框8、炉芯1、注能口1、排烟顶1，共26个部件，中央一格留空作为炉膛。三层俯视图如下，图的下边是正面：

    底层 y=0              中层 y=1              顶层 y=2
    砖 砖 砖              框 注能 框              框 砖 框
    砖 砖 砖              入 空膛 入              砖 排烟 砖
    砖 出 砖              框 炉芯 框              框 砖 框

以空膛C为原点、炉芯外向F为正面、R为从正面看右向，核心位置P=C+F；旧芯P不搬，底层P.y−1、顶层P.y+1，后注口朝−F，排烟朝上。闲置GUI/扳手可转四向；不同炉不得共用部件，跨未加载区块显示“未加载，暂停”而非缺件。

炉芯模型露出拱形炉门，铜框是有厚度的立柱/顶角，注能口有透明脉纹，顶部排烟口只冒短小烟束；激活时内部热光、炉门与整圈符纹同时回应。结构只验证这些位置，不吞掉或替换玩家的部件；炉膛被填、缺框、注能口反向或排烟顶缺失都显示具体位置并暂停。GUI右上角有三层预览，可以逐层看缺件，而不是要求玩家猜27格。

铁匠铎恩免费给《炉台工匠札记》，第一枚炉芯合成也附书；书有三层搭建图、投料与注魔、用电线路、故障排查四页。最后一块就位时炉纹逐节亮起并响短音；缺一块即暂停，GUI 指出缺哪格，不扣魔力、不吞原料。右键炉芯打开 GUI：四个**通用输入槽**、一个输出槽、独立魔力仓、当前数据配方与进度（默认80刻，各配方可指定工时）、注入25魔力按钮、`生活设施／路途工具／工坊材料`筛选、只显示不扣物的幽灵配方。15块炉砖明确分为12普通砖＋2中层左右侧壁投料砖＋1炉芯正下方的出料砖；漏斗接侧壁外侧投料、接出料砖下方取成品。端口只代理唯一炉芯库存，不另存货，结构缺件时关闭代理；比较器报告进行/已完成状态。餐食、织物仍用厨房/纺织台，不让炉成为万能合成台。

注魔时从玩家到炉心出现可见流光和短音；制作期间铜角火星与纹路分段亮起；出炉有短促金色脉冲。粒子只给附近玩家，频率有限。旧单方块炉的已存材料与 `Charge` 用 NBT 版本迁移：旧0/1槽到新输入0/1，旧2槽到新输出4，先选配方、补齐三层结构再开工；挖核心正常吐物，拆环只暂停。断线、满产出、缺料、多人同时操作均不得复制/丢失。

电学首版是**真正有账本的小网**：

```text
玩家魔法石 / 蓄魔根芯 / 成熟绿脉枝
              ↓ 实际扣除的魔力
            魔力发电座
              ↓ 1 魔力 → 5 FE
            导能线 ── 蓄能匣
             ├─导能作业灯：每4刻耗1 FE
             ├─水纹灌溉阀：真水源/雨囊，每次20 FE 只浇授权邻田
             └─苇纸压纹机：苇杆2＋真实水125mB→纸3，每批80 FE
```

发电座魔力仓200、FE仓2000，单刻最多转换2魔力、输出最多20 FE；植物直邻扫描六面，每株每20刻最多实扣1魔力。植物需要成熟、适光、适水且持久化有储量；它是缓慢可再生能源，不是每刻无条件发电。只有真正从植物扣到魔力，才看见绿色粒子沿植物→发电座流动。导线网络最多64个已加载节点，不能跨卸载区块拉能，不能从邻家的植物抽能；蓄能匣容量5000 FE，夜间给灯和机器续航。断电时灯熄、灌溉和压纸停止，库存保留。Forge `IEnergyStorage` 用于兼容 FE 设备；现有 Create 6.0.8 的机械应力不是 FE，首版**不能**宣称魔法直接驱动 Create。以后真要做魔力电机，应另算应力/FE比率和机器 API，再作为独立设计。

### 小电网的实际账目与玩法

既有常亮归路灯保留旧ID与行为，耗FE的导能作业灯使用新ID，不能悄悄让玩家旧灯断电。

一游戏日是1200秒（20分钟），不是银行的现实24小时。绿脉枝储魔40，成熟、湿润、白天日光≥12时每秒补1魔力，每秒最多被抽1；修剪取导魔枝会清空储量并退阶段，**收材料与留着发电互为选择**。按每魔力5 FE，一株理想白天600秒出3000 FE。灯每4刻用1 FE，即每秒5 FE，全天6000 FE。没有太阳/水或区块未加载时不得照这份理想产量结算。

|装置安排|一天的收入/支出|实际体验|
|---|---|---|
|一株绿脉枝＋蓄能匣＋夜灯模式|白天3000 FE，夜间灯3000 FE|初级院灯白天充、晚上亮；天气遮阴会短电，玩家可手动补魔|
|两株＋5000 FE蓄能匣＋常亮灯|白天6000 FE，其中3000 FE供白天灯、3000 FE存到夜间|理想日照下可保持一灯，不能再白送机器功率|
|三株＋蓄能匣＋一灯＋一台工作机|理想9000 FE−6000 FE灯＝3000 FE余量|余量可压纸37批、共111张（每批80 FE、苇杆2、水125mB）或浇田150次（每次20 FE）；共享余额，不把两者同时算满|
|蓄魔根或玩家补能|40本人魔力育根→30存量→150 FE；直注25→125 FE|便携救急与人工开工；根是有损储能，不是复制魔力|

夜灯可选「关／常亮／仅夜间／红石控制」，断电显示“缺光、缺水、储能空”中的实际原因。电力用途为照明、有限浇水和压纸，不把完整现代工业强塞进魔法世界。灌溉阀缓存8份水，每次扣一份雨囊水，或从被授权的一格真实水源抽取并消耗该源；不把旁边有水当无限免费水。每次20 FE只照料一株相邻植物，不能大范围扫田。导线网扫描与能量结算分开，重叠/闭环网络只归一份账，入口锁定主人及已授权地块，设备重新加载不得产生复制缓存。

锻炉魔力仓上限200，玩家一次注入最多25并只扣实际接收数；根芯不足30空位时不吃芯，提示剩余容量。注能口可接邻接绿脉枝，每秒最多1真实魔力，并受地权；植物可同时靠近炉与发电座，但两者争用同一存量。**FE只驱动用电器，不能反向换回玩家或锻炉魔力**；3×3×3炉的生产仍用魔力。

炉内配方、零件到成品的唯一定义见 [工坊部件与设备配方](原创生态品种与物品规格-20261003.md#工坊部件与设备配方)。炉制警路灯芯再装配成野外警灯，绝缘炉泥进结构/发电座/线材，邮封印每次寄送真实消耗，镜片/聚光片进对应灯的升级槽，断路护符是防止未经授权跨领地连接的线路许可器，不引入首版尚不存在的过载事故。所有配方由可编辑数据和JEI显示，工时按实际配方读；生存基础炉芯/电路不锁在先驱者击杀之后，首领调查解锁工坊图样与便利服务。

## 七、委托、首领与结构怎样串在一起

Bountiful 原生纸只处理可真实交物的供货、料理、牧场材料单；观察、巡夜、现场勘查、送信由同一41号栏打开 TN-C 行为委托页面，服务端记录行动证据；商行/铁匠/银行有各自独立页面，不把所有功能塞进 Self。特别委托采用每人保存的阶段状态：**酒馆登记 → 委托人物说明地点和可选补给 → 找到一个真实生成的结构实例 → 完成两类现场证据 → 实际参与该实例 Boss 战 → 向对应 NPC 复核 → 酒馆结案**。结构未生成、模组缺失或召唤机制不可达时不发无法完成的单。杀敌证明记录实体、结构实例和参战者；买来掉落物不算击杀，队友各自有进度。现场证据和生活准备让委托有故事，但都可通过自制、商购或玩家互换获得，不强迫种田。

### 行为证据、多人战斗与结构失效

行为页不认“持有一张调查纸”等于已经调查。每单先生成玩家专属委托ID，记录接单时间；观察需在指定生态近距离停留10秒，并看见该株本次实际事件；夜巡记录三处路标各10秒夜间观察和一次真实敌情。图鉴签章/路签只是服务端记录的展示件，买来的纸、复制NBT、别人的签名或接单前的旧报告都不能自动结案。供货则不要求自产，允许玩家交易，这是生产者与冒险者互相需要的地方。

首领实例以维度＋结构起点＋实例包络标识。击杀须在包络或其向外64格可追击边界，且登记后近60秒有有效参战记录；治疗/护盾支援队友也计真实贡献，不只认最后一击。伤害零/路过旁观不记。离开维度、死亡或断线清除短期参战记录，保留已完成调查；回来可继续这单。每个接单队友单独判定并永久保存证明；领取时事务扣证/记结案/发奖励，满包不丢奖励，重复包不重发。实例先被别人击败或遗迹被拆时，玩家可无罚换到同类另一实例，个人调查保留、现场证据重新做。找不到实例的世界不接该单，给探索传闻而不是不可完成坐标。

城镇回应首版只改已核对的对话、档案地图标记和商行列表；公共桥、路灯、告示、桌面之类实体锚点须等内饰版现场确认后逐件添加，**本轮生态开发不改天空岛模板、地形或合伙人内饰**。

### 三段跨玩法经历

**失灯邮路**（公共实体锚点验内饰后实施）：41酒馆收到夜间断信 → 玩家夜间查看旧路标与失联邮架 → 用警路苔、远照果或商购灯芯向28铁匠订制部件 → 修好经过审核的公共路灯锚点 → 下一夜灯真的亮，邮羽鹭或居民的信恢复投递 → 32商行出现防雨邮封图样和小批采购。采集员、工匠、邮差各有参与方式，无强制 Boss/房产。

**季外餐桌**：厨师听说雨书莓雨囊与晨晖盘葵晨蜜能做两种味道的餐食 → 玩家发现样株、保留种源，在野地或私田观察雨纹与黎明转盘两种行为 → 用收成做两道料理 → 在酒馆公共桌邀请 MCA 成年居民，偏好不同、各记住一道菜 → 商行开一日节庆采购。植物行为、食物消费和人与人的回应都实际发生。

**废厂停机**：41特别调查 → 32查实际耗料账 → 远古工厂记录机器与危险位置 → 真实参与击败先驱者 → 28复核证明 → 铎恩教玩家搭有安全环的3×3×3锻炉，亲手注魔/绿脉供能点亮耗电灯。事故只解释地方工坊，不擅自改写衍或黑暗潮的原因。

### 纯冒险者也能得到补给

32号商行新增少量现做远行货，玩家不种田也能买：归路饼两份20铜、雨囊饮一份25铜、野外雾帐一份40铜、远照果一份30铜、缓降布一份45铜，每玩家每现实日每种最多四份；不能向商行反售成品。商业玩家可通过实际供货单补库存；系统日初只补低限量基础货，以便没有其他玩家开店的单机仍可玩。私下交易自由定价。所有首领准备步骤都给原版替代方案（普通熟食、火抗/水肺药水、梯子/回程坐标等），原创物品带便利与风味，不是拦住剧情的材料锁。

以上新价格是待实际采收时长校准的起点。1000铜一天赚100铜、1万本金一天上限1000铜，会让后期玩家基础现金宽裕。继续种养的理由还包括品种、真实功能、朋友、定制家具和见闻；不能通过花钱直接买“第一次看见花灵”或“给朋友送去种子”的完成记录。

委托分四种账：首次研究个人一次，给图鉴/配方/声望和少量铜；普通供货可重复，按实际消耗与现有收购额度或更低职业额度计价；区域事件/首领一次较高报酬与服务变化；关系/节庆主要给回忆、台词和外观图样。所有 NPC 共用个人销售账，避免换按钮绕限额。商行不无限回购加工品，检查买料→合成→回售套利。

家具仍遵守作者要求：**成品家具只能用钱购买**。植物/动物出产织物、灯罩等原料，玩家可交材料委托织夏/工匠制作定制款，再花钱购买成品；普通功能工具、旅食和机器可自行加工。材料交单不是把自己制造家具开放出去。

## 九、任务书、图鉴、人物与视觉

任务书负责教程与收藏；酒馆栏负责委托，对应 NPC 才打开银行/商行/铁匠/制杖页面。作者在亲改「归」、主线和法杖页，本轮新增内容只合并隔离章节，不覆盖现用稿。图鉴按迎人/守护、昼夜/天候、共生/牧养、记录/旅途、蓄能/工坊、奇观六页组织，一页少量大图，显示野外线索、环境、真实用途和观察状态。完整发现条件必须可以从线索推断，不用“提交64个物品”冒充探索。

发现记录分四格：见到野生株、观察魔法行为、成功续种、使用一次产物。任务书可显示收集进度，奖励以研究页/造型而非大量铜币为主；不把29株全部做必过主线。动物图鉴记录观察、第一次非屠宰取产、首次繁殖/邮递等动作。

视觉以 Minecraft 清晰方块比例为准：普通材质16×16或整倍数、硬像素、有限调色，成熟株至少有前后层次、厚叶/花托/菌伞，品种在高度、轮廓和负空间明显不同。原版也有交叉面植物，因此问题不在“绝不许交叉面”，而在整株轮廓、像素密度、体积与动画是否统一；不能全用一个基模换色。分节花茎连续动画、花灵实体、毛脊采前采后分别有自己的渲染与服务端状态。发光纹理与真实光照要区分，玩家能看到何时通电/断电。

美术验收使用独立测试场：原版草、蘑菇、浆果、羊与每株幼苗/成株和每种动物并排，拍白天、雨夜、第一/第三人称与正侧背。图标、手持、世界模型的像素密度一致；说明书和 GUI 在不同缩放与 JEI 打开时都能读清。概念图、JSON 解析和服务器测试通过不等于美术验收。
