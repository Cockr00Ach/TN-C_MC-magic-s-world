# 石英之巅

石英之巅是天空岛维度 `tnc:skyhaven` 内的离岛竞技场，位于主岛东侧的魔水海上空。沿用确认过的石英建筑和朝向。建筑底角为 `1152 144 -416`，安全落点为 `1248.5 162 -289.5`，面向东侧场心。落点供后续载具或传送接入；本次没有加入常规交通和竞技规则。

竞技场和主岛使用不同的区块文件。预制存档只为新世界安装建筑，不添加常加载区块、刷怪或每刻任务。已有存档不被修改。

在已启用作弊的新世界里，可用以下命令试玩：

```mcfunction
/execute in tnc:skyhaven run tp @s 1248.5 162 -289.5 -90 0
```

复烘：`python tools/bake_quartz_summit.py`。模板为 `data/tnc/structures/quartz_summit.nbt`，来源是适配到 Minecraft 1.20.1 的石英之巅投影。竞技场位置也记录在天空岛预制包的 `manifest.json`。辉耀决台保留原先的预览用途。
