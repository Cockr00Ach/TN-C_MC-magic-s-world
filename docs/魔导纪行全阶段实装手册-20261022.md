### 三个量必须分开

- **M** 是机器/瓶/装备已经拥有的储量；**M/s** 是来源真实产量或接口/路径带宽。
- 每株植物、每只魔兽共享自身余额；摆多个采集器只会分流，不能复制同一份魔力。
- 普通晶纤是双端，可自动拐弯与升降；带宽按实际路径最窄处。远距用配对镜面，跨维用高维棱镜。
- F8显示真实传输与元素，而不代表天空每一颗环境粒子都能被收集。没有来源余额，机器不能凭特效获得魔力。

## 2. T0—T1：从首炉到第一锅药

### 启动顺序

1. 注能台工作台合成，不需要灵纹铁。空手保持右键按5M/s把自己的魔力注入；潜行空手右键开面板。
2. 左一放玻璃瓶，100M装一满瓶；铁桶400M变流动魔力桶。八泥土＋满瓶做魔法土源，放下10秒转化同高9×9泥土。直接种植，无须再锄地。半径8格内流动魔力润泽，土地微弱蓝绿反馈。
3. 首座锻炉先手动注60M，铁锭炼灵纹铁需6秒。之后才造集露盏、晶纤与浅魔池，避免“要铁才能采魔、要采魔才能炼铁”的循环。
4. 成熟翠脉等产魔植物旁一格放集露盏，接青辉晶纤，再接池和机器。集露盏4M/s，青辉线8M/s，浅魔池1000M。
5. 剥离台产药粉等；引火桩贴药锅提供魔法火/水流；寻迹仪帮助寻找已生成的真实野生魔植和入口。

### 两种多方块不要混淆

**锻炉3×3×3**：底层9耐火炉砖；中层7炉砖＋正面炉口＋中心炉核；顶层8炉砖＋中心排烟顶。总计24砖、1炉口、1炉核、1排烟顶。右键炉口开GUI，材料入输入槽，供应实际魔力，等待配方加工；炉核与排烟顶位置错误会显示未成型。

**药锅2×2**：一个四方魔焰锅物品铺四个水平占位，四格共享同一锅库存和状态；四方封魔盖覆盖同一锅。用水桶倒水，把三味实物药材投入可见液面或手持右键加入。药材顺序无关，种类须匹配一条药方，不能拿未做出的图标当药材。

### 这锅药看什么

药锅有0—1000温度、0—100融合度两条独立状态。F8外围流光**蓝色**表示低于360，**绿色**表示360—620合适，**红色**表示超过620。真实火魔法升温/点燃，水/冰魔法降温；引火桩也是实际魔法热流。药材缓慢旋转，每味有自己的彩色漩涡，绿温时逐渐同心，不使用搅拌棒或焰蕊盐。

| 封盖时机 | 品质 | 药效 | 淤积 |
| --- | --- | --- | --- |
| 融合不足60 | 浑浊次品 | 基础30% | +25 |
| 融合60—89（或未抓住黄金帧） | 标准 | 基础100% | +10 |
| 100%合一闪星后1.5秒内 | 臻品·大师 | 基础200%，持续增益翻倍 | **0** |
| 已过融合时机/持续失控 | 古怪废液 | 无药效，可除野草或投掷蚀甲 | 0 |

盖上锅盖先锁定融合和品质，再在绿温续煮累计6秒才可用玻璃瓶装药。封盖后冷/热会暂停续煮，不能继续改变锁定品质；开盖状态持续严重过热5秒会炸锅出毒雾和废液，建筑不被爆破。成品未取走时先取成品，再开下一锅。

## 3. T2：兽材、点化与每日药膳

### 喂养、共鸣、点化

正常养殖仍用捕笼、牧务杖窝点、食槽；相近兼容动植物且同主人，产能共鸣+20%，不用复杂仪式。共鸣台要求“实际照料＋实际产魔”，不只是摆着动物：镜瓣夜蛾→镜鳞；曳彩角羚→棱角片；星绒兽→柔茸；鸣线蜥→雷余晶。相邻集息器/色靶必须真正抽取，不能无余额凝物。

熏蒸釜比直接灌药更精密：扭曲药雾作用水生魔植80%变蒸气魔莲、20%烧毁成灰；巨人药使魔植巨果化；分裂药给同主人幼兽永久精英产魔+25%；坚肤石蜜给实物金锭/钻石打预处理标记。**整份锻炉配方消耗的输入均为已处理金锭/钻石时**，该炉耗魔减半；混进其它未处理材料不能白享减半。直接手浇水植的扭曲药仍是50%成功，不能把两种途径混为一谈。

### 药膳从两味开始

雕花魔力餐盘可以只放2—9味，不要求每次摆九格。手持合格食材对准格子右键放一份；潜行空手点格取回；普通空手右键享用整盘。消耗每格一份，蜂蜜瓶等容器返还。

### 成型、供魔和维护

深渊塔核心外绕3×3周边三层、共24聚能砖；中心上方两格留空。核心容量100万M、接口4096M/s。可接晶纤/镜面，也像集露盏直接收附近自有产魔生态；直收仍扣植物/动物真实余额，并与接口共用限流。基础池始终不触发过载。

### 跨维绿洲逐步操作

先满足整合包已有的维度解锁：获取邪恶之眼（`endrem:evil_eye`）后解锁下界，获取不朽护符（`whispering:immortal_amulet`）后解锁末地。原有KubeJS维度门槛保留；未解锁时连管理员式传送也会被阻止，不能误判为绿洲故障。

1. 在主世界搭好自己的塔并充入足够魔力，4格内放第一面高维棱镜。
2. 手持检流尺潜行右键选中主世界端。端点周边少量必要区块临时保持5分钟加载，供走过传送门后配对。
3. 去下界或末地，放第二面棱镜，用同一检流尺潜行右键绑定。两端都须有所有权和使用权限。

## 8. 测试与常见停机

| 现象 | 先检查 |
| --- | --- |
| 台子0M | 必须有真实来源→通路→接入口；可空手注魔或用有余额的魔力瓶。创造测试可用既有调试大容量供魔物品，勿把视觉粒子当余额。 |
| 转相仪/祭坛不收玩家注魔 | 这是类型限制；转相只收太阳/太阴，祭坛只收所插王杖同属性元素。先建天体收集→转相→祭坛。 |
| 寻迹无目标 | 500格内需有已生成且未探索地点；不会凭空创建植物/入口。换已探索边缘再试，不收费。 |
| 共鸣台没兽材 | 是否同主人、成年、最近亲喂、真实产魔已被集息器抽取？每次照料最多一份，留空右输出格。 |
| 熏蒸不扣药 | 无合适邻近目标、所有权不同、满输出或瓶格不够时保留药剂。 |
| 锅封盖仍取不了 | 封盖锁品质后还要累计6秒绿温续煮；别在红温/冷温一直等。 |
| 九味没太阳 | 检查五类是否全、直接相克是否0、相生线＋桥是否≥6；不是任意九物都成阵。 |
| 下界植物种不下/不回魔 | 塔是否真实付100M/s，是否在棱镜48格内？目标库存有魔力不等于主世界维护仍供得上。 |
| 终局配方材料齐仍停 | 核对禁忌古卷、维度/绿洲、露天极光、旁边节点200M星界账本，不要只看炉内普通M。 |
| 队友pull看不到新内容 | Git源码不含编译JAR；须运行构建安装脚本或应用本次验证更新包。不能只复制任务文件而留旧JAR。 |
