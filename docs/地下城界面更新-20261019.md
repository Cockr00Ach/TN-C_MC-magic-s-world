# 地下城界面更新：旧铜星仪

沿用此前确认的深色书页、旧铜边饰、蓝绿晶体与星仪风格。入口、宝匣、整备、六类奇遇、手册和地下城进度显示统一更新。

| 原来 | 现在 |
| --- | --- |
| 段落与操作纵向罗列 | 六个五层段分两列展示，已解锁、未解锁与等待队长分别提示 |
| 奖励与奇遇以文字为主 | 方形物品图标、铜饰选择按钮、效果与价格简述 |
| 界面缩放时留白与元素比例不统一 | 600×360等比布局，图标不拉伸，点击区域与绘制使用同一坐标变换 |
| 手册与账本混在正文 | 顶部三项账本，左侧操作，右侧星仪／已知房间地图及玩法规则 |

保留组队邀请、接受邀请、寻找界门命令及倒地、保包、20%本段遗币损失说明。地图不会显示尚未告知客户端的房间。按钮沿用原有服务器动作、会话与权限。

本轮不修改怪物、战斗、奖励数值、任务章节、天空岛或已有世界。怪物设计留待下一轮。

## 安装与队友更新

本机安装入口：`tools/install_dungeon_ui.py --live <PCL版本目录> --apply`。脚本检查构建、单元测试和14张完整客户端截图记录，只替换TN-C JAR，备份旧JAR并核对安装前后所有FTB任务文件哈希。

本机补丁为 `work/dungeons-ui-update-20261019.zip`，供已经安装地下城第一版的队友使用。解压后，完全关闭游戏，再运行包中的 `apply_dungeon_update.ps1 -Pack <PCL版本目录>`。该界面补丁只含JAR，不覆盖队友自行修改的任务书。

仓库push提供代码与验证记录；PCL实际运行文件仍需替换JAR，或使用更新后的整包。
