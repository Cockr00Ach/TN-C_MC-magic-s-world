# 天空岛团队客户端同步

本说明用于 Windows 上已有「元素觉醒 1.4.3」基础包的 PCL 实例。队友告诉 Agent「pull 最新版」即可。Agent 先安全拉取并保留工作区修改，再从仓库根目录执行下面的同步和只读复核。普通 Git 客户端只更新文件，实际安装由 Agent 调用这个入口完成。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\sync-team-client.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\sync-team-client.ps1 -VerifyOnly
```

### Agent 如何找到游戏、处理重试

- 自动寻找正在运行的目标版本、标准 Minecraft 目录及便携式 PCL。多实例时，Agent 根据本机 PCL 选中的版本或最近的启动记录确定实际路径，再加 `-GameDir "实际版本目录"` 执行两条命令。已有 `TNC_LIVE_ROOT` 的机器沿用其指向的 `versions` 目录。
- 游戏正在使用该实例时，安装会等待正常退出。网络中断时可重复同一命令，安装器在 `.tnc-client-sync/partial` 暂存已收到的 GitHub 文件分段，按发行文件的 SHA-256 区分版本。整包校验通过后清除分段，再替换托管文件。旧版和改名的重复模组会移到该实例的备份目录。
- 更新后以命令退出码、七项文件的校验和正式实例路径作为验收依据。报告实际提交、TN-C 的 SHA-256、是否需要重启。已有存档和个人按键继续使用。新版地形要在**新建的天空岛世界**查看。

包含学院研习、无昼圣堂、虚镜魔核和战士兵器美术的版本请从[阶段交接](handoff/TN-C-阶段交接-20261127.md)查看试玩入口。检测到 FTB Quests 时，同步器只备份和更新团队维护的学院任务章节。

### 各项内容从哪里来

| 内容 | 锁定版本与安装位置 | 用途与发布来源 |
|---|---|---|
| TN-C | `mods/tnc-1.0.0.jar` | 团队 GitHub Release 的同一份成品。包含新岛地形、瀑布、观星山和七系五阶共 35 把法杖。 |
| Voxy | `mods/voxy-0.2.15-Forge-1.20.1.jar` | Forge 1.20.1 社区移植，供团队成员从作者源自行安装到客户端。[对应发布页](https://github.com/realBritakee/voxy-neoforge/releases/tag/0.2.15) |
| Complementary Unbound | `shaderpacks/ComplementaryUnbound_r5.8.1.zip`，保留 ZIP | 这版包含 Voxy 远景光影支持。[光影发布页](https://modrinth.com/shader/complementary-unbound/version/r5.8.1) |
| 渲染与加载依赖 | `mods/` 中的 Connector beta.49、Forgified Fabric API 0.92.6+1.11.14、Embeddium 0.3.31、Oculus 1.8.0 | 以实测基础包的发行文件为准，匹配的文件直接复用。同版本同名但字节不同也会对齐。 |

Agent 从[首方发行锁](../tools/tnc-client-release.lock.json)和[第三方下载锁](../tools/skyhaven-client.lock.json)读取**文件名、固定下载地址和 SHA-256**，不要自行改选最新版。Voxy 社区移植和光影通过各自发布方下载。对外分发整合包时遵循 [Voxy 原作者的整合包说明](https://modrinth.com/mod/voxy)。

部分旧实例曾把法杖手持模型和贴图装进团队 OpenLoader 资源包。这些文件在游戏中优先于 JAR。入口会备份并校准这里已有的受管法杖文件，复核模型与贴图实际使用的版本。其他个人材质包照常保留。

**Voxy 仅下载备用，默认关闭。** 首次同步及从旧自动开启配置升级时，安装器关闭 Voxy 总开关，保留玩家当前的光影包和光影开关。主世界、天空岛都没有开启提示。玩家日后自行更改选项后，重复同步会保留选择。

**联机**时，房主或服务端需要对应的 TN-C。Voxy 与光影只装在各自客户端。天空岛地形已经烘焙，新建世界即采用新版地形，无需另装 ReTerraForged 或开启远景。仅在玩家日后自行开启 Voxy 渲染与区块记录时，单人新岛才会预热远景。

**原有本地素材**在换包前恢复到当前实例的 `kubejs/data` 和 `kubejs/assets`。已有的个人版本优先。某台机器从来没有的本地专属建筑会使用内置小型入口，安装日志会指出。F9 的离线中文识别运行时独立于地形与光影；需要首次启用语音输入时，按[语音安装与自动自检](../tools/free_magic_voice/README.md)执行。

### 后续发布者如何让队友继续自动对齐

当改动涉及 `src/main`、Gradle 配置或 Wrapper 时，维护者在准备推送前先提交完整源码，用 JDK 17 构建公开版。首次开发构建的编译依赖可运行 `tools/fetch-libs.ps1 -PackDir "实际版本目录"` 从现有基础包取得。公开版自动排除本机专属素材。

```powershell
.\gradlew.bat -PteamPublicRelease build
python tools/publish-team-client.py --jar build/libs/tnc-1.0.0.jar
git add tools/tnc-client-release.lock.json
git commit -m "Pin verified team client release"
```

发布工具需要 Python 3.11+ 和当前仓库的 GitHub 发布权限，它会核对 JAR 内嵌的源码树、建立按源码提交命名的标签、上传发行文件，并核对 GitHub 返回的 SHA-256。维护者验收同步流程后，把源码和新锁一起推送到团队分支。仅改文档时可以继续复用现有发行包。源码与锁不一致会在改动游戏文件之前报错，维护者用上面的发布流程修正。
