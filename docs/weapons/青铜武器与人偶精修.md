# 青铜武器与人偶模型精修

本轮细化现有五把青铜武器和召唤人偶。战士连招、投掷、强化、合成、生命、时限及召唤冷却沿用现有实现。

## 武器

参考当前越式青铜剑、方天戟、偃月刀与龙剑的四分之一单位细节密度。这些模型约有773～1541个部件。青铜武器重新构建刃口倒角、中央铸脊、双面雷纹、兽面护手、皮缠、铸环和连接套筒。

五把武器继续使用原有物品ID、握持坐标、第一/第三人称变换和碰撞/攻击逻辑。长枪与战戟的主轴及连接套筒连续，侧刃具有实际连接梁。模型均符合原版方块物品模型坐标及UV限制。

共用青铜图集由128×64重新绘制为512×256。锈蚀以连续斑块、铸造小坑和刃口磨耗表现，避免把旧纹理单纯放大。

## 人偶

由47个盒体重建为约780个部件。头部包含收束的下颌、深眼窝、倾斜怒眉、瞳孔、鼻翼、鼻孔、闭合下垂嘴线、颊纹和卷耳连接。身体包含胸甲铸纹、铸钉、分层肩甲、裙甲、分节指骨、腕肘膝踝关节及分趾足甲。

贴图使用2048×2048独立UV图集，密度8像素/模型单位。每个盒体分配不重叠的展开区域；材质与几何分别生成。模型读取器支持每个细节盒体的静态旋转，并只调整UV密度，不缩放骨骼和身体比例。仍使用原来的七个人形骨骼和现有战士动作曲线。

## 再生成与验收

`tools/bronze_art_detail.py` 是几何、图集与离线深度缓冲渲染的共同来源。原来的 `gen_bronze_weapons.py`、`gen_bronze_puppet.py` 入口已改为调用新模型，避免再次运行旧脚本覆盖精修资源。

预览直接读取最终JSON与PNG，采用深度缓冲、实际UV与旋转，包含五武器总览、人偶持戟全身和头部双角度。预览是静态造型展示，不是游戏截图。

验收使用原版 `BlockModel.fromStream` 解析全部五把武器，并烘焙真实人偶模型；捕获顶点验证纹理尺寸、UV范围、像素密度与未缩放的头部几何。按用户要求不启动游戏。

高密度物品模型采用紧凑JSON序列化。原来的缩进排版使大剑文本达到2,187,464字符，超过现有Windows PowerShell安装器 `JavaScriptSerializer` 的2,097,152字符上限；原版游戏解析正常。紧凑序列化保留所有部件和UV，兼容现有安装器，无需修改或跳过其检查。测试同时覆盖该文本大小限制。
