# 青铜战戟与召唤人偶

- 工作台中放入古铜大剑、长枪、大刀、匕首各一把，全部强化10级，合成 `tnc:bronze_halberd`，结果保留10级强化。只继承强化等级，不合并四件输入的附魔。
- 战戟近战归入既有长枪家族；普通右键保留30tick蓄力投掷、自动回手；潜行＋右键召唤人偶。
- 每位玩家最多一个 `tnc:bronze_puppet`，名额按玩家UUID保存在主世界 SavedData，与武器物品、维度、登录状态解耦。
- 人偶最大生命在召唤时快照为玩家最大生命的10倍。高于原版1024属性上限时按比例存储生命与伤害，保留实际承伤容量。暂定攻击12，常量在 `PuppetBondData.ATTACK`。
- 人偶优先协助主人的近期攻击目标、攻击主人的敌人，其次寻找附近敌对怪物；平时跟随主人。攻击从已有长枪战士连招目录选取，复用战士动作曲线、范围角度、伤害倍率、打断与命中反馈。
- 12000游戏tick（10分钟）到期，最后30tick消散；死亡也先消散，再移除。每次真正消失之后开始2400tick（2分钟）召唤冷却。冷却与时限使用主世界游戏时钟，不读系统时间。
- 区块卸载不立即释放名额；卸载期间到期时，台账结束该绑定，旧实体再次加载会立即自检移除，不能产生第二个有效人偶。其他玩家的绑定和冷却独立。
- 人偶不掉落武器、物品或经验。召唤位置需要无碰撞空间；失败不消耗名额或冷却。
- 几何和材质由 `tools/gen_bronze_puppet.py` 生成，人物运行模型从同一份 `bronze_puppet_parts.json` 读取；预览为离线模型图。

按用户要求只做构建、自动化回归与安装校验，不启动游戏。具体手感与整合包视觉由玩家自行验证。
