# 鱼群线条表现

鱼群改为程序化立体线稿：双侧鱼形轮廓、眼睛、鳃线、侧线、胸鳍、朝上的背鳍与分叉尾，附低透明度色面。活鱼青绿，金属鱼银蓝并以金色标记眼睛和鳍边。线条用四棱细管绘制，8×2静态笔触纹理提供深色边缘；使用已有的 entityTranslucentEmissive 实体层、全亮光照和正常深度测试，无需额外模组或 shader。

运行时不再注册、烘焙或绘制原来的实体鱼模型。FishSchoolModel、旧图集与其生成器作为旧方案源资料保留，不被当前渲染器调用。手持的尚方宝鱼、尚方宝剑模型继续沿用。

一条鱼66条线段，每段4个四边形侧面；27个色面三角形各提交正反面，总318个声明四边形、1272个顶点。12条鱼同时可见时3816个声明四边形、15264个顶点，共用一个材质纹理和一套静态结构。尾部按游戏tick变形，不保存整鱼逐帧副本。透明色面有覆盖成本；这些数字不是Minecraft帧率或显存实测。

12个非规则空间采样点构成散群，前后深度、高低和侧向错开；实体UUID生成双方一致的相位，每次施放略有不同。分批起游、小幅浮动和独立摆尾均受最大3格宽、10格射程和原碰撞体约束。服务端、客户端使用相同轨迹公式。保持8tick聚集、16tick推进以及原伤害/消耗/冷却、每目标一次结算、各鱼独立撞墙消散、Boss保护与控制限制。

验证包括全摆尾周期的线条/色面边界、绘制成本和重复线段、不同seed的范围/单调推进/空间错落、窄门和薄墙原有回归、JDK17完整构建及标准安装。离线预览不代替Minecraft内的遮挡、画面与性能验收。加载新客户端类需完整重启。
