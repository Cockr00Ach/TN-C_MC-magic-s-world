# 本轮范围与验收

作者要求修正正手持杖；右键对应NPC只打开其岗位页面；店员在建筑内；任务书内容由作者自行编辑。此前已授权自主实施，不再追加设计确认。

采用贴图握柄/杖头采样计算手持轴向和握点，保留35件贴图、物品ID、阶位与库存显示。验证左右手与第一/第三人称的实际渲染变换链，避免只改一个固定角度而再次把竖杖、斜杖统一误转。

采用点击岗位的显式角色打开单一面板；手册独立显示个人档案，保留旧委托归档入口，Bountiful实际委托栏保留原生界面。交易依然由服务器校验距离和订单归属，不新增贷款或娱乐规则。

室内岗位：莉娅(320,87,270)，铎恩(201,101,259)，米洛(228,94,234)，艾琳(428,94,285)，均相对岛原点。落脚搜索限制同一层的已核对房间范围。旧NPC一次迁移并保留UUID，迁移完不覆盖作者以后手动摆放；房间无可用空间时等待，不能退回街道。

任务书及图片默认保留，更新代码不触碰章节或章节组；作者使用已核对版本的FTB编辑模式操作并返还完整配置目录。内容编辑命令、保存目录和快捷操作来自本地2001.4.22模组代码核对。

验证：新增35件握持方向/握点回归测试；各岗位显式路由和个人档案测试；Forge服务器测试多岗位邻近情况下的页面选择、UUID迁移和无户外回退。安装前备份，安装后核对jar与任务书哈希；不停止用户游戏、不直接编辑用户世界文件。
