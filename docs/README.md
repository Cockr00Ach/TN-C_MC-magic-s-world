## 三、整理规则（以后新增文档请照此办）

1. **活文档**（有维护者署名头 + 文件名不带日期）→ 直接放 `docs/` 顶层或它自己的主题目录；
2. **一次性记录**（修了什么、验收了什么）→ **文件名带 `YYYYMMDD`**，放对应主题目录（`spells/` `tavern/` `ecology/` …），没有主题就放 `misc/`；
3. **不要往 `docs/` 顶层堆文件** ✗ —— 顶层只留"入口文档 + 配图"；
4. **移动/改名请用 `git mv`**，并顺手更新引用它的链接与脚本；
5. 改别人维护的文档**先打招呼**（见仓库根 `README.md` 的「多专题协作约定」）。
