# 零式 · 五相术式机关枪

六联晶铳仍然保留；新增零式 `tnc:zero_spellgun`，通过天穹式魔导铠供能。

| 形态 | 连发的原有法术 |
|---|---|
| 水 | 水炮弹 |
| 火 | 大火球术 |
| 土 | 土球 |
| 雷 | 大雷球 |
| 风 | 大风球 |

穿戴天穹式后，主手拿零式，长按右键持续射击；潜行右键依次切换形态。每秒10发，每发72M，不消耗箭或个人魔力。满机铠12000M可以发射166发，额定持续16.6秒，最后剩48M。使用机铠推进、屏障等其他耗能技能会减少可用余额。零式使用独立回路，晶铳的过热排放和过载射速不会中断这段额定续航。HUD显示当前形态、法术名、储能及剩余连续射击秒数。

零式复用既有法术的实际弹体、原有模型和命中规则，既有的伤害对象、碰撞、吸引或灼烧机制同样适用。它不更改法杖的学习、读条、个人魔力和冷却。

魔力炉配方：六联晶铳×1、星髓×8、辉金×12、风暴晶体×6；1800M，40秒，四个材料槽。六联晶铳仍可另行制作和使用。

测试拿取：`/give @s tnc:zero_spellgun`。供能测试可用 `/give @s tnc:creative_mana_prism`，潜行对空气右键可充满背包中的机铠，再穿戴测试；也可把机铠放入已供能的饰品充能台。

模型：`model-source/zero_spellgun/zero.bbmodel`。单炮口、开放导轨、五瓣悬浮导流翼及发光核心，五种形态改变辉光；开火加速旋转、展开并带有轻后坐。更新射击动画时间戳不会触发重复换装下沉。

构建验证：271项单元测试、52项路线/机铠/零式服务端测试通过。服务端续航测试真正生成166次弹体并检查账本，不以公式代替实射。完整PCL隔离测试复用281个已安装模组，实际长按右键验证五种法术、连续供能、真实命中及12张原生截图，五种形态各166发、各剩48M，个人魔力均保持350。伤害依据 LivingDamageEvent：自研弹体按零式标记识别；SpellEngine 土雷按实际施法者及零式形态识别，不以日照燃烧或怪物血量变化充数。续航按服务端实际运行刻检查，避免新世界生成卡顿导致客户端提前结束计时。
