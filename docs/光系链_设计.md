## 一、链结构（3 档，均为**自身增益**）

| 档 | 名字 | 效果（累积 ✓：高档包含前面所有效果 ✓） |
|---|---|---|
| **t1** | **飞行** | 展开光翼 ✓ ＋ **可飞行**（原版 `mayfly`）✓；无速度/减伤加成 |
| **t2** | **极速飞行** | 上面全部 ＋ **移动速度 +50%** ✓ ＋ **受伤减少 25%** ✓ |
| **t3** | **光翼展开** | 上面全部（速度取**更高档**，不相乘 ✗）＋ **移动速度 = 150%（+150%）** ✓ ＋ **受伤减少 50%** ✓ ＋ **光属性伤害 +50%** ✓ |

★ **链级规则**：**这条链的任一技能生效期间**，光翼都展开且可飞 ✓ —— 也就是说飞行只看"身上有没有这条链的 buff"，不再看光亲和力 ✓（现在的实现是"光亲和力 ≥ 3 就给翅膀" ✗，要改成这个 ✓）。

| 项 | 做法 | 文件 |

## 四、风险与注意（都踩过 ✓）

- **别往 `Chain` 枚举中间插值** ✗（存档按索引读数 ✓，插中间会把所有人的技能页搞乱 ✗）。
- **减伤不要相乘** ✗（t3 = 速度取最高、减伤取最高、不相乘 ✓）。
- 飞行是**原版能力**开的 ✓：客户端要**双击空格**起飞 ✓ —— 你说过"不会飞"✗，如果确认是手势问题 ✓ 我就顺手加"**按住空格二段跳就起飞**"的兼容 ✗（也可以做成"离地按跳即飞" ✓）。
- 翅膀模型现在是**作者的 geo**（`geo/entity/light_wings.geo.json` ✓ ＋ 动画 `waving` ✓）——⚠️ 它的 `waving` **没有 `loop: true`** ✗，接线时要让它循环播 ✓，否则"飞的时候会动"只会动一次 ✗。
