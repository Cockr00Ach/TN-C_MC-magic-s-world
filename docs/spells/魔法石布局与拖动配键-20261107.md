# 魔法石布局与拖动配键（2026-11-07）

## 界面

面板改为 680×360 的设计尺寸，小窗口按实际 GUI 视口等比适配。顶部区分资源信息、学习／配键页签与元素筛选。学习页保留用户亲和力水晶贴图和点位，扩大法术行距，元素与独立魔法筛选统一移到顶部。

配键页上方是可配置法术库，下方横排九个槽位，保留两页配置。按住法术拖入槽位，松手才提交；空槽配置、占用槽替换，已有配键也能直接拖动移动。同一法术只占一个槽。右键清空；槽外释放、Escape、失焦、界面刷新或关闭会取消拖动。配键法术仍按既有规则展示每条链的已学最高档。

拖动时显示跟随图标与名称、目标高亮；只按下而没有实际拖动不会提交配键。原有 SET_SLOT／CLEAR_SLOT 请求及服务端合法性检查继续生效。

## 手动配置保存

`MagicStoneData` 增加持久化的 `ManualLoadout` 标记，手动配置后规范化不再自动把未绑定法术补回空槽。仍保留链等级更新、去重、失效法术清理，以及未手动配置／旧存档的默认补槽。标记包含在复制和 NBT 往返中，没有批量覆写存档。
