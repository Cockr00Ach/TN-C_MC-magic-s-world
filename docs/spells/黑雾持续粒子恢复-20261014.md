# 黑雾持续粒子恢复

当前 PCL2 五档黑雾配置的 `release.target.cloud.client_data.particles` 都为空；同时备用服务端粒子发射逻辑已被移除，导致持续雾气消失，只剩模型与领域效果。

恢复原版 `minecraft:squid_ink` 外缘黑雾与 `minecraft:large_smoke` 体积烟气。T1–T5 持续批次总量限制为 11、14、17、20、23，保留粒子缩减，避免重新使用原来的高密度多层批次。同步修正生成器，后续重新生成法术不会再次清空持续雾气。

五档 JSON、非空持续粒子、总量上限和原版粒子 ID 检查通过；`SpellParticleSafetyTest` 通过。安装只修改 PCL2 五档法术的持续粒子列表，逐项核对其他字段完全一致，保持伤害、范围、持续时间与施法者视野规则。重新启动游戏加载更新配置。
