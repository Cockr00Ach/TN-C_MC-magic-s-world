## 2. 暗系读条前戏：放大 + 挪远 + 去掉"雷锲感" + 淡入

### 2.1 「雷锲出现的太突兀」

之前的暗系小阵画的是 **完整圆环 + 一圈等距刻度齿** —— 那正好是雷锲的形（作者早在衍 boss 那轮就说过
「暗系不要雷锲」）。这一轮整段重画（`DarkCastFx#seal`）：

- **三道断弧**（每道 ≈110°，缺口错开、半径带 ±2.8% 摆动，线本身走 `darkBoltDeep` 的抖动路径）；
- **五道爪痕**从环外斜着擦进环内（角度/长短按 seed 不均），**取代刻度齿**；
- 环上**三块墨渍**（压扁的血珠）；
- 阵心一团暗雾 + 四根往里收的短须。

### 2.2 「太突兀」＝ 出现方式也改了

| 项 | 之前 | 现在 |

| 小阵淡入 | 3 tick 硬涨到满 | **9 tick** `smooth` 涨到满 |
| 主阵半径 | `1.55 + 0.38×档` | **`1.95 + 0.46×档`** |

| 幽灵 | 12+档 tick、`scale 0.55+0.06×档` | **18+档 tick、`scale 0.64+0.07×档`**，控制点抬更高 |
| 外圈 | t3+ 才有 | **t2+** 就有 |

### 2.3 新加的（"也可以优化一下"）

**t4+ 阵边"伸出手"**：阵的外缘（`0.80R~0.90R`）有三道位置，各自循环「从地里慢慢伸出来 → 胡乱抓一把 → 沉回去」，
用的是 `DarkHandLines` 那份唯一骨架（和黑手/黑雾手长得一样），掌心朝向施法者，`scale 1.35` ⇒ 约 2 格高。

## 3. 缠绕龙：改成"所有实体画完之后"再画

### 3.1 为什么原来"永远在背后"

`LightningRenderTypes.BOLT` 是**加色混合 + 不写深度**（`COLOR_WRITE`）。龙和玩家都在实体层里画，
排序上龙先画、玩家后画 ⇒ 玩家的片元把龙整段盖掉。所以从侧面看，龙永远像"贴在背后"，没有"绕着"的感觉 ✗。

### 3.2 现在的做法

`TNLightningDragonRenderer#render` 的 `coil()` 分支**不再画几何**，改由新类
`client/CoilDragonOverlay` 在 `RenderLevelStageEvent.Stage.AFTER_ENTITIES` 里补画
（所有实体、包括玩家都画完，深度已写入）：

- 朝着镜头的那半圈：深度更浅 ⇒ `LEQUAL` 通过 ⇒ **看得见** ✓；
- 被玩家挡住的那半圈：深度更深 ⇒ 被丢掉 ⇒ **看不见** ✓。

于是「绕」第一次真的成立：头在前、尾在后，镜头转到哪边都对 ✓。
参数与原来完全一致（半径 `0.80+0.55×scale`、跨度 `1.15+3.45×scale`、自转 `age×0.11`、
淡入 8 tick、末尾 20 tick 淡出、头顶白闪），只是换了**画的时间点**。
`dive()`（雷球链俯冲）和普通升龙仍在实体层，不受影响 ✓。

## 4. 黑雾：顺序反过来 + 换测深层 + 抓取半径放大

| 问题 | 原因 | 修法 |
| --- | --- | --- |
| 「雾加载在手之后，导致手一直看的见」 | `renderHands(...)` 在雾片**之后**调用；且手用的是 `DARK_OVERLAY`（`NO_DEPTH_TEST`，天生永远压在最上面） | ①**先画手、再盖雾片**（雾是半透明 `alpha≈.43`，盖上去以后手只在雾里透出来一点）；②手改用会测深度的 `DARK` |
| 「抓周围的敌人的距离要很远，起码比黑雾范围大」 | 抓取判定是 `d2 > radius²`，只抓雾最里圈；渲染的手也只画到 `0.85×半径` | 抓取半径 = **雾半径 × 1.45**（`DarkFogCloudEntity#gripIntruders`），渲染侧搜人范围同步 ×1.45（`DarkMistRenderer.GRAB_RANGE`）；Boss 领域雾（150 格）单独封顶 96 格，避免两百格范围太重 |

## 8. 验收（实机）
1. **雷系**（`雷击`）：三张阵出现在 **4~6 格**外（不是脚边），阵明显变粗变大；开阵前有一道忽明忽暗的电弧连到胸口；
   小雷龙比之前**大近一倍**，飞得更久；脚下一整片噼啪的雷网 + 外围尖刺，聚雷球更高更大。
2. **暗系**（`黑暗之手链` 读条）：主阵 8 tick 淡入，**边缘是断的、带爪痕**，不是"圆环 + 一圈齿"；
   t4+ 能看到阵边有手从地里伸出来抓一下。
3. **雷速/闪电登神**：缠绕龙**头在前、尾在后**（侧面看能挡住玩家一半），不再是"贴在背后的贴纸"。
4. **黑雾**：手在雾里若隐若现（不是浮在雾上）；站在雾**外面一两格**也会被拽进去、被上减速。
5. **黑暗之手链**：手 ~1 秒才完全张开（能看清五指依次展开），线明显更粗、颜色更深（黑里透暗红，不再发亮红）。
