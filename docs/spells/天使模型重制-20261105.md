# 天使模型重制（2026-11-05）

> 作者：「天使模型全部优化了」
>
> 两个模型都重做了：`angel`（法阵中心那尊 4/6/10 格高的雕像天使）和
> `fightingangel`（召唤出来的战斗天使）。旧的 15 个扁盒子、128px 贴图、一张
> 40×20 的 UV 被整件长袍共用——10 格高的雕像近看就是一块金板。

## 1. 改了什么

| 部位 | 旧 | 新 |
|---|---|---|
| 长袍 | 一个 12×12×8 方盒 | 4 层收腰裙摆 + 前后裙片 + 侧摆 + 金边下摆 + 露出的鞋 |
| 躯干 | 9×9×5 方盒 | 收腰胸甲、护心镜（青蓝宝石）、金领、腰带、肩甲 |
| 头 | 8×8×8 头 + 3 块头发板 | 头 + 后发/发盖/刘海/侧发/发髻 + 金冠 + 几何眼睛/眉线 |
| 光环 | 4 根金条 | 16 段圆环 + 4 颗青蓝宝石 |
| 翅膀 | 每侧 2 片 1px 平板 | 每侧 16 片羽毛（肩羽/中羽/飞羽/覆羽四层，带弧度） |
| 手臂 | 方块直接挂在离肩 20 格的 pivot 上 | 肩/袖/前臂/护腕/手，pivot 回到肩关节 |
| 武器 | 无 | 右手白金光矛（木杆 + 钢刃 + 金护手 + 聚焦宝石） |
| 多臂 | 8 条（雕像）/ 6 条（战斗） | 收掉：只保留双臂；多余骨骼留空，动画照常解析 |
| 贴图 | 128px，UV 大量重叠 | **256px**，每个 cube 独立 box-UV，按材质绘制 |

- 立方体：15 → **106**（每个模型）。
- 贴图：`angel_bedrock.png` / `fightingangel_bedrock.png` 都是 256×256 RGBA。
- 高度：模型包围盒 y 0..40，正好 2.5 格；雕像的 `scaleFactor = 高度 / 2.5`
  仍然成立（10 格高不再缩水）。

## 2. 动画兼容

`fightingangel.animation.json` 的 idle / walk / fly / attack / cast / death 都还在：

- 用到的骨骼全部保留：`body / head / robe / halo / wingRight / wingRightMid /
  wingRightTip / wingLeft / wingLeftMid / wingLeftTip / armRight / armLeft /
  armLeft2 / armLeft3 / armLeft4 / armRight4`。
- `armLeft2/3/4`、`armRight4` 现在没有 cube（不再挂 6 条小手臂），动画通道照常
  求值，不会崩；攻击/施法仍由主双臂完成。
- **pivot 修正**：旧 `armRight` 的 pivot 在 `[-25,22,0]`，离手臂 20 格，攻击时
  整条手臂绕着体外一个点甩——这就是作者说的“用背部攻击”之外的另一个怪相。
  现在主臂 pivot 回到 `[±5,22,0]`，翅膀 pivot 也收拢，`preview_geo_anim.py`
  的 attack/fly 逐帧检查没有炸模。

雕像原本 `angel.animation.json` 是空的（完全静止）。现在加了一个 8 秒循环的
`idle`：身体 ±0.28 浮沉、衣摆 ±1.1°、头 ±1.5° 微转、光环 360° 自转、翅膀轻扇，
幅度很小，远看仍是一尊庄严的降临天使。

## 4. 生成器

模型和贴图不是手改 JSON，而是由 `tools/gen_angel_models.py` 生成：

```powershell
python tools/gen_angel_models.py
```

- 从 `work/angel-backup-20261105/` 的原始 geo 读骨架；
- 重建 cube、分配独立 box-UV、生成 256 贴图；
- 自带 UV 重叠校验（重叠直接抛 `UV overlap`）。

以后要调羽毛长度/裙摆层数/配色，改脚本里的数值重跑即可。
