# 二、登神链雷龙：显示位置异常

## 诊断

缠绕形态的雷龙（`MODE_COIL`）在 `CoilDragonOverlay` 里画（`AFTER_ENTITIES`，为了让它"绕"人）。
那条分支原来读的是**雷龙实体自己**的位置：

```java
Vec3 at = entity.getPosition(partial);   // ✗
```

问题在于 `TNLightningDragonEntity` 是**非生物实体**（`extends Entity`），
它的位置同步很稀：服务端对非生物大约 **每 20 tick** 才发一次位置包
（生物是每 tick 走 `ClientboundMoveEntityPacket`）。
而这条龙每 tick 都在**贴到玩家身上**（`setPos(wearer.getX(), ...)`）……

⇒ 玩家一跑一跳，客户端那份龙的位置**最多晚 1 秒** ✗
⇒ 画面就是"龙拖在人后面 / 浮在半空 / 落地了龙还在上面"—— 也就是"显示位置异常" ✓

（`TNLightningDragonEntity.tick()` 第一句就是 `if (level().isClientSide()) return;`，
客户端根本不会自己修位置 ✗。）

## 修法

`CoilDragonOverlay` 不再信实体自己的坐标，改成**直接挂到穿戴者身上**：

```java
Vec3 at = wearerPosition(mc, entity, partial)
        .orElseGet(() -> entity.getPosition(partial));   // 兜底
```

`wearerPosition` 按 `entity.ownerId()`：

1. 先 `mc.level.getPlayerByUUID(owner)`（绝大多数情况就是玩家）✓
2. 再退到 `mc.level.entitiesForRendering()` 里按 UUID 找人（非玩家穿戴者也支持）✓
3. 都找不到 ⇒ 才用实体自己的位置（至少不会消失）✓

读的是**客户端那份带插值**的位置（`getPosition(partialTick)`）⇒ 跟着玩家每帧走，
延迟从"最多 1 秒"变成 0 ✓，跑动/跳跃时龙不会脱开 ✓。

## 没动的地方

- 龙本身的几何（`LightningDragonGeometry.coil`）、半径/高度/转速、颜色 —— **一个字没改** ✓
- 俯冲形态（`MODE_DIVE`）、破土形态（`MODE_ERUPT`）—— 本来就正常，没碰 ✓
