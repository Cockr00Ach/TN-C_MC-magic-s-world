# 水球链 t4/t5 重做：「金闪闪法阵群」— 2026-11-09

作者原话：

> 我觉得这样直接射一个太单调了，你看过圣杯战争吗，就是金闪闪那样，在释放 t4 之后，玩家身边会有两个小法阵围绕，
> 然后当玩家攻击了某个敌人之后，玩家身边就会出现几个法阵并且像光线那样快速射出我们的这个新水波，
> 记得要先出现法阵，法阵全部出现完之后再一起发射水波；
> t5 就是法阵和水波变大，然后攻击结束之后几个法阵汇聚到一起射出一个巨大的水波。
> 这个水波可以就不用原来那样持久，就跟光线一样就行了。

问清的三件事（作者 2026-11-09 选）：

| 问题 | 选择 |
| --- | --- |
| 一次施法能触发几次 | **法阵在的期间每次攻击都齐射**（内置 2 秒冷却） |
| 法阵存在多久 | **20 秒** |
| t5 收尾那道巨大水波 | **比普通高一档（约 2 倍）** |

## 1. 以前是什么样

施放 t4「龙啸」/ t5「龙滅」⇒ **当场**放出一根实体光柱（t4 3 秒、t5 12 秒），
它自己往前钻、每 0.5 秒结算一次伤害 ✗。作者："直接射一个太单调了"✗。

## 2. 现在的时间线

```
         施放 t4 / t5
              │
              ▼
   ┌───────────────────────────┐
   │ IDLE（20 秒）             │   两个小法阵绕着玩家慢慢转（阵面朝着准星方向）
   └───────────────────────────┘
              │ 玩家打中一个敌人（每次攻击都算，内置 2 秒冷却）
              ▼
   ┌───────────────────────────┐
   │ OPEN                      │   N 个法阵一个接一个亮起来
   │  t4 六个 / t5 八个        │   每个间隔 2 tick、亮起来用 4 tick
   │                           │   ★ 全部亮完还要再憋 6 tick 才许射
   └───────────────────────────┘   （作者特意强调："先出阵，全部出现完之后再一起发射"）
              ▼
   ┌───────────────────────────┐
   │ FIRE                      │   N 道水波**同一 tick**全部射出，各自从自己的法阵飞向目标
   └───────────────────────────┘
              ▼
   ┌───────────────────────────┐
   │ LINGER（10 tick = 0.5 秒）│   水波已经飞走，法阵留在原地淡出（2026-11-10 作者：
   │                           │   "射完激光之后法阵还要残留半秒"）
   └───────────────────────────┘
        │ t4                    │ t5
        ▼                       ▼
      回到 IDLE           CONVERGE：八个法阵飞到身前一点、叠在一起
                                 ▼
                          GIANT：那里撑开一座巨大的阵，射出一道**巨大水波**（×2 伤害、≈2 倍粗）
                                 ▼
                              回到 IDLE
```

数值全在 `magic/water/WaterGateRules.java`（**服务端判定和客户端表现读同一份常量** ✗ ——
两边各写一套就会"看着射中了却没伤害"）：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `GATE_TICKS` | 400 | 施法后法阵存在 20 秒 |
| `VOLLEY_COOLDOWN` | 40 | 两次齐射至少隔 2 秒 |
| `APPEAR_STAGGER` / `APPEAR_TICKS` | 2 / 4 | 相邻法阵间隔 / 单个亮起用时 |
| `CHARGE_TICKS` | 6 | 全部亮完再憋几 tick |
| `FIRE_TICKS` | 8 | 齐射的闪光姿态 |
| `LINGER_TICKS` | 10 | 齐射之后法阵**残留半秒**再散（2026-11-10 作者要求） |
| `CONVERGE_TICKS` / `GIANT_TICKS` | 10 / 14 | t5 汇聚 / 巨大水波 |
| `portals(tier)` | 6 / 8 | 法阵个数 |
| `ringRadius` / `sealRadius` | 3.2 / 4.4 · 0.62 / 0.95 | 阵环半径 / 阵面半径（t5 更大、阵之间留一格多 ✓） |
| `giantSealRadius` | ×5 | t5 汇聚成的大阵 = 小阵的 5 倍 |
| `lanceRadius` | 0.9 / 2.2 | 一道水波的粗细 |
| `giantRadius` | = 大阵半径（4.75） | 巨大水波正好填满阵口 |
| `lanceDamage` | 4 / 7 | **单道**水波伤害（一次齐射是 6~8 道同时命中 ✗） |
| `giantDamage` | ×2 | 作者选的"高一档" |
| `lanceTicks` | 10 / 12 | 水波活多久（作者："跟光线一样"✓，老光柱是 60 / 240 ✗） |

## 3. 代码结构

| 文件 | 干什么 |
| --- | --- |
| `magic/water/WaterGateRules.java` | **纯规则**：时间线、法阵几何、粗细/伤害（无 MC 运行时依赖 ⇒ 单测直接跑 ✓） |
| `magic/water/TNWaterGateEntity.java` | 法阵群本体：跟着主人走 ✓、推进阶段 ✓、到点生成水波 ✓、记住"这一轮打谁"✓ |
| `magic/water/TNWaterLanceEntity.java` | 一道水波：一闪而过、**只结算一次**伤害、不碰地形 ✗ |
| `magic/water/WaterGateEvents.java` | 扳机 `LivingHurtEvent`：玩家真的打出了伤害才算 ✓（空挥、打队友不算 ✗；自己水波打的不算 ✗，否则一轮滚成无限轮） |
| `client/TNWaterGateRenderer.java` | 法阵几何（三环 + 辐条 + 阵心点，纯几何、便宜 ✓） |
| `client/TNWaterLanceRenderer.java` | 水波几何 = 上一轮那根"加粗的闪电"（`WaterBeamVisuals` ✓），淡入淡出 ✓ |
| `TNWaterSpellEntity.cast` | t4/t5 不再放光柱 ✗ ⇒ 挂法阵群 ✓；t1~t3 完全没动 ✓ |

**法阵朝向**：朝着<b>这一轮的目标</b> ✓（不是朝着玩家前方 ✗ —— 那样像贴在脸上的一块牌子 ✗）。

**为什么水波不钻地形了**：作者要"跟光线一样"⇒ 一闪而过、一次结算 ✓；
老的那套 `WaterTerrainBore`（挖隧道）代码仍在文件里，只是玩家这条路不再走到它 ✓
（利维坦 Boss 的 t5 光柱走 `castBoss`，一如既往不受影响 ✓）。

## 4. 测试

新增 `WaterGateRulesTest`（10 条，纯几何/时间线 ✓）：

- 每档法阵个数 / 环半径 / 阵面 / 水波粗细逐级变大 ✓
- **齐射一定晚于最后一个法阵亮满** ✓（这条就是作者强调的顺序 ✗ —— 靠试玩几乎抓不住）
- 第一个法阵从第 0 tick 就开始长（不是所有阵一起憋到最后 ✗）
- 冷却盖得住整个动作（t5 的动作里有汇聚 + 大波，比 2 秒长 ✓）
- 法阵落在同一个圆环上、胸口高度 ✓；两个环绕阵分得开 ✓
- 汇聚点在身前 2.2 格、**只看水平朝向** ✓（抬头不会把阵甩到天上 ✗）
- 巨大水波 ≈ 2 倍伤害 ✓、单道伤害低于老光柱的单次结算 ✓（因为现在是 6~8 道同时命中）
- 水波寿命 10~12 tick，**明显短于**老光柱 ✓
- 零向量朝向不炸（给一个合法默认值 ✓）

`WaterMagicGameTests` 两条 GameTest 跟着改成新设计：

`gateVolleySpawnsOneLancePerPortalOnlyAfterCharging`（触发后先只有阵、一道水波都没有 ✓；
推够 tick 之后**同一刻**出现 6 道 ✓）。

## 5. 还没实机看

本轮**没进客户端**。要试玩确认的四点：

1. **法阵美不美**：现在是"三环 + 3/6 根辐条 + 阵心一点"，半径 0.62~0.92 格围绕在 1.95~2.75 格的环上
   —— 想要更华丽就把 `TNWaterGateRenderer.seal` 里换成 `WaterGeometry.staticSeal`（贵 ✗）；
2. **齐射够不够"齐"**：现在是同一 tick 生成 6/8 道水波 ✓，如果看着像"逐道"，
   把 `WaterGateRules.APPEAR_STAGGER` 调小、`CHARGE_TICKS` 调大；
3. **伤害**：单道 4 / 7、齐射 6~8 道 ⇒ 一轮 t4 约 24、t5 约 48~56 + 收尾 14。
   嫌高/嫌低只改 `lanceDamage` 一个数 ✓；
4. **20 秒是不是太长**：`GATE_TICKS` 一个数 ✓（400 tick）。
