# 衍的处决时钟 → 水墨法阵表盘（第二版：亮墨 + 毛笔指针）— 2026-11-15

作者原话（按顺序）：

> ①「玩家被衍处决了之后不是屏幕会出现时钟吗，你把那个时钟换成就是我们之前水墨法阵，旋转，然后给那个水墨法阵加上分针时针啥的」
>
> ②「时针分针一点水墨感都没有，然后不用这个白色圆盘」

## 1. 原来是什么

`world/yan/YanPrologueDefeatClient.clock(RenderGuiEvent.Pre)`：处决演出到 `CLOCK_START`（第 84 tick）时
在屏幕中央画一个**纯 GUI 手搓的钟** —— 60 个 `gui.fill` 小方块当刻度 + 两根金色矩形指针（倒着转）。
和本作的笔墨语言没有关系 ✗。

## 2. 第一版（被作者否掉的）

宣纸白盘 + 墨色漩涡阵 + 矩形指针 ⇒ 作者：「时针分针一点水墨感都没有，然后不用这个白色圆盘」✗。

## 3. 现在（第二版）

| 层 | 内容 |
| --- | --- |
| 背景 | 只把画面压暗（`0x07050b`）—— **不再有白盘** ✗ |
| ① 亮墨漩涡阵（外层） | 墨系那张 `ink_vortex_seal.png` 的**亮墨版** → `textures/gui/ink_clock_seal.png`（512²），**慢慢转** 0.9°/tick |
| ② 亮墨漩涡阵（内层） | 同一个阵：反向 −1.45°/tick、0.66 倍大、更淡 ⇒ 墨在水里化开 ✓ |
| ③ 时针 / 分针 | **毛笔笔锋贴图**（`ink_clock_hand_hour/minute.png`）：起笔粗、收笔尖、边缘不齐、几道飞白 ✓；倒着转 ✓ |
| ④ 轴心 | 一点朱红 + 金点 ⇒ 像盖在画上的印 ✓ |

### 3.1 为什么是"亮墨"

原图是**黑墨** ✗ —— 处决画面本来就暗，黑墨贴上去等于没画 ✗；作者又不要白盘 ✗
⇒ 唯一的路是**让墨自己发光**：生成器把原图按"暗度"转成月白、**纸白的地方直接透明** ✓。
（只反相 RGB 是不够的 ✗：原图的亮部会变成黑块，盖在暗画面上就是几坨黑斑 ✗。）

### 3.2 为什么指针要贴图

`gui.fill` 画的是**矩形**：直边、方头、粗细不变 ✗ —— 一点毛笔的感觉都没有（作者第二版的原话）✗。
新贴图是程序生成的**笔锋**：宽度按 `t^1.6` 收、边缘 ±6% 抖动、7~9 道飞白断口、
笔尖最后 4px 再收一次、外加一层高斯模糊当"湿笔洇开" ✓。

指针渲染时叠两遍：
1. **淡边**（放宽 1.25 倍、原色、alpha×0.45）—— 既是湿笔的洇边，也是**暗底上的轮廓** ✓；
2. **浓墨本体**（贴图是月白的，用 `setShaderColor(0.24,0.20,0.18,α)` 乘成浓墨 ✓）——
   不压暗的话，白笔锋压在亮墨阵上会糊成一片 ✗。

## 4. 数值都在 `YanPrologueClockRules`

| 常量 | 值 |
| --- | --- |
| `outerTurn(t)` / `innerTurn(t)` | `t × 0.9°` / `-t × 1.45°` |
| `OUTER_ALPHA` / `OUTER_SCALE` | 0.92 / 1.0 |
| `INNER_SCALE` / `INNER_ALPHA` | 0.66 / 0.46 |
| `hourAngle(t)` / `minuteAngle(t)` | `60 − t²×0.19` / `158 − t²×0.9`（都倒着走 ✓） |
| `HOUR_LENGTH` / `MINUTE_LENGTH` | 56 / 88（GUI 单位） |
| `DIAL_RADIUS` | 92 |

生成器：`tools/gen_prologue_clock_ink.py`（亮墨阵 + 两支笔锋，一次出三张 ✓）。

## 5. 验证

`YanPrologueClockTest`（5 条）：

1. **亮墨**：不透明像素平均亮度 > 200 ✓，覆盖率 15%~85% ✓（既是墨、又不是一整块盘 ✗）；
2. **指针是笔锋**：从根部到笔尖的覆盖率必须掉到 < 根部的 55% ✓（矩形不会变窄 ⇒ 这条会红 ✗），且够亮 ✓；
3. 阵在转：外层单调、两秒 12~90°，内层反向且更快 ✓；
4. 指针倒着走：角度随时间减小、分针比时针快、两秒时针 >60° ✓；
5. 出图：`build/prologue_clock_face.png`（t = 0/1/2 秒三帧：暗底 + 亮墨 + 毛笔指针 ✓）。

全量 `test` **全绿**（15:28）。预览：`docs/previews/yan-prologue-clock-20261115.png`
