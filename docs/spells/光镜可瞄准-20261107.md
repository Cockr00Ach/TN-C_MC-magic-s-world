# 光镜变成"能瞄准的东西"（光线 t4/t5 才落得到它身上）— 2026-11-07

作者原话：

> 然后那个镜子要把它弄成可以瞄准的东西嘞，不然光线t4t5砸不到它身上

## 1. 为什么原来砸不到

分光逻辑本身是**通的**：

- `TNLightBeamEntity.tick` 每 tick（`STYLE_DESCENT` 是**每 tick**，其它样式首 tick 一次）调 `interactMirrors()`；
- 它用 `LightMirrorRules.intersects(from, end, mirror.opticalBounds(), radius())` 做**纯几何**判定 ✓；
- 命中就按 `LightMirrorRules.split(axis, tier)` 扇出 `STYLE_REFRACTED` 子光柱（t4/t5 的 descent 那一路还会
  `sixDirections` + `discard()` 把镜子打碎 ✓）。

所以"砸不到"不是分光的锅，是**落点**的锅 ✗：

- **t1~t3**（`castForward`）从眼睛直射 ✓ —— 准星对上镜子，光柱自然穿过去 ✓；
- **t4/t5** 走 `castSky`：天阵开在**准星落点**上，落点来自 `aimPoint(caster, reach)` =
  **准星打到的方块面**（或高度图）⇒ 浮在空中的光镜**不在那条竖线上** ✗，柱子从旁边一米落下去 ✗。
  而且 `ServerPlayer` 那条路 `targets` 恒为空（不给玩家做实体索敌），连"落在敌人脚下"都帮不上忙 ✗。

## 2. 改法：新增 `light/LightMirrorAim`

```java
public static TNLightMirrorEntity pick(Level level, LivingEntity caster);   // 准星瞄着的那面镜子
public static int nearest(Vec3 eye, Vec3 look, List<AABB> boxes,
                          double reach, double cosLimit, double padding);   // 纯几何，单测直接跑
```

挑镜子的四条规则：

1. **只认自己的、活着的**（`mirror.belongsTo(caster)` ✓）—— 别人的镜子不该被你的天阵点亮 ✗
   （`interactMirrors` 那侧也是这么判的 ✓，两边一致才不会"瞄上了却不分光" ✗）；
2. **视线锥 20°**（`COS_LIMIT = cos(20°)`）：光镜是薄片，锥太小很难对上 ✗；
3. **靶子盒子 = `opticalBounds()` 外扩 0.45 格**（1.8×2.4×1.8 的"光路盒子"，不是那 1 格碰撞盒 ✓）——
   瞄准和分光用**同一个盒子** ✓；
4. **沿视线最先碰到的那面** + 一次方块遮挡 `level.clip(eye, center)` ✓（隔着墙瞄不到 ✓）。
   距离上限 `REACH = 48` 格。

## 3. `castSky` 里的接入（唯一改动点）

```java
TNLightMirrorEntity prism = LightMirrorAim.pick(level, caster);
List<Vec3> spots;
if (prism != null) {
    spots = List.of(prism.center());            // ★ 只落一列，正对镜子
} else {
    ... 原来的 spreadSpots(wanted, fallback, spell.circles(), ...)   // 一个字没动
}
...
double ground = prism != null ? prism.getY() : groundY(level, at);  // 浮空的镜子也保证柱子在它头顶
```

**为什么"只落一列"**：t5 会撒 5 根 27 格宽的柱子 ✓，每根再被镜子分成 6 道 ✗ ⇒ 30 道同时出现，
画面直接糊掉 ✗。瞄着光镜时按"一次精准打击"处理：1 根柱子落下来，被镜子接住 → 分光 ✓。
（阵、音效、`SKY_DELAY=20` 的读秒、`STYLE_DESCENT` 每 tick 判定全部照旧 ✓。）
玩家提示里也会多一句"瞄中光镜 ⇒ 只落一列" ✓。

另外给 `TNLightMirrorEntity` 补了

```java
@Override public float getPickRadius() { return 1.1F; }
```

—— 光镜是 `noPhysics` 的薄片，碰撞盒只有 1 格，原版拾取要正好戳中那 1 格才中 ✗；
放到 1.1 格之后"看着它就能选中" ✓（准星高亮、左右键交互都好用了 ✓）。
**不动 `getBoundingBox()`** ✗：`LightMirrorSpells.cast` 用 `mirror.getBoundingBox()` 做放置时的
`noCollision` 检查，放大它会开始在墙里/别人身上摆镜子 ✗。

## 4. 验证

`LightMirrorAimTest`（6 条，纯几何 ✓ 不需要起 Level）：

| 用例 | 断言 |
| --- | --- |
| 正前方一面 | 选中 ✓ |
| 背后 / 侧面 60° / 80 格外 | 都不选中 ✓ |
| 一排三面（20 / 6 / 12 格） | 选**最近**那面 ✓（挡在前面的要先分光） |
| 近处偏 40° + 远处正中 | 选**远处**那面 ✓（锥外的近镜子不该挡住锥内的） |
| 擦边 0.12 格 / 偏离 1.8 格 | 前者算命中 ✓、后者不算 ✓ |
| 空列表 / 零视线 | 返回 −1，不炸 ✓ |

全量 `cleanTest test`：**860 用例全绿**（17:01）。

## 5. 还没实机看

- **锥度 20°** 是否太宽/太窄（`LightMirrorAim.COS_LIMIT` 一处改 ✓）；
- 瞄中镜子时"只落一列"够不够爽（t5 想多落几根就改 `castSky` 里的 `spots`，但上面写了为什么只落一列）；
- 光镜在**天花板/脚下**时：竖着落的光柱碰不到脚边平躺的镜子 —— 那是几何限制（t4/t5 本来就是
  从天上竖直落），要打脚边的镜子请用 t1~t3（直射 ✓）。
