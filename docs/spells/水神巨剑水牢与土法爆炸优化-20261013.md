# 水神巨剑、水牢与土法爆炸优化

水神的冥穴中央巨剑改为注册烘焙实体模型：蓝水晶剑身、金色护手与刃侧、珍珠白发光脊，保持 64 格巨剑和原落剑伤害时间表。模型坐标归一化到原版允许范围，再由渲染器恢复尺寸。

水牢 T1–T4 水板增加蓝金纹理、边框和立体符文。海浪斩击改为尖端渐细的分层刃面、亮切边和克制的水流尾迹。

土系投射物增加棕色尘尾与环绕碎石；万岩突齐射后在目标地面升出巨大岩刺，地面由向下碰撞射线定位。巨刺达到地表时命中并短暂保留实体外形。土球爆炸增加土尘云、方块碎屑、径向粒子、18 块飞散实体碎石、爆炸声和衰减镜头震动。高空土球的爆炸实体位置同步到地面伤害中心。

土神枪仍保留五倍尺寸，改为敌人上方 55 格显现，停留 20 tick 再瞬间下砸；准星附近可见敌人允许宽容锁定，高空枪使用发光渲染。
