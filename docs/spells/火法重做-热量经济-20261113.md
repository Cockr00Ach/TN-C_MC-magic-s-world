# 火法重做：热量经济（2026-11-13）

> 作者：「重做所有火法，做点创新的」「加一条火手链：从敌人脚下伸出一只燃烧的巨手，狠狠捏爆，
> 爆炸特效按敌人身上的热量决定」「让我感觉火的力量感极强，非常疯狂和炽热」

## 1. 核心：热量（`FireHeat`）

| 项 | 数值 |
| --- | --- |
| 上限 / 燃点 / 过燃 | 100 / 60 / 100 |
| 燃点效果 | 自燃 + 受到火系伤害 ×1.25 |
| 过燃 | 当场自爆：每点热量 0.22 伤害，半径 3.5，按距离衰减 |
| 衰减 | 每秒 8（不追着打就凉） |
| 叠热入口 | `TNScorch.apply`（每次火系命中都会走这里）|
| 反馈 | 动作栏 `热量 62 / 100`，到燃点变 `燃点` |

## 2. 四条链的分工

| 链 | 干什么 | 伤害来源 |
| --- | --- | --- |
| 点火（原射线链 5 档） | 攒热：火星 / 燃痕 / 焚风 / 炎狱 / 天火 | **很低**，主要叠热 |
| 引爆（原火球链 5 档） | 花热：爆燃 / 连爆 / 火种 / 熔核 / 殉爆 | **热量 × 2.2~2.6** |
| 燃烧形态（原燃烧链 5 档） | 以伤换伤（暂未重做） | 火伤加成 |
| 火手（新增 5 档） | 抓住并捏爆，爆炸按热量放大 | 档位 + 热量 |

点火链各档的叠热量：火星 +12、燃痕 +10、焚风 +14、炎狱 4×10、天火 +45（24 格全体）。
引爆链：爆燃 `热量×2.2`（保底 8）、连爆炸 `×2.5` 并把一半热量传给周围、
火种 3 秒后炸（按埋下时的热量）、熔核拆成三颗、殉爆 24 格内全体引爆（血量越低自身燃料越高）。

## 3. 火手链（新增）

`TNFlameHandEntity` + `TNFireHands` + `FireHandRenderer`：

- 阶段：破土 → 张爪 → 依次收拢 → 三下捏（36/46/56 tick）→ 炸开（62 tick）
- 抓取期间每 tick 把目标按在掌心；第三下捏泼岩浆；炸开半径 `2.4 + 0.55×档 + 热量×0.006`
- 渲染：整体 alpha .62 的**虚影** + `RenderType.lightning()` 自发光；
  `ghostFade(y)` 让**贴地处淡出**（0.75 格内 → .02），手臂没有断口；
  目标在天上时额外画一根**火柱**（`pillar()`）
- 几何：17 段骨骼现场生成，指管用 Catmull-Rom + 半径剖面自己鼓关节（不挂球）
- 力量感：每捏一下抖屏 `2.5+1.4×档`、冲击波、岩浆；炸开 `5+2.2×档` + 雷声；
  渲染层 `crushPulse()` 让火光与捏的节拍同步（峰值 ×1.55）
