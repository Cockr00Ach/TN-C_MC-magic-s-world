# 暗线齐射与土法分阶段实体施法（2026-10-13）

## 暗法

黑夜之手撤回逐只延迟释放，所有槽位同时启动。普通手仍使用按模型尺寸分开的起点；每只手的管线通过同步槽位编号获得不同的左右偏转、上抬/下垂及弯曲幅度，不再共用一个弧度。保留原手实体模型和无阵设定。

以伤换伤停止调用红色粒子串，改为黑色手臂线同一网格结构的红色实体管线。双方身体位置按客户端插值，沿线明暗脉冲从敌人流向施法者。仍按 T1–T5 每目标 1–5 股，沿用范围和目标数规则。管线剔除盒覆盖双方，避免敌人在屏幕外时连接线消失。旧吸血结算、血盈与回魔逻辑保留。

## 土法

| --- | --- |
| 土弹 T1/T2 | 原弹体模型缩放乘二 |

| 岩神枪 T5 | 瞄准敌人上方三十六格显形一支巨大尖岩枪；短暂显形后在一个 tick 内完成砸落 |

| 岩突 T3 | 前方六根更大的尖土刺 |
| 大地之裂 T4 | 六个方向，每个方向六根岩突；尺寸再次放大 |
| 震星 T5 | 敌人脚下同时五根巨大尖刺；上方形成土球，周围实体土块向球汇聚，随后爆炸 |

新增独立模型 `earth_spear_sharp` 与 `earth_spike_sharp`，分别沿 Z/Y 轴收尖；使用 Minecraft 石材贴图。模型注册统一走普通资源 ID，十二个目标模型均进入直接烘焙通道。土系模型 UV 限制在单块纹理范围，避免长模型默认 UV 取样越过材质区域。

分阶段土法由 `EarthAttackEntity` 负责等待、运动、碰撞、一次伤害及清理；服务器使用原土法伤害系数和 Earth 学派伤害源。新连发、十枪和突刺数量会改变整次释放的攻击次数与总伤害。旧引擎重复投射/云伤害入口撤下，避免二次结算。费用、冷却、等级及学派字段逐项审计不变。

土球伤害中心与高处展示中心分开，保证空中爆炸仍能命中地面目标。爆炸有声音和粒子，但不调用删除方块的世界爆炸。实体均有有限生命周期；施法者失效时取消。地表起伏和视角震动是视觉表现，不改动永久方块状态。

## 风法

撤掉高阶解锁即永久飞行的条件，飞行许可只取有效施法状态和既有光翼状态；T4 风速 III 在有效期间允许飞行，到期撤销。删除每秒补发常驻风速展示实体的调用，以及展示实体因解锁进度获得无限生命周期的分支。不再生成风速链的持续程序螺旋展示；保留有限状态期间的粒子表现。

龙卷风继续使用原 `TNTornadoRenderer`、32 个模型元素的 `wind_tornado.json` 和原贴图，三项资源在打包时逐字节确认保持不变。实体追加客户端到期清理兜底，保留服务端 T3/T4/T5 的 8/12/16 秒寿命。当前实例上一轮真实资源日志曾确认十个模型烘焙 10/10；新尖枪/土刺加入后检查目标为十二个，需重新启动客户端取得新的实测记录。
