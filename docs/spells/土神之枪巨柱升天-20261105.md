# 土神的枪：细柱命中 + 巨柱升天

日期：2026-11-05（第三轮土法表现）

## 问题

- 旧实现（`earth_god_spear`，tier 5，mode 3）是从目标上方 55 格砸下一根 25 倍放大、70 格高的 `earth_spear_sharp`。
- 它走 `EarthAttackRenderer.renderSkySpear`：直接用**方块图集**（`TextureAtlas.LOCATION_BLOCKS`）绘制 `projectile/` 模型，而这类模型平时由 `CustomModels` 用独立贴图管线渲染。两条管线不一致时就会出现贴图错位/紫黑/穿插，观感上就是“枪老是显示有问题”。
- 同时土系整体以尘团和小碎石为主，缺少“大地被掀起来”的重量感。

## 新表现

1. **细土柱射出**：`earth_pillar` 沿飞行方向拉长（宽 0.42、长 3.4），从施法者眼睛射出，带尘尾；模型原本是竖的，渲染时先绕 X 轴 +90° 立到 +Z 飞行轴上。

   > 2026-11-05 20:03 起，tier 5 的飞行体已改为 5 把石化武器随机之一（长 5.2、宽 2.4 倍缩放），见[土法石化武器](土法石化武器-20261105.md)；`earth_pillar` 仍用于巨柱本体与部分小岩柱。
2. **命中生成巨柱**：爆点地面升起 mode 8 巨柱，45 tick（约 2.25 秒）升到 **96 格**；柱顶托着被命中的目标一起上天，半径 2.6 格内的敌人都会被带走。
3. **命中瞬间**：屏幕尘幕（棕色低透明覆盖）、FOV 内收 7%、镜头震动、柱脚尘环与高空碎石雨；升到顶时 24 点石屑炸开；再 40 tick 后整根柱崩解成石块粒子。
4. **普通土爆**：额外一圈尘墙 + 高空落石，爆炸有明确边界，不再只是中心一团尘。

## 实现

- `EarthAttackEntity`：新增 `LAUNCH` 同步位与 mode 8；托举期间每 tick 用 `EarthLaunchLayout.top()` 计算柱顶，并把 `lift()` 作为目标上升速度，避免目标从柱顶滑落；`clientFx` 沿整根柱撒尘。
- `EarthLaunchLayout`（纯数学）：`grow`（smoothstep）、`top(age,height)`、`lift(age,height)`；45 tick 到顶，最高 96 格。
- `EarthAttackMechanics`：tier 5 改为 mode 0 `earth_pillar` + `setLaunch(true)`；`spawn` 返回实体以便打标记。
- `EarthAttackRenderer`：mode 8 逐段堆叠 `earth_pillar`（3.2 格/段，最多 30 段）+ 顶部 5 根碎冠 + 底部 6 块碎岩；细柱按 +Y 轴向修正。
- `EarthTremorClient`：mode 8 持续震屏、起步 FOV 冲击、屏幕尘幕；巨型土核爆炸同样给短促冲击。
- 表现层约束不变：`LightEmission.NONE`、纯客户端粒子、不改地形/碰撞；伤害仍由原有 `hit()` 结算。

## 参考

- **光法**：`TNSpellClientVisuals` 的整屏 flash、FOV、相机抖动分层（`pulseFlash`、`onComputeCameraAngles`、`onComputeFov`）。
- **雷法**：`TNLightningStrikeRenderer` 的分层几何 + billboard 闪光 + 近距离屏幕闪烁，说明“大体积 + 屏幕层”比单纯粒子更震。
- **外部检索**：DeepSeek 搜索后端缺少 API key；Bing 中文/英文查询被地域重定向到“地球/词典”等无关结果（`https://cn.bing.com/search?q=...`），没有拿到可引用的外部方案。因此本轮方案来自项目内光/雷实现与动作游戏通用手法，未使用未核实的来源。

## 限制

- 巨柱是纯视觉，不改变地形；目标落回时按原版摔落伤害结算。
- 目标在柱顶仍可自由移动，离开半径会掉队。
- 96 格高度在低渲染距离/浓雾下可能被裁剪；culling box 已按柱高扩大。
