## 一、水缚链（`WaterFx.bindFx`）

粒子**长在客户端那个笼子上**（照抄 `TNWaterFieldRenderer` kind==2 的公式 ✗），不是在笼子旁边乱撒 ✗：

- **三道环**：`y = .12 + height*i/2` ✓ 与客户端同一条公式 ✓
  - t1/t2 只是"绑住" ⇒ 粒子**向内收**（速度 `-.14`）✓
  - t3 起服务端真的会把敌人往里拉 ⇒ 粒子**也跟着向内**（`-.24`）✓ —— 表现与机制同向 ✗
- **立柱顶端水冠** + t2 起沿柱身落下的水（`RAIN`）✓
- **t3 水葬起**：底部 `BUBBLE_COLUMN_UP` 往上冒泡 ✓（"淹"的感觉 ✗）
- **t4 深渊起**：贴地一圈深色 `SQUID_INK` 墨花 ✓（深渊=深海黑水 ✗）
- **t5 冥穴**：`CURRENT_DOWN` 从高处往下灌 ✓ + 环上 `GLOW` 亮星 ✗

节流：整体 `age % 2 != 0` 直接 return ✓；环上点数 t1–t3 用 8、t4/t5 用 12 ✓。

## 二、冥穴落剑冲击（`WaterFx.cryptImpact`）

**这一处是本批最该补的** ✓ —— 原来看不出"剑砸下来了" ✗。

- 由 `lastSwordImpact` 去重 ⇒ **一剑一次** ✓（不是每帧 ✗）
- 内容：贴地浪冠（`crown`，18 点沿地面向外翻 ✓）+ 44 点 `SPLASH` + 20 点 `BUBBLE`
  + 16 点 `SQUID_INK` + 12 点 `CLOUD` + 10 点 `END_ROD` ✓
- 第一剑（`index==0`）额外一记 `FLASH` ✓
- 落剑前的两下提示（`cryptCue`）也补了：出现时 64 格高处炸一圈、下坠时从 64 格往下淌 ✓
  —— 由 `SeaGodSwordRules.cue` 保证一次一发 ✓

**没动**：8 次落剑的时刻（140 + k*60 ✓）、每剑 60 伤害 ✓、领域 26 格 ✓、64 格巨剑 ✓。

- **雨幕**：雨是**体积**不是细线 ⇒ 直接用 `puff` 随机填充 ✓

- **t5 天洪天空法阵**（`skySeal`）✓ —— **本次点名要补的另一处** ✓
