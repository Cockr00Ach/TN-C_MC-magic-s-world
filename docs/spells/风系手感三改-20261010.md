## 一、风刃：龙卷风 → 月牙斩击（`tools/gen_wind_blade_model.py`）

**作者**：「这个风刃可以抄一下水法的**海浪斩击**」✓
水法的 `tnc:wave_slash` 是**月牙／斩击**造型（`docs/spells/water-magic-feedback-20260928.md`：
"向八个方向发射更大、更高速的**月牙斩击**……波刃增加水体厚度、白色浪沫与闪光"）。

**做法**：写了一个**程序化生成器**（照 `gen_dark_hand_model.py` 的路子）✓：

```
16 个重叠方块沿 170° 圆弧排成新月
  * 径向半厚 0.30 → 1.65 单位（中段最厚，两端收到尖 ✓）
  * Z 向半深 0.28 → 1.23 单位（同样的收尖 ⇒ 读起来才像"刀"✓）
  * 旋转角 0，UV 全落在整 16 分格上（16 段 ⇒ u 步长正好 1.0，**不会花脸** ✓）
  * 包围盒 1.179 × 0.615 × 0.147 格，已居中到 (8,8,8) = 引擎 translate 的原点 ✓
```

模型号**不变**（还是 `tnc:projectile/windblade` ✓）⇒ 法术 JSON、`TNProjectileModels`、
以及"五档 scale 0.5/0.7/0.9/1.2/1.4"**一个字都不用改** ✓ ⇒ 风刃宽 **0.59 → 1.65 格** ✓。

**顺手删掉了上一批的龙卷风资源** ✗：`windblade_1..5.png` ＋ 5 个 `.mcmeta`（10 个文件）——
它们不再被任何模型引用 ✓（现在只有一张 `spell_projectile/windblade.png`，32×16，无动画 ✓）。

> ⚠️ **纹理规格**：新贴图 32×16，上半 4 px 是**亮白的刀口**、往下渐深到青蓝 ——
> 方块模型的 UV 是 0..16 空间（不管贴图多少像素），所以 u 沿弧长铺开、v 沿厚度铺开 ✓。
> 想调形状就改生成器顶部的 `R / ARC / half_thick / half_deep` 再重跑 ✓。

## 二、风灵：粒子 → 真实体（`tnc:wind_spirit`）

**作者**：「风灵链怎么五个全是放一个围绕着玩家的小风球啊，**风灵呢**」✗ ——
说得对：那一整条链**一个实体都没有** ✗，`TNWindMechanics.tickOrbs` 每 tick 在玩家周围
`sendParticles(CLOUD)`，每 10 tick 打一下最近的敌人。**玩家看不见"风灵"，只有一团云** ✗。

### 2.1 新实体 `magic/TNWindSpiritEntity`

**为什么是 `Entity` 而不是 `Monster`**：它是**纯服务端控位置、客户端只画外观**的召唤物 ✓ ——
这正是本仓 `TNThunderOrbEntity`（环绕雷球）那条已验证的思路，`docs/法术专题_交接.md` §四
把它记作"**将来召唤线的模板**" ✓。好处：不用 AI、不吃重力、不会寻路卡住
⇒ 行为**完全可预期**（不会因为它自己乱飞而"看起来不像在护主" ✗）。

| 项 | 值 | 说明 |
|---|---|---|
| 行为 | 绕主人转（半径 **1.9 格** / 高度 **1.15 格** / 一圈 **80 tick**） | 比雷球（6 格）贴身得多 ✓ |
| 攻击 | **每只各自**每 10 tick 打一次自己最近的敌人（5 格内），并往主人这边**拽 0.12** | ★ 见下 |
| 朝向 | 每 tick 跟着主人的 yaw | "护法"的感觉 ✓ |
| 寿命 | 主人的档位标记没了 ⇒ **自己 discard**；档号变了也**自己退场** | 维护方只需"补数量" ✓ |
| 可攻击性 | `hurt()` 恒返回 false ＋ invulnerable | 它不是战斗单位 ✓ |

★ **顺手修掉一个旧毛病**：老代码是"一轮只打一个然后 `break`" ✗ ⇒ **球数纯粹是装饰**，
多两个球一点伤害都不多 ✗。现在是**每只各打各的** ⇒ "只数多"终于是真的"伤害更高" ✓。

## 三、脚下风环（"踩在风上"）

**作者**：「风速不是后面可以飞吗，我希望**释放风速之后玩家的脚下一直有风在绕**，感觉踩在风上」✓

`TNWindMechanics.tickFootWind()`：

| 什么时候吹 | 只要"风给了你飞行"就吹 ✓ —— `permanentFlight`（4 级起解锁即永久）**或** `tnc:wind_flight` 标记在身（1~3 级时限飞行）✓ |
|---|---|
| **光翼链的飞行不吹** ✗ | 那是光耀链的翅膀，脚下起风会串味 —— 两者共用一个 `mayfly` 裁决点（见 `onPlayerTick` 里记的那次事故）✓ |
| 站着 | 6 颗 `cloud` 沿半径 0.48 格绕圈（相位随 tick 前进 ⇒ 看着在"绕"✓） |
| 每 4 tick | 补一道 `sweep_attack`（**原版那道"挥砍的弧"** ✓ —— 只靠 cloud 像烟，加它才像风 ✓） |
| 真飞起来 | 环加密到 10 颗、半径 0.62，**再加向上的 `end_rod` 白点**（"风往上托" ✓） |

> ⚠️ **实现上有个坑记一下** ✗：`tickFootWind` 必须调用在 `onPlayerTick` 的**早退之前** ——
> 那段"状态没变就 return"会**把每 tick 的视觉一起吃掉** ✗（加在末尾 = 看不到效果）。
> 开销：站着 6 颗/tick、飞着 10 颗/tick，和原来的绕身球同量级 ✓。
