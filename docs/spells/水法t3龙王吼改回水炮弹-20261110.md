# 水球链 t3「龙王吼」改回"水炮弹弹幕"版 — 2026-11-10

作者原话：

> 然后把 t3 改回不是蓝金水渊兽的版本

## 1. 两天前 t3 变成了什么

2026-11-06/07 那两轮把水球链 t3「龙王吼」改成了**一段过场动画**：
唤出蓝金水渊兽的虚影冲过去 → 咬住目标 → 带着它升空 → 化成巨剑虚影砸地，
附带的还有 `WaterRestraints`（临时搬运目标）和 `DragonRoarRules`（时间线常量）。

那一套现在**整块删掉** ✓：

| 删掉的 | 原来干什么 |
| --- | --- |
| `magic/water/DragonRoarCombo.java` | 咬住 → 升空 → 砸地 的状态机 |
| `magic/water/DragonRoarRules.java` | 上面的时间线常量（BITE / IMPACT / END / height） |
| `client/DragonRoarVisual.java` | 水渊兽虚影 + 巨剑虚影的渲染 |

`TNWaterSpellEntity` 里那句 `if(tier()==3 && !BOSS_CAST) roarCombo.tick(...)` 也删了
⇒ **玩家和 Boss 现在走同一段 t3 逻辑** ✓（Boss 那版本来就是下面这套，一点没变 ✓）。

## 2. 现在是哪一版

回到 2026-10 那版 —— 作者当初描述的「龙王吼」：

> 在身后展开竖直水色法阵，持续 10 秒连续射出 150 枚单体水炮弹。

- 施法时在身前展开一张**阵**（`richCircle`，t3 的阵半径 4 格）；
- 之后每 4 tick 从阵面**螺旋喷出 3 发水炮弹**（`TNWaterBoltEntity`，带弹道、会追踪准星锁到的目标 ✓）；
- 10 秒共 50 轮 × 3 = **150 发**；
- 阵面每轮补一圈水花（`WaterFx.sigil`）＋ 阵口喷发（`WaterFx.muzzle`）；
- `TNWaterSpellEntity.length()` 在 t3 恒为 0 ⇒ 那根"光柱"根本不会画 ✓，屏幕上只有阵 + 弹幕。

文案（`zh_cn` / `en_us`）也改回来了 ✓：
「在身后展开竖直水色法阵，持续 10 秒连续射出 150 枚单体水炮弹。」

## 3. 没有跟着删的东西（它们不只服务 t3）

| 类 | 现在还有谁用 |
| --- | --- |
| `WaterRestraints` | **t5 水缚链**（水牢/水葬/冥穴把人锁住）✓ |
| `SeaGodSwordVisuals` | **t5 水缚链**的冥穴天降巨剑 ✓ |
| `LeviathanGhostVisual` | **读条前戏**（`WaterCastFx`：读条时从门里飞出的水渊兽残影 ✓，作者 2026-11-06 要的） |
| `WaterSpellRules.canRestrain / segmentDistanceSquared` 等 | 判定直方图的公用件 ✓ |

也就是说：**t3 不再出现水渊兽** ✗，但"读条前戏里那只小的"和"t5 冥穴的巨剑"都还在 ✓
（作者这次只说 t3 ✗）。
