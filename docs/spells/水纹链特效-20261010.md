## 零、一句话

水纹链原来**只有几何、一颗粒子都没有** ✗（水纹是三层地面环、水波/海啸是一张卷浪、
斩击是 26 片薄刃、灭世之海是 360° 卷浪波前 ✗），而且只有 alpha 混合 ⇒ 不会发光 ✗。
本批：**粒子长在浪上** ✅ ＋ **浪唇/环边加一层加色发光** ✅。

**这一链的粒子没有"随手撒"** ✗ —— 位置全部照抄客户端画的那条曲线 ✓：

| 档 | 粒子位置来自 |
|---|---|
| 1 水纹 | 客户端那三层地面环的 `r = age*.2 + i*.3` 公式 ✓ |
| 2 水波 / 4 海啸 | `WaterWaveVisuals.rollingWave` 的卷浪 `profile()` 剖面（浪唇 j=1）✓ |
| 3 海浪斩击 | `WaterWaveVisuals.crescent` 的薄刃弧（±0.55π）✓ |
| 5 灭世之海 | `OceanWaveRules` 的**服务端共享浪前剖面**（`frontRadius` / `profileRadius` / `profileHeight` / `waveLift`）✓ |

所以看上去是"**浪把水花甩出来**"，而不是"浪旁边有一团粒子" ✗。
