## 一、手：不转了／掌心朝前／不再黏成一团／没有黑带

作者原话：
> 「手发射出去怎么一直在旋转，**掌心直直出去**就好，然后**三个手掌黏在一起很丑**，
> 抓住敌人手再把敌人拉回来可以不」
> 「**黑带很怪**，要那种**从我的后背伸出来**的感觉不是黑雾，可以做一个**黑线连接着手腕跟后背**，
> 不过这个雾很适合放在黑雾那边」

| 问题 | 真因 | 改法 |
|---|---|---|
| **一直在转** | 上一轮用的是 `TOWARDS_CAMERA` —— 它是"**朝相机偏航**"⇒ 手飞过去时相机与它的相对角一直变，看起来就在转 ✗ | 改成 **`ALONG_MOTION` ＋ `rotate_degrees_offset: 0`**：把模型 +Z 锁到**飞行方向**上 ⇒ 相对弹道固定，**不转** ✓ |
| **掌心要朝前** | 旧模型是"掌心朝下、手指朝前" | 模型重做成**掌心朝 +Z 的平板**（Z 只有 0.56 格厚，掌面 1.38 × 1.62 格）⇒ 配 `ALONG_MOTION` 就是**掌心直直朝前** ✓ |
| **三个手掌黏一起** | 三只手做在**同一个模型**里、绕 Z 轴各转 26° ⇒ 掌心互相穿插 ✗ | 模型里**只放一只手**；"好几只手"改由引擎**多发**（`extra_launch_count: 2` ＋ `extra_launch_delay: 5`）⇒ 三只**沿弹道错开约 2.7 格** ✓ |
| **黑带很怪** | 那条粗黑带**烤进了模型**，长度固定 ⇒ 手飞远了够不到施法者、近了又穿进他身体 ✗ | 模型里的黑带**删掉** ✓；改由 `TNDarkHandCord` **每 tick 按"后背 → 当前手位置"重算**一条**黑索** ✓ |

### 黑索（`TNDarkHandCord`）

- 只认 `group == dark_hand` 的手，且 `getOwner() == 该玩家` ✓（别人的手不画）；
- 线段两端：**施法者后背**（沿视线反方向外移 0.45 格、身高 65% 处）→ **手当前位置**；
- 沿线段等距撒 `squid_ink`（间距 **0.35 格**、**零扩散**、每点 1 颗）⇒ **绷紧的一条黑线** ✓；
- 为什么不用真正的几何线：那要自己写世界空间渲染（`RenderLevelStageEvent` ＋ 自建 RenderType），
  风险与工作量都大得多 ✗；密到 0.35 格的粒子本来就成线 ✓。
- ⚠ 卡就把 `SPACING` 调大 / `MAX_POINTS` 调小 ✓。

### 尺寸指标跟着改

模型变成"掌心平板"后，**沿飞行轴（Z）只有 0.56 格** ⇒ 原来按 Z 算"长度"会得出 ~57 倍的荒唐 scale ✗。
`gen_dark_hand_scales.py` 改成用**三个跨度的最大值**当尺寸 ⇒ 仍是
**1.6 / 3.2 / 8 / 16 / 32 格** ✓（scale 0.98 / 1.97 / 4.92 / 9.85 / 19.69）。

## 三、以伤换伤索敌：改成"玩家瞄住谁就锁谁"

作者原话：
> 「可以有血爪，但是我想要那个就是**我瞄敌人敌人身上会高亮**的那种索敌释放，
> **不是范围我直接开技能然后他自己去找敌人**，是要**玩家瞄住敌人**的那种，
> 有点像**雷击的那种瞄**」

### 为什么不能"没瞄中就不让放"

引擎的 `CombatEvents.SPELL_CAST` 是**只能通知、不能取消**的
（`Event<T>` 只有 `register/invoke`，javap 确认 ✗）⇒ 拦不住施法 ✓。

### 实际做法（`TNDarkAimMechanics`）

| 环节 | 做法 |
|---|---|
| **找谁** | 施法那一刻用**准星射线** `player.pick(32, 0, false)`（**就是雷击 t3 用的那套** ✓）|
| **锁定** | 射到 `EntityHitResult` 的活体敌人才锁定 ✓；射到方块/空气 ⇒ **不锁定** ⇒ 血爪没有追踪目标 ⇒ 效果上就是"没瞄准就抓不到人" ✓ |
| **高亮** | 原版**发光描边** `setGlowingTag(true)`（同步字段 ⇒ 服务端一设**所有客户端**都看得到 ✓，不用自己写渲染 ✓）|
| **追我锁的那只** | `SpellProjectile.setFollowedTarget(Entity)`（javap 确认存在 ✓）⇒ 引擎只追这一只，而不是"最近的敌人" ✓ |
| **瞄准期间就亮** | 拿着法杖（`TNMod.WAND` 或 `ElementWands.Wand`，与 `SpellEngineBridge` 同一套判定）时，
每 tick 射线一次并续高亮 ⇒ 松手约半秒后灭 ✓ |
| **过期清理** | 高亮有到期时间，不用的话满地图的怪会一直亮 ✗ |

**并把引擎的"自动找敌人"调小** ✓：`homing_angle` 0.41~0.65 → **0.19~0.31**
（它原来的语义就是"自己去找最近的敌人" ✗）。⚠ 要**完全**不自动追就把这五个值改成 0.0 ✓。
