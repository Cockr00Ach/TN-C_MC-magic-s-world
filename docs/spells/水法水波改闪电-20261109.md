# 水球链 t4/t5 的「水波」换成闪电 — 2026-11-09

作者原话：

> 你来改改水法的水球那个链的 t4 t5 不是射出一道水波吗，你去看一下闪电，一根直直的闪电像不像水波嘞，
> 然后你把这个闪电加粗加大到跟水波一样，替换一下看看效果

一次**纯表现替换**：光柱的判定 / 伤害 / 破坏半径 / 范围 / 时长**一个数都没动** ✗。

## 1. 换的是什么

| | 换之前 | 换之后 |
| --- | --- | --- |
| 外形 | 真 3D 水管（外壁 tube + 中轴细管 + 缠绕水流线 + 每 8/16 格一圈水环 + 末端圆盘） | 雷系那套**加色光带**（外辉光 / 主色 / 白芯三层 ✓，配色换成本系的蓝） |
| 代码 | `WaterBeamVisuals.render` 里那一串 `WaterGeometry.tube/stroke/ringColor/disk` | 同文件，改成 `LightningBoltGeometry.polyline`（和落雷、风系龙卷风同一套光带 ✓） |
| 粗细 | 半径 `WaterSpellRules.radius(tier)` = t4 **0.8** / t5 **15** 格 | 按同一个半径放大：t4 一根闪电的白芯半宽 0.68 格、主色层 ≈ 0.8 格半径 ✓ |
| 抖动 | 无 | 起伏幅度按**半径**的 0.45 倍（t4）/ 0.16~0.30 倍（t5）给 ✓ —— 作者要"直直的"✗，所以不用雷系那种"按段长抖" ✗（48 格的光束会歪成一条蛇 ✗） |

### 1.1 为什么 t5 不是"一根更粗的闪电"

光带永远是**正对镜头的平面带** ✗ —— 30 格宽的一根，就是**一堵墙** ✗（第一版就是这么试的：
`docs/previews` 里没有留，但软件光栅图里能明显看到一块平板的边缘）。

所以 t5（半径 15 格 = 30 格宽）改成**一束 10 根细闪电**（每根白芯半宽约 0.9 格），
在同一个圆截面里随机分布、各自起伏 ⇒ 远看是一根粗壮的水色光束 ✓、近看是十股缠在一起的电 ✓。
t4 半径只有 0.8 格，一根就够 ✓。

### 1.2 顺手给雷系加的一个参数（不影响雷）

`LightningBoltGeometry.boltTinted(..., double jitterScale, ...)`：新增一个重载，
1.0 = 雷系原样（老签名原样转发，落雷/雷龙/暗线/旅行形态**一个字节都没变** ✓），
0 = 完全笔直 ✓。水法这次没用它（最后走的是 `polyline` + 自己的折线），
但它是"光带能不能被非雷系复用"的那个开关，先留着 ✓。
