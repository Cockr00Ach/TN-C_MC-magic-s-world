# 领域法术第二轮：七系补齐

2026-11-08 · 作者：「可以尝试做做别的法术领域」

第一轮只做了雷和暗（见[领域法术-雷霆与暗黑-20261108.md](领域法术-雷霆与暗黑-20261108.md)），
这一轮把**另外五系**（火 / 风 / 水 / 土 / 光）按同一套骨架补齐 —— 现在七个元素各有一条领域，
规则、状态、闸门全部共用一份代码，只有"出手长什么样"不一样。

---

## 0. 三行结论

1. **七系各一条**：雷霆 / 暗黑 / 焚天 / 风神 / 深海 / 大地 / 圣光，全在魔法石「独立」页。
2. **规则没变**：一人只能选一个、只要有该系亲和力（≥1）就能学、展开 30 秒 / 冷却 90 秒 / 半径 16 格、
   战士攻击附 30%（封顶 12）元素伤害、刀光按元素变色。
3. **每系一句话**：雷＝落雷、暗＝黑雾抓手、火＝火柱点燃、风＝风刃推开、水＝水浪泡住、土＝岩刺定身、光＝烧敌人顺便给队友回血。

## 3. 代码结构（为什么加五系只花了一份代码）

```
DomainSpells      一张表：7 条 Domain(element, path, name, kind, interval, telegraph, style, damage, radius)
                  查表：of(Element) / byPath / elementOf / pathOf / nameOf / isDomain
                  状态：active(Entity) → Domain（读 7 个效果里的哪一个在生效）
DomainService     cast()：展开（关掉其它六个）
                  onPlayerTick()：按 Domain.interval() 出手 → telegraph() → resolve()
                  resolve()：switch(Domain.kind()) → 七个方法
                  onHurt()：战士附伤 + 记录「谁在被玩家/队友打」
TNEffects         domain_lightning / dark / fire / wind / water / earth / light（7 个效果）
                  + DOMAIN_EFFECTS 查表（Element → RegistryObject）
spells/*.json     7 个，只在 jar 里（数据包里**不许**再放一份）
```

- **状态用状态效果**：原版自动同步（客户端 `hasEffect` 就能读到 ⇒ 刀光变色不用发包）、自带倒计时、HUD 有图标。
- **「加 X 伤」没写新代码**：`TNSpecialMagic` 的「亲和力 ×5% → `spell_power:<school>`」本来就覆盖七系
  （雷 lightning / 火 fire / 风 air / 水 water / 土 earth / 光 healing / 暗 soul），学会领域即打开开关 ✓。
- **预警样式**：雷 11、暗 13、土 4、风 5、光 9 都有专属阵；火、水暂时用 0 号通用阵
  （靠落点周围的火/水粒子区分）—— 专属样式是下一轮的活 ✓。

## 4. 闸门

`DomainSpellTest` **8 条**（全绿）：

| 测试 | 钉的是什么 |
| --- | --- |
| `domainsSitOnTheIndependentPageWithNoElement` | 七条都在「独立」页、元素 null、不分档、path 反查一致 |
| `everyElementHasADomainAndNoElementIsLeftOut` | 元素数量 = 领域数量；间隔 ≥ 4 秒、预警 > 0 且短于间隔；阵样式至少 5 种 |
| `affinityIsTheOnlyRequirementAndYouMayOnlyPickOne` | 没亲和力拒绝 / 有 1 级能学 / 学完 special 打开 / 第二个被拒 / 遗忘可换 |
| `domainJsonMatchesTheRulesTable` | 七个 JSON 的冷却 90、exhaust 0、读条 >0、效果 id 与 group 对齐；**数据包不许重复定义** |
| `everyDomainHasItsOwnStatusEffect` | `TNEffects` 里七个效果都注册了 + 有 `DOMAIN_EFFECTS` 查表 |
| `darknessTurnsTheWarriorTrailBlackAndEveryDomainRepaintsIt` | 暗＝近黑、雷＝紫电、**七系刀光不许撞色** |
| `serviceActuallyDoesWhatTheAuthorAskedFor` | 源码扫描：预警、`visualOnly`、记忆窗、排除友军、氛围雷、黑雾、`launchFrom`、控制、附伤走 `indirectMagic` |
| `onlyOneDomainEffectCanBeOpenAtATime` | 开新领域会遍历七系把旧的关掉 |

本轮回归：`magic.*` + `warrior.*` **323 个用例 / 84 个套件全绿**（含 `SpellBalanceTest` 7、`SpellCatalogStructureTest` 4）。

## 6. 待定

1. 火、水要不要专属法阵样式（现在是通用阵 + 粒子区分，认得出但不够"贵"）
2. 五系间隔 5~7.5 秒够不够"久"？要不要统一拉到 8~10 秒
3. 土"定身 1.2 秒"、暗"按住 3 秒"对 boss 要不要免疫或减半
4. 光领域回血 4 点 / 7.5 秒是不是太强（等于给队友一个常驻小奶）
5. 领域要不要也进 HUD 常驻条（现在只有状态效果图标）
