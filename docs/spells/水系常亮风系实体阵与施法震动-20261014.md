# 水系常亮、风系实体阵与施法震动

巨剑和雨链实体法阵补上独立加色发光层，按满亮度渲染，区别于只设置 light-map 亮度。巨剑的发光强度不随原淡出透明度减弱，在模型消失前保持发光；雨链法阵保留原透明阵面，但亮纹独立发光。

风系改为独立注册的 `wind/seal` 实体烘焙模型，与水、土系采用同类的多环、符文结构；使用青蓝、珍珠白和浅青材质，平滑旋转，沿用 45 tick 显示期限。

水柱主体转为蓝色，约十分之一的细流段以紫色点缀；水球 T4/T5 的水束同样采用蓝色主体、少量紫色流线。

水球 T4/T5 的蓄力阶段添加轻微震动，释放时产生衰减震屏（12 tick），T5 力度高于 T4，按距离衰减。释放后的持续水束不一直强烈晃动，法术结束后无永久镜头偏移。
