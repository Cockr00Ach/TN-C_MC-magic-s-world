# 土法实体模型与龙卷风回退（2026-10-12）

根据实机反馈，撤回上一轮风法龙卷风的连续几何版本；土法撤下发光线圈、程序生成的裂纹和半透明泥面，改用雷球相同的贴图烘焙模型路径，加客户端碎石粒子。

## 龙卷风

`TNTornadoEntity`、`TNTornadoRenderer`、`TNWindBladeEntity`、`TNWindBladeRenderer` 恢复到上一轮优化前保存的源文件，字节核对一致。发布 JAR 直接从当时底包恢复这四个类、五份范围风法术 JSON 及 `windblade.json`，共 10 个条目，逐项保证与旧版一致。恢复原实体模型、旋转、粒子和风刃表现；关闭新增的范围风几何法阵。

风法飞行、召唤链及水法、暗法保持当前版本。

## 土法四条链

- 投射：保留五种独立土石弹体；施法时出现小块悬浮碎石，撤下竖直发光线圈。
- 震地：贴图岩柱逐个升起，结合分叉排布的碎石与石屑粒子；高阶增加柱高和阵列数量。
- 泥潭：带泥土纹理的分层泥块和露出的岩石，使用泥尘粒子；T4 加入流向碎石，T5 保留悬浮岩核。
- 护身：分段岩柱，T4/T5 加入具有木质枝干、根部和苔藓叶面的立体根系。

新模型 `earth_pillar`、`earth_mud_plate`、`earth_root` 与已有五种土系弹体一并注册烘焙，并将普通模型 ID 关联到已烘焙模型。正常渲染使用 `CustomModels.render` 和 `LightEmission.NONE`，保留材质贴图、实体深度和环境光照。土法渲染入口不再调用原 `WindEarthGeometry.spell`。

只修改展示，不改变伤害、范围、冷却、消耗、弹体数量、状态效果及原有地形机制。展示实体不具有碰撞、伤害或方块修改逻辑。
