# 黑雾：瞬间把人拽进来 ＋ 体积随档位一起长（宽度 ＋ 高度）

2026-11-11 · 作者：「噢噢那个黑雾不是可以拉周围的敌人吗，我要你瞬间给他拉进来，
然后黑雾的大小也要随着 t 级增长变大，你别只加宽度，高度也要加」

---

# 一、以前是什么样

**抓取**（`DarkFogCloudEntity.gripIntruders`，每 6 tick 一次）：

- 抓取半径 = 雾半径 × 1.45（t1 6.5 格 → t5 13 格）
- 每 6 tick 给目标一个**很小的速度**：`0.10 × 距离`，而且上限很松
  ⇒ 站在 6 格外的人要**被拽好几秒**才进得来 ✗，看起来像"雾里伸出很多手在慢慢蹭"

**体积**：

| | 宽度（JSON `volume.radius`） | 高度 |
| --- | --- | --- |
| 数据来源 | t1 4.5 / t2 5 / t3 6 / t4 7.5 / t5 9 格 ⇒ 宽度 9 → 18 格 | **渲染器写死** `1.1 + 档位×0.1` |
| 结果 | 随档位翻倍 ✓ | t1 1.2 → t5 1.6，几乎不变 ✗ |

⇒ 高档黑雾变成"又宽又扁的一层饼" ✗ —— 正是作者说的"只加宽度"。

---

# 二、现在

## 1. 瞬间拉进来

够到抓取半径、并且**高度也在雾的圆柱里** ⇒ 直接 `teleportTo(...)` 到雾内：

| | 值 |
| --- | --- |
| 抓取半径 | 雾半径 × 1.45（t1 6.5 → t5 13 格） |
| 落点 | 离雾心 **45% × 半径**（t1 ≈ 2.0 格 → t5 ≈ 4.1 格；至少 0.6 格，免得卡在雾心抖） |
| 高度 | 保持目标自己的 Y，但夹在雾的半高范围内 |
| 附带 | 速度清零、`fallDistance` 清零、一串 `SQUID_INK` 黑雾粒 ⇒ 读作"被一把抓进去" |
| 频率 | 每 6 tick 一次（和以前一样，只是**一次就到**） |

## 2. 体积：宽度和高度一起长

半高 = **半径 × 0.5**（`DarkFogRules.HEIGHT_RATIO`）：

| 档 | 半径 | 宽度 | 半高 | 总高 |
| --- | --- | --- | --- | --- |
| t1 | 4.5 | 9.0 | 2.25 | **4.5** |
| t2 | 5.0 | 10.0 | 2.50 | **5.0** |
| t3 | 6.0 | 12.0 | 3.00 | **6.0** |
| t4 | 7.5 | 15.0 | 3.75 | **7.5** |
| t5 | 9.0 | 18.0 | 4.50 | **9.0** |

⇒ 宽度 9→18 格、总高 4.5→9 格，**一起翻倍** ✓（以前高度只有 2.4~3.2 格 ✗）

## 3. 雾变成了"圆柱"

- **抓取判定**：除了水平距离，还要求 `|目标中心 − 雾心| ≤ 半高 + 半个身位`
  ⇒ 站在头顶悬崖上的人不会再被"隔空拽进雾底" ✓
- **渲染**：雾片按同步过来的半高散布（`syncedHeight()`），不再全挤在脚边 ✓
  —— 这就是补上"只加宽度"的另一半

## 4. 两个例外（有意保留）

| | 为什么 |
| --- | --- |
| **Boss 领域雾不瞬移** | 那是半径 150 格的战场雾，瞬移会把玩家**直接甩到 BOSS 脸上**（67 格）✗ ⇒ 领域雾仍然只给一点轻推（和以前一样）✓ |
| **Boss 领域雾半高仍是 3.2** | 150 × 0.5 = 75 格高会把整张图糊掉 ✗ |

## 5. 闸门

新增 `DarkFogRulesTest`（**6 条**）：

- **宽度和高度都必须随档位严格变大**（核心那条：作者说"别只加宽度"）
- 半高 = 半径 × 0.5，且有 2.0 格下限（不然最小的雾贴成一张纸）
- Boss 领域雾半高保持 3.2、抓取半径封顶 96 ✓
- 抓取半径 > 雾半径 × 1.3、落点 < 半径 × 0.5 且 ≥ 0.6
- 圆柱判定：雾内 ✓、高度内 ✓、头顶太高 ✗、半径外 ✗
- **源码扫描**：`victim.teleportTo(` / `SQUID_INK` / `DarkFogRules.halfHeight(` /
  `DarkFogRules.insideDistance(` 都接上了；而且 `if (domain) {` 必须**排在** `teleportTo` 之前
  （领域雾不许瞬移）；渲染器必须读 `entity.syncedHeight()`、且不再有写死的 `1.1F+tier*.1F`

回归：`magic.*` + `client.*` + `warrior.*` + `world.wind.*` **501 用例 / 120 套件全绿**。

# 四、进游戏要验

1. 放 t1 黑雾：站在 6 格外的小怪应该被**一下拽进雾里**（不是慢慢蹭）
2. 站在 3 格高的台子上：不该被拽下来（圆柱判定）✓
3. 连放 t1 → t3：雾**整体变大**（宽 9→12 格、高 4.5→6 格），不再是一层薄饼
4. 黑暗巨人/黑魔法师的领域雾：**不该**把玩家瞬移（只有轻推）✓
