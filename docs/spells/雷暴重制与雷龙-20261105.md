# 雷暴重制 ＋ 雷龙（2026-11-05）

作者这一次的原话（按时间顺序）：

1. "雷电怎么只掉下来一个模型？我要一条从天上一直落到地上的、很震撼的雷，而且可以多劈。"
2. "类似蛛网一样的雷网特效，可以丰富我们的法阵还有自身周围的特效。"
3. "颜色黄的、蓝的、紫的都有，但不要纯色 —— 中心是白的，渐变到边，然后发光。"
4. "爆炸特效也优化一下。"
5. "再做一条雷龙。尽管堆砌模型块数，但我要他是实体建模并且**没有身体** ——
   一条用雷电勾线出来的龙。龙的威风要出来，龙须、头都得会动。
   在 t5 砸下雷电之后，砸中的地面有龙直冲云霄。
   特效在游戏里的体积一定要和现在差不多，甚至更大 —— 只要你有足够细节。"
6. "弄完别忘了装机。"

这篇文档记录**做了什么、为什么这么做、怎么验收**。

## 一、落雷：从天到地的一整根

### 之前的问题

主链的雷用的是作者给的 `flash` 模型（`models/projectile/flash.json`）——
那是**一小段电光**，`TNLightningStrikeRenderer` 把它 `scale` 到 4~9.6 倍后**摆在天上**，
于是游戏里看到的就是"天上悬着一个模型，地上闪一下"，中间是断的 ✗。我们收到过至少两次
"雷只掉下来一个模型"的反馈。

### 现在

`TNLightningStrikeRenderer.renderFullBolt(...)`（kind = 0 走这条路）：

| 东西 | 数值 | 说明 |
| --- | --- | --- |
| 高度 | `SKY_HEIGHT = 46` ＋ `min(26, scale × 1.6)` | 从云层一路画到落点（`groundY`）✓ |
| 主干宽度 | `min(1.25, max(0.16, scale × 0.072))` | 越大的雷越粗，但有上限（不然像光柱 ✗） |
| 分叉 | `min(6, 2 + scale × 0.32)` 根、带二级分叉 | 每根用不同种子 ⇒ 形状不重样 ✓ |
| 二次劈 | size ≥ 9 时 `sinceHit ∈ [6,10]` 再补一记大的 | "天雷"该有的回响 ✓ |
| 副雷 | 2 / 3 / 5 道（按体型），各错开 2 tick | 作者要的"可以多劈" ✓ |
| 落点 | 雷网 ＋ 贴地白光 ＋ 面向相机的白闪 ＋ 扩散光圈 ＋ 云底光斑 | 见 `LightningBoltGeometry` ✓ |

全部几何都是**加色混合的相机朝向带状面**（没有实体模型、没有贴图拼图），
所以从任何角度看都是一根有体积的电，而不是一张纸片 ✓。

### 为什么必须自建 RenderType（踩过的坑）

`RenderType.lightning()` 写的是 `WEATHER_TARGET` —— 在实体渲染阶段画出来**完全不可见** ✗
（这个坑在之前的"光杖"上已经踩过一次）。所以有了
`client/lightning/LightningRenderTypes`：自己 `extends RenderType`，
把 `LIGHTNING_TRANSPARENCY`（`SRC_ALPHA, ONE`，即加色）、`NO_CULL`、`LEQUAL_DEPTH_TEST`、
`MAIN_TARGET`、`RENDERTYPE_ENTITY_TRANSLUCENT_EMISSIVE_SHADER` 和
`textures/entity/beam_white.png`（16×16 纯白）拼在一起 ✓。
**注意：不能把工具类放进 `net.minecraft.client.renderer`**（JPMS 会炸），
只能像 `LuminousStaffRenderer.StaffGlow` 那样继承 ✓。

### 颜色：白芯 → 主题色 → 透明

`client/lightning/LightningTheme`：金 `GOLD=0` / 蓝 `BLUE=1` / 紫 `VIOLET=2` / 暗 `DARK=3`，
每个主题给三档色（`glow` 外圈辉光、`mid` 主色、`edge` 近白过渡），
`LightningBoltGeometry.strands()` 再叠四层：

```
辉光  width × 3.4   α 0.15
中间  width × 1.55  α 0.40
白芯  width × 0.55  α 0.92   ← 中心永远纯白 ✓
高光  width × 0.17  α 0.88
```

所以横截面是 **白 → 浅 → 金/蓝/紫 → 透明**，在加色混合下自带发光感 ✓，
不是一根纯色塑料棒 ✗。

随机取色在 `TnSpellMechanics.randomLightningTheme(...)`：紫 45% / 蓝 35% / 金 20%
（金色一多就变"圣光" ✗）。

## 二、雷网 / 雷笼：法阵和"自身周围"

### 法阵

`TNMagicCircleEntity` 新增 `STYLE_LIGHTNING = 7` ＋ 同步字段 `DATA_THEME`，
`TNMagicCircleRenderer` 在贴图阵之上**再铺一张 `groundWeb`**（三圈 12 辐 ＋ 弦 ＋ 节点，
形状每 2 tick 换一次 ⇒ 电在爬 ✓）。

> 为什么不直接改 `STYLE_STORM = 0`：0 号还被暗系召唤 / 暗龙那些阵用着，
> 给它们也加雷网会让"黑阵"变成"雷阵" ✗ —— 新开一个样式最干净 ✓。
> 另外 `STYLE_STORM` 的语义是"雷系默认阵"，其余调用方（黑雾边界等）行为保持不变 ✓。

### 雷笼（`TNLightningAuraEntity`）

施法者身上罩一圈**会呼吸的雷笼**，只存在于表现层：

| 法术 | 半径 | 高 | 时长 | 风格 |
| --- | --- | --- | --- | --- |
| 雷场 t2 | 4.2 | 4.6 | 120 | `STYLE_FIELD`（正弦脉冲） |
| 雷暴 t4 | 5.2 | 6.0 | 205 | `STYLE_STORM`（15 tick 一轮，前 5 tick 最亮 = 和落雷同拍 ✓） |
| 天雷 t5 | 5.0 | 6.5 | 140 | `STYLE_STORM` |
| 闪电登神 t5 | 3.6 | 4.2 | 240 | `STYLE_STORM` |

几何：`cage()` = 10 根竖弧 ＋ 3 道横环 ＋ 顶环 ＋ 8 条斜拉弧；脚下一张 `groundWeb`；
每 3 tick 从笼子往身上跳 4 道短电弧。种子 = `getId()*31 + age/2` ⇒ 每 2 tick 换一批点，
观感是"电流在骨架上乱爬"，而不是一盏匀速呼吸的霓虹灯 ✗。

`TnSpellMechanics.spawnAura(...)` 会先清掉玩家 3 格内**旧的**雷笼再挂新的 ——
连着放雷场/雷暴时不会两圈糊成一团 ✓。

## 三、雷龙（重点）

### 需求翻译成设计

| 作者的话 | 落地 |
| --- | --- |
| "实体建模" | 独立的实体类型 `tnc:lightning_dragon` ＋ 独立渲染器，模型由**几百个方块**现拼 ✓ |
| "没有身体" | 躯干**中空**：只有闪电脊线 ＋ 22 节悬浮脊椎 ＋ 左右肋骨弧 ＋ 鬃刺，肋骨间能看穿 ✓ |
| "用雷电勾线出来的龙" | 脊线、龙须、龙角、鬃刺、肋骨、尾鳍全部额外描锯齿电弧 ✓ |
| "龙的威风" | 三对龙角（每对 7 节）、两根 18 节长龙须、12 颗獠牙、发光龙眼、四爪三趾、尾鳍扇骨 ✓ |
| "龙须、头都得会动" | 头：yaw/pitch 双频摆动；下颚张合；龙须：18 节逐节正弦；龙角/鬃刺/四爪/尾鳍都带 sway ✓ |
| "t5 砸下雷电之后，砸中的地面有龙直冲云霄" | 天雷 / 神在投篮大雷球落地 / 黑暗衍天打五雷轰 —— 三处都生成，见下 ✓ |
| "体积和现在差不多甚至更大" | 默认 45 格长，t5 用 1.15~1.3 倍 ⇒ 50~58 格；比 29 格高的"神"更大 ✓ |

### 轨迹（`magic/LightningDragonPath`）

服务端（粒子、剔除盒）和客户端（模型）必须用**同一条曲线**，否则"龙从这儿冲、电花从那儿冒" ✗，
所以轨迹抽成了一个纯数学类：

```
sky(scale)      = 52 + 10 × scale          // 龙头最高点（格）
rise(age)       = sky × (1 − (1 − age/78)²)  // ease-out：一上来就窜 ✓
angle(age)      = age × 0.105               // 螺旋角
radius(age)     = (1.8 + 3.6 × rise/sky) × scale
point(age)      = (cos·r, rise, sin·r)
```

- **螺旋收紧再外扩**：贴地时半径 1.8 格（破土有冲劲），越高越外扩到 5.4 格（云里盘住）✓；
- 龙身每一节只是把同一条曲线**往回延迟** `LAG = 1.15 tick` 取点 ⇒ 自然拖尾，
  前 78 tick 是"从地里一节节被拽出来"，之后整条龙在云里盘旋 ✓；
- 整个实体**钉在落点不动**，只同步 `age` / 尺寸 / 主题 / 种子 ⇒ 不需要每 tick 发位置包 ✓。

### 模型（`client/dragon/LightningDragonGeometry`）

约 230 个方块 ＋ 80 道电弧（≈2700 个四边形/帧），全部即时生成，不读模型文件、不依赖 GeckoLib：

- **脊椎**：22 节，逐节变细，带一点沿曲线的 wobble；
- **脊线**：相邻两节之间一道锯齿电弧（width 0.13×S），两侧再各挂一条"游离"长弧；
- **肋骨**：10 组 × 左右各 2 段弧，从脊椎甩出去又收回到腹侧（**中间是空的** ✓）；
- **鬃刺**：10 根，沿背脊排开，长度/方向随年龄摆；
- **头**：头骨 / 颅顶 / 眉骨 / 颊甲 ×2 / 吻 / 鼻 / 上唇 / 下颚（铰链张合）/ 上牙 14 颗 /
  下牙 12 颗 / 眼（白核＋光晕）/ 耳鳍 3 对；
- **龙角**：3 对 × 7 节，锥形、逐节摆；
- **龙须**：2 根 × 18 节 × 0.56 格，两条不同频率的正弦叠加 ⇒ 飘得很自然 ✓；
- **四爪**：肩→膝→足 三段 ＋ 3 根纯白爪尖；
- **尾鳍**：5 片扇骨 ＋ 一道尾电弧。

方块的面**按朝向给了 0.58~1.10 的亮度系数**（顶面最亮、底面最暗）——
即使加色、无光照，也有体积感 ✓。

### 生成点

| 位置 | 代码 | 参数 |
| --- | --- | --- |
| 天雷 t5（主链） | `TnSpellMechanics` 的 `heavenly_thunder` 分支 | `scale 1.15`、`delay 14`、`life 175`，位置 = 准星落点 |
| 神在投篮 t5 大雷球落地 | `TNLightningStrikeEntity.landBlast` 末尾 | `scale 1.2`、`delay 0`、`life 180`，位置 = 爆心 |
| 黑暗衍「天打五雷轰」 | `YanDarkBossEntity.castHeavenlyThunder` | `scale 1.3`、`delay 12`、`theme 3`（暗紫）、`life 190` |

`delay` 那段时间渲染器只画**地面雷网 ＋ 越来越亮的地光 ＋ 几道往上顶的电弧**
（"地下有东西要出来"），然后才破土 ⇒ 不是凭空出现 ✗。

另外两条落地保护：

- **按到地面**：天雷那条走 `groundBelow(...)`，把"准星落点"往下最多找 24 格、站到第一块实心方块上
  ⇒ 朝天/朝远处放 t5 时，龙不会从半空里钻出来 ✗；
- **同地不叠龙**：`spawnDragon` 会先收掉 16 格内的旧龙 —— 一条龙本来就 50 格长，
  两条叠在一起必然穿模 ✗（黑暗衍和玩家连着放 t5 时很容易撞上）。

### 破土那一下的"屏幕反馈"

几何再猛，屏幕不抖、不亮，冲击力就少一半 ✗。`TNSpellClientVisuals` 就近侦测雷龙实体
（同落雷/光柱那套办法，不需要新增网络包 ✓）：

- **只有破土后 6 tick** 给震屏（`near² × (4.6 + 1.8×scale) × 衰减`，越晚越弱 ⇒ 像一记闷响 ✓；
  全程 8 秒猛晃会晃吐人 ✗ —— 这是 2026-09-29 落雷那次的教训）；
- 同时给 0.42 的白闪（按距离衰减）；
- 地面雷网从原来 14 tick **拉长到 26 tick**，并且 8 tick 后再叠一层反向旋转的内圈余电
  ⇒ 龙窜上去以后地面还在"滋滋"，而不是干干净净 ✗。

### 剔除

实体本体只有 0.1 格，但龙有 50 多格高、10 格宽 —— **必须覆盖剔除盒**，
否则平视时整条龙会被视锥裁掉 ✗（落雷和雷笼都踩过这个坑）：

```java
getBoundingBoxForCulling() → inflate(12×s, sky(s)+8, 12×s)
shouldRender(...)          → 距离 < 131072（不按视锥 ✗）
clientTrackingRange        → 16（200 格外也看得见天上那条发光的龙 ✓）
```

## 四、爆炸特效

`TNLightningStrikeEntity` 的落地爆发重写：

- 粒子数量/半径/速度全部**跟着体型缩放**（size = `scale/4.5`）；
- `TnSpellMechanics.arcBurst(...)`：以落点为中心、向四周甩出一圈锯齿电弧（不是圆环粒子 ✗）；
- 冲击波环：大雷（size ≥ 1.8）额外在 +3 tick 补一发；
- 音效音量跟着体型走（远处也能听见"轰"）；
- 客户端 `TNSpellClientVisuals`：落雷**落地那几 tick** 加白闪（0.22 + scale×0.022，上限 0.60）✓
  —— 以前只有震屏、没有光 ✗。

## 五、验收

### 自动测试

- `OrbEntityRendererCoverageTest`：**每一个** `TNOrbEntities` 字段都要有字面量
  `registerEntityRenderer(TNOrbEntities.X.get(), ...)` —— 新增的 `LIGHTNING_AURA`、
  `LIGHTNING_DRAGON` 都已按这个格式注册（漏一个 = 一生成就 NPE 卡退 ✗）✓
- `YanDarkSpellAudioTest`：`playRollingThunder`、`THUNDER_DELAY`、`CONDUIT_AMBIENT`/`BEACON_AMBIENT` 全部保留 ✓
- `MagicCircleGuaranteeTest`：`needsGuaranteedCircle` 行为未改 ✓
- 全量 `gradlew test`：723 个测试里 48 个失败 —— **全部是本次之前就存在的**
  （Wand / Wearable / Guidebook / LightWings 系列，和雷系无关）；雷系相关测试全绿 ✓

### 游戏内怎么确认

1. 服务端日志 grep：
   - `TN-C: spawn circle at ... style=7` —— 新法阵铺出来了；
   - `TN-C: spawn lightning aura r=...` —— 雷笼挂上了；
   - `TN-C: spawn lightning dragon at ... scale=1.15` —— 龙出来了。
2. 放 t5 天雷：准星落点先亮起雷网（14 tick），然后一条发光的龙螺旋冲上云层，
   头会左右摆、下颚会张、两根龙须在飘 ✓。
3. 放神在投篮 t5：大雷球落地 → 冲击波 → 龙从爆心直接冲出来 ✓。
4. 站在雷暴里：身上一圈雷笼每 15 tick 跟着落雷"鼓"一下 ✓。

### 装机

```powershell
gradlew build -x test
# 校验 build/libs/tnc-1.0.0.jar 的 SHA-256 与实际实例 mods/ 下的副本一致
```

- 实际实例：`E:\download\正式版 2.12.6.1\.minecraft\versions\元素觉醒1.4.3-魔改版-20260915`
- 安装副本：`mods\tnc-1.0.0.jar`，SHA-256 `CF399386…D351096`（**reobf** 后的 jar，
  常量池里能看到 `m_8119_`/`m_20185_`，不是开发环境那份 SRG 名 ✗）
- 装机前确认没有 `javaw`/PCL 在跑 ⇒ 安全覆盖 ✓
- KubeJS 这次**没有改动**（法术 JSON 全部沿用），所以不需要同步 `kubejs/` ✓

> ⚠️ 踩坑记录：中途有一次 `reobfJar` 报 `zip END header not found` —— 是因为构建被中断，
> `build/libs/tnc-1.0.0.jar` 只写了一半，而 `jar` 任务以为它是最新的。修法：
> **删掉 build/libs 里的 jar 再 build** ✓（不要用 `--rerun-tasks` 去赌）。
> 另外那一版 `reobfJar` 失败后，`build` 任务没有产出最终 jar，
> 千万别把 `build/libs/tnc-1.0.0.jar`（未 reobf）直接拿去装机 ✗ —— 进游戏会缺方法/崩 ✗。
