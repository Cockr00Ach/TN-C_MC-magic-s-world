### 2.1 为什么还是拆成四段

- 水牢高度是变的（t1 约 7 格 → t5 约 24 格 ✗）⇒ 一整根只能整体拉 y，柱础和柱头会被拉成一坨 ✗；
- **柱头浮雕单独一个模型** ✓：它是"精致"的来源，也是最贵的一块 ✗ ——
  只给**离镜头 18 格内**的那几根画 ✓（`romanColumns(..., Vec3 camera)` 里逐根判距离 ✓）。

### 2.2 收分（entasis）

柱身分**三段**画，直径 100% / 98.5% / 97% ✓ —— 古典柱"上细下粗"的那点弧度 ✓，零额外方块 ✓。

## 4. 虚化

`WaterSolidModels.romanColumns(...)`：
1. 走**半透明**通道（`opacity = fade*0.62` ✓ = "虚化"）；
2. 叠一层**很淡的加色自发光**（0.30 ✓）—— 只半透明会像塑料 ✗；
3. 柱础 / 柱身（三段）/ 柱头 / 浮雕分别摆好 ✓。

**柱距与粗细**（`WaterGeometry.columnCount` / `columnDiameter`）：
柱距按 4.2 格 ⇒ t1 8 根、t3 18 根、t5 22 根（上限 22）；
粗细 = min(柱距六成, **高度÷6.5**, 2.6 格) ⇒ t1 1.08、t3 1.94、t5 2.60 格（6.5~9 : 1 ✓）。
