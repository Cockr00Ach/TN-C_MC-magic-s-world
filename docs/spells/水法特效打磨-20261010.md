## 一、魔法阵自发光（这一条**影响全部四条水链** ✓）

**问题**：法阵（`WaterGeometry.richCircle` → `sigil`）只有 alpha 混合的**细线条** ✗ ⇒
看上去是"画上去的图案"，不是"在发光的东西" ✗。

**做法**：新增私有方法 `WaterGeometry.sigilGlow(...)`，在 `richCircle` 末尾再画一遍**加色层** ✓：

| 层 | 内容 | 作用 |
|---|---|---|
| ① | **8 层同心环**光晕盘（宽度 `radius*.20`、alpha 由内向外递减）| 把线条之间的空隙填成柔和的径向发光 ✓（纯 alpha 做不到 ✗）|
| ② | 主环 / 内环 / 中心环各叠一条**加色亮线** | 重叠处被推向白亮 ⇒ "线在发光" ✓ |
| ③ | **3 层流动亮弧**（不同半径、不同转向）| 法阵里有能量在转 ✗ |
| ④ | 中心**亮核** | 阵心"烧着" ✓ |

**覆盖面**（这四处都走 `richCircle`，所以一次改动全受益 ✓）：

- 水球链 t3/t4/t5 —— `TNWaterSpellRenderer`
- 水缚链 t3+ —— `TNWaterFieldRenderer`（`kind==2 && tier>=3`）
- 水神的冥穴（**两层大阵**）—— `SeaGodSwordVisuals`
- 雨滴链 t4/t5（最多三个阵）—— `WaterRainVisuals`

> ⚠️ 只给**主阵**加光 ✗，**子阵 / 卫星阵不加** ✗ —— 雨滴链一次能画三个阵，
> 全加会白花花一片 ✗，而且纯粹是白烧 GPU ✗。

## 二、水球链 t5「射出速度太慢」（`WaterTerrainBore`）

**诊断**（不是猜的 ✗）：原来 `tick()` 里是 `next = length + 1` ⇒ **每 tick 只推进 1 格** ✗。
开阔处要 96 tick（**4.8 秒**）才射到 96 格；实心岩里一段 1 格 = π×15² ≈ **707 个方块** ÷
每 tick 128 的破坏预算 ≈ **5.5 tick 才走 1 格** ✗ ⇒ 96 格要 500+ tick，
而技能总时长只有 240 tick ⇒ **在岩石里永远射不到头** ✗。

**做法**：**空段自适应跳进** ✓
```java
advance = wasEmpty ? min(MAX_EMPTY_ADVANCE(8), advance*2) : 1;
```
- 上一段是**空的** ⇒ 下一段加长：**1 → 2 → 4 → 8 格/tick** ✓（开阔处约 15 tick 射满 96 格 ✓）
- 一旦那一段**有方块** ⇒ 立刻回到 **1 格/段** ✗

**刻意没动的**（这些是被文档和测试钉住的 ✗）：

| 不变项 | 为什么 |
|---|---|
| 每 tick **128** 直接破坏预算 | `fullApertureSliceRespectsBudgetAcrossTicks` 等 3 条测试钉着 ✗ |
| **整段先验证、后编辑** | 受保护方块不可能被"半格"跨过去 ✗ |
| 实心处推进速度 = 1 格/段 | 与旧行为**逐字一致** ✗ |
| 蓄能 30 tick / 持续 240 tick / 射程 96 / 半径 15 | 都是作者点过头的数字 ✗ |
