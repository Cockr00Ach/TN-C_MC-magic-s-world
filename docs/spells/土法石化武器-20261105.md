# 土法石化武器：把现成武器模型重绘成土/石材质

日期：2026-11-05（第四轮土法表现）

## 思路

不新做模型，直接把项目里现成的 3D 武器模型复制一份，重绘成石/土材质，作为土神的枪的飞行体，以及爆点小岩柱的一部分。这样一套土法里能同时出现剑、刀、戟、镰、锤、阔刃、细剑七种“石化兵器”，体积也比原来的细土柱更大。

| 原模型 | 石化后 | 材质基调 |
|---|---|---|
| `dragon_sword` | `earth_wpn_dragon_sword` | 琥珀岩（`earth_amber_stone` 暖棕） |
| `frost_katana` | `earth_wpn_frost_katana` | 灰白岩（浅色、高对比） |
| `sky_halberd` | `earth_wpn_sky_halberd` | 青灰岩 |
| `doom_scythe` | `earth_wpn_doom_scythe` | 黑玄武岩 |
| `earthshaker_hammer` | `earth_wpn_earthshaker_hammer` | 土褐岩 |
| `crimson_warblade` | `earth_wpn_crimson_warblade` | 赭红岩 |
| `star_rapier` | `earth_wpn_star_rapier` | 银灰岩 |

## 生成方式

`tools/gen_earth_weapons.py`：

1. 从 `block/earth_amber_stone.png` 下采样出 16×16 石板，按武器调色（暖棕/灰白/青灰/玄武/土褐/赭红/银灰）。
2. 把武器原贴图缩到 16×16 取亮度，乘到石板上，保留原模型的明暗分区（刃亮、柄暗）。
3. 模型坐标统一缩放/平移：长轴（原 +Z）归一到 0..16，X/Y 居中，长轴正好 1 格；去掉 `display`/`tnc_grip`/`texture_size`，所有面改成单一贴图。
4. 输出 `models/projectile/earth_wpn_*.json` 与 `textures/block/earth_weapon/*.png`。

飞行体不需要额外旋转：这些持握模型本来就是沿 +Z 建模，正好是弹道方向；只有把它们竖起来当岩柱时才绕 X 轴 -90°。

## 用在哪

- **土神的枪（tier 5）**：每次施法从 7 把里随机一把射出，长 **5.2 格**（原细土柱 3.4 格，+53%），宽/厚按 2.8 倍缩放；命中后仍然是 96 格巨柱托举目标升天。
- **爆点小岩柱**：每 3 根里有 1 根换成石化武器，高度 2.6 格（巨型 3.4 格）起，比原来 0.95/1.7 格更高；其余仍是 `earth_pillar` / `earth_spike_sharp`。
- 巨柱本体、破土岩柱、碎石仍用原 `earth_pillar` / `earth_spike_sharp` / `earth_clod`，没有被删掉。

## 注册与成本

- `TNDirectSpellModels.PATHS` 从 13 条增到 20 条，`TNDirectSpellModelsTest` 同步断言 20 与新增键。
- 7 个模型共 7,611 个 cube（原模型就是体素武器），烘焙后是启动时一次性开销；渲染每把是一次模型绘制，不逐帧重建。
- `EarthWeaponModels` 持有模型名与飞行尺寸，服务端随机选型、客户端只读名字。

## 限制

- 石化贴图是 16×16 的“石块 + 原模型亮度”，不是逐把精修的手绘土纹；远看是石制兵器，近看纹理会偏粗。
- 武器模型偏薄（剑/刀尤其），侧对镜头时像一条石片；要更厚可以调大 `FLIGHT_WIDTH`。
- 七把武器共用同一套爆点逻辑，没有单独技能差异。
