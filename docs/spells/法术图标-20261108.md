## 3. 每张图要"一眼看出是啥"

一个图标 = **一个能认出来的主体剪影** + 内核高光 + 右下暗边 + 少量碎屑，和旧图标同一套读图语言：

| 链 | 画的是什么 | 玩家应该读到 |
| --- | --- | --- |
| 岩弹（EARTH_SHOT） | 一块带棱角的尖石 + 身后三道风 | 石头被射出去 |
| 地动（EARTH_MOVE） | 地面裂开、石刺从底下顶上来 | 地面长刺 |
| 泥潭（EARTH_MUD） | 一汪泥，中间一个往下陷的漩涡洞 | 把人陷下去 |
| 石环（EARTH_RING） | 一圈立起来的石头 + 中间发亮 | 石头围成圈 / 石牢 / 石王国 |
| 光镜（LIGHT_MIRROR） | 立着的水晶 + 斜切的反光带 + 光刺 | 反射、折光 |
| 雷印（THUNDER_SEAL） | 地上法印（双环 + 放射刻痕）+ 中间雷楔 | 烙印、锁定落点 |
| 风球（WIND_BALL） | 打着旋的风团 + 两条拖尾 | 会飞的风球 |
| 风刃（WIND_WEAPON） | 一柄弯刀 + 护手，高档多一把 | 风凝成的剑 |
| 狂风（GALE） | 几道带卷的风 | 大范围风 |
| 神在投篮（god_descent） | 雷球正落进地上的圈 | 从天砸进落点 |

## 4. 怎么画的（`tools/spell_icons.py`）

```
64×64 画矢量（可以画曲线/尖角/渐细的带子）
  → BOX 缩到 16×16
  → 每个像素吸附到三色之一：暗边 / 主体 / 高光
```

三色蘸的是**旧图标里取出来的颜色**（脚本 `build/icon_palette.py` 统计出来的主色），
所以新旧混在一起不会串味。最后一步的三色吸附是关键：直接用 32px 缩到 16px 会糊成一片灰边，
吸附之后就是硬边像素块，和手画的旧图一样。

整条链的 5 个档位靠"内容"区分，不靠角标：主体变大、碎屑变多（风刃多一把、狂风多一道、石环多两块）。

## 5. 验证

- `build/icon_parse.py`：135 条 → 缺图 0 条、共用图 0 组。
- 预览图 `docs/spells/法术图标-预览.png`：46 张重画的图标，按链一行、从左到右 t1→t5，6 倍放大。
- **不是游戏截图**：最终要看 16px 实际显示效果，进魔法石列表确认。

## 6. 想改的时候

| 想要 | 改哪 |
| --- | --- |
| 换某个图的样子 | `tools/spell_icons.py` 里对应 `g_xxx` 函数（都是几十行矢量） |
| 换配色 | 同文件 `PALETTE`，或重跑 `build/icon_palette.py` 从旧图重新取色 |
| 只重画一条链 | `python tools/spell_icons.py` 会重画全部 46 张，单张就直接改 png |
| 换预览图 | `python tools/spell_icons.py --sheet` 会写 `build/new_icons.png` |
