# 领域法术第一轮：雷霆领域 / 暗黑领域

2026-11-08 · 作者原话：

> 准备做领域法术，你先做雷，这个领域法术放在独立法术那里，并且告知玩家只能选择一个领域法术，
> 条件是有亲和力就行
>
> 雷法的领域我希望是开展雷领域，加雷伤，并且给战士的攻击附上雷属性伤害，战士的攻击会携带小闪电，
> 周围会时不时遭雷劈，不过间隔要很久，然后主要劈玩家和队友攻击的目标，劈之前地面有明显落点
>
> 暗法就是开展暗领域，加暗属性伤害并且给战士的攻击附上暗属性伤害，战士的刀光剑影变成黑色，
> 然后主要索玩家和队友攻击的目标，目标脚下会出现小团黑雾，然后伸出一个手抓住目标，一直控制，
> 间隔也要久

---

> 2026-11-08 第二轮：另外五系（火/风/水/土/光）已经补齐，七系总表见 [领域法术-七系补齐-20261108.md](领域法术-七系补齐-20261108.md) ✓ —— 本文只保留第一轮（雷/暗）的设计过程。

## 0. 三行结论

1. **位置与门槛**：两个领域是「独立法术」页里的一次性法术（元素为 null），
   **一人只能选一个**，学它只要求该系**亲和力 ≥ 1**，不看等级、不看链进度。
2. **雷霆**：展开 30 秒，每 **6 秒**在「玩家/队友正在打的目标」脚下铺一圈预警，
   **1.1 秒**后真雷落下（半径 2.2 格、14 点），战士每一刀 +30% 附雷伤、刀上溅电火花。
3. **暗黑**：展开 30 秒，每 **8 秒**在目标脚下先起一团黑雾，再从雾里伸出一只手抓住它，
   按住 **3 秒**（移速 6 档减速 + 黑暗 + 发光标记），战士刀光剑影转近黑。

## 1. 放在哪、怎么学、怎么换

| 项 | 做法 |
| --- | --- |
| 目录位置 | `SpellCatalog` 里 `Chain.INDEPENDENT`、`element == null` ⇒ 只出现在魔法石「独立」页 |
| id | `tnc:lightning_domain`（雷霆领域）、`tnc:dark_domain`（暗黑领域） |
| 解锁条件 | `data.getAffinity(该系) >= 1`，其余不看（等级、链进度都不参与） |
| 只能选一个 | `MagicStoneLearning.check` 里遍历 `data.specialElements()`：已经选了别的系 ⇒ `DOMAIN_CONFLICT` |
| 学会即拥有 | `unlock` 成功后 `data.grantSpecial(该系)` ⇒ `TNSpecialMagic` 的「亲和力 ×5% → spell_power」立刻生效 |
| 想换领域 | 先在魔法石里遗忘旧的（`revokeSpecial`），再学新的 —— 不会把人永久锁死 |
| 告知玩家 | 魔法石悬停：`领域魔法 · 全部元素只能选一个` + `要求 <系>亲和力 ≥ 1（不看等级）` + `当前：已选「…」`；学不了时聊天栏给中文原因 |
| 兜底 | 万一两个领域效果同时挂着，开新的会把旧的 `removeEffect` 掉 |

> 为什么元素写 `null`：`Entry.element()` 非空就会进七元素的 NBT 数组（存档结构），
> 而领域本来就不属于任何一条链。真实归属由 `DomainSpells.elementOf(id)` 反查 —— 它和
> `SpellCatalog.specials()` 的七条 id 一一对应。

## 2. 数值表（`DomainSpells` 顶部，改这一处就够）

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `DURATION` | 600 tick = **30 秒** | 领域持续 |
| `COOLDOWN` | 1800 tick = **90 秒** | 冷却（JSON 同步写 90） |
| `RADIUS` | **16 格** | 找目标的半径 |
| `TARGET_MEMORY` | 160 tick = **8 秒** | 「刚被打过」的时间窗 |
| `STRIKE_INTERVAL` | 120 tick = **6 秒** | 雷：多久劈一次 |
| `GRIP_INTERVAL` | 160 tick = **8 秒** | 暗：多久抓一次 |
| `FIRST_DELAY` | 40 tick = 2 秒 | 开领域后第一次出手的延迟 |
| `TELEGRAPH` | 22 tick = **1.1 秒** | 地面预警到落地的时间 |
| `STRIKE_RADIUS` / `STRIKE_DAMAGE` | 2.2 格 / 14 点 | 落雷范围与伤害 |
| `GRIP_TICKS` | 60 tick = **3 秒** | 抓住后的控制时长 |
| `MELEE_BONUS` / `MELEE_BONUS_CAP` | +30% / 最多 +12 点 | 战士附伤 |

读条 0.9 秒（不是瞬发 —— 领域是「展开」，按平衡表属于重法术），exhaust 仍然 0。

## 3. 谁是「玩家和队友正在打的目标」

`DomainService.HIT`：任何玩家**直接**打到生物（`LivingHurtEvent` 的 `directEntity` 是玩家），
就记一条 `目标 uuid → 当时的 gameTime`。

- **队友也算**：所有玩家共用这张表 ⇒ 队友在打的目标，领域主人也能劈 ✓
- **8 秒记忆**：超过 `TARGET_MEMORY` 就不算「正在打」
- **都排不出人时**：退而求其次挑半径内最近的敌人（不至于对着空气放技能）
- **一定排除**：自己、友军（`isAlliedTo`）、其他玩家、旁观者 —— 领域不误伤 ✓

## 4. 雷霆领域

1. **展开**：脚下 6 格紫电大阵 + 低音雷声 + 行动栏提示「雷霆领域 展开（30 秒）」
2. **每 6 秒**：挑最近挨打的目标 → 在它**脚下**铺 `STYLE_LIGHTNING_MINOR` 电圈（1.1 秒可见）
3. **落地**：真雷（`setVisualOnly` ⇒ 伤害由我们结算，不会双算）+ 半径 2.2 格内 14 点魔法伤害
4. **战士附伤**：领域开着时，玩家用刀/斧直接砍中的那一下 +30%（封顶 +12），
   命中处溅电火花，25% 概率补一根视觉小雷（作者：「战士的攻击会携带小闪电」）
5. **加雷伤**：`TNSpecialMagic` 的 `spell_power:lightning` 按亲和力 ×5% 加成（学会即生效）
6. **氛围雷**：半径内**一个可打的都没有**时，在玩家周围 6~14 格随机落一根**纯视觉**的雷
   （`sceneryBolt`，不造成伤害）—— 对应作者「周围会时不时遭雷劈」，也不会莫名劈死路过的动物 ✓

---

## 5. 暗黑领域

1. **展开**：脚下 6 格暗紫大阵 + 魂音 + 行动栏提示
2. **每 8 秒**：挑最近挨打的目标 → 脚下铺 `STYLE_DARK_MINOR` 圈 → 1.1 秒后出手
3. **出手**：脚下炸开一小团黑雾（`SQUID_INK` + `SCULK_SOUL`）→ 从雾里伸出一只手
   （`TNNightGripEntity.launchFrom`，起点在脚底下 0.9 格 ⇒ 读作「从地里伸出来」）
4. **一直控制**：落点 2 格内所有敌人 —— 移速 6 档减速（等于走不动）+ 黑暗 + 发光标记 + 立刻清零动量，持续 3 秒
5. **战士附伤**：+30% 附暗伤，命中溅黑雾；**刀光剑影变黑**：
   `WarriorTrail` / `WarriorWaves` 检测到领域效果就把元素改成 `dark`
   ⇒ 拖尾底色 `0x10101B`（近黑）、剑波同样转暗（雷领域则是紫电 `0xE2C9FF`）
6. **加暗伤**：`spell_power:soul` 同样按亲和力 ×5%

## 6. 状态为什么用「状态效果」而不是存档字段

| 方案 | 同步 | 到期 | 客户端能否读到 |
| --- | --- | --- | --- |
| 玩家 NBT 时间戳 | 要自己发包 ✗ | 要自己每 tick 判断 ✗ | 读不到 ✗ |
| **状态效果**（采用） | 原版自动同步 ✓ | 自带 duration ✓ | `hasEffect` 直接读 ✓ |

顺带的好处：HUD 上有个图标，玩家一眼看得出「我的领域还开着」。

## 7. 雷锲：改成「直接闪出」（同一轮）

作者：「雷锲的出现直接闪出就行，你不要雷劈了之后还从地里长出来」。

| 之前（2026-11-07） | 现在（2026-11-08） |
| --- | --- |
| 天雷落地后模型从 0.02 缩放到 1，还有 0.12 的过冲 | **落地即满尺寸**，不缩放、不过冲 |
| 6 道短雷从地面往楔轴上「收」 | 删掉；改成雷环**向外**炸开（越炸越大、离楔轴越远） |
| 未落地的楔子也画一根半透明竖雷 | 没劈到就什么都不画（`continue`） |

保留：30 格天雷砸下 + 落点白闪 + 楔子立起来那根竖雷 + 一楔一道雷的时序。

## 8. 闸门

`src/test/java/com/tnc/tnc/magic/domain/DomainSpellTest.java`（6 条，全绿）：

1. `domainsSitOnTheIndependentPageWithNoElement` —— 独立页、element 为 null、不分档
2. `affinityIsTheOnlyRequirementAndYouMayOnlyPickOne` —— 没亲和力拒绝 / 有 1 级就能学 /
   学完 special 打开 / 第二个领域被 `DOMAIN_CONFLICT` 拒绝 / 遗忘后可换
3. `domainJsonMatchesTheRulesTable` —— JSON 冷却 90、exhaust 0、读条 >0、效果 id 与时长对齐；
   **并禁止数据包里重复定义**（重复会被数成两个同档法术，平衡闸门当场红）
4. `darknessTurnsTheWarriorTrailBlack` —— 暗拖尾近黑、雷拖尾紫电
5. `serviceActuallyDoesWhatTheAuthorAskedFor` —— 源码扫描：预警圈、`visualOnly`、
   记忆窗口、排除友军、黑雾、`launchFrom`、减速控制、附伤走 `indirectMagic`
6. `onlyOneDomainEffectCanBeOpenAtATime` —— 开新领域必然关旧领域

另外 `ThunderSealBirthTest` 的雷锲闸门同步改成「不许再有任何长大的痕迹」：
禁止 `float pop =`、禁止按 `born` 淡入、禁止 `800L + slot`（收拢雷），要求满尺寸直接闪出。

本轮测试：`DomainSpellTest` 6/6、`ThunderSealBirthTest` 4/4、magic 包全量 **119/119**。
