## 二、每套骨骼动了哪些（生成器会核对"骨头真的存在"✓）

| 模型 | 动的骨头 |
|---|---|
| `dark_imp` | `blob`（整体前扑/自转）+ `eyeL`/`eyeR`（发光脉冲）＋ `wisp`（尾焰甩动 ✓） |
| `dark_guard` | `cloak` `body` `head` `armRight` `blade` `armLeft` `wisp` |
| `dark_lord` | 上面那些 ＋ `cape` ＋ `blade2` |
| `dark_king` | 上面那些 ＋ `crown`（自转 + 放大 ✓） |
| `evil_god` | `robe` `body` `head` `ring`（光环自转 ✓）＋ **6 条手臂 × (arm + blade)** ＋ `wisp` ×2 |

> `root` 故意不动 ✓ —— 它是整尊的锚点，动了整个模型会整体位移 ✗（实体位置由实体自己管 ✓）。
> 生成器最后一行会打印 `animated bones=x/y`，**没动到的骨头会列出来** ✓
> —— 这样"我写了动画但骨头名写错了"这种静默失效一眼就能看见 ✓。

## 三、旋转符号（前 = −Z ✓，和天使/巨龙那两套一致 ✓）

| 部位 | 规律 |
|---|---|
| 手臂 / 刀（方块在 pivot **下方**） | **+x = 向前劈** ✓（所以蓄力是 −x、挥出是 +x ✓） |
| 躯干 / 头（方块在 pivot **上方**） | **−x = 前倾 / 低头** ✓（`attack` 里的身体前冲、`death` 里的前扑都是 −x ✓） |
| 斗篷 / 长袍（挂在下方、在后面 +Z） | **−x = 往后飘** ✓（`walk` 里用 −6°～−9° ✓） |
| 光环 / 王冠 | **y = 自转** ✓ |
| 尾焰 `wisp` | x/y/z 都给了小幅摆动 + `scale` 呼吸 ✓ |
