# 光镜与持镜信徒细化版

仅修改缓存模型几何和表面表现；光镜等级、寿命、分束数、伤害、信徒 AI 和光系学习链均不改动。

## 光镜

- 镜面改为 32 分区、8 层径向明暗，去掉原来的八大片纯色三角。
- 五重双色金属框、内侧蚀刻环、24 个刻度、12 组卷草镂空、立体镶钉、八向尖饰。
- 周围的彩色小方块替换为有前后厚度的切面晶石与独立包镶框，数量仍对应等级。
- T5 为约七千个四边形（包含退化三角面），模型一次生成复用，不额外细分镜面，不使用全屏特效或实时反射。

## 信徒

- 八片式收口兜帽、眉甲与分片面罩、立体冠冕宝石、双层放射光环。
- 三层肩甲、胸口太阳圣徽与宝石、腰带扣件、披肩褶片、袍服金线纹样、护腕与手指细节。
- 较大的表面在建模阶段烘入细分明暗、针织网格与细小色差；所有面法线预先计算缓存，不在每帧重新生成。
- 仍使用阿波罗同系的象牙白、古金、灰紫底色，靠结构、金线和明暗区分材质，不用大幅换色掩盖平面。
