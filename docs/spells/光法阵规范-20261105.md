# 光法阵规范（2026-11-05，第二版：低阶/中阶/高阶分开）

> 作者：「统一一下光法里的法阵」→ 第一版把所有光阵统一成 `STYLE_LIGHT`；
> 随后作者：「法阵要是每个都是一样的施法方式就不好看了，低级和高级应该是有区别的」→
> 这一版在“同一套白金光语言”里拆出 **三档施法方式 + 四种阵样式**。
>
> 代码守门：`src/test/java/com/tnc/tnc/light/LightRitualSequenceTest.java`（仪式结构）
> ＋ `LightSealStyleTest.java`（样式使用）。

---

## 1. 一句话规范

**光系只用光阵，不用雷阵；光阵按档位分四种样式：**

| 样式 | 用在哪 | 渲染 |
|---|---|---|
| `STYLE_LIGHT_MINOR = 9` | **t1/t2** 主阵、所有卫星小阵、天使落点、召唤落点 | 一圈主环 + 6/8 道光芒 + 6/8 道符文；**没有**双层辅助环/内层八角星/光柱 |
| `STYLE_LIGHT = 1` | **t3** 主阵、竖立光环、光龙、Apollo | 标准白金光阵（原来的满配几何） |
| `STYLE_LIGHT_GRAND = 10` | **t4/t5** 主阵、天降光柱落点 | 标准阵再套一圈外环 + 12 道向外刻痕 |
| `STYLE_LIGHT_SKY = 8` | 只给「天降光柱」悬在落点上方的天阵 | 同一套几何；**不往上长柱**，改往下垂 12 片光幕 |

**禁止**光系再使用 `STYLE_STORM`（雷法线条型）。0 号样式仍然归暗系召唤 / 暗龙，别动。

## 2. 三档施法方式（`LightRitualSequence.Rite`）

| 档位 | Rite | 主阵 | 小阵 | 绕身门环 | 屏幕演出 | 核心 |
|---|---|---|---|---|---|---|
| t1 | `INSCRIPTION` 铭刻 | `MINOR` | 2 颗，**无竖立伴生环** | 0 | 无压暗/无过曝/无心跳/无震屏 | 一颗低空小光种，**无光柱** |
| t2 | `INSCRIPTION` 铭刻 | `MINOR` | 3 颗，**无竖立伴生环** | 0 | 同上 | 同上 |
| t3 | `SANCTUARY` 圣所 | `LIGHT` | 4 颗，各带竖立伴生环 | 2 | 暗角 0.45×、心跳、轻震 | 细光柱 + 水平光芒 |
| t4 | `DESCENT` 天穹 | `GRAND` | 6 颗，带伴生环 | 4 | 暗角 0.8×、心跳、明显震屏 | 三层光柱 + 8 向光芒 + 光带/脉冲/光雨 |
| t5 | `DESCENT` 天穹 | `GRAND` | 8 颗，带伴生环 | 6 | 满档暗角 1.0×、心跳、最重震屏 | 同上，数量/亮度最高 |

> 低阶不是“缩小版高阶”：t1/t2 **没有竖环、没有光柱、没有屏幕压暗**，
> 读条结束只是阵亮一下；t3 才第一次出现“门”和心跳；t4/t5 才是“暴风雨的前夕”。

数值入口（服务端铺阵和客户端读条共用）：

- `satelliteSeals`：2 / 3 / 4 / 6 / 8
- `gateRings`：0 / 0 / 2 / 4 / 6
- `uprightHalos`：0 / 0 / 1 / 2 / 3（释放后真正留在场上的竖环）
- `groundRays` / `outerRunes`：6 / 8 / 12 / 18 / 24
- `screenFx`：0 / 0 / 0.45 / 0.8 / 1.0
- `hasCorePillar` / `hasUprightCompanions` / `hasRibbons`：t3 起
- `hasLightRain`：t4 起

## 3. 各处的实际用法

| 来源 | 位置 | 样式 | 半径 |
|---|---|---|---|
| `TNLightChainMechanics.spawnGraceArray` 主阵 | 施法者脚下 | 按 `rite(tier)`：MINOR / LIGHT / GRAND | `spell.radius()`（8~16） |
| 同上，卫星 | 两圈轨道 | `STYLE_LIGHT_MINOR` | 1.0~2.8 |
| 同上，竖环 | 身后，t3 起 | `STYLE_LIGHT` + `upright` | 2.4~2.8 |
| `TNLightChainMechanics.castSummon` 主阵 | 施法者脚下 | 按 `rite(tier)` | 3.2 + 0.28×tier |
| 同上，每只天使落点 | 天使脚下 | `STYLE_LIGHT_MINOR` | 1.2 + 0.08×tier |
| `TNLightBeamMechanics.castSky` 天阵 | 落点上方 28 格 | **`STYLE_LIGHT_SKY`** | `spell.radius() × 1.6` |
| 同上，落点地阵 | 地面 +0.04 | t4/t5 `STYLE_LIGHT_GRAND`；否则 MINOR | 上面的 0.8 倍 |
| `TNLightDragonChain` | 光龙脚下 | `STYLE_LIGHT` | `SCALES_RADIUS × 0.6` |
| `TNApolloEntity` | Boss 脚下 | `STYLE_LIGHT` | 3.8 |

> 天阵不往上长柱：光柱是从阵心**往下**落的，阵再往上长一根就会和光柱穿模。
> 地面主阵仍然保留 7 格光柱（`min(7, 1.6 + 0.30r)`）——低阶样式不画光柱。

## 4. 细节分级（样式优先，半径兜底）

`ElementSealRenderer` 里：

- `STYLE_LIGHT_MINOR` ⇒ **simpleSeal**：2 圈环、6 道刻痕、中心亮核；
- `STYLE_LIGHT` / `STYLE_LIGHT_GRAND` 且 `r >= 4`、不竖立 ⇒ **grand**：20 道日冕、5 圈环、
  4 条饰纹、24 道符文、8 颗小阵、8 根辐条、2 个方框、12 道内刻、中心核、光柱/光幕；
- `STYLE_LIGHT_GRAND` 额外再套一圈 `1.10R` 外环 + 12 道向外刻痕；
- `r < 4` ⇒ simpleSeal（小阵不需要单独模型）。

新增光系内容时：**先按档位选样式**，再把真实半径传给 `configure(...)`，
不要为了“看起来大”虚报半径。

---

## 5. 尺寸契约（不许缩）

- 地面主阵：外环 1.16R，日冕 1.02~1.24R；高阶外环 1.10R；
- 竖环：2.4~2.8 格；
- 天阵：`spell.radius() × 1.6`，**比旧贴图只大不小**；
- 小阵：1.0~2.8 格；
- 光柱：最高 7 格；天阵光幕：向下 2.4 格。

---

## 6. 新增一个光系法术时的检查单

1. 需要阵吗？需要就按 `tier` 选 `STYLE_LIGHT_MINOR` / `STYLE_LIGHT` / `STYLE_LIGHT_GRAND`；
2. 是悬空天阵吗？用 `STYLE_LIGHT_SKY`，并把 y 放在落点上方（参考 `SKY_HEIGHT=28`）；
3. 半径用**法术真实范围**，不要写死；
4. 竖立光环才传 `upright=true` + `facingDegrees`，普通阵不要传；
5. 别再 `import` 或写 `STYLE_STORM`；
6. `gradlew test --tests "com.tnc.tnc.light.LightSealStyleTest"` 与
   `--tests "com.tnc.tnc.light.LightRitualSequenceTest"` 必须绿。
