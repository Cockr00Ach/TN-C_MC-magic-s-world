# 魔力视覆盖、手动注魔与测试棱晶

## 快速测试

创造模式输入 `/give @s tnc:creative_mana_prism`。

- 拿棱晶右键自己放置的机器：充满该机器的缓冲。
- 机铠或饰品放进充能台最左格，再用棱晶右键台子：同时充满装备的真实充能账本，机铠即为12000M。
- 潜行对空气右键：给背包、身上及副手的充能物品补满。魔力瓶必须单个分开，多个空瓶堆叠不凭空复制能源。
- 没有生存配方；生存模式拿到棱晶也不能使用。仍不能给其他主人或不允许使用的机器注能。魔力炉需先正确成型。

正常玩法：成熟供魔植物→集露盏→晶纤/储池→充能台。台子0/800表示没有缓冲魔力；装备充电后也可能立即用光缓冲，应同时看装备储量。机炮使用穿戴中的机铠，不需要单独充能。

机器面板的「注入5秒 · 5M/秒」会开始一次5秒注能，从个人实际魔力逐秒转入，需保持四格内。充能台与其他正容量机器现在也可使用。想一次大量补充请用创造棱晶，正常玩家注魔保留真实扣费和速率。

## 修复依据

打开界面时客户端原先把所有机器暂时当作INFUSER，Screen.init因此创建了不属于该机器的按钮。收到后续类型同步后，流出文本出现，覆盖按钮；服务器又只接受INFUSER操作，导致植物能供魔、点击个人注入却失败。

菜单打开包现在携带机器类型，在初始化控件之前设置。流量、注能按钮、背包分别占独立行。充能台仅开放左一格接收有效饰品/机铠，其他格变暗，Shift转入只进入有效格。

还复现了普通魔力瓶被机器GUI拦截、充能台接收泥土占住有效格的问题；两个回归测试先失败，再验证修复。普通满瓶右键可转入25M，余额真实扣除。

## 魔力视

保持柔光粒子、星芒、局部旋涡、柔雾的形态。全粒子档覆盖96格，预算24000；减少档80格/14400，最少档64格/6000。世界坐标的粒子团增加纵深，按旋转顺序填充，避免总是先填某一方向。真实传输独立保留预算。

细粒与星芒使用与机铠光核同类的原生发光shader，采用正确NEW_ENTITY顶点格式；柔雾通过更低亮度软边纹理参与同一发光通道。粒子仍有深度遮挡、距离渐隐和寿命，关闭F8及退出世界清理。没有改光影包、光影配置或全局视频设置。
