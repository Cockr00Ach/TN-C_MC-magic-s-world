# 魔力视、折光镜与天穹式魔导铠

## 玩家入口

- F8：开关魔力视。硬边彩色线带已删除，改为原生图集里的柔光微粒、星芒与局部魔力雾团。真实输送粒子按服务端接受的流量从源移向目标，环境粒子不产生能源。
- 折光镜：检流尺潜行右键镜A，再点镜B，必须同一主人。普通12格、远折24格，混用取较短距离；可斜向、跨高度。镜头自动转向对方。实心墙挡住会停机，拆墙恢复；空手潜行右键镜子解除。区块没加载时不强制加载。
- 机铠：魔力炉锻造天穹式魔导铠及六联晶铳，充能台充好再穿胸甲位。完整模型覆盖头、躯干、双臂和双腿，仍只占一个槽。
- 持晶铳长按右键：正常10发/秒、每发12M；潜行右键轮换水、火、雷、风、土、光、暗。无需箭。
- V：150M推进突进，5秒冷却。B：200M启动8秒屏障，12秒冷却，挡伤另耗35M/HP、最多挡80%。G：1000M启动8秒过载，30秒冷却，20发/秒、18M/发。潜行V：800M范围震荡，20秒冷却，只打敌对怪物，不破坏方块。按键可重设。
- 持续射击积热，满热强制排放3秒；机铠容量12000M，充能台最多128M/秒，受实际网络供给与带宽限制。普通饰品仍16M/秒。复制同一充能物品不会复制余额。
- 创造测试：`/give @s tnc:mana_mech` 和 `/give @s tnc:mech_spellgun`。拿到空铠仍须充能，不能用物品NBT绕过真实充能账本。
- 城堡独立维度：`/give @s tnc:heroskand_gate`，放置后右键进入，落点的界门可返回。

## 验证范围

`test build runGameTestServer -PlifeRoutesTests -PbuildingGameTests -PftbQuestLoadTests -PftbQuestLoadDir=work/skyward-ftb-test`：实际载入当前整份任务书，37章、1829任务、3奖励表；41项必要GameTest通过。覆盖镜子斜向传输与守恒、存档配对、墙体阻断、主人隔离、机炮真实扣魔与射速、屏障扣费/冷却/最后9M余额、过热拒绝、旧容量升级、震荡不伤农畜与地形。

`test build runClient -PbuildingGameTests -PmanaSightAudit -PmanaSightShaderAudit -PmechAudit`：隔离的原生Minecraft客户端，使用实际Oculus 1.8.0、Embeddium 0.3.31、ComplementaryUnbound r5.6.1。截图覆盖日夜、开关、实际传输、全身穿戴、第一人称开火、屏障、突进、过载、震荡和两面镜子的方向；另录制60帧实际粒子动态。审计会检查枪渲染器已挂接且三个零件有实际烘焙几何，避免“能射击但看不见枪”。

独立审查修复：Oculus把自定义粒子队列放入不透明/透明两个阶段，现只在正确阶段提交粒子几何；战斗与魔力视共享质量相关上限，战斗另占至多1/3；离开世界与资源重载释放粒子和ClientLevel引用；屏障先计算可支付的整数扣费，避免浮点进位拒绝最后一笔。

这不是整套PCL模组的人工逐项通关测试。隔离夹具不装天空岛模板、Spell Engine等无关完整包资源，会出现相应缺失提示；它验证本次原生渲染和真实服务端行为，最终JAR另做运行引用与安装字节校验。完整检查结果和安装哈希在 `release/skyward-particles-mirrors-install-20261018.json`。

## 安装与保留

`tools/install_skyward_update.py --prepare`复制当前完整任务书到测试夹具，仅替换工坊页。通过检查后`--apply`备份旧JAR和整份任务书，再安装到PCL与工作镜像。工坊83个任务保持原ID，更新配对、配方、容量和能力说明；其余41个任务书文件逐个校验不变。不修改任何存档和天空岛蓝图。队友的石枪兵分层护甲更新也保留在合并构建中。

可编辑模型源及说明见 `model-source/skyward_mech/README.md`。预览图片与视频均来自原生客户端，不是效果概念图。
