# 玩法任务书正文草案

九页正文已接入玩家按 E 后左上角的 **FTB Quests 任务书**，在“TN-C - 玩法指南”分组中按顺序展示。不是独立 G 键指南，不替换 WhisperingQuests 剧情界面。正文资源以 `src/main/resources/assets/tnc/guide/gameplay.json` 为准，原生章节位于 `questbook/ftbquests/chapters/`；本稿保留完整节点草案。

等级、钱袋、委托结算、匠人、食物袋、生活魔法、房产与关系行为尚未启用，页面明确标记“筹备中”，不设置无法完成的活动目标。剧情单列，由合作者维护，本稿不改变人物经历或剧情台词。交付与验证范围见 `玩法指南交付-20260929.md`。

## 第一页：剑与魔法的世界

这里既有剑与铠甲，也有魔法与未知。作为冒险者，你可以走进遗迹、回应酒馆的委托，也可以在旅途之间经营农田、准备晚餐，拥有一个值得回去的家。

你的旅途有三种指引：剧情告诉你为什么出发；玩法任务教你怎样成长；酒馆委托让每次出发都有明确目标。你不必一开始就决定全部路线，但最好先认识自己的魔法石。

### 七种魔法师

- 水魔法师：全能。水球追求单体打击，水纹控制战场，水缚限制敌人，雨滴照顾持续治疗和保护。攻、控、续航都能找到路线。
- 雷魔法师：迅捷与爆发。雷击和雷球制造压力，机动能力让你掌握进攻节奏。
- 火魔法师：强攻与代价。射线和火球压制敌人，强化路线需要留意自己的生命与周围地形。
- 风魔法师：速度与干扰。位移、风灵和范围风让你自由穿梭，不必在敌人的节奏里战斗。
- 土魔法师：防御与控制。岩石、泥沼和地形是你的工具；尚在筹备的技能以目录状态为准。
- 光魔法师：治愈与守护。照顾自己和同行者，是光系的方向；具体技能随版本开放。
- 暗魔法师：侵蚀、献祭与召唤。力量可能伴随代价，不要只看名字就忽略技能说明。

冰属于水的衍生。农事用的通用魔法不新增一个元素，也不与乱魔混在同一栏。

### 先弄清四个词

亲和力决定你能理解某元素到什么程度；魔力是施法时消耗的力量；魔力上限是你能够容纳的总量；魔法点数是用来学习新法术的资源。亲和力不是可以随便花掉的学习点。

法术按路线逐阶学习，各条路线互不占用进度。法杖上显示的是每条路线当前学过的最高阶；你的知识在魔法石中，不在那根棍子里。

**下一步：查看自己的魔法石。默认按 V，可在控制设置中改键。**

## 第二页：法杖与匠人

魔法石保存知识，法器帮助你把知识化成力量。第一件法器可以是一枚法阵，高阶则是能承载更强魔法的法杖。

水系武器顺序：水·冒险者法阵 → 水·精良法杖 → 水·王级法杖 → 水·传说级法杖 → 傲慢的水龙王。

精良是武器品级；勇者级是法术等级。不要把它们误认成同一件事。即使拿到神杖，也不会凭空学会神级法术。

本包计划把职业战斗装备交给匠人打造：你寻找矿石、晶体与战利品，匠人完成制作。订单界面会列出材料、人工费和成品；本版还没开放的装备显示“筹备中”，不要求你找不存在的配方。

灶具、农具和建筑部件仍然可以自己制作。你是在委托打造装备，不是在放弃建设自己的生活。

**下一步：查看匠人订单说明。具体配方后续开放，第一次教学打造免人工费。**

## 第三页：魔法师怎样变强

你的力量来自先天亲和与后天旅途。冒险等级积累经历，亲和力决定法术理解上限；只有等级，没有亲和力，不能越过所有学习门槛。

计划采用永久的冒险等级：击败野外敌人、完成委托、完成旅途里程碑都会带来成长；附魔或死亡不会把这些经历花掉。原版经验仍用于附魔，不是你的职业等级。

成长草案：每升一级，魔力上限＋10；每到 10、20、30……100 级，各获得 5 魔法点数。具体版本是否启用，以本页顶部状态为准，不以原版经验条猜测。

按七系亲和力都为 3 的角色举例：Lv.1 容纳 210 魔力，Lv.50 容纳 700。更大的魔力池提供施法空间，但学习新路线仍要投入点数。

初学技能可以尽早选择；神级奇遇不是普通练级奖励。找到自己的主路线，比把每个图标都点亮更重要。

**下一步：选择一条想学习的路线，查看下一阶要求。**

## 第四页：让协会记住你

等级是个人经历，职称是协会对你的认可。成为高阶冒险者，需要足够的等级、声望和一次实际晋升挑战。

成长顺序：初级 → 精锐 → 王级 → 帝级 → 龙级 → 冠名冒险者。

等级/声望草案分别为：1/登记、10/100、25/350、45/900、65/1800、85/3200。数字只说明门槛，晋升挑战会告诉你要证明什么。

最后的神阶职称不只是名字前加一个“神”字。你将完成冠名试炼，选择自己的名号，让本包 NPC 在以后的对话中称呼你为“名号·玩家名”。例如“苍潮行者·你的名字”。

称号属于你的故事，不自动等于法杖名字；冠名试炼的具体剧情交给主线作者。

**下一步：去酒馆完成冒险者登记，查看当前可接的委托。**

## 第五页：酒馆的委托栏

每张委托背后，都是一个需要冒险者的人或地方。低阶委托让你熟悉周围，高阶委托把你带往更大的未知。

委托分为 E、D、C、B、A、S，另有由剧情开启的世界委托。板上每档暂定展示 8、6、4、3、2、1 单：阶位越高，数量越少，但一单包含的事情越多。

初级冒险者通常接 E 单，最高可以挑战 D 单，不能直接接 C 单。之后依此类推：最多越过一档。最多持有三单，其中最多一单为越阶挑战。

低阶不是没价值：补给、食材、送餐同样支撑旅途。但做远低于职称的工作不再获得晋升声望，想被协会认可，就需要证明新的能力。

大型远征可能要求先侦察入口，再准备补给，最后击败首领并带回证据。不是把“杀十只怪”改成“杀三百只怪”。

委托刷新不会删除你已接取的普通任务。世界委托不在酒馆随机刷出，不能靠不停睡觉提前刷到结局。

**下一步：选择一份符合资格的教学委托。**

## 第六页：钱袋与交易

铜币用于日常生活，银币让你准备像样的远征，金币留给珍贵装备与更大的家园。100 铜换 1 银，100 银换 1 金；价格会同时显示你当前钱袋中的余额。

钱袋计划拥有独立饰品栏。你可以看到账目、收取委托报酬、支付匠人费用，也可以取出实体币给同行者。绿宝石仍是原来的交易物，不是无限铸币的材料。

你真正付出的不只有金币：高级装备需要稀有材料，特色料理需要自己的种植与采集。一份低阶委托应当足以补足食物，并让你存下一点钱。

金币方案推荐死亡后保留钱袋；拿走或复制袋子不会拿走或复制角色余额。这条还在讨论，正式开启前会在本页明确说明。

**下一步：结算教学委托后，看看第一笔收入和下一件想打造的装备。**

## 第七页：田园与餐桌

农田不是冒险的反面。它让你的下一次远征有可靠的饭菜，让你能给朋友一份有心意的礼物，也让家中多一件可以一起完成的事。

计划提供五格食物袋，帮你把旅途食物收在固定位置。料理与碗瓶各有去处，不把非食物塞进去，也不让容器在使用后消失。

真正死亡后，饱食度只恢复到 30%，需要重新吃饭。倒地后被队友救起不算死亡，不再触发这条重生规则。出发前记得准备返程与意外所需的食物。

首领掉落中的可食素材可以制成珍馐。第一次吃每种珍馐，必定获得对应生命上限提升；同种再吃不会无限加血。食谱会显示你是否已经获得永久收益。

你可能会对第一次吃到的特色菜作出评价；NPC 也有自己的口味。喜欢的食物能增进关系，但一百个同样的面包不会替代真实相处。

农事通用魔法计划包括初芽术、田园之息和丰穰法阵。它们帮助作物生长，不替你自动收获，也不要求放弃普通种田。

**下一步：种下一小片作物，尝试完成第一份料理。**

## 第八页：买房、装修与家庭

天空岛不只是远征的起点。这里计划划分居民住处与待售空屋，你可以先认识邻居，再用自己的委托收入买下一栋房子。

交付的房屋只有完整建筑外壳，没有家具与现成装修。床、桌子、灶台、储物和装饰都由你自己安排；也可以请朋友来帮忙，把带回来的纪念品变成家的一部分。

第一处小型空屋暂定 5 银币，正式价格与房源以售房栏为准。购买是一次性付款，没有每日房租；重登不会清除产权或装修。买房前可以在野外搭建临时营地，没房子也能继续接单、练级和推进剧情。

共同生活从认识彼此开始，不从一张购买菜单开始。居民有口味、日常与需要帮忙的小事；朋友、伴侣或家人会记得你带回来的东西，也会对你的生活作出回应。

婚姻与家庭细节正在筹备。先完成攒钱买房、自己装修、认识邻居、准备餐桌和共餐的基础流程；后续共同生活需要合适住处，剧情人物不会因此自动变成可以结婚的居民。

你可以选择伴侣，也可以选择室友、挚友或一个人的家。没有每日房租和离线惩罚，不必为了保持好感每晚放弃冒险赶回来。

**下一步：去看一间待售空屋，把房款作为你的第一个家园目标。**
