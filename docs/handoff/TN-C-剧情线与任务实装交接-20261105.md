## 2. 故事核心与世界真相

故事不是打一串无关联Boss：**吴归衡寻找不告而别的挚友公孙衍，最后发现对方是为保护自己才出走；追寻真相的行动反而触发灾难，归用自己的消失换来一次重来的机会。**

世界之外还有世界，外部有黑暗围绕；另有某个存在保护这个世界，使其保有魔力源泉。保护者是谁，用户明确要求**先不说**，不能新模块里顺手揭底。归的均衡意味着能容纳所有魔法，也使他可能成为容器或桥梁。获得别人的魔法石能读到对方施法相关记忆，但具体限制仍待细化。

魔法石、亲和力、魔法点数、链、领域/特殊魔法要统一用词。五阶是冒险者、勇者、王、传说、神；这些既有魔法等级不代表授权制作此前暂缓的社会职称/晋升系统。原稿“只有亲和6才能神级”等是原有成长规则，归终局的临时伪神级属于特殊剧情，不应直接变成一般玩家跳级特权。

## 7. 与天空岛、生活及新模块怎样共存

区分三条线：

1. **正史主线**：寻找衍→黑暗潮→黑暗深处→挥戈→二周目钩子，承载人物和世界真相。
2. **阶段居民教学**：命名/抵达片、夜间首次F8、风铃林视界谜题、田庄生态、工坊输送等，教真实玩法。不能用它代替正史，也不能在演示中泄露容器真相。
3. **可选择的生活与冒险**：委托、地下城、药锅、科技、成家、经营、归航札记，给多年旅途真实内容及返回小镇的牵挂，不强迫结婚/买房/借贷。

`docs/town/RouchNao剧情与生活推进-20261001.md`已有三条三章生活故事：酒馆晚餐、远方见闻、自家灯火，代码/里程碑属另一支；文中Bountiful栏和“天空岛注视”是旧时期设定，委托已换自制栏、新岛已禁旧注视通知。不要按旧文档恢复。

**新模块的接入检查（工作约定，不新增正史）：** 它属于哪段；何处找谁；通过哪项实际行为推进；只是可选经营还是必须主线；涉及哪些人物和真相；是否占用还没定的二周目/保护者；FTB教学与剧情账本分别由谁授予。适合放进多年旅途的模块不必强行变成终局开关。
