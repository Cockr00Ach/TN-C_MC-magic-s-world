# 水法反馈修订 · 2026-09-28

## 本次修改

1. 补齐20个水法及乱魔的独立16×16图标，不再依赖不存在的资源。V键GUI加入实际技能描述、自动换行提示与路线翻页，小窗口仍可访问所有路线。
2. 水球与水炮弹增加三轴能量环、三股旋转尾迹、水花/气泡；水炮弹增加高压环。服务端仍只伤害首个命中目标，没有增加范围爆炸伤害。
3. 法阵使用项目已有雷法符文纹理，增加反向旋转内环、环绕小法阵、青白水环和金色符文。仅复用已有材质，不修改雷法逻辑。纹理使用双面无剔除渲染，仅提交一个面，避免重复混合。
4. 龙滅主束直径14格、主阵直径30格，最大范围96格，持续12秒；六股粗螺旋与压力环加强轮廓。每tick直接破坏预算仍为128，基岩/容器/领地/未加载区块保护保留。遇保护或复杂附着物可能提前停止，不能保证总能打满96格。
5. 海浪斩击从施法者眼部向26个方向发射：水平8、向上45°8、向下45°8、正上/正下各1。波刃增加水体厚度、白色浪沫与闪光。命中检测是薄横截面的扫掠，不使用提前命中前方目标的巨大球形端帽；上下小型飞行目标也在候选范围内。
6. 治疗路线不再只有相同下雨：雨滴是蓝色水滴涟漪，初雨是翠绿螺旋，雨落是冰蓝莲瓣护罩，暴雨落是金青四柱阵，天洪是白金天空法阵、六道水柱与地面多环。治疗量和友方规则保持首版。
7. 乱魔改为V键GUI的「独立魔法」入口，可用原有魔法点学习、法杖选取和原施法系统施放。不增加第八元素，不要求元素亲和力、不推进元素路线。射程24格、沉默3秒、冷却10秒；学习/魔力消耗使用原系统第一级配置。旧符印保留注册以兼容存档，但停止施法并从创造栏移除。

## 使用

退出并重新启动同一个PCL魔改实例。普通玩家按V进入「独立魔法」学习乱魔，再从法杖选择；水法仍在水系各路线学习。管理员可用 `/tnc learn tnc:chaos_magic` 学习，但仍需要足够魔法点。

独立测试世界的 `/function water_test:setup` 现在学习乱魔，而非给予旧石头。该函数仅在本机测试存档中手动执行，不会自动重置正式玩家数据。

龙滅永久破坏地形，先在独立测试世界使用；普通水法调试入口继续拒绝龙滅，单独使用 `/tnc water destructive`。

## 实现与美术维护

- 图标源生成脚本：`tools/gen_tnc_water_icons.ps1`，原创像素/矢量图案，输出jar资源目录内21个PNG。
- `WaterGeometry`：符文材质叠层；`WaterWaveVisuals`：波刃/卷浪/环形巨浪；`WaterRainVisuals`：五级不同治疗几何。
- 海浪参考 [Alex's Caves WaveRenderer](https://github.com/AlexModGuy/AlexsCaves/blob/main/src/main/java/com/github/alexmodguy/alexscaves/client/render/entity/WaveRenderer.java) 的水体与泡沫分层思路；激光参考 [Cataclysm Death Laser renderer](https://github.com/lender544/new1.20.1/blob/master/src/main/java/com/github/L_Ender/cataclysm/client/render/entity/Death_Laser_beam_Renderer.java) 的主束、末端光晕分层。没有复制这些模组的贴图、模型或代码，也不新增它们作为依赖。
- 同伴安装必须更新构建出的 `mods/tnc-1.0.0.jar` 与15份KubeJS水法JSON。用 `tools/install-water-update.ps1 -LivePack <完整实例目录>` 进行备份、覆盖和SHA256校验；该脚本不编辑存档，并拒绝游戏运行时更新。
