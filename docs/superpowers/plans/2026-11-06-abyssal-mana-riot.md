# 玄潮黑海魔力暴乱实现与验收

1. 扩大并加密稳定锚点布局，调整宽高比例，限制最近两座高细节及全部形体低于Y170。
2. 单独实现纯数值魔力几何：上卷流束、海面旋臂、扩散脉冲、剪切乱流和受限邻近连接。发光贴图与风体分层绘制，不改物理海水。
3. 保留根点检查、F8与深度，增加通用从远到近绘制和分档预算，记录仅供原生验收的特效数量与耗时。
4. 扩充有意义的几何/预算测试，静态代码审查；JDK17离线构建，检查原型武器类、原混入、资源与CRC仍完整。
5. 仅在隔离实例启动并拍摄三视角，检查体量、密度、流动层次和光影；不足则改完再拍。
6. 确认游戏退出，备份真实PCL旧包，标准安装器完整校验并核对哈希。记录验收和安装结果，仅提交本次自有文件。
