# 地下城实装计划

用户已批准随机房间方案，并要求四门全部使用、先完成杂兵与地下城，Boss 专属机制后补。本轮直接制作与安装。

1. 新增黄沙遗庭、锁钟地牢、沉潮回廊、星眠幻庭四主题与独立维度；生成器必须保证八房连通、门数不超过三、出口可达。
2. 实现十类杂兵及职业／颜色变种，独立家族模型、贴图与动作；骷髅和史莱姆允许沿用原版造型基础。Boss 层暂用明确标注的基础守关试炼，不宣称专属机制已做。
3. 完成房间建筑、走廊、刷怪、封门清场、宝箱、事件、当段祝福、三十层与五层存档、代币与返程。
4. 服务器持久化实例与玩家资格，保包失败结算和20%本段遗币损失，安全重登、多人邀请、原实例隔离及保护。地下城失败接管自己的倒地流程，避免全服 co-op 团灭分组串联。
5. 野外大门使用用户蓝图本地导入，代码仓库提交导入工具和来源清单；入口资源随本机运行包安装，第三方源文件不擅自公开上传。原生世界生成与安全显式测试入口均支持。
6. 制作分开的地下城面板、地图/进度显示、手册、独立任务章节及酒馆引导；保留原任务书全部章节。
7. 随机图与存档单元测试、实际服务端房间和怪物测试、原生客户端模型/四主题/界面截图；只读代码审查，修复后安装和push。

不修改家庭系统、天空岛模板或用户已有世界建筑。只有新增未探索区块生成新野外入口；测试入口按明确指令放置。
