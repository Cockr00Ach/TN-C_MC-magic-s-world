# 离岸龙卷轮廓修订

1. 将H降低为42～62、R降低为20～38，收窄顶部曲线及翻卷云边；外围光流跟随，并收紧垂直剔除界限。
2. 以固定作者岛外接区块定义保护范围，风暴全包围半径外另留80格海带，连线同样避让；保证8区块视距下无额外加载的离岸背景可见。
3. 回归尺寸、高度、胖瘦、离岸半径、角落与桥接安全，继续运行原淡入/折返与预算测试；静态审查所有分支。
4. JDK17离线构建，检查武器原型58个类/资源和原有混入仍一致；仅在隔离实例按70FOV/8区块从实际岛岸拍摄昼夜与近海图。
5. 观察到明确空海带、完整收束漏斗、低于岛面的顶部后，备份并通过标准安装器同步实际PCL；核对哈希与ModernFix唯一true，记录验收。
