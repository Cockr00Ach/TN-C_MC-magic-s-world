# 战士锻造手感原型实施计划（2026-11-05）

用户已批准开始，精细建模后置。此轮完成设计稿阶段A的可玩闭环，不把兵魂、完整地下城掉落和全武器迁移混入首轮手感验证。

1. 独立规则：四种代表兵器的目标部位、力度、轮廓偏差、修正机会；五项评分与七档品质。节奏只占锻打15%，按错节奏仍可正常塑形。
2. 独立炉／砧／槽：真实投入与扣料、热坯转移、轻重锤、预设姿态淬火、装柄、成品；暂停和卸载保留本次状态，不丢物或复制。
3. 占位但可读的表现：现有纹理搭出的工作台，坯料随锤击变形，颜色反映热量；落点提示、声音与水纹读取规则真实状态。精细设施与武器模型不在本轮新建。
4. 七档结果与神铸：保存全工序记录、制作者；应用工艺属性；最高档可命名，异象先做程序化原型，不声称最终美术完成。
5. 验证：正常完整制作、错误落点／力度、低温／过烧、重淬与修正上限、七档边界、暂停重载、多人归属、满背包和重复取出；规则单测与真实服务端GameTest。
6. 独立代码审阅并修复重要问题；交付实际实现与测试范围和玩法入口。原有法杖、枪械、旧魔力锻炉、FTB和存档均不修改。不自动安装未试玩原型。

精细建模、兵魂成长、全武器接入、掉落与旧古铜迁移在该手感原型试玩后分阶段继续；不能将此原型报告为全系统完成。
