# 主世界天空岛新手村实施计划

对应设计：`docs/superpowers/specs/2026-09-20-overworld-sky-island-starter-town-design.md`

## 1. 建立可重复的离线资产生成器

文件：

- 新增 `tools/generate_sky_island_structures.py`
- 新增 `tools/test_generate_sky_island_structures.py`
- 读取 `kubejs/data/tnc/structures/medieval_town/manifest.json` 与现有 100 个 NBT 分块
- 输出 `kubejs/data/tnc/structures/sky_island/` 和运行清单

要求：

- 岛局部尺寸固定为约 `520×220×520`，根尖为局部最低层，城镇道路基准面为局部约 `Y=85`。
- 城镇按中心锚点重新定位；删除旧矩形深层地基，只保留建筑、方块实体与浅层支撑。
- 使用固定种子生成不规则圆边、草土层、岩壳、4 条主根、4–8 条副根、晶体和自然环。
- 中央城镇占地区域不生成会填入建筑空气空间的地形。
- 结构按 `48×48×48` 分块，跳过空分块，保留源 DataVersion 与方块实体 NBT。
- 测试尺寸上限、圆形轮廓、根系最低点、城镇锚点、方块实体坐标、分块唯一性和确定性哈希。

## 2. 生成并验证天空岛资产

- 运行离线生成器生成正式 NBT。
- 输出方块数、结构数、压缩体积和各层统计。
- 验证旧城镇 100 个分块中的全部方块实体均进入新城镇层。
- 对局部俯视掩码和侧面高度输出可审查的 PNG 预览。
- 若总非空气方块或模板数超出预算，优先减少岩壳厚度和小根数量，不裁剪建筑。

## 3. 实现 Java 持久化状态机

文件：

- 新增 `src/main/java/com/tnc/tnc/world/SkyIslandManifest.java`
- 新增 `src/main/java/com/tnc/tnc/world/SkyIslandSavedData.java`
- 新增 `src/main/java/com/tnc/tnc/world/SkyIslandManager.java`
- 新增 `src/main/java/com/tnc/tnc/world/SkyIslandEvents.java`
- 修改 `src/main/java/com/tnc/tnc/TNMod.java`

要求：

- v5 状态保存阶段、操作序号、岛原点、中心、南门、地面入口和本系统拥有的强制加载区块。
- 首次登录只启动一次；每 tick 按耗时预算执行少量模板。
- 每个工作区块加载、等待、放置、保存检查点、释放；启动时回收残留票据。
- 只释放本系统成功添加的票据，不把返回 0 的既有强制加载当作错误。
- 任何模板失败均保留准确错误信息，不写成功版本，不激活入口。
- 完成后停用旧 `initial_town.js` v4 生成入口，避免两套系统同时运行。

## 4. 实现地面入口与双向传送

- 离线生成器同时输出约 `15×15` 的地面传送阵模板。
- Java 在出生点 `100–250` 格内加载候选区块并选择安全小区域。
- 天空岛成功前入口不生成或不激活。
- 玩家进入中心触发区时，在地面入口与天空岛南门间双向传送。
- 传送前验证目标脚下实体方块和头顶两格空气；成功进入岛上后设置重生点。
- 登录时显示入口、岛中心和南门精确坐标。

## 5. 自动化测试与故障注入

- 为清单解析、状态推进、检查点恢复、失败停止和票据所有权添加测试。
- 保留现有 KubeJS v4 测试作为回归参考，但确认正式入口已禁用。
- 添加缺失模板、放置异常、中途保存恢复、已有强制加载和传送落点阻塞测试。
- 执行 `gradlew clean build`、NBT 全量校验和资源存在性校验。

## 6. 安装到实际整合包并验收

- 使用 Java 17 构建 `tnc-1.0.0.jar`。
- 游戏关闭时同步 jar、天空岛结构与清单到 PCL 实例，并逐文件校验哈希。
- 使用全新世界测试：正常出生、入口坐标、后台生成、双向传送、重生点和侧面轮廓。
- 生成中途强制退出一次，再进入验证续建与票据释放。
- 检查日志中无 KubeJS 错误、无缺失模板、无重复生成。
