# 水球路线实施计划

用户已确认设计并要求开始。当前环境未提供 writing-plans 技能，按已确认设计建立本地计划。

最初范围为五个水球链技能。用户随后明确要求「一次性设计完，中间不要问」，范围扩展为四链20技能、天气联动及独立乱魔原型；以下保留水球链的实施顺序，完整首版行为、测试状态和限制见 `docs/water-magic-20260928.md`。

1. 独立 WaterSpellRules / WaterTerrainBore：几何、参数、目标规则、有限截面的预算化破坏。
2. 五个 JSON 改用 SELF + 无属性短暂标记，通过已有扣蓝后 RELEASE 回调创建水法实体；不再有引擎范围伤害，避免重复计算。
3. 水弹实体每次只打首个敌人，遇墙消失；水炮伤害高于水球。48发弹幕分16批从背后法阵绕开施法者射出。
4. 法阵/光束实体固定施放方向，维护生命周期、服务端伤害与同步后的实际光束长度；死亡、离线、跨维度、过远后取消。实体不保存，避免读档后重新开火。
5. 独立客户端几何渲染：青白符文环、旋转双层法阵、水球、连续圆柱水束及螺旋水流；不改雷法渲染器。渲染可见范围覆盖完整光束，不受小实体包围盒错误裁剪。
6. 龙滅仅有限长圆柱破坏，每tick最多128块，遇基岩/方块实体/保护拒绝/未加载区块停止。破坏前发Forge方块破坏事件并尊重生成点保护；不自动在正式存档发射。
7. 编译、单元测试、独立世界GameTest，核对单体、穿透、遮挡、半径/预算/保护/寿命；检查整合包是否有同ID覆盖。正式客户端仍运行时不替换jar。

## 首版可调参数（并非最终平衡）

| 档位 | 射程 | 伤害 | 表现/时序 | 冷却 |
|---|---|---|---|---|

沿用原有魔法石的学习、亲和力与扣蓝，不另造进度。水属性倍率采用存在时的 spell_power:water 属性（至少0）；开发环境没有此属性时倍率1。普通伤害不无条件重置原版受伤无敌帧。

龙滅掉落默认关闭，避免一次数千掉落物；方块实体作为阻挡保留库存。地形损伤永久且默认不自动修复。默认敌人为Enemy或正在攻击施法者的Mob，排除队友、玩家、驯服生物，避免误杀任务NPC。

完成状态与未验证项写在实际交付记录中，编译通过不等于实机画面已验收。
