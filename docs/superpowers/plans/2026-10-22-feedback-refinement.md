# 10月22日交互与视觉修订

本轮以用户最新实测反馈为准，直接实现、验证、安装并提交；不改用户任务书和队友装修。

- [x] 日月采集：取消通用垂直射线。日轮、日珥、来自太阳方向的聚光；月相、银色星雨、水盘涟漪。按实际入账魔力显示，不用已有库存假装工作。
- [x] 高维魔灵：移除叠加发白的实心面，保留四维投影骨架、错位折叠光环、沿棱流动的能量节拍。开关光影分别检查。
- [x] 锻炉：输入自动匹配；制作成功才记入工艺手册；点手册只显示材料，不决定配方。四个输入格维持手动放料。
- [x] 多方块供魔：锻炉、聚能塔外表面接晶纤均可传输；虚拟端口与实际晶纤连接臂一致、保护和带宽守恒。聚能塔成型有可见展开动作与内部运转。
- [x] 动物：牧杖先选动物后选集息器，无须驯养/喂食。保护他人绑定。物种行为产魔，食物只加速20%。无功能界面移除、工具优先、绑定声光提示。
- [x] 药锅：封闭实体锅底、厚壁、锅脚与炉火；水使用水纹、自然明暗、气泡与蒸汽。温度只在外圈表现，不染成巨大白盘。
- [x] 锅盖：生存消耗一件实物锅盖安装，封存融合度，继续控温后煮；取药返还锅盖。拆卸存储不复制不吞物。
- [x] 餐盘：不同五行搭配制成可携带料理，成品记录材料/相生/相克；吃成品时才结算效果。布局仍有意义。
- [x] 同步操作文档和本项目拥有的FTB指引。
- [x] 服务端回归、实际光影开关截图、安装校验、提交push。

视觉取舍：使用现有MC材质和已有天路光尘；日月各自有可识别轮廓。魔药锅的实体和水负责真实感，魔力视负责温度和药性信息，两者各有清晰层次。
