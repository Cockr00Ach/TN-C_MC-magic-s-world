# 药釜仪式、委托栏与成人开局

用户授权直接完成、安装并推送。本轮以实际世界交互为核心，不再追加确认环节。

## 方案

采用敞口实体药釜。保留插槽工作台不满足互动要求；全程复杂手势又会妨碍日常炼药。因此使用可见投料、火法点火、三次搅拌和装瓶的短仪式，暂停不会毁掉原料。

1. 水桶右键倒水，一桶供三次炼制。水位真实下降。
2. 三种配方原料各一件投进锅口，也可手持右键投入；只有配方原料和焰蕊盐被接收，不吞无关掉落物。仅接收有权限玩家投出的物品，每种最多一件，配方不合时保留并提示。潜行空手可取回未完成原料。
3. 焰蕊盐提供植物药焰。只有玩家实际火系法术命中能点火；燧石、普通火、GUI按钮都不能点火。
4. 空手或持搅拌棒右键搅拌，每次有冷却与可见旋转。炼制分为浸润、融合、凝结三个阶段，各需要一次搅拌；火焰与搅拌不足时暂停，材料不毁。空瓶最后盛取成品，必须真正消耗空瓶，药液未取出前不能继续吞料。
5. 药釜无制作GUI。空手查看简洁状态，潜行书本打开只读配方药典，不能通过配方界面放材料或点火。
6. 魔力装置邻接可选辅助，必须已用火法点火且满足本阶段搅拌，不能跳过仪式。

## 视觉

敞口深色釜体、分层铜箍、三个支脚、弯曲把手与蓝绿晶饰。药材漂在液面上，搅拌时加速旋转、逐渐浸入药液。不同配方采用不同液色和异象：

- 回春／净秽／归途：暖色花粉、环绕的叶片光尘，附近空闲动物短暂靠近（不强制传送、不改窝点）。
- 魔力／共鸣／夜航／显影：蓝绿星团在釜上方旋转汇聚，近处法力粒子被吸入。
- 战斗／防护／火系：金铜火花、向外扩散的碎晶与短时焰冠。
- 潮息／轻羽／迅步：蒸汽螺旋、上升泡沫与漂浮微光。

高阶配方体积、粒子层次更强；完成有一次明显爆发，局部光尘逐渐散去。深色旧铜配套药典和16种不同轮廓的药瓶。限制距离、粒子预算与更新频率，不持续修改世界时间、天气或方块。

## 委托与人物

新增可辨认的旧铜木框纸张委托栏。天空岛固定委托位置原有 Bountiful 板只升级该方块，附近旧板右键也路由到新页面；保护任意其他玩家建筑和普通村庄板。接单、交付仍服务端校验，保留纸张兼容交付路径。

新玩家 MCA 数据明确设置成人年龄；一次迁移纠正本整合包前版自动初始化造成的幼年状态，保留皮肤、名字与关系。验证实际 MCA API 读回成人状态，而非仅写一个未被读取的自定义标签。

## 验证与交付

合并队友17种地下城怪，保留现有怪物、土系场地和主线。测试真实投物、普通火拒绝、火法命中、水与原料消耗、阶段暂停、装瓶、重载、权限和旧菜单绕过；新增委托方块实际右键测试与 MCA 成人读回。原生客户端检查釜体、各阶段、药瓶、委托、人物。只修改新增魔药章节，保存已有任务。更新 PCL、制作队友更新包、提交 main 并 push。
