# 水法视觉第二版与独立乱魔

用户已实测首版，要求按七条反馈修改，并授权自行设计、不再提问。本次直接采用下列方向；不改雷法、不改地图、不重置正式玩家进度。

## 取舍

纯加粒子成本低但难形成完整法阵/浪体；直接依赖Alex洞穴和灾变的实体会引入依赖与伤害语义冲突。采用自有几何+已有符文发光贴图+有上限的客户端粒子，参考其分层浪峰、泡沫和激光终点的表现，不复制模组资源或代码。

## 七项落实

1. 补20个水法原生小图标和独立乱魔图标，GUI显示真实中文描述。图标由可复现的原创像素绘制脚本生成，不再落到缺失贴图；图标家族按路线、等级变化。
2. 水球增加绕球螺旋水带、气泡/飞溅和运动拖尾；水炮更粗、更长压力尾流。始终单体无范围伤害。
3. 法阵使用雷法同类的双面发光纹样，叠加反转青白环、金色外围符文、卫星子阵。水法独立渲染，雷法资源和数值不动。
4. 龙滅光束直径14格、法阵直径30格、射程96格、发射持续12秒；破坏仍每tick最多128块，不加载新区块，实际长度由钻进进度同步。基岩/容器/保护区阻挡不变。
5. 海浪斩击发射26个三维方向（水平8、上倾8、下倾8、垂直上下2）；月牙斩击横截面垂直于飞行方向，服务端扫掠判定和击退同方向，地面不能让向上波立刻消失。浪体采用有厚度的曲面、翻卷浪峰与泡沫。
6. 雨系保持现有治疗、防护数值不变：雨滴=蓝色露珠与小涟漪；初雨=碧绿螺旋水带；雨落=冰蓝水莲/穹顶；暴雨落=金青护盾与四根水柱；天洪=白金巨大悬空法阵、多层水幕、护域环。雨丝仅作为其中一层，每档有明显造型与颜色区别。
7. 乱魔加入魔法石“独立”页，可花基础一级学习点解锁、无元素亲和力和升级前置，学后挂到法杖，与现有扣蓝/冷却/遗忘/同步共用路径。独立目录不新增第八元素，不改七元素NBT数组。暂用基础一级魔力消耗和10秒冷却，效果60tick。旧符印保留注册ID避免存档丢失，移出创造栏并停用施放，提示改从GUI学习。

## 验证

编译、数据图标测试、三维方向/判定测试、独立技能无亲和限制与NBT往返测试、扩大光束预算/保护测试。审查客户端/服务端边界、资源覆盖、GUI独立页和小窗口可达性。退出游戏才安装，备份可回滚。实际画面未观测时如实记录，不把编译当视觉验收。
