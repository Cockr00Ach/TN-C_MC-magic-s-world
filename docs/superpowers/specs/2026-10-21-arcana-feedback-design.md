# 魔力生活交互修订

用户已明确授权直接完成、安装与推送，不追加核对环节。以本次七项反馈替代旧交互。

1. 药釜采用真实2×2占地，而非单格碰撞配大贴图；四角共用唯一库存和计时，拆任意角只掉一份整锅。配套整幅锅盖。删除焰蕊盐、搅拌棒及其配方。火法点燃，水冰法降温；无需燃料、手动搅拌。药材独立漩涡随温区内的真实时间靠拢，最高融合时同心成一个漩涡，错过后解离。外侧蓝/绿/红完整温度辉光。盖锅锁住当前融合与品质，继续在合适温区煮六秒才可装瓶；盖后不再改变融合度。过程、成品和整锅搬运全部持久化。
2. 天路按每刻连续牵引，初入缓慢接住，逐渐加速至每刻0.16格；导靴上限0.23。轻柔中心回正和转角过渡。持续沿整条路径显示均匀流动光屑，普通视野也可见。标记杖独立useOn处理，成功与失败均反馈，潜行对空清除选择、潜行点环重新起选，不保留无效死状态。
3. 任意真实TN-C委托栏可在近距打开；酒馆旧栏仍能打开新UI。操作必须持有效服务端会话并仍在原栏附近，走远或拆栏后不能远程接取/领奖。六张纸卡展示目标、数量、奖励、等级和接取/交付操作；保留现有无纸任务和家庭事件。
4. 高维魔灵保留实体，F8下附加四维投影形变几何、错位轮转的空心截面和晶面光晕，区别于环境粒子；不用满屏硬线。
5. 餐盘仅接收自制魔法植物的收获物，显式分类，不按物品名字猜。九格各自常驻属性颜色微粒，F8强化并呈现相生/相克反馈。普通食物、金属和种子不可放入；完整五类组合仍可获得已有药膳效果。
6. 成型深渊塔直接从外壳周围三格收取同主魔植和魔兽真实余额，遵守既有共享产能账本，不重复造魔；接收量参与过载，原网络输入保留。奇点核心同样可直收，基础储池仍无过载。
7. 极光取消围成一圈的等高分段墙，改为天顶数条宽阔、柔软的曲线幕带；连续空间色彩、边缘透明归零、多层稀薄亮纤、缓慢波动。普通视野微光，F8显露完整天幕。使用连续过程密度与顶点渐变，配合真实光影截图检查。

验证覆盖：四格放置/拆除/唯一库存、自动融合/盖后锁定/烹煮装瓶、删除物品、标记重置与错误、柔和运动连续性、真实委托栏UI和走远拒绝、餐盘白名单/各色输出、共享直收和不造魔，以及光影下药锅、锅盖、天路、魔灵、极光实机画面。保持玩家任务文本、队友内饰与存档不变。
