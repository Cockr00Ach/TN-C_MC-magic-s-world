# 遗忘后重新学习修复

原因：每 40 tick 的后台补学仅检查亲和力，把所有可学等级当作已解锁等级，调用正常购买并重复扣点；补学后没有同步界面和法杖。

采用有限补学，保留合作者换链/换法术 ID 的兼容功能。不采用完全删除补学，也不在遗忘时按当前配置猜测退款。

- 补学必须同时满足亲和力、已记录的该链进度，且不是明确遗忘的法术；只恢复已解锁等级，不购买新等级，不扣点。
- 保存历史学习集合与明确遗忘集合，随 NBT、死亡复制一起保留。手动重新学习历史法术不重复扣点；亲和力及进度限制继续有效。
- 旧存档以当前已学集合初始化历史，不猜测旧版本遗忘记录，不自动退还历史损失。
- 补学实际改变数据时同步界面和法杖一次；手动学习沿用原网络路径。
- 不改变法术、建筑、队友资源及存档本体。用户已授权自主修复并覆盖本地包；游戏关闭后备份覆盖模组。

实施顺序：先建立失败回归用例；修改学习状态和补学；运行单元/Forge 集成测试；审查、构建、安装并推送。验收涵盖水、雷、乱魔遗忘后重学、重复扣点、存档复制及新玩家不自动学习。
