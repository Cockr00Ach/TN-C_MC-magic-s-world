# RouchNao 修复与生活札记

先修复已交付事故：门牌 TextDisplay 不参与施工占位；银行等独立岗位不等待酒馆外沿施工；抵达提示与传送只在完整地形完成后开放。现有世界只补未完成的地形，原点、产权、账户、任务书和实体保留，禁止重新生成整座岛。

增加三条自愿参加的生活故事，每条三章，在酒馆协会接待员艾琳的独立“归航札记”面板办理。委托仍走原生 Bountiful 栏，银行、商店和匠人继续各自独立。

* 酒馆晚餐：筹集蔬菜 → 准备熟食 → 邀请两位成年邻居并交付牛奶与鸡蛋。结局获得盖章纪念页、解锁长桌家具，居民记住晚餐。
* 远行见闻：接取后亲自探索岛外三种群系 → 带回纸墨整理札记 → 与三位成年邻居分享。无需打 Boss，结局获得旅途纪念页、解锁远行灯。
* 第一盏灯：买下自己选的房子 → 房内实际摆放床、光源和原生家具 → 在自家完整睡过一夜，回酒馆归档。结局获得归处纪念页、解锁陈列柜。

每章经验、铜币一次领取；材料只收普通物品；容器返还；满背包、钱袋达到上限、目标不满足时全部保留。服务器计算探索、居民身份、家中摆设和睡眠，客户端仅展示，远程请求不能交付。关系仍由凡家物语控制，不另造亲密度或婚姻。

商店每天按真实时间推荐一种农牧产品，按正常收购价的 150% 收购，仍占原有额度。跨天刷新与离线时间一致，同一天所有玩家相同，系统时钟回退不重抽。不售卖农产品，避免买入卖出套利。

本次不制作开场视频、不强塞婚姻、不安排神装遗迹、不改用户任务书、不假称娱乐游戏已完成。内饰由用户后续提供，当前只修复完整源地图与可用岗位。
