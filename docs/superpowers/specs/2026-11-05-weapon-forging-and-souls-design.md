# TN-C 战士锻造与兵魂升级设计

日期：2026-11-05（北京时间）

状态：**用户已批准开始实施，精细建模后置；当前先交付阶段A的手感原型。七档品质最高为“原初·神铸”，支持命名与异象。法杖暂不设计，魔导枪械留在魔法科技。**

源码核对基线：`54b3d273397513cd032b847bf0678337c730a575`。

## 1. 核心目标与最新边界

**玩家要能感觉到：这把兵器是我一锤一锤打出来的，品质来自我的手艺。**

地下城提供武器与原料，手工锻造把原料变成想要的兵器，唤魂祭坛再赋予兵魂。玩法重心是有判断、有形变、有力度、有完成时刻的短过程。

本稿按用户最新三点要求修订：

1. **法杖暂不动。** 不迁移王杖器灵、不整合法杖温养、不设计杖芯工艺，等用户另行设计。
2. **魔导枪械属于魔法科技。** 零式、六联晶铳、机铠及其升级和制造保持原体系，不移入战士锻造。
3. **战士锻造独立。** 新设计炭火锻造炉、百锻砧、淬锋槽，不复用3×3×3魔力锻炉，不增加其兵器炉口，也不靠给旧机器换皮交付。
4. **全过程决定品质。** 加热、压坯、塑形、淬火、装配均计分；不能前面随便做，只凭最后一次完美操作得到高品质。
5. **品质独立于魔药。** 用户指定七档：拉夯了、普通、精良、史诗、传奇、大师、原初·神铸。最高档可由玩家取名，锻成时必须有天地异象；“原初·神铸”是最终修正名称。

上一轮“所有武器统一升级”，按最新边界收束为**战士武器范围内统一**：十把传统兵器、古铜四武器、原有剑／刀／重剑／镰／锤／枪戟、木制战斗兵器及弓弩。原版与第三方同类兵器逐项适配；纯盾牌、工具、护甲、饰品和弹药不在本次升级对象内。

保留原物品ID、精细模型、家族、连招、蓄力、天赋门槛和冷却。十兵器只是首批手感样本，不是最后覆盖上限。材料、工艺、淬火和兵魂保存于同一把武器，不按品质和材质批量注册新武器。

### 路线比较

| 路线 | 体验与代价 | 本稿选择 |
|---|---|---|
| 独立工坊，直接敲出受控形变，短流程世界交互 | 每一步都能看懂、能练熟，制作量可控 | **推荐** |
| 全自由金属雕刻 | 自由度高，但镜头、精度和模型成本高，容易变成繁琐编辑器 | 不采用 |
| 材料入槽后自动成品，完成时播放锤击动画 | 流程短，但玩家的手艺没有作用 | 不采用 |

用户已批准按本稿方向开始玩法开发，精细建模后置。操作与数值通过原型测试迭代；旧古铜补偿等尚未实施的内容仍保留明确的迁移预览与保护要求。本轮原型实际覆盖范围见《战士手工锻造玩法原型-20261105.md》，不能把完整设计当作已全部实现。

## 2. 战士工坊：独立、有辨识度、少跑动

### 2.1 三件工位，组成一个锻造角

| 工位 | 外观和结构 | 玩家真正操纵的部分 |
|---|---|---|
| **赤膛炉**，独立炭火锻造炉 | 2×2占地、2格高；正面敞口炭床、内衬耐火石、铜铁压边，侧面自带皮风箱。火光来自可见炭床，金属坯摆在火上 | 添一份燃料、压风箱、在合适火候夹出；炉内确实出现正在加工的坯，不只亮一盏灯 |
| **百锻砧** | 1×1占地、约1.2格高；沉重砧面、木墩、金属束箍，侧边一体翻面支架与装柄座；长武器按成品长度伸出，不缩成小图标 | 握锤选落点、轻敲／重锤、翻面、校正、最后压合装柄；侧边支架也支持木作与弓臂调校 |
| **淬锋槽** | 1×2占地、1格高；深色石槽与金属包角，水面可见，槽边一体夹架 | 摆入水姿态、压下、保持、提起；看得到兵器浸入的真实深度和冷却色带 |

三件工位摆成开口U形，砧在中央、炉与槽在左右，正常站位转身一步即可换工序；不是三台分散设备之间反复搬材料。自带夹具和风箱，不要求额外制作取坯钳、测温计、模具、风管、齿轮或泵。

炉、砧、槽均独立于旧魔力锻炉的结构、容器、配方和加工状态。制作它们使用原版石材、铁铜、木材和皮革等基础材料，初次锻造不要求先搭魔法科技网络。精确合成数量属于批准后的配方平衡工作，不在此声称已有配方。

旧魔力锻炉继续处理原魔导材料、机器和已有风灌注；其界面与供魔规则不改。新工坊可使用现有灵纹铁等材料，但**使用同一种材料不等于共用同一台设备**。

### 2.2 工具和物品保持克制

- 随身只有一把锻造锤；夹取、翻面、装柄工具属于工位，自带动作，不新增必带道具。
- 金属武器仍只需武器头＋一个柄，三种柄沿用：剑柄、长柄、锤柄。护手、剑首、缨和镂空装饰保留在模型里，不拆物品清单。
- 通用坯料与武器头用数据记录形制和阶段；回炉钢料、青铜料、硬木料沿用原稿的三类回收物。
- 齐眉棍整根木作；弓弩作为一件本体调校，不另买一背包弓弦、弩机、弓梢。
- 同一工坊一次一件活跃工件，手中是锤或由一体夹具托住的工件，不允许热坯塞进物品栏无动画瞬移完成操作。

铁匠铺提供公共工位，出售锤、柄、基础金属与燃料；自建工坊可选，不要求买地、买房或修炼魔法。cava只做功能铁匠与操作带教，不新增隐藏人物身世。

## 3. 一次锻造的节奏：短、连贯、有完成感

正常完成一把金属兵器目标为**75～110秒，含转身和夹取动作，其中大部分时间都在操作和观察形变**。首次带教约2～3分钟；高手不必等待NPC重复讲解。各工序自然相接，不出现每步开面板确认的打断。

| 环节 | 目标时长 | 玩家关注的唯一主要判断 |
|---|---:|---|
| 入炉与提温 | 12～18秒 | 观察颜色，短压风箱，把热量推到锻造区后夹出 |
| 压坯与塑形 | 30～45秒 | 对准当前部位，用合适力度让形状接近目标 |
| 校正与定形 | 8～12秒 | 找出剩余偏斜，以少量轻锤收尾 |
| 入水、冷却、提起 | 8～12秒 | 用正确姿态连续入水，读水纹收束并提起 |
| 装柄与亮刃 | 8～12秒 | 对正压合，让完整兵器第一次出现在手中 |

时间是原型目标，不是强迫玩家赶完全部步骤的倒计时。读提示、停下查看和翻面不偷偷扣分；热量只在玩家实际加工与运送时推进，进入明确的“托管暂停”后冻结本次工件状态，重新进入有2秒观察准备。只有操作中的炉热、水温和锤击会影响品质，不能把照顾现实中断变成失败来源。

**不按敲击次数发奖。** 建议正常12次左右，8～14次有效锤击能够形成兵器，另留最多2次局部修正；达到目标就结束，不要求高手为凑次数多敲。重型宽刃目标上限16次，不随武器等级堆成几十锤。

初次可跟随亮起的局部轮廓；熟练后目标部位仍由实际形状和音色提示，关掉文字也能判断。每次只面对2～3个大区域，阶段结束再换部位，避免满屏标点和到处追鼠标。

### 一把汉式铁剑的体验示例

> 玩家压一下风箱，炭床呼地亮起来；夹出橙红的坯料，放上百锻砧。第一记重锤砸下，身体随落锤前倾，坯料被压展，氧化皮和火星朝落点两侧飞出。随后左右交替轻敲，剑脊留下、两刃逐步展开，敲对部位的声音越来越清。最后两次校尖，偏斜收回，剑体轮廓贯通。转身把热刃斜压入槽，水面沿剑身分开，第一阵蒸汽升起；嘶鸣变细、水纹向刃口收拢时提起，一条冷亮的刃线从根部亮到剑尖。装柄压合后，角色举剑检视；若达到大师，完整刃线短促鸣响并出现一次克制的星芒。成品旁同时列出“火候、锻打、定形、淬火、装配”的结果，玩家知道这次哪里做得好。

## 4. 具体操作、动作与反馈

### 4.1 共用控制

放入与取出用原有右键，锤击为短按／长按右键后松开，潜行右键操作翻面支架或选预设姿态。操作中只显示这一状态可用的含义，避免同一输入同时翻面又退出。退出使用ESC，返回正常控制；它只能退出操作，不能跳过加工。

选择兵器形制可用一次简短目录，之后不进全屏小游戏。轻敲、重锤、装配压合由手臂与身体动作表现；第一人称和F5旁观都能看到相同落锤和真实落点。采用可退出的近距离观察角度，保留自由观察选项，不强行持续转镜头。

工位辅助夹具只搬运已托管的那一份工件：夹出、上砧、入槽都有短动作与实物位移；不生成可拾取的复制品。受伤、倒地、断线或切维度立即结束视角控制并安全托管。

### 4.2 加热：让玩家把火候推到位

一份燃料完成一次正常工艺，工件放上敞口炭床即可开始升温。短压风箱1～2次可明显加快升温，松开后仍有足够宽的好火候窗口；没有持续狂点风箱的耐力条。炉口氧化色、风箱起伏、炭火变亮和呼声一起反馈操作。

游戏化热度0～1000：650～850可锻，700～800为良好火候。高于850时明显发白并有刺响，连续5秒才记一次过烧；低温不会出现裂坯和突然吞料。热度不作为屏幕中央永久数字，悬停可查看，F8显示热量沿坯身扩散。

夹出时判断整体颜色是否均匀，而非抢一个毫秒闪点。锻打过程中正常完成不必回炉；慢速模式延长可加工热量时间。冷坯能重新加热并继续，不重新买材料，也不把回炉强制插入每个阶段。

### 4.3 锻打：每一锤都改变一件看得见的东西

| 阶段 | 操作重点 | 必须看到的改变 |
|---|---|---|
| 压坯，约3锤 | 重锤从厚处向外压展，左右交替 | 金属厚块逐步拉长、展宽，厚度减少，不能只缩一条进度条 |
| 塑形，约5～7锤 | 剑尖、刃面或连接位分区处理，轻重相配 | 目标区域真实收尖、弯曲、保脊或生成棱面；轮廓逐锤接近成品 |
| 定形，约2锤 | 找出当前最大的偏斜，轻敲修正 | 可见偏差减小，刃线／枪脊／棱面连成一体 |

短按0.30秒内为轻敲，按住0.45秒进入重锤准备，约0.80秒达到足够力度；按更久不无限加力，松手只落一次。0.30～0.45秒之间按轻敲处理，不制造“按法落在死区所以敲坏”的挫败。

节奏由上一锤后金属回弹与锤头回位提示，不跟外部BGM绑定。正确落点与力度是主判断，节奏是把这一锤从普通推向优秀的加分；错过节拍但位置正确仍有正常形变，不能“没按准节拍就完全白敲”。普通窗口建议±0.35秒、优秀窗口±0.18秒，慢速模式放宽且不封顶原初·神铸。

落点只有尖／身／根等大区域，不用像素级点选。敲偏会出现轻微、可解释的偏薄或弯曲；工位只突出最该修的一处，允许少量补救。没有隐藏随机“这一锤失败率”。连续乱打同点会偏形，不会靠连点自动满分。

### 4.4 打击感的明确规格

| 结果 | 动作与受力 | 声音、材质与画面 | 判定意义 |
|---|---|---|---|
| 正确轻敲 | 小幅抬腕，接触后短促回弹 | 清亮金属声、小股定向氧化皮、局部红光收紧 | 精细修形，目标区域确实变化 |
| 正确重锤 | 躯干承重、双臂抡落、砧座轻颤，锤头在接触点停留约2～3渲染帧再回弹 | 低频撞击＋短金属尾音，较多碎屑向两侧飞，表面出现压展 | 重压坯、宽刃塑形有效 |
| 优秀一锤 | 同上，额外一瞬清晰的压实感 | 中心白热小亮点、连贯刃鸣，局部轮廓稳定亮一下 | 对应工序得分更高，不能只加特效 |
| 敲错位置或力度 | 明显侧滑或软回弹，不做同样有力的胜利动作 | 闷音、碎屑很少，错误处可见偏斜；一行短提示说明原因 | 留下能修正的工艺偏差 |
| 完成定形 | 最后一锤后角色自然停手，工件摆正 | 刃线贯通、由低到清的一声收束鸣响，飞散碎屑停止 | 自动进入可淬火状态，不偷偷多扣材料 |

接触停顿只作用于本地锤与工件表现，不暂停服务器、敌人或旁观玩家。轻微画面冲击可独立关闭；默认不大幅甩镜头，不靠全屏闪白制造力度。音量与低频峰值限制，连续三把也不刺耳。

没有任何一记“空挥也爆同样火花”的假反馈。声音、碎屑、形变和得分都来自服务端接收的同一个有效落锤事件；网络有延迟时允许先表现挥锤，确认前不提前显示大师分数。

### 4.5 不同兵器要有不同的手艺

| 兵器 | 核心手法 | 最终组成 |
|---|---|---|
| 越式青铜剑 | 双刃交替、短身收尖 | 剑体＋剑柄 |
| 汉式铁剑 | 保住剑脊、两刃拉开、校直剑尖 | 剑体＋剑柄 |
| 柳叶腰刀 | 沿根到尖递进压弧，不能把弧度集中一处 | 刀体＋剑柄 |
| 环首刀 | 较短的刀身重压、尖端轻修 | 刀体＋剑柄，环首包含在柄的外观 |
| 偃月刀 | 宽刃两区重压、弧口轻修 | 刀头＋长柄 |
| 方天画戟 | 中央尖与两侧月牙轮转校正 | 整套戟头＋长柄，不拆三把小刃 |
| 红缨枪 | 枪尖对称、枪脊保厚、根部固形 | 枪头＋长柄 |
| 四棱铁锏 | 支架四面轮转，各棱敲到相近厚度 | 锏头＋锤柄 |
| 月牙铲 | 宽铲与尾月牙两个主区域分别定形 | 整套武器头＋长柄，不多买一套尾部零件 |
| 齐眉棍 | 在附带木作支架上顺纹校直、分段压正、收两端 | 整根棍身，不烧木、不淬金属火 |

弓弩在百锻砧的支架上校正弓臂、调节两侧张力、试拉至对称；手臂与弦有动作，回弹音和箭台对齐有反馈，不按热度敲打一整把木弓。古铜及其他近战兵器复用合适的手法，但展示自己的轮廓和连接点。

所有形变使用受控阶段模型与局部变形，不提供无限自由雕刻；成品仍使用队友现有精细模型，不能为了小游戏把成品做成粗糙条块。

### 4.6 淬火：把“热刃入水”做成第二个高潮

完成定形后利用操作的自然降温到达550～700淬火区，不强迫玩家再等半分钟。夹架给出两到三种兵器专用姿态，普通剑以斜刃连续入水，枪以尖端入水，宽刃按刃线递进入水，锏在同一过程内转一次棱面。

玩家按住右键压下，松开提起；工件约1.5秒连续浸入，之后观察冷却。热刃触水的瞬间，水面从接触点被推开，刃边形成气泡带与短蒸汽柱；冷却色带沿浸没部分推进，水纹从扩散转向向内收束，嘶鸣由粗变细，提供一致的提起提示。

清水最佳提起窗口约1.2秒，寒泉0.8秒、魔力泉1.0秒；大约在入水后3～5秒出现，具体按武器形制调整。慢速模式窗口至少1.2秒，不改变原初·神铸上限。各介质都有明确音色和水纹提示，不能单靠颜色或F8，也不靠一个突然跳出的QTE按钮。

提起时沿剑身留一道快速滑落的水膜，薄汽从刃口散去。优秀淬火的冷亮线完整而平稳；普通结果有较轻的间断水纹；失败结果出现可见应力纹和短促不谐声，提示“提早了／入水太急／冷却过久”中的真实原因。失败不炸掉稀有金属，可用一轮局部整修和重新淬火修复。

| 介质 | 手感差异 | 满质量收益建议 |
|---|---|---|
| 清水 | 反应柔和、读水纹最容易 | 最大耐久额外＋5% |
| 寒泉水 | 蒸汽更细、冷却色带推进更快，需要稳准 | 武器自身攻击加成额外＋3% |
| 魔力泉水 | 刃边有低亮流纹，水纹向武器汇聚 | 入魂成功少耗50M，兵魂契合收益＋10% |
| 玄潮魔水 | 高阶异变方向 | 暂缓，不设计本轮数值 |

每槽装填支持10次尝试，退出不刷新次数；同次中途暂停不重复扣。特殊介质只用槽内配方，不新建世界流体。寒泉与魔力泉沿用前稿建议的主题材料／满魔力瓶来源；不强制战士会施法或自建魔导管线，铁匠可提供已调制介质。

收益随淬火分Q折算：Q≥90为全额、60～89为半额、低于60无额外收益；同一把武器只保存一层结果。**淬火Q同时进入总品质**，不能只把它当一个额外词条。

### 4.7 装配与“这把是我做的”

正确柄放上装配座后，玩家对准工件与柄的中心线按住右键约1秒压合，手臂随夹具推进；最后一次短按锤击锁定，武器头、柄和原模型装饰完整合为一件。对正宽容，不做新的高难QTE；错误柄不吞，偏斜可重摆。

完成后角色举器检视约1.5秒，可跳过动作但结果已由服务端保存。七档成品按5.1的声音、刃线和光效递进；普通成品干净利落，传奇与大师突出成器仪式，原初·神铸进入专属天地异象。最低档“拉夯了”也交付真实可用成品并指出缺陷，不播放高阶成功特效。

结果只显示一条简短信息，如“你锻成了【大师·汉式铁剑】”，旁边展开五项过程结果。成品保存制作者与工艺记录；原初·神铸追加专属命名与铸造铭记，详见5.2。其他品质原有铁砧改名功能不被剥夺，但改名不会改变品质或取得神铸身份。重复制作可跳过普通检视，不反复打断控制。

## 5. 品质与精炼：每一步都留下结果

### 5.1 武器独立的七档品质

品质名称与顺序由用户确定：**拉夯了 → 普通 → 精良 → 史诗 → 传奇 → 大师 → 原初·神铸**。不沿用魔药的三档名称；借鉴的是“真实过程决定品质、最高成就有天地回应”的体验，不照搬药效200%的数值，也不改现有魔药规则。

严重未完成的坯料仍属于“未完成”，不是第八档成品。以下分数、属性和演出时长是本稿建议，尚待整体评审；七档名称与最高档命名、异象要求已按用户指令确定。

| 过程分，均0～100 | 权重 | 实际评估 |
|---|---:|---|
| H 火候 | 15% | 出炉热量均匀、有效锻打时的可塑性、是否持续过烧 |
| P 锻打 | 25% | 落点、力度与节奏综合；乱敲不能代替正确落点 |
| S 定形 | 20% | 直度／弧度、刃脊／棱面、根部是否达到形制要求 |
| Q 淬火 | 30% | 入水温度30%、姿态与过程30%、提起时机40% |
| A 装配 | 10% | 柄头对正、压合和最后锁定；流程短但仍留下结果 |

P中落点占50%、力度35%、节奏15%。其余分数依据本次实际热量、几何偏差、浸入过程及装配对正计算，详细曲线在手感原型中校准；不得用“客户端报完美”或单纯凑次数替代。每个分数都要能追溯到一项可见操作，玩家才能通过反馈学会改进。

从最高档向下检查，同时满足总分与全部五项下限的最高档即为结果；高分但短板明显时，按短板降到满足条件的一档。任何工序未完成就不能出成品，存在未修复严重过烧／淬裂缺陷时直接判“拉夯了”。评分无隐藏随机抽档，不用天象、稀有材料或充值抽签替代实际手艺。

示例：H/P/S/Q/A＝95/94/93/92/95，G＝93.45且每项≥85，出大师；五项均99时，G＝99且每项≥95，出原初·神铸。若H/P/S/A均100但Q＝90，G＝97，结果为大师；若Q＝40，即使其余均100，G＝82，也只能达到精良的每项下限，存在淬裂缺陷则判拉夯了。玩家能清楚看到哪一步阻止了更高品质。

原初·神铸是极高完成度的工艺结果，不要求额外完成100锤、再加一道隐藏工序或碰随机概率。慢速／无障碍模式保留最高品质资格，按自身窗口归一评分；不让低延迟设备成为神铸的隐形材料。普通材料也能做出原初·神铸，材料阶段仍决定该兵器的基础强度。

木作与弓弩也保留五项评分结构，但把火候、金属锻打、淬火分别替换为选纹预整、校直／弓臂塑形、封护／张力调校；仍按15/25/20/30/10计入总品质。不会要求木棍下炉或用没有做过的工序自动补满分。

### 5.2 原初·神铸：天地异象与玩家命名

**触发时点**：最终装配完成、服务器确定七档结果并保存神铸身份后，立刻触发一次异象；不是按命名按钮才升品质，也不是每次取出武器都播放。

建议专属演出约10～12秒，以“天地像一座巨大的锻造场”形成战士辨识度：

| 时间 | 天地回应 | 与兵器的联系 |
|---|---|---|
| 0～2秒，凝声 | 炉焰向兵器方向低伏、地面碎屑短暂悬起，近处锻击余音被拉长 | 最终落锤的锋线留在兵器表面，中心本体仍清楚可见 |
| 2～5秒，天穹开炉 | 上空浮现直径约40格的分层云隙与巨大古老砧纹，银白与金色光流沿弧面缓慢汇入 | 不用一堵彩色墙或一条直射天柱；光流最终聚向刚锻成的实物 |
| 5～8秒，天地合锤 | 一次有厚度的天穹锤影缓缓压下，悬空砧纹与地面锋纹相应，响起一声低沉天锻鸣 | 锤影在高处化开，锋纹沿武器真实轮廓贯通，不砸建筑、不伤生物 |
| 8～12秒，神兵出世 | 云隙向外舒展，细金雨与银白碎光缓落，地面纹路收回刃身，留下清晰长鸣 | 玩家举起神铸兵器，进入取名；旁观者能看到同一件兵器与同一场异象 |

户外可完整仰望天穹，室内保留天空事件在真实天穹的位置，并在工坊内显示沿屋梁掠过的映光、炉焰与兵器回应，不穿墙画整片锤影或强行拆开屋顶。地下城／封闭维度使用空间穹顶上的砧纹与地面共鸣版本，不强制传送到室外。日夜各有配色，异象不修改服务器真实时间、天气或全服光照。

普通视野就能看到完整事件，F8补充魂脉与天地灵流；不把最高成就藏在F8开关后。建议同维度128格内玩家可看到，空间音量按距离衰减；远处不强制转镜头、不打断战斗。事件周围适度压低环境音，不停止他人的剧情／音乐会话。光影开关均须实际验收，不能只贴一张天空图片。

**命名**：异象进入尾声时，制作者获得一次专属命名入口，建议2～16个可见字符，可预览“原初·神铸「名字」”。例如“原初·神铸「照夜」”，详情保留“汉式铁剑”、材料阶段和制作者。品质不是用户输入文本，普通武器手动改成同名也不会得到神铸身份。

允许跳过或关闭命名，不丢武器、不降品质，先保留默认形制名；以后在百锻砧补命名。首次确认记录玩家所取的神铸名与制作者；后续普通铁砧改显示名不改铸造铭记、不再次触发天地异象。重铸继承神铸铭记：若只是保养／改名／转交／取回，不重新演出；只有该武器首次由低品质真正升到原初·神铸时触发。

每件武器保存唯一神铸事件与命名状态。背包满、掉线、重复包和服务器重启后可继续领取或命名，但不重复发武器、重复触发天象。多人同时神铸，各自结果即时保存并排队播放附近重叠天象，不把后成功的成品降档或吞事件；玩家可先领武器，演出顺序不成为等待制造的门槛。

这是本次新增演出提案：落实用户“像魔药最高成就那样发生天地异象”的要求，不声称当前魔药已有完全相同的天穹锤影实现，也不修改魔药系统。

### 5.3 修错不折磨，重做也不能刷最后一步

每阶段结束简短显示“火候稳／刃线偏左／淬火提早”，最多突出一个待修区域，过程不连续弹五个评分窗。成品才展开五项完整记录。

最多2次局部修正允许把偏差修回，评分使用修复后状态并保留有限过程损失；不是一次手抖永久失去高品质资格。普通错误可补，持续冷敲、连续重打同点等明显错误才留下更大损失。每次修正只允许修复真实缺陷，不刷节奏次数获分。

重新淬火只更新Q，前面H/P/S及装配A不自动提升；单纯拆装只更新A。若问题在塑形，必须回到相应工序整修，不能拿大师淬火覆盖错误形状。完成品重铸沿用原品托管与明确采用结果的规则，不随机降掉原有大师武器。

### 5.4 材料阶段与重铸

材料阶段与工艺品质独立：好材料不保证大师，普通材料也能打出原初·神铸。升级材料保持原武器形制和独有能力，不让所有武器变成同色发光白剑。

| 阶段 | 金属兵器 | 木器／弓弩 | 自身攻击加成 | 最大耐久 |
|---|---|---|---:|---:|
| 基础 | 原有铁／铜等形制材料 | 普通硬木、原本体 | ＋0% | ×1.00 |
| 灵导 | 灵纹铁参与重铸 | 灵纹铁参与束固，不把本体改成铁 | ＋12% | ×1.20 |
| 曜纹 | 灵纹铁与曜纹金复合 | 曜纹金参与细部加固与张力稳定 | ＋25% | ×1.40 |

材料可来自旧魔法科技，但**新工坊加工不额外扣120M／240M、不接旧锻炉网络**。赤膛炉的高阶火床通过自带风箱和耐火内衬处理既有成材，不把旧魔导材料的原始冶炼配方搬来，也不让煤直接炼出本应由魔法科技生产的灵纹铁。

建议基础新锻材料当量：剑刀4、枪戟5、宽刃／锏6份，另加一个柄；齐眉棍4份硬木。基础→灵导使用同等形制当量灵纹铁；灵导→曜纹使用同等灵纹铁＋2份曜纹金。弓弩保留原本体配方，升级当量暂按4。高阶专属武器保留原获取门槛，不用普通铁锭就能锻出龙魂或剧情器物。

重铸原品托管，名称、附魔、风标记、兵魂、契合、耐久损耗比例和其他合法数据保留；玩家预览并选择采用后才扣新增材料并更新原品。取消退原品，已烧燃料与实际用过的介质不返，不同时交付原品与新武器头。新材料不直接复制旧大师分，仍要完成本次手工加工。

无新字段的旧战士武器默认基础材质、普通工艺，原能力保留；有古铜旧等级的先按迁移提案兼容。法杖和魔导枪械不读取、不添加、不迁移本模块数据。

### 5.5 加成口径

近战W0为原武器自身攻击属性加成，不含玩家基础1点、药效和附魔；新W＝W0×（1＋材料＋品质＋淬火收益），三者相加。最高暂按25%＋5%＋3%＝33%，原10倍巨大化不参与伤害加成。古铜W0取未强化原值，不叠旧十阶倍率。

汉式铁剑原基础总伤害7，W0＝6；曜纹原初·神铸完美寒泉后，基础总伤害＝1＋6×1.33＝8.98，再走原有招式、附魔和防御流程。品质的主要奖励仍是耐久、可见工艺和制作成就，不让高品质数字直接碾压同阶段所有其他兵器。

耐久按材料×品质×介质计算；曜纹原初·神铸清水为1.40×1.60×1.05＝2.352倍，缺陷已通过最低品质体现，不再额外叠一层隐藏裂纹减耐久。

弓弩只在武器贡献的射击伤害入口加成一次，投射物命中不重复乘；古铜匕首投掷同理。木作封护和弓弦调校占同一最多3%的特性预算，不额外叠第四种强化。原有攻速、射速、弹药、连招范围和冷却保持。

### 5.6 古铜十阶迁移：停止旧升阶，保留武器与投入记录

用户已确认取消古铜四武器独立升级路线。**如何补偿旧投入是本稿新增建议，尚待整体评审，不代表已授权执行迁移或削减旧武器属性。**

1. 新系统交付启用时停用“八铜块包围武器”的旧升阶配方；古铜匕首投掷、铜锭维修、名字、附魔、耐久损耗和物品ID保留。原强化等级保留为只读历史，不再计入新伤害，不可借铁砧合并恢复旧倍率。
2. 旧武器保持原倍率可正常使用，直到持有者在铁匠工位主动选择“转入新体系”；未迁移状态不能叠加新材料、工艺、魂契或新回收收益，工位直接显示迁移预览。这样不扫描旧世界，也不会更新后突然降低手中武器伤害。
3. 建议L级旧古铜武器转入后统一为基础材质、普通工艺，**一次返还8×L个铜块**，对应原升级用料。返还随武器迁移记录结算一次；背包不足留在工位领取，不重复取放刷返料。
4. 预览并列显示旧攻击、新攻击、返还铜块、保留数据。L＝10返80铜块；不能同时保留旧100%攻击加成再加新33%。旧高强化转入后攻击可能下降，必须明确展示，由用户评审决定是否采用这一补偿提案。
5. 原材料与新平衡无法同时保证“旧满级翻倍”及“新加成最高33%”；本稿不假称两者无损等价。若用户希望旧满级迁移后仍保持原战力，应重新评审全体系数值或迁移补偿，而不是偷偷添加永久历史伤害倍率。
6. 未迁移旧古铜与已迁移古铜禁止跨状态合并维修；迁移后的维修只保留同一套新成长数据。投掷／回收中的匕首不允许迁移、重铸或回收。

该兼容状态只用于旧物品平稳交接，新造古铜武器直接使用新成长，无可继续升级的旧十阶路线。

| 星眠幻庭 | 方天画戟及其余兵器；“稀有”体现来源与工艺，不凭空另造一套变体属性 |

普通宝箱保留原奖励，建议额外30%概率获得一件兵器战利品：完整25%、磨损50%、残破25%。完整剩余耐久70%～100%，磨损15%～40%；残破使用通用残破兵器物品，记录形制和材料，无法攻击，不伪装成0耐久仍可使用的剑。

材料档位建议：1～10层仅基础；11～20层基础／灵导80%／20%；21～30层65%／35%。曜纹材料可由高层材料奖励推进，但首版不直接掉落曜纹成品，不掉落已觉醒兵魂。可用成品的工艺分布建议拉夯了20%、普通65%、精良15%；史诗及以上主要留给手工制作，原初·神铸不随机从普通宝箱直接发出。

### 回收守恒

- 金属在新赤膛炉回收，不进旧魔力锻炉；木器在百锻砧木作位拆解，不能把木头烧成硬木料。
- 标准配方形制当量为C，完整／磨损／残破的最大回收比为50%／35%／25%，向下取整，最低0；小额不足可累计为工位回收进度，不凭空保底1份。
- 品质改变其档内回收率：拉夯了按上限的80%，普通90%，精良及以上100%；“高品质回收更多”也不能超过档位上限。
- 对旧工作台和商店武器，C取注册配方可保证的最低基础材料当量与新锻C的较小值；无已知成本的第三方物品拒绝回收。实际接入前逐一审计全部已登记武器配方，包括镜像和商店价格；可升级不等于可任意熔出特殊Boss材料或第三方合金。
- 灵导／曜纹成品仍只回收基础钢料、青铜料或硬木料，不返灵纹铁、曜纹金、柄或附魔材料。掉落残破兵器按登记的基础C计算，不能自己改标签骗取高阶原料。
- 有兵魂、附魔、命名或特殊标记的武器不接受“丢炉即融”。普通珍贵物品先给明确回收预览并潜行确认；有兵魂的首版直接拒绝熔炼，避免误销毁灵魂。

例如基础金属配方C＝4，磨损武器最多回收1份钢料；重新制造仍需4份金属与一个柄。原有齐眉棍旧配方只用3根木棍，回收上限因此为1份硬木料，不能因为新配方是4份就按4返还。木料、钢料和铜料不可互换套利。

奖励以房间／玩家／本次挑战记录防重领；背包满则保留领取权。退出重进、掉线、重开界面不能重抽品质或灵魂。新增武器物品按原地下城装备保留规则携出，不随未结算遗币20%损失被删除。

## 7. 唤魂祭坛与契约试炼

### 7.1 建筑、能量与进入条件

首版固定**7×7仪式场地**：中央兵器台、四盏魂灯、外圈地面阵纹；上方至少4格无遮挡，地面不要求玩家买下。首处公共祭坛作为可选探索节点，由铁匠在第一次获得残魂印后提示；放置位置另行选址，不覆盖现有天空岛建筑与产权，不修旧世界。

中央台接既有晶纤与真实储魔，容量1000M、最大输入8M/s；亦允许玩家以5M/s注入自己的魔力。试炼本身不要求角色已加入磨砺，成功振刀等操作仍遵守既有天赋和技能门槛：无资格者改给基础普攻／走位版本，不能要求未解锁技能才能得到第一兵魂。

这一段供魔只属于尚待确认的唤魂仪式，不属于战士锻造。公共祭坛负责提供初次试炼所需储魔，不要求战士先学法术、搭魔力锻炉或建设管网；个人祭坛可选复用通用能源接口，不能据此把魔导枪械搬进本模块。

每次开坛先实扣100M启动费；成功另扣300M，失败不返启动费但保留武器和残魂印。魔力泉淬火在成功时把300M降为250M，不能返出魔力。开坛前须预存足够总费用，成功阶段的费用预留，防止临近完成被别的设备吸空。无额外喂养货币，无战斗续航电池。

### 7.2 残魂印来源

只给已登记的特殊魔物、精英和地下城守关者，不采集普通牲畜、NPC、玩家、槐／让等剧情人物、公孙衍或未授权剧情Boss的灵魂。

地下城以队伍真实击败目标为一次事件，为各有效参与者生成个人奖励；参与包括伤害、救援或承受该敌攻击，不抢最后一刀。训练木桩、教官、祭坛魂影、召唤友军、机器圈养刷怪不产印；首版以地下城自然生成登记为准。

建议精英个人掉印率15%；每5层守关首次结算保底1枚对应来源印，重复结算25%。关卡首通标记与掉落一起保存，不能通过重启重抽；现有四个守关者只有在其来源属于可收魂白名单时才发该魂，否则从本主题已登记普通魔物魂池选取，不擅自把Boss身份改成新魂种。

残魂印记录来源种、显示名和外观变体，首版不随机洗隐藏资质。可以交易；同一来源印可按相同数据堆叠。

### 7.3 四段仪式

| 阶段 | 演出 | 玩家操作与真实判定 |
|---|---|---|
| 献器 | 武器落在台面，魂灯逐盏导流 | 放入兼容武器和残魂印，确认开坛；本人锁定本次会话 |
| 显魂 | 法阵聚拢成来源魔物的半透明轮廓 | 约5秒，保留原怪特征，不用统一人形烟雾代替 |
| 契约 | 魂影用可读前摇展示习性 | 30～45秒，完成2～3次实际操作；不以击杀魂影作为成功条件 |
| 入魂 | 魂影绕器一次并融入兵器，魂灯依次暗下 | 约5秒，服务器统一扣成功费与残魂印、写兵魂并返还原武器 |

献器武器托管在中央台，试炼使用临时魂铸投影，复制其家族与已解锁招式但不给背包物品、掉落或其他新奖励；完成后销毁。这样玩家能用自己这类武器应试，又不会同时持有原武器和一把可带走复制品。

没有资格振刀时，祭坛明确显示替代目标。试炼伤害只扣本会话的三次失误额度，不扣真实生命、不耗药、不改真实装备耐久；不赋予玩家抵御场外怪物的无敌。外部真实受伤或倒地立即暂停／取消会话。

失败魂影回印，祭坛30秒后可重开；离场、断线、跨维度或取消直接结束，所有非成功情形均保留武器与印。试炼完成不奖励磨砺、兵魂共鸣、战利品或教官记录，防止祭坛自刷。

同一祭坛一次服务一人，其他人可观看，不能取走或代完成。卸载保存原物品与会话结果；重新加载后未成功会话回到可取回状态，不自动消耗印、不凭空复制武器。成功扣料、结果保存和物品发放必须具有唯一领取记录。

## 8. 兵魂能力、外观与搭配

每把武器最多一枚兵魂，拥有一个被动倾向、一个战斗触发和一套显灵外观。不同魂种是不同玩法倾向，精英来源首先体现外观，不建立十层稀有度与随机词条。

首个闭环建议选四魂：**骷髅、史莱姆、兽人、拟态蟹**，覆盖进攻、防守、重击和振刀；最终扩到下表十魂。不为每种魂与每把武器单独制作全新AI，而是“魂种轮廓＋武器动作挂点＋真实触发方向”组合。

下表以近战为说明。弓弩按真实射击命中、已有蓄力释放和特殊射击适配；没有相应招式时契约改为两次独立有效命中。无振刀／盾挡的弓弩以真实步法避击作为契约替代，防御魂收益改为避击后同额护盾，不新增未解锁格挡。魂体沿弓臂和箭矢方向演出。法杖、魔导枪械不接本次兵魂，也不修改原器灵。

下表为觉醒阶段能力上限的首轮建议；寄宿只开被动，共鸣开放触发的60%数值，觉醒达到表中数值。触发均使用有效事件，不按客户端动画或按键次数直接发效果。

| 来源／性格 | 被动倾向 | 战斗触发（觉醒值） | 契约目标 |
|---|---|---|---|
| 哥布林／灵巧 | 武器攻击耐久损耗有10%免耗 | 主攻命中后下一次有效普攻追加该次基准伤害10%，5秒内有效 | 连续命中两个不同方位的魂靶 |
| 骷髅／锐利 | 有效命中后追踪显示该目标3秒，仅本人可见 | 主攻命中附加该次基准伤害12%的兵魂伤害，沿用原伤害防御结算 | 两次准确刺击或主攻命中 |
| 史莱姆／柔韧 | 来自活体敌人的击退减少10% | 受活体敌人伤害后获得2点吸收生命，持续4秒、不叠层 | 躲过两次跳击，再命中一次 |
| 兽人／勇猛 | 受击中断蓄力后下一次重新蓄力提示更清晰，不改变中断规则 | 蓄力达到1秒并命中时增加0.4格击退，Boss按原抗击退处理 | 蓄势魂影露出破绽后重击命中 |
| 触手／执着 | 自己命中施加的减速持续＋10%，不延长Boss僵直 | 特色招式命中使普通敌减速15%、持续2秒 | 躲过牵引方向并反击 |
| 恶魔／炽烈 | 命中时只显示目标身上一道可见裂焰，无额外常驻伤害 | 主攻或重击命中追加该次基准伤害15%的兵魂伤害 | 连续避开两次扇面后命中 |
| 拟态蟹／谨慎 | 持本武器时盾牌受击击退减少10% | 成功振刀后自身获得2点吸收生命，持续4秒 | 一次有效振刀；无资格则挡住一次投影攻击 |
| 噬魔幽浮／饥渴 | 命中显示目标是否具有已登记魔力容器，不探测未公开Boss秘密 | 命中有真实魔力的敌人转移至多2M到玩家，目标不足不凭空产魔 | 命中两次变向移动的魂影 |
| 强光闪灵／警觉 | 危险前摇时魂体短促明灭，提示不提前于敌人真实前摇 | 战斗步法成功避过一次已登记攻击后，下次命中令普通敌减速10%、2秒 | 步法避过投影闪击后命中 |
| 源晶吞噬虫／蓄势 | 蓄力时在武器附近显示已达到的秒数段，不增加伤害倍率 | 三次有效命中后，下次特色招式追加基准伤害12%；最多存一次、10秒失效 | 对准三处晶壳裂隙命中 |

部分“被动”刻意采用信息或手感提示，不强行给十种魂都叠攻击属性。噬魔仅对拥有可扣真实余额的目标生效，普通怪不能当无限充魔器。强光闪灵的“成功闪避”须攻击路径真实经过玩家原位置且无伤命中，不凭步法按钮计数；第一批四魂不依赖此后续检测。

“基准伤害”取该次攻击在兵魂新增伤害之前、目标防御结算之前的主伤害值；兵魂伤害仍经过目标相应防御，不能绕甲。额外伤害不再次触发兵魂、连击计数或磨砺奖励。原攻击被取消、伤害为0、目标友方、隔墙或已经死亡时不触发。

所有触发共用玩家12秒的兵魂触发冷却，武器也保存自身到期记录，采用两者较晚值。切武器、转交、重登、死亡不清冷却；蓄积型魂的计数／待发状态在离手时清空。持续效果不叠层，不改变连招自身冷却。

### 可读的三阶段外观

- **寄宿**：普通握持偶有轮廓从护手、刃根或棍纹浮现，不常驻整只怪。
- **共鸣**：攻击或蓄力时，局部魂体依附实际武器；收招消退。F8能看清灵流方向和契合状态。
- **显灵／觉醒**：真实能力触发时，完整来源轮廓出现0.6～1.0秒，沿该武器攻击方向演出。兽人随枪前冲、随锏砸落、随剑收斩；没有真实额外判定的轮廓不能撞飞或伤害场外敌人。

默认每名玩家最多一套兵魂投影，完整显灵32格内可见；同屏最多显示最近四套完整魂体，其他降为局部轮廓。普通视野降低亮度与面积，第一人称避开准星；不与重武器巨大化再次相乘，不绕远距离遮挡，不生成常驻宠物实体。光影开关都需原生画面验收，离线图只用于造型检查。

## 9. 契合成长、觉醒与换魂

一条总契合度0～600，另记进攻、防御、重击三种使用倾向，只用于外观和提示，不再开三棵要刷满的技能树。

| 阶段 | 门槛 | 收益 |
|---|---|---|
| 寄宿 | 首次入魂 | 被动与微弱轮廓 |
| 共鸣 | 总契合100 | 开放战斗触发，效果为觉醒值60%，魂体可局部显现 |
| 觉醒 | 总契合600后回原类祭坛完成一次短试炼 | 完整触发与显灵；不另喂材料、不再消耗残魂印，祭坛实扣100M |

近战有效主攻／特色连招命中＋1；成功振刀＋2；Z蓄力至少1秒并真实命中＋2。普通近战普攻可以触发兵魂能力，但不直接刷契合。弓弩有效独立射击命中＋1，既有蓄力至少1秒释放并命中＋2，真实步法避击＋2；一次多箭或范围射击只按一次原始发射计，不按箭矢数量／命中目标重复刷点。武器更换不丢已存总契合。

同一目标20秒内最多计一次契合事件；同一事件只取最高一项。训练木桩、魂影、教官、同队玩家、宠物、圈养生产怪、无敌或零伤害目标不计。多目标横扫一次只算一次，Z蓄力不按蓄力秒数无限增加契合。参与地下城每5层结算另加15，每次挑战每段只领一次。

不要求三倾向都达标，纯防御或重击玩家也能觉醒。首次觉醒试炼读取玩家最高倾向，给振刀、连招或重击三者之一的可完成版本。合理目标是数次出征后进入共鸣、多个完整五层段后觉醒；若原型实测过慢，调整门槛而非加入日常签到和喂养。

兵魂契合跟随武器。首版允许赠送兵魂武器，新持有者不清成长，需在祭坛做一次不耗印的认主试炼；费用100M。未认主时兵器仍可用，兵魂能力休眠，不锁死物品产权。

首版不提供换魂／剥魂／融合功能：要换搭配就培养另一把武器，旧魂不会被静默覆盖。后续若用户希望换魂，应另设计保留契合与防复制流程，本稿不额外增加离魂瓶和剥魂机。

有兵魂且原本具备耐久的战士武器，耐久耗尽后进入“失锋／失调”而非消失，保留物品身份和兵魂，不能近战攻击或射箭，修好后恢复；普通无魂武器仍走原破损规则。无耐久的战士武器不人为添加这一状态，弓弩弹药按原规则处理。这个保护不改变法杖、魔导枪械、护甲或工具的原规则。死亡掉落、产权和地下城保装按原规则，不新增自动回包或跨维召回。

## 10. 学习入口与任务串联

把教学放进正史“多年旅途”的可选成长区，不设为开正史后段、入地下城、结婚或买房的门槛。

| 教学节点 | 地点／人物 | 玩家亲手完成的验证 |
|---|---|---|
| 第一柄兵器 | cava铁匠铺 | 亲自完成一件工艺成品；买来的成品不代替锻造教学 |
| 火候与水声 | 赤膛炉、百锻砧、淬锋槽 | 有效落锤与一次正常以上淬火；能解释结果，不强迫大师 |
| 旧刃新用 | 任意地下城和铁匠铺 | 本人领取兵器战利品，再回收或重铸一次 |
| 灵纹入刃 | 新战士工坊 | 真实消耗灵纹铁、完成手工重铸；不要求旧魔力锻炉或120M |
| 第一枚残魂印 | 地下城／祭坛 | 获得印后提示可选探索；不刚出生就剧透整套仪式 |
| 兵魂相认 | 唤魂祭坛 | 显魂、完成契约、实际得到有魂原武器 |
| 共行与觉醒 | 战斗与祭坛 | 达到契合并完成觉醒试炼，不以手动勾选冒充 |

新增FTB自有章节“炉火与兵魂”，复用真实事件授予；不重新生成整本任务书，不改变原ID。教学奖励以工具、基础材料补给为主，不直接发大师成品或600契合绕过过程。齐眉棍有木作版教学，不能要求它完成淬火才毕业。

## 11. 保存、多人与异常处理的硬性要求

以下属于玩法交付要求，具体类名和存储字段留到批准后的实施计划确定。

- 武器保存版本、身份、来源、材料阶段、七档品质、五项过程分、淬火结果、兵魂与契合；原初·神铸另保存制作者、神铸名、唯一异象事件及其已触发状态。角色磨砺仍保存于原系统，不迁入物品。必须保留无法识别但合法的外部物品数据。
- 工位保存操作者、输入原物、阶段、已扣成本和唯一会话；同一物品不得同时存在于手中、工位和奖励队列。漏斗不能抽走托管品，其他玩家不能替它领取。
- 扣料、变更武器、消耗魂印与返还结果按单一成功记录提交；重复网络包、背包满、区块卸载、服务器重启都不能重复领奖。背包满先留工位，不把珍贵武器扔成无主掉落物。
- 温度只在本人操作中的有效世界刻推进；托管暂停、断线或区块卸载时保存热量与全部过程分，重新进入有观察准备。恢复不回满热量、不重置过烧或淬火记录；暂停不会凭空给分。工件不可丢地后重新识别为全新高温坯。
- 自家工位被拆时返还托管原武器和未消耗稀有材料，当前半成品按会话保存，不原品与半成品双返。产权保护仍优先，不能借拆祭坛偷别人武器。
- 镜像、远端源码、队友回执与本机运行包分别记录。将来涉及包更新必须按仓库流程构建、校验、保存退出后安装；本次文档没有更新任何运行实例。

## 12. 分阶段交付与验收

本系统分工艺、战利品、兵魂三个相连子项目，先通过第一把兵器的完整闭环，再扩全，不一次铺完所有设备后才发现操作不好玩。

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| A 手感原型，优先验收 | 先做汉式铁剑完整独立工坊，再补偃月刀、红缨枪、四棱铁锏；真实落锤、形变、淬火与五项过程评分 | 打击、变形和水面反馈足以读懂；75～110秒连贯完成，普通视野可玩；用户试玩认可后再扩内容 |
| B 成品成长 | 十兵器、古铜及原有近战、木作、三阶材质、品质、重铸、维修、失锋保护与古铜迁移 | 原ID和战斗记录保留；附魔、风标记、兵魂字段不丢；迁移前后数值和返料可核对 |
| C 出征循环 | 四领域战利品、个人残魂印、回收 | 不重复领奖、不重抽、不抢最后一刀；逐旧配方验证材料不增殖 |
| D 首次入魂 | 7×7祭坛、四魂、契约投影、失败恢复、第一轮共鸣 | 魔力实扣、失败不吞印、成功一次、多人不可代领；有真实能力与魂体 |
| E 扩展与觉醒 | 其余六魂、600契合觉醒、认主、FTB完整教学、光影优化 | 真实战斗判定与全链持久化；无无限充魔、递归触发或满屏常驻魂宠 |
| F 战士武器覆盖 | 弓弩、原版与第三方同类战士兵器清单、专用工艺、魂契事件及旧系统兼容 | 每项登记兵器有真实升级与伤害适配；法杖、魔导枪械与旧魔力锻炉保持原状 |

阶段A先验证是否好玩，不以“流程能跑通”冒充手感完成。没有获得用户对原型手感的认可，不用批量扩武器和设备掩盖不好玩的问题。完整模块仍要覆盖本稿已界定的战士兵器范围，未接入项目逐项列明。

### 手感原型的必过标准

| 观察项 | 验收方式 |
|---|---|
| 每锤有实效 | 同一坯料录制完整加工过程，逐锤指出落点、局部形变和声音差异；只响一声或只涨进度不通过 |
| 成功与失误能读懂 | 关闭文字数值，玩家仍能分出正确重锤、错误落点、淬火可提起三种状态；普通视野与F8分别验证 |
| 流程短且不断 | 带教后连续完成三把，记录实际用时、锤数、回炉和界面次数；熟练制作不需要多次强制回炉或十余次开关面板 |
| 大师确实来自手艺 | 有意只改变火候／锻打／定形／淬火／装配中的一项，其余一致，结果记录与品质按规则变化；极品材料也不能自动补满工艺分 |
| 失败可恢复 | 一次敲偏能局部修正，淬火提早能重淬，退出后无丢料；玩家看得懂为什么没达到大师 |
| 成功值得停下来看看 | 七档成器反馈层次分明；原初·神铸有完整天地异象、专属命名与制作者铭记，低品质不冒用神铸演出 |
| 反馈有力度但不扰人 | 普通三把连续制作无刺耳峰值、长震屏和遮挡；关闭镜头冲击后仍靠动作、音色、形变读懂打击 |

这些是尚待实现与实测的目标，不把纸面设计写成已经好玩；用户的实际试玩感受是手感是否交付的最终依据。

需要覆盖的关键验收：

1. 四种代表兵器＋齐眉棍，各做普通和一次失败修正；慢速模式也能达到原初·神铸。弓弩五项评分不使用虚构金属工序。
2. 冷坯、过热、错误柄、空液槽、燃料不足、背包满均不吞原武器或稀有材料；祭坛魔力不足另行拒绝开坛。
3. 重铸有名、有附魔、有风标记、有兵魂、有损耗的武器，逐项核对前后数据；取消不产生双物品。
4. 普通水、寒泉、魔力泉实际只保留一层结果；魔力泉减耗不返魔，10次槽液不因重登复满。
5. 地下城四主题奖励、个人参与、断线、重复领取、原五层结算与遗币惩罚不回归。
6. 第一魂入魂、失败、死亡打断、拆工位、区块卸载、重启、队友围观，全程没有复制、丢失或串归属。
7. 命中、振刀、蓄力的真实事件触发能力；挥空、隔墙、零伤、友军和训练目标不加共鸣。
8. 满磨砺十倍重武器＋兵魂＋风灌注＋附魔组合，分别核对伤害、范围、冷却；外观巨大不擅改判定。
9. 实际PCL中第一／第三人称、左右手、光影开关、至少双人同屏检查；16GB机器不同时跑客户端和大型构建。
10. 只能报告本次实际完成的测试和截图，队友历史测试数与离线预览不替代本次验收。
11. 古铜0／1／10级迁移、背包满返料、取消、重复提交、铁砧合并和投掷中拒绝迁移逐项核对；无旧新倍率叠加或重复返铜。
12. 弓弩与投掷匕首分别验证伤害归因和弹体快照不重复增幅；战士新工位拒绝修改法杖和魔导枪械，原王杖、零式与旧锻炉相关内容保持原状。
13. 五项过程分分别变化时，七档结果按总分和每项下限共同判定；G≥98但任一项不足95不能出原初·神铸。未修复严重缺陷判拉夯了，未完成工序不产成品。
14. 原初·神铸在户外、屋内、地下城、日夜和光影开关下均有匹配异象；多人看到同一事件。命名取消、断线后补命名、重复包、修理、转交与重启均不重复天象或武器奖励；普通物品改同名不能伪造神铸品质。

## 13. 本轮请用户优先评审的决定

以下均已有本稿默认方案，便于直接修改，不是要求用户重新设计全部细节：

1. **范围（用户已明确）**：战士武器统一升级，法杖暂不动，魔导枪械留魔法科技。古铜旧升阶停用仍按前次方向，具体迁移补偿待审。
2. **独立工坊（用户已明确方向，具体造型为提案）**：赤膛炉＋百锻砧＋淬锋槽，U形近距离布置，自带风箱和夹具，不使用旧魔力锻炉或新增其兵器炉口。
3. **品质名称（用户已明确）**：拉夯了／普通／精良／史诗／传奇／大师／原初·神铸，独立于魔药。火候15%、锻打25%、定形20%、淬火30%、装配10%；各档评分门槛为本稿提案。
4. **成长数值（待审）**：三阶材料＋七档工艺＋一层工艺特性＋一枚兵魂；新品质攻击建议逐档0／0／1／2／3／4／5%，材料／工艺／淬火最高仍合计33%自身攻击加成。
5. **保留感**：重铸保名、附魔、灌注和兵魂；有魂战士武器耗尽耐久失锋可修，不直接消失。
6. **手感与节奏（本轮重点提案）**：正常75～110秒，约12锤，高手够形就收；有落锤承重、局部接触停顿、定向碎屑、真实形变、淬火水纹、冷却色带与成品刃鸣，不靠繁琐步骤凑时长。
7. **契约与觉醒（仍待审）**：四魂先行，非击杀试炼；开坛100M、成功再300M；失败保印。100契合共鸣、600契合后实操觉醒，不签到或喂养。
8. **旧投入迁移（仍待审）**：旧古铜先保持可用，主动转入时预览伤害变化并一次返还8×旧等级个铜块；不继续保留旧翻倍与新33%叠加。这条补偿与可能降伤尚未获批准，确认前不实施。
9. **神铸成器（用户已明确要求，具体演出为提案）**：原初·神铸允许玩家命名，锻成触发天地异象；约10～12秒天穹开炉、天地合锤、神兵出世，保存唯一事件与铸造铭记，改名和取回不重复演出。
10. **暂缓**：玄潮淬火、换魂／剥魂、多魂融合、自由雕刻。法杖与魔导枪械是明确排除本模块，不作为本模块后续待补工艺。
