# TN-C 武器锻造与兵魂升级设计

日期：2026-11-05（北京时间）

状态：**第一版评审稿，等待用户确认；未开始功能开发。**

源码核对基线：`54b3d273397513cd032b847bf0678337c730a575`。

## 1. 设计目标与本次决策

**玩家亲手打造武器，地下城提供武器和材料，唤魂祭坛赋予武器灵魂。**

升级围绕现有十把传统兵器展开，保留物品 ID、武器家族、57个招式变体、30个普攻动作、按键、解锁门槛及冷却。材料和兵魂改变同一把兵器的成长与表现，不重新做一套战斗系统。

本稿以用户粘贴方案为方向，新增规则均是供评审的设计建议，不是已经批准或实装的事实。所有数值为首轮调试起点，不代表已完成平衡。

| 可选组织方式 | 优点 | 代价 | 本稿选择 |
|---|---|---|---|
| 同一兵器保存材料、工艺、兵魂三类成长 | 保留陪伴感和旧数据，玩家能一直升级喜欢的形制 | 必须认真处理重铸与数据继承 | **推荐** |
| 每种材料、品质都注册新武器 | 配方和成品直观 | 同形武器大量膨胀，旧附魔与兵魂转移复杂 | 不采用 |
| 全部压缩成强化等级 | 最省操作和设备 | 锻造与唤魂失去自己的玩法 | 不采用 |

完整循环：

> 买锤和柄／探索得兵器 → 加热 → 压坯、塑形、定形 → 淬火 → 装柄 → 使用或重铸 → 获得残魂印 → 显魂与契约 → 战斗共鸣 → 觉醒。

第一把可用武器不要求先探索地下城；第一次入魂也不要求先升级到最高材质。战斗、手艺和魔导是相互补充的路线。

## 2. 与当前系统的关系

| 当前内容 | 本次处理 |
|---|---|
| 十把传统兵器的工作台配方 | 保留，产出“基础材质·合格·无兵魂”武器，不追溯改旧物品 |
| 越式青铜剑与古铜四武器 | 两组不同武器；前者是十兵器之一，后者有独立铜块十阶强化 |
| 古铜四武器强化、匕首投掷 | 本稿暂按保留处理，不把新材料加成叠到旧十阶上；最终以用户回复为准 |
| 魔力锻炉 | 保留3×3×3结构、灵纹铁等材料加工、风灌注和原GUI；增加外置“兵器炉口”作为同一成型炉的世界交互工位 |
| 普通燃料加热 | 基础金属坯允许煤炭供热；不因此允许煤炭代替旧魔力配方的真实供魔 |
| 法杖温养祭坛、王杖器灵 | 原样保留；新设备称“唤魂祭坛”，近战能力称“兵魂”，不借用王杖觉醒标记或10000M温养进度 |
| 风元素灌注 | 原标记、材料、门槛与冷却保留；不让兵魂替代风刃，也不让兵魂触发再次触发风刃 |
| 角色磨砺、天赋、教官课 | 属于角色；升级武器不赠送天赋、磨砺或未解锁连招 |
| 重剑／锤攻击时3～10倍实体巨大化 | 沿用最新规则；兵魂不额外放大武器，也不暗中扩大命中半径 |
| 地下城遗币、检查点、自救与奖励 | 保留；新增战利品接入个人奖励账本，不覆盖原奖励 |
| FTB与正史 | 只新增自己的工艺教学页和行为判定，不改原ID；不改正史任务、人物命运和保护者秘密 |

兵器炉口只接入现有炉体，不另造第二套大型冶炼多方块。铁匠铺先提供公共工位；自家建设是可选项，不要求买房、买地或完成整套自动化。

## 3. 物品、工位与铁匠铺

玩家随身只需要一把可重复使用的锻造锤。夹具、翻面支架、取坯夹和风箱属于工位，不注册为必须购买的工具。

| 类别 | 设计内容 |
|---|---|
| 工具 | 锻造锤1种；首版不设置容易中途损坏的工具耐久 |
| 柄 | 剑柄、长柄、锤柄3种；沿用到各材料阶段，不拆护手、剑格、剑首、环和缨 |
| 半成品 | 金属坯、已成形武器头各使用通用物品数据记录形制和材料，不为每个工序注册十套ID |
| 木作 | 硬木料兼作齐眉棍棍身原料，不额外造“棍身零件”ID |
| 回收材料 | 回炉钢料、青铜料、硬木料3种 |
| 灵魂 | 残魂印1种，以物品数据记录来源、稀有度和外观变体 |
| 工位 | 兵器炉口、锻造铁砧、淬火槽、唤魂祭坛；魂灯和中央兵器台为祭坛组成部分 |

铁匠铺销售锤、三种柄、少量原版金属与煤、基础过渡武器；暂不销售无限量高阶材料和残魂印。不新增复杂合金冶炼链。新增商品价格在实现前以现有商店和委托收益校准，不在本稿凭空确定货币价值。

玩家初见cava时可选“想亲手打一把兵器”，得到短操作示范和基础材料清单。cava保持功能铁匠，不扩写隐藏身份；槐的正史不受此教学影响。

## 4. 世界交互与手工锻造

### 4.1 通用交互

- 放入、取出、装配使用既有右键；锤击用锤子右键；潜行右键是翻面、调整姿态或退出，依工位显示一行当前提示。
- 不新增常驻按键。轻敲为短按，重锤为按住后松开；到蓄力上限也不自动连续敲击。
- 工位上的实物轮廓、颜色、音调和火星说明状态；F8增加热流、应力和轮廓误差，普通视野仍能独立完成。
- 配方选择可用一次简短目录，之后的锻打、淬火和献器全部在世界中进行，不把小游戏放进全屏面板。
- 操作使用固定俯视斜角辅助观察，保留退出手段；退出后解除相机限制，坯料留在工位。受伤、倒地、切维度或断线必须恢复控制。

### 4.2 烧红金属

兵器炉口放入一份形制材料，显示实物坯料。选择形制不收费、不消耗图纸。加热完成得到通用坯料，不直接生成成品。

首版使用游戏化热度0～1000，不宣称模拟真实冶金。越式青铜剑也按本世界的可塑青铜规则处理，不冒称历史青铜剑制造工艺复原。

| 热度 | 锻打状态 |
|---|---|
| 低于650 | 不可有效塑形，提示回炉；误敲不扣稀有材料 |
| 650～850 | 可锻；700～800是宽容的良好火候区 |
| 高于850 | 明显发白、火花刺响；持续5秒才记一次过烧缺陷，不因一帧越界立即处罚 |

首次出炉热度建议780；一次正常锻打可在约60～90秒内完成，允许中途重新加热，回炉不重新收费。升温不设毫秒级取出奖励，避免把第一步也做成节奏考试。

加热火候得分H取有效加工时处于良好区间的比例，并扣除有提示的过烧缺陷；单纯等待、反复取放不能刷分。

### 4.3 压坯、塑形、定形

首把教学使用12次有效锤击：压坯4次、塑形6次、定形2次。熟练后同类武器仍约12～18次，不要求数十轮重复点击。

| 阶段 | 玩家判断 | 可见变化 |
|---|---|---|
| 压坯 | 重锤交替处理两到三个区域 | 坯料由厚块逐步展成长条，连续重打同点会偏薄 |
| 塑形 | 选择部位、轻重与先后顺序 | 剑尖收拢、刃面展开、刀身弧度或锏的棱面逐步形成 |
| 定形 | 修正剩余偏斜，以轻敲完成 | 实物轮廓与细薄目标轮廓逐渐重合 |

短按在0.30秒内松开为轻锤；重锤按住0.45～0.90秒后松开，继续保持不产生更强无限重锤。敲击后的金属回弹与音调给出下一次落锤提示：中心±0.18秒为精准，±0.35秒内为普通。服务器延迟补偿与慢速模式必须一起实现，具体网络容差在原型测试后调校，不能只信任客户端报分。

重锤的落点窗口按“达到可释放状态后的回弹提示”显示，不要求同时猜蓄力长度和隐藏节拍。短按／重锤之间的空档不给一次惩罚性误击。

错误敲击产生可见局部偏斜和一次修正机会，不把一次失误判整把失败。连点只接收完成动作后的有效输入，挥空、同tick重复包不累计。

### 4.4 十把兵器的工艺差异

| 兵器 | 制作重点 | 最终装配 |
|---|---|---|
| 越式青铜剑 | 双刃交替、直身与收尖 | 剑体＋剑柄 |
| 汉式铁剑 | 剑脊保厚、两刃交替、尖端校直 | 剑体＋剑柄 |
| 柳叶腰刀 | 从根到尖递进塑弧，避免一处过弯 | 刀体＋剑柄 |
| 环首刀 | 短促连敲刀身、尖端收束 | 刀体＋剑柄；环首属于柄外观 |
| 偃月刀 | 宽刃重压、弧刃轻修 | 刀头＋长柄 |
| 方天画戟 | 中央尖与左右月牙交替处理 | 整体戟头＋长柄；不拆三把刃 |
| 红缨枪 | 细尖对称、枪脊与根部连接位 | 枪头＋长柄；红缨包含在外观内 |
| 四棱铁锏 | 工位支架四面轮转，均匀保棱 | 锏头＋锤柄 |
| 月牙铲 | 宽铲与月牙分别成形 | 铲头＋长柄；尾月牙随整套武器头表示，不单卖零件 |
| 齐眉棍 | 在铁砧附带木作位选纹、校直、修整两端 | 整根棍身；不烧木、不淬火、不装金属头 |

首版只制作上述差异的明确可见操作，不采用自由雕刻任意模型；阶段形变使用少量受控形态，不能因重铸破坏原有精细成品模型。

### 4.5 淬火

已成形武器头在炉口调整至550～700热度，600～650最适宜。它与锻打温区不同，铁匠会明确教玩家稍等降温。槽内实物水面、蒸汽、水纹和音调共同提示时机。

入水后按住右键逐步浸入，松开提起；潜行右键循环有限的预设入水姿态，模型与文字同时反馈，避免要求玩家徒手控制六轴角度。剑、刀、枪使用一个连续过程；宽刃、四棱锏、双端铲按提示在同一过程内翻面或转向，不拆成多次付费工序。

首版最佳提起点约在入水3～5秒内：水面第二次收束、蒸汽转细时给出约0.8秒清晰窗口。普通清水窗口1.2秒，寒泉0.7秒，魔力泉1.0秒；慢速模式把全部窗口放宽到至少1.2秒且不降低品质上限。时间是玩法参数，不能把“长期浸泡必裂”写成现实冶金知识。

| 淬火介质 | 设计收益 | 取得与限制 |
|---|---|---|
| 清水 | 无额外攻击，完美淬火额外耐久＋5%；容错最高 | 普通水即可，首把教学使用 |
| 寒泉水 | 完美淬火使武器自身攻击加成额外＋3%，不加攻击距离 | 建议由沉潮回廊材料与清水调制；这是新配方建议，不声称已有寒泉流体 |
| 魔力泉水 | 入魂仪式成功时少耗50M，兵魂共鸣收益＋10% | 既有满魔力瓶调制清水，魔力须实际扣除；不等同于已有流动魔力自动获得此效果 |
| 玄潮魔水 | 后续异变路线 | **首版不开放操作与数值**；不把岛下黑海变成免费前期强化源 |

不为两种常规特殊介质新增世界流体系统，用淬火槽内部介质配方表示。每槽一次装填支持10次完整淬火尝试；中途退出同一尝试不额外扣次数，也不能通过退出刷新已耗次数。介质耗尽前显示余量；不要求一把武器一瓶药，特殊介质也不无限免费。

完美结果保留完整介质收益；普通结果保留一半数值收益；失败无介质收益并留下可修复缺陷。裂纹不随机摧毁武器头，选择重新加热再淬或回收，最多保留一个有效淬火结果，不能多槽叠加。

### 4.6 装柄与工艺品质

武器头与正确柄放入装配位，空手右键完成，错误柄不消耗。齐眉棍在木作定形后直接完成。

锻打精准P由有效落点与节奏评分，形状完整S由各区域偏差评分。金属工艺总分G＝20%H＋45%P＋35%S；木作以40%操作准确＋60%直度与端部完整度评分。

| 工艺品质 | 分数 | 武器自身攻击加成 | 最大耐久 |
|---|---:|---:|---:|
| 粗制 | 小于50 | 不增加 | ×0.85 |
| 合格 | 50～74 | 不增加 | ×1.00 |
| 精工 | 75～89 | ＋3% | ×1.15 |
| 大师 | 90～100 | ＋5% | ×1.25 |

严重未定形时不允许装配，保留可修正坯料；“粗制”仍必须有完整可用形状。淬火失败在修复前另有耐久×0.90缺陷，无随机战斗断裂。品质不改变攻速、连招窗口、振刀判定或命中半径，不引入含义模糊的隐藏“稳定性”属性。

## 5. 材质精炼与旧武器重铸

材料决定成长阶段，工艺决定玩家的制作水平。低阶大师不会直接超过高一阶的合格成品。

| 材质阶段 | 金属兵器路线 | 齐眉棍路线 | 自身攻击加成 | 最大耐久 |
|---|---|---|---:|---:|
| 基础 | 现有铁／铜基材料 | 普通硬木 | ＋0% | ×1.00 |
| 灵导 | 现有灵纹铁参与换芯 | 灵纹铁作为固结材料、真实供魔处理木纹 | ＋12% | ×1.20 |
| 曜纹 | 灵纹铁与现有曜纹金复合 | 曜纹金参与木纹温养，不变成金属棍 | ＋25% | ×1.40 |

这里只新增三档材料记录，不新增“每个材质×十武器”的ID。越式青铜剑升级后保留青铜轮廓与配色，加入克制的灵纹变化；不因换材全变成同一把发光白剑。

建议基础新锻所需材料当量：普通剑刀4份、枪／戟5份、偃月刀／铲／锏6份，另加一个柄；木棍需4份硬木料。铁锭、铜锭及同类回收料各按对应材料1当量；不能钢料冒充铜料。金属之外的装饰不单独收费。

基础→灵导重铸：对应形制当量的灵纹铁＋120M。灵导→曜纹重铸：同等灵纹铁＋2份曜纹金＋240M。木作使用相同阶次的强化材料与魔力，过程改为校直、导纹和固结，不进入金属火候与淬火。基础阶段不需要魔力；配方仅为本稿建议，不改变原工作台旧配方。

### 重铸必须守住的规则

1. 每把武器有稳定身份；重铸保留名称、附魔、兵魂身份、共鸣、所有权、风灌注及其他兼容数据。物品ID、招式和家族不变。
2. 投入完整武器后，进入“重铸托管”：原品封存，玩家操作新坯；兵魂在工位可见地休眠，不另做剥魂道具。
3. 只有玩家查看结果并选择“采用新工艺”时，才统一消耗新增材料、魔力并更新原武器。取消则退原品，额外燃料和介质已用部分不返；材料不能先变成可带走的新武器头再取消取回原品。
4. 预览必须展示材质、品质、耐久变化与保留内容。重铸不会随机把大师降成粗制；本次工艺较差可选择不采用。不能把旧的大师分自动复制到更高材质上，不操作就升阶。
5. 保留耐久损耗比例：100/850剩余耐久的旧剑不会因升阶自动变满耐久。日常维修另走既有铁砧流程；本系统新增材料的修复映射需专门实现与验证。
6. 更换淬火介质需要重走加热与淬火，只替换本层结果；不能洗附魔、改魂种或刷新兵魂冷却。

无新数据的旧十兵器默认基础材质、合格、无新兵魂，不扫描存档批量改写。

### 加成口径示例

设W0为原武器自身攻击属性加成，不含玩家基础1点、药效和附魔。新W＝W0×（1＋材质加成＋工艺加成＋淬火加成）。三项相加，不连乘。

汉式铁剑原基础总伤害7，即W0＝6。曜纹＋大师＋完美寒泉后：W＝6×1.33＝7.98，基础总伤害为8.98，随后再按既有战斗流程结算附魔、招式倍率与防御。不会把玩家药效攻击也整体乘1.33。

耐久按材质倍率×品质倍率×清水收益×缺陷倍率计算；示例曜纹大师清水为1.40×1.25×1.05＝1.8375倍。原模型10倍巨大化不再参与攻击加成计算。

## 6. 地下城战利品、残破兵器与回收

四领域保留主题偏好，但不是强制独占：80%在本主题池选、20%在全十兵器池选，避免喜欢某种兵器就只能刷一座地下城。

| 主题 | 偏好池 |
|---|---|
| 黄沙遗庭 | 越式青铜剑、柳叶腰刀、偃月刀 |
| 锁钟地牢 | 环首刀、汉式铁剑、四棱铁锏 |
| 沉潮回廊 | 红缨枪、月牙铲、齐眉棍 |
| 星眠幻庭 | 方天画戟及其余兵器；“稀有”体现来源与工艺，不凭空另造一套变体属性 |

普通宝箱保留原奖励，建议额外30%概率获得一件兵器战利品：完整25%、磨损50%、残破25%。完整剩余耐久70%～100%，磨损15%～40%；残破使用通用残破兵器物品，记录形制和材料，无法攻击，不伪装成0耐久仍可使用的剑。

材料档位建议：1～10层仅基础；11～20层基础／灵导80%／20%；21～30层65%／35%。曜纹材料可由高层材料奖励推进，但首版不直接掉落曜纹成品，不掉落已觉醒兵魂。可用成品的工艺分布为粗制20%、合格65%、精工15%，大师主要留给手艺玩法。

### 回收守恒

- 金属在同一锻炉回收；木器在铁砧木作位拆解，不能把木头烧成硬木料。
- 标准配方形制当量为C，完整／磨损／残破的最大回收比为50%／35%／25%，向下取整，最低0；小额不足可累计为工位回收进度，不凭空保底1份。
- 品质改变其档内回收率：粗制按上限的80%，合格90%，精工／大师100%；“高品质回收更多”也不能超过档位上限。
- 对旧工作台和商店武器，C取注册配方可保证的最低基础材料当量与新锻C的较小值；无已知成本的第三方物品拒绝回收。实际接入前逐一审计十把旧配方，包括镜像和商店价格。
- 灵导／曜纹成品仍只回收基础钢料、青铜料或硬木料，不返灵纹铁、曜纹金、柄、附魔材料和魔力。掉落残破兵器按登记的基础C计算，不能自己改标签骗取高阶原料。
- 有兵魂、附魔、命名或特殊标记的武器不接受“丢炉即融”。普通珍贵物品先给明确回收预览并潜行确认；有兵魂的首版直接拒绝熔炼，避免误销毁灵魂。

例如基础金属配方C＝4，磨损武器最多回收1份钢料；重新制造仍需4份金属与一个柄。原有齐眉棍旧配方只用3根木棍，回收上限因此为1份硬木料，不能因为新配方是4份就按4返还。木料、钢料和铜料不可互换套利。

奖励以房间／玩家／本次挑战记录防重领；背包满则保留领取权。退出重进、掉线、重开界面不能重抽品质或灵魂。新增武器物品按原地下城装备保留规则携出，不随未结算遗币20%损失被删除。

## 7. 唤魂祭坛与契约试炼

### 7.1 建筑、能量与进入条件

首版固定**7×7仪式场地**：中央兵器台、四盏魂灯、外圈地面阵纹；上方至少4格无遮挡，地面不要求玩家买下。首处公共祭坛作为可选探索节点，由铁匠在第一次获得残魂印后提示；放置位置另行选址，不覆盖现有天空岛建筑与产权，不修旧世界。

中央台接既有晶纤与真实储魔，容量1000M、最大输入8M/s；亦允许玩家以5M/s注入自己的魔力。试炼本身不要求角色已加入磨砺，成功振刀等操作仍遵守既有天赋和技能门槛：无资格者改给基础普攻／走位版本，不能要求未解锁技能才能得到第一兵魂。

每次开坛先实扣100M启动费；成功另扣300M，失败不返启动费但保留武器和残魂印。魔力泉淬火在成功时把300M降为250M，不能返出魔力。开坛前须预存足够总费用，成功阶段的费用预留，防止临近完成被别的设备吸空。无额外喂养货币，无战斗续航电池。

### 7.2 残魂印来源

只给已登记的特殊魔物、精英和地下城守关者，不采集普通牲畜、NPC、玩家、槐／让等剧情人物、公孙衍或未授权剧情Boss的灵魂。

地下城以队伍真实击败目标为一次事件，为各有效参与者生成个人奖励；参与包括伤害、救援或承受该敌攻击，不抢最后一刀。训练木桩、教官、祭坛魂影、召唤友军、机器圈养刷怪不产印；首版以地下城自然生成登记为准。

建议精英个人掉印率15%；每5层守关首次结算保底1枚对应来源印，重复结算25%。关卡首通标记与掉落一起保存，不能通过重启重抽；现有四个守关者只有在其来源属于可收魂白名单时才发该魂，否则从本主题已登记普通魔物魂池选取，不擅自把Boss身份改成新魂种。

残魂印记录来源种、显示名和外观变体，首版不随机洗隐藏资质。可以交易；同一来源印可按相同数据堆叠。

### 7.3 四段仪式

| 阶段 | 演出 | 玩家操作与真实判定 |
|---|---|---|
| 献器 | 武器落在台面，魂灯逐盏导流 | 放入兼容武器和残魂印，确认开坛；本人锁定本次会话 |
| 显魂 | 法阵聚拢成来源魔物的半透明轮廓 | 约5秒，保留原怪特征，不用统一人形烟雾代替 |
| 契约 | 魂影用可读前摇展示习性 | 30～45秒，完成2～3次实际操作；不以击杀魂影作为成功条件 |
| 入魂 | 魂影绕器一次并融入兵器，魂灯依次暗下 | 约5秒，服务器统一扣成功费与残魂印、写兵魂并返还原武器 |

献器武器托管在中央台，试炼使用临时魂铸投影，复制其家族与已解锁招式但不给背包物品、掉落或其他新奖励；完成后销毁。这样玩家能用自己这类武器应试，又不会同时持有原武器和一把可带走复制品。

没有资格振刀时，祭坛明确显示替代目标。试炼伤害只扣本会话的三次失误额度，不扣真实生命、不耗药、不改真实装备耐久；不赋予玩家抵御场外怪物的无敌。外部真实受伤或倒地立即暂停／取消会话。

失败魂影回印，祭坛30秒后可重开；离场、断线、跨维度或取消直接结束，所有非成功情形均保留武器与印。试炼完成不奖励磨砺、兵魂共鸣、战利品或教官记录，防止祭坛自刷。

同一祭坛一次服务一人，其他人可观看，不能取走或代完成。卸载保存原物品与会话结果；重新加载后未成功会话回到可取回状态，不自动消耗印、不凭空复制武器。成功扣料、结果保存和物品发放必须具有唯一领取记录。

## 8. 兵魂能力、外观与搭配

每把武器最多一枚兵魂，拥有一个被动倾向、一个战斗触发和一套显灵外观。不同魂种是不同玩法倾向，精英来源首先体现外观，不建立十层稀有度与随机词条。

首个闭环建议选四魂：**骷髅、史莱姆、兽人、拟态蟹**，覆盖进攻、防守、重击和振刀；最终扩到下表十魂。不把十魂×十兵器制作成100套全新AI，而是“魂种轮廓＋武器动作挂点＋真实触发方向”组合。

下表为觉醒阶段能力上限的首轮建议；寄宿只开被动，共鸣开放触发的60%数值，觉醒达到表中数值。触发均使用有效事件，不按客户端动画或按键次数直接发效果。

| 来源／性格 | 被动倾向 | 战斗触发（觉醒值） | 契约目标 |
|---|---|---|---|
| 哥布林／灵巧 | 武器攻击耐久损耗有10%免耗 | 主攻命中后下一次有效普攻追加该次基准伤害10%，5秒内有效 | 连续命中两个不同方位的魂靶 |
| 骷髅／锐利 | 有效命中后追踪显示该目标3秒，仅本人可见 | 主攻命中附加该次基准伤害12%的兵魂伤害，沿用原伤害防御结算 | 两次准确刺击或主攻命中 |
| 史莱姆／柔韧 | 来自活体敌人的击退减少10% | 受活体敌人伤害后获得2点吸收生命，持续4秒、不叠层 | 躲过两次跳击，再命中一次 |
| 兽人／勇猛 | 受击中断蓄力后下一次重新蓄力提示更清晰，不改变中断规则 | 蓄力达到1秒并命中时增加0.4格击退，Boss按原抗击退处理 | 蓄势魂影露出破绽后重击命中 |
| 触手／执着 | 自己命中施加的减速持续＋10%，不延长Boss僵直 | 特色招式命中使普通敌减速15%、持续2秒 | 躲过牵引方向并反击 |
| 恶魔／炽烈 | 命中时只显示目标身上一道可见裂焰，无额外常驻伤害 | 主攻或重击命中追加该次基准伤害15%的兵魂伤害 | 连续避开两次扇面后命中 |
| 拟态蟹／谨慎 | 持本武器时盾牌受击击退减少10% | 成功振刀后自身获得2点吸收生命，持续4秒 | 一次有效振刀；无资格则挡住一次投影攻击 |
| 噬魔幽浮／饥渴 | 命中显示目标是否具有已登记魔力容器，不探测未公开Boss秘密 | 命中有真实魔力的敌人转移至多2M到玩家，目标不足不凭空产魔 | 命中两次变向移动的魂影 |
| 强光闪灵／警觉 | 危险前摇时魂体短促明灭，提示不提前于敌人真实前摇 | 战斗步法成功避过一次已登记攻击后，下次命中令普通敌减速10%、2秒 | 步法避过投影闪击后命中 |
| 源晶吞噬虫／蓄势 | 蓄力时在武器附近显示已达到的秒数段，不增加伤害倍率 | 三次有效命中后，下次特色招式追加基准伤害12%；最多存一次、10秒失效 | 对准三处晶壳裂隙命中 |

部分“被动”刻意采用信息或手感提示，不强行给十种魂都叠攻击属性。噬魔仅对拥有可扣真实余额的目标生效，普通怪不能当无限充魔器。强光闪灵的“成功闪避”须攻击路径真实经过玩家原位置且无伤命中，不凭步法按钮计数；第一批四魂不依赖此后续检测。

“基准伤害”取该次攻击在兵魂新增伤害之前、目标防御结算之前的主伤害值；兵魂伤害仍经过目标相应防御，不能绕甲。额外伤害不再次触发兵魂、连击计数或磨砺奖励。原攻击被取消、伤害为0、目标友方、隔墙或已经死亡时不触发。

所有触发共用玩家12秒的兵魂触发冷却，武器也保存自身到期记录，采用两者较晚值。切武器、转交、重登、死亡不清冷却；蓄积型魂的计数／待发状态在离手时清空。持续效果不叠层，不改变连招自身冷却。

### 可读的三阶段外观

- **寄宿**：普通握持偶有轮廓从护手、刃根或棍纹浮现，不常驻整只怪。
- **共鸣**：攻击或蓄力时，局部魂体依附实际武器；收招消退。F8能看清灵流方向和契合状态。
- **显灵／觉醒**：真实能力触发时，完整来源轮廓出现0.6～1.0秒，沿该武器攻击方向演出。兽人随枪前冲、随锏砸落、随剑收斩；没有真实额外判定的轮廓不能撞飞或伤害场外敌人。

默认每名玩家最多一套兵魂投影，完整显灵32格内可见；同屏最多显示最近四套完整魂体，其他降为局部轮廓。普通视野降低亮度与面积，第一人称避开准星；不与重武器巨大化再次相乘，不绕远距离遮挡，不生成常驻宠物实体。光影开关都需原生画面验收，离线图只用于造型检查。

## 9. 契合成长、觉醒与换魂

一条总契合度0～600，另记进攻、防御、重击三种使用倾向，只用于外观和提示，不再开三棵要刷满的技能树。

| 阶段 | 门槛 | 收益 |
|---|---|---|
| 寄宿 | 首次入魂 | 被动与微弱轮廓 |
| 共鸣 | 总契合100 | 开放战斗触发，效果为觉醒值60%，魂体可局部显现 |
| 觉醒 | 总契合600后回原类祭坛完成一次短试炼 | 完整触发与显灵；不另喂材料、不再消耗残魂印，祭坛实扣100M |

有效主攻／特色连招命中＋1；成功振刀＋2；Z蓄力至少1秒并真实命中＋2。普通普攻可以触发兵魂能力，但不直接刷契合；武器更换不丢已存总契合。

同一目标20秒内最多计一次契合事件；同一事件只取最高一项。训练木桩、魂影、教官、同队玩家、宠物、圈养生产怪、无敌或零伤害目标不计。多目标横扫一次只算一次，Z蓄力不按蓄力秒数无限增加契合。参与地下城每5层结算另加15，每次挑战每段只领一次。

不要求三倾向都达标，纯防御或重击玩家也能觉醒。首次觉醒试炼读取玩家最高倾向，给振刀、连招或重击三者之一的可完成版本。合理目标是数次出征后进入共鸣、多个完整五层段后觉醒；若原型实测过慢，调整门槛而非加入日常签到和喂养。

兵魂契合跟随武器。首版允许赠送兵魂武器，新持有者不清成长，需在祭坛做一次不耗印的认主试炼；费用100M。未认主时兵器仍可用，兵魂能力休眠，不锁死物品产权。

首版不提供换魂／剥魂／融合功能：要换搭配就培养另一把武器，旧魂不会被静默覆盖。后续若用户希望换魂，应另设计保留契合与防复制流程，本稿不额外增加离魂瓶和剥魂机。

有兵魂武器耐久耗尽后进入“失锋”而非消失，保留物品身份和兵魂，不能攻击，修好后恢复；普通无魂武器仍走原破损规则。这个保护是新近战兵魂武器的专属规则，不重写全模组装备耐久体系。死亡掉落、产权和地下城保装按原规则，不新增自动回包或跨维召回。

## 10. 学习入口与任务串联

把教学放进正史“多年旅途”的可选成长区，不设为开正史后段、入地下城、结婚或买房的门槛。

| 教学节点 | 地点／人物 | 玩家亲手完成的验证 |
|---|---|---|
| 第一柄兵器 | cava铁匠铺 | 亲自完成一件工艺成品；买来的成品不代替锻造教学 |
| 火候与水声 | 公共炉口、铁砧、淬火槽 | 有效锤击及一次正常以上淬火；不强迫大师 |
| 旧刃新用 | 任意地下城和铁匠铺 | 本人领取兵器战利品，再回收或重铸一次 |
| 灵纹入刃 | 原魔导材料系统和炉口 | 真实消耗灵纹铁与120M完成灵导重铸 |
| 第一枚残魂印 | 地下城／祭坛 | 获得印后提示可选探索；不刚出生就剧透整套仪式 |
| 兵魂相认 | 唤魂祭坛 | 显魂、完成契约、实际得到有魂原武器 |
| 共行与觉醒 | 战斗与祭坛 | 达到契合并完成觉醒试炼，不以手动勾选冒充 |

新增FTB自有章节“炉火与兵魂”，复用真实事件授予；不重新生成整本任务书，不改变原ID。教学奖励以工具、基础材料补给为主，不直接发大师成品或600契合绕过过程。齐眉棍有木作版教学，不能要求它完成淬火才毕业。

## 11. 保存、多人与异常处理的硬性要求

以下属于玩法交付要求，具体类名和存储字段留到批准后的实施计划确定。

- 武器保存版本、身份、来源、材料阶段、工艺评分、淬火结果、兵魂与契合；角色磨砺仍保存于原系统，不迁入物品。必须保留无法识别但合法的外部物品数据。
