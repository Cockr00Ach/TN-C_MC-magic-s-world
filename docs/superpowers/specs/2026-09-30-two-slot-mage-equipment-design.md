# 双部位魔法装备设计稿

2026-09-30。设计范围为身甲、魔法帽、四阶制作与一套神级遗物。**这是设计稿，当前游戏仍使用铁匠原版铁装订单；本稿中的物品、外观、属性、遗物和修复尚未安装。** 作者正在自行修改任务书，本设计不修改任何任务书章节、任务ID或图片。

概念图：[双部位魔法装备概念图](../../concept-art/双部位魔法装备概念图-20260930.png)。从左到右展示壁垒、星织、归墟神装、秘纹、远行的造型方向。它是美术参考，未直接作为Minecraft贴图使用。

## 核心规则

常规装备只需穿**一件身甲和一顶魔法帽**。身甲占原胸甲槽，视觉从肩部延伸到靴面，数值以整套胸甲＋裤子＋鞋子的总效能计算；帽子占头盔槽。新系统不制造对应裤子、鞋子。身甲穿着时裤子、鞋子槽不叠加其他防具：玩家需要先卸下旧裤、旧鞋；之后的穿戴请求被拒并保留原物。旧存档的铁装、待领取订单照常保留，玩家自愿换装。其他模组强行写入两槽时，服务端安全退还物品，不丢弃玩家装备；满背包则暂不启用身甲的额外属性并提示整理。

选择沿用原版胸甲和头盔槽，因为玩家无需学习新装备界面，背包操作也直观。另两个可行但不采用的方案是：新增一套独立装备槽（兼容与学习成本高），或把长袍和帽子合并为单件（失去自由搭配）。因此两槽穿戴与冲突保护是正式功能的一部分，不能只用任务书文案假装裤鞋已被取代。

全系列**不分元素**，任何法杖、任何亲和力都能搭配。四种身甲与四种帽子自由混穿，没有限制配套的常规套装奖励。每款常规装备有冒险者、精练、大师、传说四阶。身甲16件、帽子16件、神级2件，共34件可穿装备；另有2件未修复遗物。神级是单独的第五层，只有一款长袍和一顶帽子，不能由常规装备升级得到。

四阶的冒险等级门槛分别为1、20、45、70；神级修复需Lv85。等级只限制铁匠制作/修复，不让玩家已获得的物品因升级、掉级或交易突然失效。每阶颜色、材质与结构都升级：冒险者偏实用布铁，精练出现工艺纹理，大师出现立体符文构件，传说才有克制的动态光效。各款保留自己的轮廓，不把同一件改色当四个品种。

## 四种身甲

下表每格按“冒险者 / 精练 / 大师 / 传说”的顺序。防御为原版护甲点；魔力是穿着时增加的最大魔力。防御数值已包含身甲替代三件防具的份额。

| 款式 | 定位与外形 | 防御 | 额外属性 |
| --- | --- | --- | --- |
| 壁垒战甲 | 黑铁、旧铜与层叠甲裙；宽肩、重下摆，实打实的防线 | 8 / 11 / 13 / 15 | 护甲韧性 0 / 1 / 2 / 3；移速 −4% / −3% / −2% / −1% |
| 星织长袍 | 深蓝布层与银线星轨；轻、长、垂坠的典型法师衣 | 3 / 5 / 7 / 9 | 最大魔力 +30 / +65 / +110 / +170 |
| 秘纹锁甲 | 细密锁链藏在酒红短罩袍下，几何咒纹沿袖口排列 | 7 / 9 / 12 / 14 | 最大魔力 +15 / +35 / +65 / +100；韧性 0 / 0 / 1 / 2 |
| 远行外衣 | 沙色皮布、青色披肩、非对称开襟，方便跑动和探索 | 4 / 6 / 8 / 10 | 移速 +3% / +5% / +7% / +9%；最大魔力 +0 / +10 / +20 / +35 |

壁垒守住正面，星织延长施法续航，秘纹给近战法师折中选择，远行用于游走、远征和躲避。四者的属性优势不能只靠价格高低决定；高阶同款增强原定位，不逐渐变成同一种全能甲。

四阶美术也按款式分别升级，而不是统一加亮边：壁垒从铆接铁板发展为层叠鳞甲、封闭护肩、悬浮的盾纹扣件；星织从朴素披衣发展为双层星图袖、活动肩纱、流动的细线星轨；秘纹从露出的粗锁链发展为细密双层链、篆刻胸片、外浮的符文环；远行从布皮披肩发展为带护臂的短斗篷、分叉行衣、轻质折叠披风。传说阶仍一眼能看出原本是哪条路线。

## 四种魔法帽

帽子同样独立四阶，可和任意身甲搭配。概念图中的每顶帽子仅是一个搭配例子。

| 款式 | 轮廓 | 防御 | 额外属性 |
| --- | --- | --- | --- |
| 守望宽檐帽 | 硬质平宽檐、短冠、帽缘金属护片 | 2 / 3 / 4 / 5 | 击退抗性 +0 / +5% / +10% / +15% |
| 观星尖帽 | 高而略弯的尖顶、星图刺绣与小坠饰 | 1 / 1 / 2 / 2 | 最大魔力 +15 / +30 / +50 / +80 |
| 回响法冠 | 六角短冠、金属回环、耳侧小符片 | 1 / 2 / 2 / 3 | 每40游戏刻额外回魔 +1 / +2 / +3 / +4 |
| 行旅兜帽 | 柔软包头兜帽、护颈披布与窄护目边 | 1 / 2 / 3 / 3 | 移速 +2% / +3% / +4% / +6% |

星织＋观星可极限堆魔力；壁垒＋守望抗冲击；秘纹＋回响维持攻守平衡；远行＋行旅赶路最快。混搭可得到其他中间状态。回响的回复沿用原有“施法后3秒暂停回魔”规则，不能绕过施法消耗。

帽子的四阶变化也遵守各自剪影：宽檐逐渐增加护片而不变尖帽，尖帽的星图与帽尖垂饰逐阶增长，法冠增加可见的回环构件，兜帽逐阶增加护颈和窄边护目饰。高阶体积可增加，但不能遮挡第一人称视野。

## 神级遗物：归墟神袍与归墟星冠

只有这一套神级造型。长袍为象牙白外层、深夜蓝内层与不完整的金线星环；星冠像一截被修好的古代高冠，光环留有裂纹，强调“修复过的遗物”而非崭新商城道具。衣摆和帽冠在游戏中必须有独立的、克制的动态细节；不能用普通星织长袍单纯换色。

| 修复品 | 防御 | 独立属性 |
| --- | --- | --- |
| 归墟神袍 | 16，韧性4 | 最大魔力+200；每40刻额外回魔+4；移速+4% |
| 归墟星冠 | 4 | 最大魔力+100；每40刻额外回魔+3；真实施法消耗−8% |

两件同时穿着时触发“残星回响”：受到一次本应致命的普通伤害时保留1点生命，并返还当前最大魔力的20%；每位玩家冷却8分钟有效服务器时间。不能拦截虚空、`/kill`或管理员伤害。冷却状态写入个人存档，退出重进不能刷新。神装仍受正常装备穿戴、死亡掉落和世界规则约束；不会自动授予神级法术、亲和力或额外法杖阶位。

获取路线采用现有可定位的`tnc:abyss_citadel`（深渊城堡）作为唯一主题地点。结构真正生成完毕后，地下祭库的交互遗物座给“破损的归墟神袍”，上层封存室的遗物座给“断辉星冠”。每名玩家每种遗物在所有深渊城堡中只可领取一次，领取状态存服务端个人数据；多人各有探索机会，不争抢单个箱子。遗物本身无装备属性，也不能直接穿上。部署遗物座前必须在独立测试世界检查两处实际建筑空间，选择不覆盖原装饰、容器和玩家改造的位置；如果没有合适房间，先为现有遗迹扩建小型附属祭库，不凭坐标硬放到墙里。

带遗物到28号炉石铁匠铺找铎恩，进入独立的“修复遗物”页面。神袍消耗破损神袍、下界之星×1、回响碎片×8、下界合金锭×4、钻石×8与12,000铜；星冠消耗断辉星冠、下界之星×1、回响碎片×4、下界合金锭×2、钻石×4与8,000铜。两件各需5分钟有效服务器时间。先验证遗物、材料、余额和订单空位，再一次性扣除；满背包时保留已修好的成品待领取。遗物不是掉落概率、不是常规合成配方，也不会通过任务书重复发放。每名玩家的遗物领取记录可防止刷取；修复后物品可按服务器交易规则流通。

## 制作与经济

常规订单只在铎恩柜台办理。四阶人工费为40 / 220 / 1,200 / 6,000铜，制作时间为20 / 40 / 70 / 120秒。每款有下表的**一阶基础料**；高阶各项基础料数量按1 / 1.5 / 2 / 2.5倍计算，逐项向上取整，并追加阶级材料。这给32件装备一个完全确定的材料表，不必手写32次。

| 装备 | 一阶基础料 |
| --- | --- |
| 壁垒战甲 | 生铁×12、煤×2 |
| 星织长袍 | 皮革×8、线×12、青金石×4 |
| 秘纹锁甲 | 生铁×8、线×8、铜锭×4 |
| 远行外衣 | 皮革×10、羽毛×6、线×6 |
| 守望宽檐帽 | 生铁×4、煤×1 |
| 观星尖帽 | 皮革×3、线×5、青金石×3 |
| 回响法冠 | 铜锭×4、紫水晶碎片×2、线×3 |
| 行旅兜帽 | 皮革×4、羽毛×3、线×3 |

追加材料：冒险者无；精练加紫水晶碎片×4；大师加紫水晶碎片×8、钻石×3；传说加钻石×6、下界合金锭×1、回响碎片×2。若基础料已包含紫水晶碎片，例如回响法冠，两部分数量相加。每阶可独立制作，不强制吞掉上一阶的附魔装备；正式界面必须在确认前列出合计数量。例如传说星织长袍需皮革20、线30、青金石10、钻石6、下界合金锭1、回响碎片2与6,000铜。

黑匠订单界面先选“身甲 / 魔法帽 / 遗物修复”，再选款式和阶级，屏幕同时显示穿戴槽、属性、材料、费用与制作时间。旧铁盔/胸甲/裤/鞋/剑订单只留给已有存档的未领取单与旧物品兼容，不再作为新玩家的主要装备成长线。老玩家的已交材料、待领取订单和原有物品ID不能作废。法杖仍由莉娅制作；不把铎恩的装备业务放回其他NPC面板。

## 落地时的技术边界

- 常规魔力上限只取**当前穿戴**提供的固定加值，在`MagicStone.refreshMaxMana`基数重算之后应用；卸装立即回退，当前魔力按新上限截断而不凭空补满。回魔只在服务器原有40刻恢复节点附加，不创建第二条无限恢复定时器。
- 原版防御、韧性、移速与击退抗性用装备槽属性修饰器；同一件只计算一次，穿脱、死亡、登录、换维度均复算。神冠耗蓝优惠挂在真实SpellEngine扣蓝入口，不能只改提示文字。
- 两槽外观必须在玩家模型上有完整衣摆、衣袖和帽檐；背包图标和人物穿戴图层分别制作。概念图不能直接缩成32像素充数。
- 遗物座的生成只在结构完成且安全位置核验后进行；不得改写既有玩家存档或覆盖建筑。服务器校验个人领取、铁匠距离、材料、币、订单和冷却，客户端只展示。
- 任务书由作者编辑。本装备系统只准备可选的进度触发ID和物品名供作者接入，不自动生成或修改章节。

## 验收口径

常规32件和神级2件的名字、图标、穿戴模型及属性对应；两槽足以完成完整装备；四款身甲与四帽辨识度足够，四阶不是单纯调色；旧装备订单和物品不丢。更换装备、满包领取、多人遗物领取、退出重进冷却、两个NPC岗位与施法耗蓝均有服务端验证。最终还需实际游戏内近景和远景截图，特别检查衣摆是否盖住腿部、帽檐是否挡视线。
