# 水法修正与战斗玩法第一版

用户已授权自行决定实现细节，不设逐项确认阻塞；本次不改地图、音乐或合作者的法术目录。

## 分项设计与实施顺序

1. 水法：诊断已确认 SpellPower 创建魔法属性时默认 0，TN-C 原来把该值当乘数。保留最低 1 倍基础伤害，正法强超过 1 时沿用加成。水炮弹视觉半径由 0.5 增至 0.85，水球仍 0.32，单体命中不改成爆炸。龙王吼持续 200 tick。海浪斩击由单次 26 方向改为 200 tick 内每 20 tick 发射一轮，单轮仍有寿命与最大距离，不把斩击无限飞远。
2. 龙灭：用户明确授权除基岩外材质可破坏，包括容器；保留出生点、Forge 领地事件、世界边界、未加载区块保护。容器依照原版拆除行为释放库存，普通方块无掉落。每 tick 128 个直接编辑预算不变。取消因树叶、沙子、附着物等邻居直接拒绝整束激光的规则；编辑时抑制即时邻居和形状连锁更新，避免检查范围外的附着物被顺带拆除。之后游戏正常更新仍可能改变失去支撑的植物/沙子。
3. 水法法阵：使用代码几何刻画分层法阵，不再叠加金色雷法贴图。外层深蓝、符文紫蓝、内层靛紫、卫星偏亮紫，与青色水体区分；保留其他已经认可的水体、巨剑和海浪。
4. 倒地：新增独立服务端状态机，不靠客户端伪造复活。基础生命在原值上增加 20（原版 20 -> 40），与已有装备加成兼容。单人倒地可按住救援键 3 秒自救，恢复最大血量 60%；进入倒地即开始 6000 tick 冷却，冷却期间正常死亡。多人倒地无自救，由活着的队友靠近并保持救援键 3 秒；全员倒地触发团灭。优先使用现有 FTB 队伍或原版 scoreboard 队伍；未建队的在线生存玩家视为同一个合作小队，跨维度队友计入但救援需同维度且无遮挡、距离 3 格内。创造/旁观者不计入队伍。离线不成为永久存活救援者；倒地状态与冷却持久化，不能重连自救或刷新冷却。正常已生效的图腾/燃烧复活优先于该被动。
5. 吟唱：读取 SpellEngine 的真实 cast process；tier >= 4 在蓄力期间于屏幕顶部显示分句，不占大标题，不在取消后继续播放。先提供水系八个、雷系六个高阶技能的独立台词；其他元素可用通用词备用。
6. 学习：只有服务端真正首次解锁成功时才触发，失败/重复解锁不播放。以元素颜色的多个螺旋轨迹向胸口汇聚，持续约 2 秒，周围玩家可见，不生成实体、不改世界方块。

## 取舍

- 倒地选用原生 Forge 事件与同一网络通道，避免增加外部复活模组依赖。联网端仅请求“正在救援”，对象、距离、进度、伤害与复活结果均由服务端决定。
- 吟唱读取真实施法进度优于单纯 RELEASE 后显示；学习通过服务器粒子优于客户端自行宣称成功。
- 不把每轮海浪的寿命拉到十秒，否则会导致数百格不可控射程；用有限寿命的连续波次。
