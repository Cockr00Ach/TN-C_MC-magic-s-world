# RouchNao：有归处的异世界小镇

2026-10-01。作者授权本轮直接设计、完成并实装，细节之后由作者调整。此文描述目标和规则；实际完成状态另见发布验收，不把方案当成实现。

## 核心判断与路线

整合包的目标是让玩家成为异世界里有家、有邻居、有职业和牵挂的魔法师。魔法同时服务战斗和生活；剧情赋予远行理由。Boss是旅途中的难题，旅途结束仍有值得回来的地方。

三条可能路线：一口气扩充Boss与装备，内容多但会重复作者不喜欢的节奏；先完成大量内饰与居民台词，氛围好但生活经济仍断开；先完成看房、家居、交易、土地与原生居民的生活循环，再沿剧情扩展。采用第三条，并把内饰制作与程序功能并行安排。

本轮程序优先顺序：多房源与明确权限 → 商店买卖和家具 → 付费农牧地 → MCA居民与安家 → 编号地图、制作交接、剧情与后续委托设计。沿用已实装银行、法杖、两件制装备；不重写作者现有FTB页面，不改其他正在进行的遗迹工作。

## 小镇与门牌

小镇正式称呼为 **RouchNao小镇**。角色口语可简称「镇上」，店名保持归航银行、朝夕商行、炉石铁匠铺、潮生制杖屋、茶灯会馆，保留原剧情NPC姓名与原有剧情事件。

沿用现有01–41入口编号，另加F01–F04农田、P01牧场；18和20是同一训练场的两个门，编号不代表独立产权。23、31、37为居民住宅；19、28、29、32、34、41为银行、铁匠、制杖、商行、娱乐、酒馆。北区主殿和剧情建筑保持公共用途。

首批五套房为16、24、26、27、40号。选26号甜麦小屋1800铜、27号灯下小筑2600铜、40号南街三层屋3000铜、24号东庭双层宅3600铜、16号书风宅4200铜。差别是地点、面积、层数和装修空间，不是属性加成。每人先拥有一套正式住宅；五位玩家可分别购买五套，别人不能抢占已售房源。以后扩房或换房另做独立设计。

银行先显示房源卡，写清门牌、价钱、首付、位置和已售状态。「去看房」提供动态世界坐标和路线提示；玩家现场看房后记录看房进度，再回米洛处选择全款或分期。所有五套同样采用30%首付、剩余本金一次加10%费用、10期、每在线40分钟一期，离线不催。已有房贷只能绑定自己这套房，不能串房解除抵押。

付钱后属于玩家，边界内允许挖、放方块、摆家具及授权朋友。道路、商店、邻居家、其他玩家家保持保护。房源蓝图逐栋预检、逐栋清理恢复，不覆盖后来装修，不清空箱内物品。小镇内饰更新只作用未售公共/源模板区域，不能整岛覆盖已有产权。

## 从开场到第一次回家

开场视频建议60–90秒，可跳过并重看：异世界与失去的归处约20秒；天空岛的注视与邀请约20秒；生活和魔法的画面约20秒；把控制权交给玩家。不要用视频一次解释所有人物和规则。没有最终视频素材时保留接入说明，不能用文字弹窗冒充已播放视频。

第一段流程：出生阅读作者世界页 → 收到天空岛邀请 → 登岛见到RouchNao门牌 → 酒馆Self接原剧情 → 艾琳登记 → 莉娅制第一根法杖/铎恩制第一件装备 → 认识商行陆蔓、银行米洛和两位邻居 → 看房 → 获取首笔经营或委托收入 → 买房并购置床与灯 → 第一次在自己家过夜。

上述生活教学是交错支线，不要求五条全做完才允许离岛，不以结婚、生育、借款、全元素研习作为主线门槛。第一次回家之后，原剧情继续由周坐望等现有角色推动。

## 朝夕商行与钱

32号一楼营业、二楼家具样板、后区收货。店主陆蔓在屋内，页面独立于银行和铁匠。购买分家具、农牧用品、日用品；出售显示货物、实际可售数量、本次收入及个人剩余额度。钱袋用于购物，存款用于银行及购房；不显示复杂金融术语。

常规农牧收购：小麦/胡萝卜/马铃薯1铜，面包6，烤薯3，鸡蛋3，羊毛4，皮革6，生肉4，熟肉6，鱼4，奶桶4，蛋糕24。每人在线40分钟一轮，普通收购额度500铜，Lv20为1000、Lv45为2000。额度不被他人抢光，离线重登不刷新。容器照实退回；有特殊NBT的物品不混入普通产品收购。满包、满钱袋、物品不足全部不扣物、不扣钱。

家具包含真实的可放置椅子、桌子、沙发、柜、灯、床和装饰品。优先使用当前Immersive Furniture模型数据及已装Farmer's Delight/Supplementaries真实物品。TN-C制作的家具不依赖在线下载模型。家具按清单禁制作、切石和复制，关闭家具编辑台的生存制造途径，创造模式供内饰制作。普通工具、种子、围栏和生产材料仍可制作。禁止用商店买入原料，原地加工后高价卖回；每个出售配方检查商店原料成本。

工资与存款保留已确认数字，10%现实日息、1万铜计息上限、普通贷款本金扣除口径都不暗改。高本金每天1000铜足以买不少家具，所以经营应提供更快的主动收入和特殊生活目标，而不是不断新增强制税费。先测实际收成和游玩时间，再调商品价和额度。没有房租、饥饿债务、每日打卡和强制家务。

## 土地与魔法生活

中央南侧草地设四块14×16农田和一块21×20牧场，分别300铜和600铜，位置按源地形验证，避开住宅、道路、花园、传送阵。土地原状交付，玩家可以自己整理；边界和坡度写清，不每次加载重铺土地或清牲畜。每人先各有一块农田和一块牧场，未售可看，不可修改，付款后解锁使用。银行房子页提供土地入口，农业先行者无需先买房。

野外种地仍可行；买镇内土地的价值是安全、便利、靠近家和商行。朋友授权适用于生产协作。陌生人不能收割、施肥、挖地、剪别人羊毛、挤奶或伤害私有地上的牲畜。防火、防爆、活塞与模板覆盖保护同房屋。

生活魔法作为下一阶段设计：雨水术只湿润/灌溉，微风术缓解天气或短暂帮助搬运，土系整理只处理自己的地。禁止无限生成矿物和食物；成熟速度加成要看真实农牧收入再决定，不能让所有生产变成站桩施法。

## 居民与家庭

MCA为唯一婚姻、亲子和好感状态来源。六位成年居民为林禾、乔麦、蓝汐、燕岚、何舟、苏苒，住在23、31、37号。保留各自名字和职业，正常行走、休息、原生聊天、赠礼、婚姻、生育和家谱；不能把自研「同住」按钮说成凡家物语婚姻。服务NPC和剧情NPC保持岗位职责，日常居民使用MCA实体。

住房提供家与床位，MCA提供感情和家庭。结婚后可以让配偶随行回自己的住宅，再设置原生家；孩子与家谱由MCA管理。不要替玩家选伴侣、替玩家自动结婚或生育，不把儿童设为恋爱对象。家庭成员不能当成无限自动生产机器。先完成可靠安家，再做吃饭、家庭出游、周年信件等可选小事。

生活气息优先靠「可重复但不强迫」的小事：陆蔓偶尔采购当季食材、烘焙铺收集一桌晚餐、邻居请你顺路送东西、酒馆有人谈起你上次远行、家里可展示冒险纪念。事件只轻量触发，不因几天没上线掉光感情，也不把每位NPC都做成任务发布器。

## 冒险、委托与娱乐

酒馆保持Bountiful真实委托栏，Self负责剧情引导。委托按生活补给、镇外调查、危险讨伐、剧情特别行动分组。高阶灾变Boss委托设计为「线索调查→准备→讨伐→带证据归来→小镇回应」，不是每天清同一Boss。首杀委托记录真实Boss击杀和参与玩家，不把到达坐标/阅读任务当作战胜。多人击杀参与与共享证据、Boss所在结构维度和ID需要按已装3.31版本逐项核验后再接高级委托。

首个大型剧情节点建议让一次远行解决镇里的真实问题，例如航路阻断或补给失踪；归来产生公共布置、人物对话或可购买纪念物变化。商店、家庭、农场可以继续做，不要求玩家为了推进Boss线一直离家。

34号茶灯会馆先预留牌桌、茶座、观景角，营业时与晚间居民相遇。以后做2–5分钟的一局纸牌、骰子或赛果竞猜，先有无金钱练习与明确成本，娱乐奖励以装饰、称号、少量固定奖金为主，不成为必做赚钱捷径。本轮不随意替作者决定玩法规则。

## 内饰协作、系统边界与验收

给内饰制作者：源存档、原点与门牌表、重点屋用途、玩家空屋交付标准、NPC站位与通路、MCA兼容床位、禁止改外墙/屋顶/地形/房号的范围。他完成后交完整存档压缩包和改动房号列表。先在测试副本导出版本化分块模板，不用成品世界整岛覆盖所有现有世界；新世界用新模板，既有产权房只在作者明确要求时局部导入。

技术模块：房源与地块目录负责ID/边界/价格；产权服务负责所有者/访客/交付；银行只负责资金/合同；商行只负责商品和库存事务；MCA适配只负责生成与安家；编号与指引只读取目录。账户、产权、交易记账都由服务器验证。所有坐标由当前天空岛原点计算，不硬编码为某个存档世界坐标。

必验：两位玩家买相邻不同房，权限不串；陌生人访问只读；预检失败不扣款；重复购买不重复收费；产权与房贷同次保存；重启清理不破坏已装修房；土地收割、施肥、牲畜交互按主人判；物品容器与金额守恒；制作入口无漏口；MCA实体不因卸载补生副本，家庭状态只来自原生；内饰换模板不覆盖已售地块。

完成方向是「一位新玩家能自己选归处并靠生活或冒险持续改善它」。五栋看起来能买而实际上不能买、图片家具没有真实模型、NPC只站门口、原生家庭没有接上，均不算完成。
