# 玄潮黑海魔力暴乱：用户反馈修订

> 后续实机反馈要求更低、更窄且离岛更远。当前尺寸、离岸保护和岛岸实测方案见[离岸漏斗可读性修订](2026-11-06-offshore-funnel-readability-design.md)。下文记录魔力暴乱密度与特效层次的上一轮实现、验收。

本轮按用户对已安装原型的明确修订执行：更大、更密集，龙卷周围要有魔力线条和魔力涌动。保留此前确认的胖瘦差异、最高低于天空岛、F8魔力视入口；直接迭代实现并安装到同一PCL实例。

只增加风柱数量会显得重复，只堆发光粒子会遮住黑色主体。本轮采用风暴群、卷流、跨风暴乱流三层组合。

- 风暴群：锚点间距192改128格，同屏上限2改10。主风柱高66～108格，基础半径36～76格，独立收腰和宽高比例，少量主暴风更宽。海面Y49，包含动画云肩仍低于Y170。实机反馈后拉开高低差并收紧顶部，避免多座巨型云盖重叠成不透明平板。
- 风壁卷流：可辨认的长弧魔力束沿三维风壁上卷，粗暗紫光晕包住较细亮芯，亮度脉冲沿曲线传播。避免匀速同相旋转的规则铁丝笼。
- 海面暴乱：大范围旋臂汇向风眼，扩散的破碎波纹与短促甩出的乱流交替出现；相邻龙卷用弯曲流束连接，让整片海共享一次不稳定涌动。黑色风体仍是主体，紫黑为主、少量冷蓝与淡紫亮芯。

特效使用受预算约束的即时三维条带；不创建数千粒子实体，不加载远区块，不影响玩家存档、天气、战斗。继续验证真实海水根点和地形深度。分近中远三档，只有最近两座能用最高细节；同屏数量、顶点及连接数均有硬上限。

移动稳定性：56格距离差触发逐座替换，旧根30tick淡出腾槽，新根40tick淡入，同屏仍最多10座。折返重选的根重新淡入；连接按世界坐标固定端点方向，避免相机排序改变流束曲线和脉冲。每根最多选择两个近邻，合并后不超过2N条连接，完整最坏场景上限23,996四边形。使用保守包围盒剔除视锥外风暴和流束，实际提交量进一步降低。

验收：测试不同胖瘦与时间下的岛面上限、流线动画、有限顶点、预算、位置稳定与连线数量；原生281模组隔离客户端拍昼间岛面高度俯视、夜间斜侧、近海视角，检查实际暴乱层次和光影可见性。启动通过后备份旧包，标准安装器完整校验，核对实际PCL哈希和ModernFix唯一true；保留战士锻造原型。
