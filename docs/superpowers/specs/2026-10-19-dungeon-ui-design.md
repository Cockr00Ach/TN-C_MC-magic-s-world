# 地下城界面：旧铜星仪

用户已指定沿用此前确认的深色旧铜星仪／魔法书风格，直接修改并安装；怪物留待下一轮设计。

采用现有 ArcaneGui 纹理与比例正确的星仪绘制，统一入口、宝匣、整备、六类奇遇、手册和进度条。相较只换外框，正文、按钮和地图也一起调整；不另引入新美术风格或整张拉伸背景。

- 600×360逻辑画布等比缩放。旧铜边框、深色书页、暖白文字、蓝绿晶体；图标保持正方形。
- 顶部标题和三项账本信息；左侧是当前页面的选择，右侧是星仪／探索图与规则摘要。底部保留明确关闭提示。
- 入口六段以两列三行展示，已解锁段可选，锁定段及非队长状态明确区分。沿用服务器权限和传送逻辑。
- 宝匣展示奖励类型图标；整备与奇遇用带简述的铜饰按钮。地图只绘制服务器已知房间。
- 小分辨率与较大GUI倍率下仍等比，文字换行、间距和点击框保持一致。
- 只改变客户端界面，保留物品、怪物、任务书、银行、战斗、掉线恢复与世界模板。

验证：编译与现有单元测试；隔离完整PCL客户端检查所有面板、锁定入口、不同GUI倍率和窗口尺寸；核对安装前后全部任务文件哈希。验证后替换PCL与镜像JAR，提交并push。
