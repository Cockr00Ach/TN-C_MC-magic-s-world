# 连续落剑与灭世海啸

用户已验收巨剑主体，要求落剑冲击改为海浪、领域持续降剑；灭世之海扩大、连续向全方向冲出超巨海浪、持续30秒，并在之后保留30秒暴雨。依照自主实现授权直接落实，不询问实现细节。

冥穴：保留64格巨剑主体、26格领域及30秒封印；第7秒第一次落剑，此后每3秒一次（7/10/13/16/19/22/25/28秒，共8次）。每次仍60点基础水魔法伤害，保留敌我/视线/高度检查，每次结算一次，不按帧叠伤。至多两把剑影同时显示，连续凝结和下刺。取消落剑后的直管光柱，改为两层向四周翻卷的短暂冲击浪与白色泡沫。

灭世之海：半径64格（直径128）、浪峰上限40格、生命600tick（30秒）；从中心定期发出完整360°卷浪波面，向外移动至范围边缘消散。深海色浪腹、亮青水流层、外翻再回卷的浪唇、白色泡沫与薄海面共同形成海啸，不再依靠龙卷/直立光柱。有限角向与剖面段数，与半径/玩家数平方无关，不创造水源或持续粒子实体。服务端浪前位置和客户端共享规则，伤害维持基础10、最多每秒一次，仅命中当前浪前中的敌对目标，保留视线及友方规则。

30秒正常结束后才开启30秒主世界雷暴雨，沿用可持久化天气租约及管理员天气优先规则。提前因死亡、离线、跨维度、距离或重放取消时不另安排延迟天气。每个施法者最多一片灭世海域，新施放替换旧海域，其他水波等级及26方向斩击不受影响。
