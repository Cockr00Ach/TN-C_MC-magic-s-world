# 法术制作与测试指南

> 这份是"我自己是怎么加一个新法术的"完整流程 —— 照这个走，改一个数值到进游戏看到效果，大约 **2 分钟**。

---

## 一、先搞清楚：一件事分三层

| 层 | 是什么 | 放在哪 | 改完怎么生效 |
|---|---|---|---|
| **数据层** | 法术本体（伤害/范围/冷却/粒子/音效）| 整合包 `kubejs/data/tnc/spells/<id>.json` | **`/reload` 或重进世界**（数据包重载）|
| **目录层** | 游戏里"能不能学、学几级、叫什么名字" | `SpellCatalog.java` | 编译 + 装机 + **重启游戏** |
| **机制层** | 引擎表达不了的行为（燃血/复活/飞行/环绕球…）| `TNEffects` / `TNFireMechanics` / `TNWindMechanics` 等 | 编译 + 装机 + **重启游戏** |
| **美术层** | 图标/效果图标/投射物模型 | 见第五节 | 重进世界（资源包重载）|

**关键**：**只改数值和特效 = 只动第一层** ✓ —— 不用编译、不用装机、不用重启游戏（`/reload` 就行）✓。
只有"新机制/新效果/改目录"才要走编译装机 ✓。

## 二、三分钟做一个新法术（照抄模板）

### ① 投射物型（火球/水球/雷球/暗夜之手/风刃…）

```jsonc
{
  "school": "FIRE",                      // ★ 学派名必须对，见第六节
  "group": "ball",                       // 自己起个组名（只是分类，随便写）
  "range": 40.0,
  "learn": { "tier": 3 },                // 1~5 级
  "cast": {
    "duration": 0.7,                     // 读条时间（秒）
    "animation": "spell_engine:one_handed_projectile_charge",
    "sound": { "id": "spell_engine:generic_fire_casting", "randomness": 0 },
    "particles": [ { "particle_id": "flame", "shape": "PIPE", "origin": "FEET",
                     "count": 1.0, "min_speed": 0.05, "max_speed": 0.1 } ]
  },
  "release": {
    "target": {
      "type": "PROJECTILE",
      "projectile": {
        "launch_properties": { "velocity": 1.3,        // 飞行速度
                               "extra_launch_count": 0, // >0 = 一次多发
                               "extra_launch_delay": 3 },
        "projectile": {
          "homing_angle": 0.3,                         // >0 = 会追踪
          "divergence": 12.0,                           // 多发时的散角
          "perks": { "pierce": 0 },                     // 1 = 穿透
          "client_data": {
            "travel_particles": [ { "particle_id": "flame", "shape": "CIRCLE",
                                    "rotation": "LOOK", "origin": "CENTER",
                                    "count": 4.0, "min_speed": 0.0, "max_speed": 0.1 } ],
            "model": { "model_id": "tnc:projectile/fire_ball",   // ★ 细长模型要加 orientation
                       "scale": 1.2 }
          }
        }
      }
    },
    "animation": "spell_engine:one_handed_projectile_release",
    "sound": { "id": "spell_engine:generic_fire_release" }
  },
  "impact": [
    { "action": { "type": "DAMAGE",
                  "damage": { "spell_power_coefficient": 1.5, "knockback": 0.3 } },
      "particles": [ { "particle_id": "flame", "shape": "SPHERE", "origin": "CENTER",
                       "count": 40.0, "min_speed": 0.2, "max_speed": 0.8 } ] }
  ],
  "area_impact": {                        // 命中后的范围爆炸（可删）
    "radius": 3.0,
    "area": { "distance_dropoff": "SQUARED" },
    "particles": [ { "particle_id": "lava", "shape": "SPHERE", "origin": "CENTER",
                     "count": 50.0, "min_speed": 0.5, "max_speed": 2.0 } ]
  },
  "cost": { "exhaust": 0.0, "cooldown_duration": 3.0 }    // 冷却单位是秒
}
```

### ② 持续场型（雨滴/泥沼/黑雾/地面震动 —— "留在场上持续生效"）

把上面的 `release` 换成这段，其余照抄：

```jsonc
"release": {
  "target": {
    "type": "CLOUD",
    "cloud": {
      "volume": { "radius": 5.0, "area": { "distance_dropoff": "SQUARED" } },  // 范围
      "time_to_live_seconds": 15.0,        // 存在多久
      "impact_tick_interval": 20,          // ★ 每 20 tick 把 impact 重新施加一遍
      "delay_ticks": 5,
      "presence_sound": { "id": "weather.rain.above", "volume": 0.3 },
      "client_data": { "particles": [ { "particle_id": "falling_water", "shape": "SPHERE",
                                        "origin": "CENTER", "count": 12.0,
                                        "min_speed": 0.0, "max_speed": 0.2 } ] },
      "spawn": { "particles": [ /* 生成瞬间的粒子 */ ],
                 "sound": { "id": "entity.player.splash", "volume": 1.0 } }
    }
  }
}
```

### ③ 自身增益型（燃烧/风速/护盾/召唤标记）

```jsonc
"release": { "target": { "type": "SELF" } },
"impact": [
  { "action": { "type": "STATUS_EFFECT",
                "status_effect": {
                  "effect_id": "minecraft:absorption",   // ★ 原版效果优先，见第六节
                  "duration": 15.0,                      // 秒
                  "amplifier": 2,                        // 实际强度 = 基础 × (amplifier+1)
                  "apply_mode": "SET",
                  "show_particles": true } } }
]
```

> **一次施法可以挂多个效果** ✓ —— `impact` 是个数组，往里加就行（比如"速度 + 风伤"两个 ✓）。

## 三、写完怎么让游戏认它

1. 文件放到 **`modpack/元素觉醒1.4.3-魔改版-20260915/kubejs/data/tnc/spells/<id>.json`** ✓
2. `cd D:\ModTest\modpack` → `.\sync.cmd push`（同步到游戏）
3. 游戏里 **`/reload`**（数据包重载）—— **如果法术没生效，就退出世界重进**（数据包重载不一定包含法术注册表）
4. 让它能被你拿到：**`/tnc learn tnc:<id>`** ✓（直接塞进已学列表，不用先去目录里加条目）

> ⚠️ **目录（`SpellCatalog`）和法术 JSON 是两码事** ✓：
> `/tnc learn` 能学的是"目录里有的"✓；而 `/tnc learn` 之前我加过防呆闸门 ——
> **引擎里没有这个 JSON 就不会给学** ✓。所以顺序永远是：**先写 JSON → 再进目录** ✓。

## 四、测试循环（我实际用的）

```
① 改 JSON（或改 Java）
② 数据改动: /reload（或重进世界）      Java 改动: gradlew build → 关游戏 → install-to-pack.ps1 → 重启
③ 拿到法术: /tnc affinity set <元素> 6
            /tnc mana full
            /tnc learn tnc:<id>
④ 放它: 聊天栏/热键栏
⑤ 看结果:
   - 游戏里: 有没有飞出去、伤害数字、敌人身上的 buff 图标
   - 日志:   logs/latest.log 里搜 "TN-C"（我们的提示都在这一行）
   - 自检:   /tnc selftest（跑数值/门槛/NBT 的断言）
   - 装机:   tools\verify_mod_jar.ps1（检查 jar 里该有的类/资源/法术 id 在不在）
```

**最快的调试套路**（我这两小时一直这么干 ✓）：

| 症状 | 先看哪 |
|---|---|
| 法术放了没反应 | 日志有没有 `SPELL_CAST spell=tnc:xxx ours=true` ✓ → 有就是引擎收到了；**没有**说明法术没被引擎加载（JSON 路径/字段错）|
| 有 CAST 但没伤害 | `impact` 里的 `spell_power_coefficient` 是不是 0？目标类型对不对？ |
| 效果不生效（buff 图标不出现）| `effect_id` 拼写（`tnc:` 的还是 `minecraft:` 的？）—— **没注册的效果是静默失败** ✗ |
| 模型不显示/紫黑 | `model_id` 路径 vs 实际文件位置；贴图路径 |
| 细长模型看起来像方块 | **缺 `orientation`** → 加 `"orientation": "TOWARDS_MOTION"` ✓ |
| 完全没声音 | 音效 id 写错了（引擎只有 `spell_engine:generic_<学派>_casting/_release`，**风系只有 `generic_wind_charging`**）|

## 五、美术怎么改（每样放哪）

| 想要 | 尺寸 | 路径（在整合包 TN-C 资源包里）|
|---|---|---|
| **法术图标** | 16×16 | `assets/tnc/textures/spell/<法术id>.png` |
| **效果图标**（buff 栏那个）| 18×18 | `assets/tnc/textures/mob_effect/<效果id>.png` |
| **投射物模型** | JSON | `assets/tnc/models/projectile/<名字>.json` |
| **投射物贴图** | 16×16 | `assets/tnc/textures/projectile/<名字>.png` |
| **HUD 条**（魔力/磨砺条）| 168×26 | `assets/tnc/textures/gui/mana_bar/` `armor_bar/` |

改完 `sync.cmd push` + 重进世界（或按 F3+T 重载资源包）✓。

## 六、六个"写错就静默失效"的坑（必须检查）

| 坑 | 正确写法 |
|---|---|
| **学派名** | 雷 `LIGHTNING` / 火 `FIRE` / **风 `AIR`**（不是 WIND）/ 水 `WATER` / 土 `EARTH` / 光 `HEALING`（不是 LIGHT）/ **暗 `SOUL`**（不是 DARK）|
| **效果 id** | 我们的：`tnc:<效果名>`；原版的：`minecraft:<效果名>`。**没注册 = 静默无效** |
| **音效 id** | 只有 `spell_engine:generic_<学派>_casting/_release`；**风系只有 `generic_wind_charging`** |
| **模型朝向** | 细长模型必须 `"orientation": "TOWARDS_MOTION"`，否则"像火球" |
| **持续时间** | 单位是**秒**（不是 tick）—— `impact_tick_interval` 才是 tick |
| **冷却** | `cost.cooldown_duration` 单位也是**秒**，而且**不能为 0**（想"无冷却"得靠代码清 ✓，见风神降临）|

## 七、想加"全新机制"（引擎表达不了的）

比如"环绕球""飞行""燃血""无冷却"这类 —— 那要写 Java ✓：

1. **新效果**：仿 `TNWindMechanics` 里的 `WIND_EFFECTS.register(...)` ✓
   （用 `addAttributeModifier(属性, UUID字符串, 数值, MULTIPLY_BASE)` ✓）
2. **每 tick 的行为**：仿 `tickOrbs()` ✓（`@Mod.EventBusSubscriber` + `TickEvent.PlayerTickEvent` ✓）
3. **施法瞬间的行为**：仿 `TnSpellMechanics.onSpellCast(...)` ✓
4. **让法术发你的标记效果**：JSON 里加一条 `STATUS_EFFECT` 指向你的效果 ✓（参考 `wind_god` ✓）
5. **改完必须**：`gradlew build` → **关游戏** → `tools\install-to-pack.ps1` → 重启 ✓

**判据**：引擎自带的效果（`absorption/resistance/regeneration/blindness/slowness/speed/strength/wither/fire_resistance/levitation/glowing/night_vision/hunger/weakness` ✓）先用 ✓ ——
**只有"精确数值的自定义增益"**（风 +300%、火 +200%）才必须写效果类 ✓。

## 八、一次性生成器（批量做同结构的法术）

我这两小时加 108 个法术，靠的是**生成器脚本**而不是手写 ✓：

```powershell
# 例：tools\gen_tnc_water_spells.ps1
# 里面是一个表格（等级/速度/伤害/半径…）+ 一个模板函数，循环生成 JSON 并校验
powershell -ExecutionPolicy Bypass -File tools\gen_tnc_water_spells.ps1
```

⚠️ **`tools/*.ps1` 必须纯 ASCII** ✗ —— 中文注释会被 Windows PowerShell 按 GBK 读，
吞掉换行导致整个脚本解析失败（我踩过 4 次 ✗）。中文只写在 **JSON 的显示名**里（那是数据 ✓）。

**改生成器而不是改生成出来的 JSON** ✓ —— 手改下次重跑就被覆盖，而且容易改漏（我踩过 ✗）。
