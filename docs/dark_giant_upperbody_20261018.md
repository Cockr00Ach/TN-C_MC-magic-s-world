# 暗系巨兽人领主：肩、臂与手部重做

肩部、上臂、前臂、手腕已拆成连续关节链。每只手有独立拇指、四指及指尖关节，手指在释放黑夜之手时展开，以伤换伤收力时弯曲。肩甲挂在肩部节点，跟随肩胛的小幅活动；肘、腕带动手掌，避免旧版整条手臂绕肩旋转的僵硬感。

新模型共有 44 个骨骼，重做 56 个上肢部件。肩甲采用三层有间隙的叠甲，连接处是皮革与锁甲；前臂、腕甲、掌背、指节有对应的装甲分段。

站姿采用小幅外展、自然屈肘；走路按 2.2 秒周期交替摆臂，前臂和手腕有小幅跟随。重做黑夜之手、空中巨手、黑雾、以伤换伤、召唤军队五种施法动作，也适配原有三个动作名。大幅扭转躯干与手臂侧摆已收敛，肘部主要围绕单一轴屈伸。

动作从自然站姿进入并回到同一姿态，释放关键帧与原有 44 / 52 / 56 tick 施法时刻对齐。关键帧使用有边界的平滑过渡，避免 Catmull 插值过冲造成关节抖动。

贴图同步更新为 2048×2048，模型逻辑图集为 1024×1024。新增暗钢、银色磨边、旧金铆钉、皮革锁甲及紫色符文。每个新面分配独立 UV，并同步生成同尺寸发光遮罩。材质源图及基线保存在 `model-source/dark_giant_upperbody/`。

生成：`python tools/rebuild_dark_giant_upperbody.py`。
检查：`python tools/audit_dark_giant_upperbody.py`。

验证：12 项暗系巨人测试通过，含 GeckoLib 实际模型烘焙、斜切装甲、技能动作时长和新关节/图集检查。运动学检查验证骨骼无环、UV 有效、所有动作引用存在的骨骼、前向释放、头顶抬手及屈肘收回；两侧汲取动作的手掌前后收回距离约 13.52 模型单位。生成器重复执行得到逐字节一致的四项产物。
