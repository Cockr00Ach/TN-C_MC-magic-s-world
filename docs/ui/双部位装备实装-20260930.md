# 双部位装备实装与新世界测试

装备栏上方为「帽子」，下方为「全身」。全身身甲只占一格，穿戴模型包括上身、衣摆、腿部与靴面。行囊按钮移到人物预览上方，并随配方书展开后的面板位置调整。

共32件常规装备：四款身甲与四款帽子，每款有冒险者、精练、大师、传说四阶。另有归墟神袍、归墟星冠各一款，以及两件破损遗物。

常规ID末尾1/2/3/4对应四阶，例如 `tnc:astral_outfit_1`。右键天空岛铁匠铎恩，选择身甲或帽子、款式和阶级，页面会显示属性、材料、费用及制作时间。法杖仍由莉娅制作。

快速试穿：

```mcfunction
/give @s tnc:astral_outfit_1
/give @s tnc:astral_hat_1
/give @s tnc:bastion_outfit_4
/give @s tnc:divine_outfit_5
/give @s tnc:divine_hat_5
```

神装只预留物品和修复。具体遗迹、摆放和获取方式以后决定，本次不改任何遗迹。修复素材可用：

```mcfunction
/give @s tnc:broken_divine_robe
/give @s tnc:broken_divine_hat
```

神袍加防御、韧性、魔力、回魔与移速；星冠加魔力、回魔并降低施法耗蓝。两件合穿有普通致命伤保留1点生命并回复20%魔力的效果，冷却8分钟，虚空等绕过无敌的伤害不触发。
