## 三、血泪经验（都踩过，别再犯）

1. **`tools/*.ps1` 必须纯 ASCII** —— 中文注释被 Windows PowerShell 按 GBK 读，会吞掉换行导致整段脚本解析失败（已犯 4 次）✗
2. **先写引擎 JSON、再进目录** —— 反过来会"学得到但放不出"，法杖多一个空槽（用户实测到过）✗
3. **学派名要查**：风是 `AIR` 不是 `WIND`；暗是 `SOUL` 不是 `DARK`；光对应 `HEALING` ✗
4. **音效 id 要查**：只有 `spell_engine:generic_<school>_casting/release`，而**风系只有 `generic_wind_charging`** ✗
5. **原版效果优先**：`absorption/resistance/regeneration/blindness/speed/strength/wither` 能覆盖大部分辅助减益；只有"精确数值的自定义增益"（风 +300%、火 +200%）才必须写效果类 ✓
6. **结构化文件不要用正则大段改写**（把 verify 脚本改坏过一次）✓ 用 edit 工具逐处改
7. **`git add -A` 会吞大文件**：仓库守卫会拦（单文件 >2 MB），世界存档/整合包一律不进 git ✓
8. **`WinRAR.exe` 是图形版**，非交互会挂死；用 `UnRAR.exe` ✓
9. **别用文件名正则猜内容**（我因此把"水 15 个"错报成 14 个 ✗）—— 要解析 JSON ✓
10. **PowerShell 两个坑**：函数别叫 `R`/`T`（撞内置别名 `r`/`t`）；`for ($x in ...)` 不合法（要 `foreach`）✓
