## 三、每根骨头往哪转是什么效果（旋转约定 ✓）

正面是 **−Z** ✓，+Y 朝上 ✓。绕 **+X** 转的方向对"方块在 pivot 前面还是后面"是**相反**的 ✗
（天使那次栽过 ✓），所以这张表是**用预览工具试出来的** ✓（不是推的 ✓）：

| 部位 | 效果 |
|---|---|
| `neck1`/`2`/`3` | **+x = 抬头** ✓（−x = 低头）✓（方块在 pivot 前方 ⇒ 正号抬起 ✓） |
| `head` | **+x = 吻部上抬** ✓（−x = 低头咬下去 ✓） |
| `jaw` | **−x = 张嘴** ✓（+x 会把下颌顶进颅骨 ✗ —— 我第一版就是这么错的 ✓） |
| `tail1…5` | **−x = 尾尖上抬** ✓（+x = 下垂）；**z = 左右摆** ✓（一节 6°～16° 就很自然 ✓） |
| `tailFin` | z = 鳍面左右摆 ✓ |
| `wingL1…4` | **+z = 抬起、−z = 压下** ✓（左翅）；**−y = 往后扫** ✓ |
| `wingR1…4` | 和左翅**全部取反** ✓（z 正负、y 正负 ✓） |
| `legFL1`/`legFR1`（前大腿） | **−x = 往前迈** ✓，+x = 往后蹬 ✓ |
| `legFL2`/`legFR2`（前小腿） | **+x = 回折**（蹲 ✓） |
| `pawFL`/`pawFR` | −x = 脚掌前压 ✓（落地时补一点 ✓） |
| `legBL1`/`legBR1`（后大腿） | **+x = 往后蹬** ✓（−x = 往前收 ✓） |
| `legBL2`/`legBR2`（后小腿） | **−x = 回折** ✓（注意和前腿符号相反 ✗） |
| `body` | +x = 前倾 ✓（−x = 后仰）；**y = 转身** ✓；z = 侧倾 ✓ |
| `hips` | 同 body ✓（转身/侧倾一般给 hips，别给 body ✗ —— body 是它的父级 ✓） |

**一个能用的蹲姿**（见 `docs/dragon_pose_example.json` ✓）：前腿 FL1 −24 / FL2 +42 / paw −20 ✓、
后腿 BL1 +26 / BL2 −34 / paw +14 ✓、脖子 +22/+16/+10、头 −14、下颌 −40、翅膀 −48/∓18 ✓。

## 五、要改颜色 / 加细节

* **颜色**：`tools/gen_dragon_model.py` 顶部那 6 行调色板 ✓（`DORSAL` 背脊 / `DORSAL_HI` 鳞片高光 /
  `LIMB` 四肢 / `BELLY` 腹甲 / `MEMBRANE` 翼膜 / `BONE` 角牙 / `EYE` 眼睛 ✓）。
  想换火龙就把 DORSAL 改成炭黑、DORSAL_HI 改成橙红、MEMBRANE 改成暗红 ✓ —— 其它不用动 ✓。
* **加方块**：在 `left_bones()` 里 `B("骨骼名", "父骨骼", (pivot), [cube(中心x, y, z, 宽, 高, 深, "材质")])`
  里加一行就行 ✓ —— **不用手写 UV** ✓（贴图装箱是自动的 ✓，512 只用了 20% ✓）。
* **左右对称**：只写左边（名字里带大写 `L` ✓）⇒ 右边自动生成 ✓（x 取负 ✓）。
* **尺寸全在数字里** ✓：所有 cube 坐标都是 1/16 格 ✓，想整体缩小就在实体渲染器里 `poseStack.scale(...)` ✓。

## 六、要进游戏还差什么（说一声我就接）

现在只有**模型 + 贴图**（未注册实体 ✗）。要让它出现在世界里，还差：

1. **实体类**：`Monster implements GeoEntity` + 三段控制器（idle / fly / attack / roar ✓）；
2. **三处注册**：`TNOrbEntities`（或 boss 包 ✓）+ `TNNpcAttributes`（**漏了属性 = 生成即崩** ✗）+ 客户端渲染器 ✓；
3. **hitbox 与剔除**：这模型**长 12 格** ✗ ⇒ 碰撞箱要给大一点（约 3.5 × 3 格 ✓），
   而且**必须自己撑大** `getBoundingBoxForCulling()` ✗ —— 不然抬头只看它上半身时会整条消失 ✗
   （天使/雕像那两个都踩过这个坑 ✓）；
4. **动画**：`idle`（呼吸 + 尾巴轻摆 ✓）/ `fly`（扇翅 + 收腿 ✓）/ `roar`（抬头张嘴 + 展翅 ✓）/
   `attack`（咬 / 甩尾 ✓）/ `death` ✓ —— 生成器我可以照天使那套写 ✓（`tools/gen_*_animation.py` ✓）。
