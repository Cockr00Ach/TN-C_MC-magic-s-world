### 尺寸 / 约定

| 项 | 值 |
|---|---|
| 全长（吻 → 尾焰尖） | **约 23 格**（z −168 … +200 ✓）—— "长长的" ✓ |
| 体高 / 站高 | 身体直径 16 → 6 单位（前面的节粗、往后越细 ✓）；站高约 **2.6 格**，角尖约 4.5 格 |
| 朝向 | **正面 −Z** ✓（吻部/下颌/爪尖都在 −Z ✓）—— 和工程里其它模型一致 ✓ |
| 结构 | 12 节身体 **一节一根骨头** ✓（舞龙那种一节一节 ✓）＋ 5 节尾巴 ＋ 尾焰 ＋ 4 条腿 ＋ 龙头（角/须/鬃/下颌） |
| 旋转 | 骨头只带**极小的静态旋转**（颈抬头 14°/10°、身体的 S 形 ±2～4° ✓）；方块有少量旋转（角/须/鬃/尾焰 ✓） |
| 镜像 | 右半边**按 x 取负**自动生成 ✓（旋转取 y/z 反号 ✓）—— **没有 `mirror` 标记** ✗（那个会连贴图一起反，翅膀那次踩过 ✓） |

### 东方龙的特征（就是这几处让它不像西式 ✗）

1. **没有翅膀** ✓ —— 改成一条**背鳍**从脖子一直连到尾（每节一片 ✓）；
2. **身体又长又软** ✓ —— 12 节 + 5 节尾，每节一根骨头 ⇒ 能像舞龙那样一节一节地波动 ✓；
3. **节与节之间有金箍** ✓ —— 每节前端一圈金色（`belly` 材质 ✓），就是舞龙那种"一节一节"的观感 ✓；
4. **龙头**：鹿角（每边两节、带分叉 ✓）＋ 两根长须（每边两节 ✓）＋ 向后飘的鬃毛（6 撮 ✓）＋
   鼻角 ＋ 獠牙 ＋ 颌下胡 ＋ 大眼（在前角上，正面也看得见 ✓）＋ 金眉 ✓；
5. **四只短腿 + 爪** ✓、**火焰状的尾鳍** ✓。

## 二、骨骼表（44 根）

`pivot` 单位 = 1/16 格 ✓。

| 骨骼 | 父 | pivot | 方块 | 内容 |
|---|---|---|---|---|
| `root` | — | 0,0,0 | 0 | 整条龙的根（在身体最前面那节上 ✓） |
| `body1` … `body12` | 依次（body1 的父是 root ✓） | z = −96 起，每节 +16 | 各 4 | 每节 = 体节 + 背鳍 + 腹甲 + **金箍** ✓（直径 16→7 递减 ✓） |
| `tail1` … `tail5` | 依次（tail1 的父是 body12 ✓） | z = 96 起，每节 +16 | 各 4 | 尾节（更细 ✓ 直径 8→4 ✓） |
| `tailFin` | tail5 | 0,29,176 | 5 | 火焰尾（主焰 + 上下两片 + 两侧两片 ✓） |
| `neck1` | body1 | 0,34,−96 | 2 | 脖子第 1 节（静态 +14° 抬头 ✓） |
| `neck2` | neck1 | 0,42,−111 | 2 | 脖子第 2 节（+10° ✓） |
| `head` | neck2 | 0,50,−126 | 16 | 颅 + 眉脊 + 上吻 + 鼻梁 + 鼻角 + 双眼 + 金眉 + 双耳 + 头顶鬃 + 4 獠牙 |
| `jaw` | head | 0,47,−152 | 3 | 下颌 + 颌下胡（张嘴靠它 ✓） |
| `antlerL` / `antlerR` | head | ±6,60,−132 | 各 2 | 鹿角主杆 + 第一叉 |
| `antlerL2` / `antlerR2` | antlerL / R | ±11,72,−126 | 各 2 | 角的第二叉（往外 + 往回各一 ✓） |
| `whiskerL` / `whiskerR` | head | ±6,48,−156 | 各 1 | 长须第 1 节（斜着往外后 ✓） |
| `whiskerL2` / `whiskerR2` | whiskerL / R | ±24,49,−150 | 各 1 | 长须第 2 节（往上翘 ✓） |
| `mane` | neck1 | 0,40,−100 | 6 | 鬃毛 6 撮（向后飘 ✓） |
| `legFL1` / `FR1` | body2 | ±9,22,−72 | 各 1 | 前腿大腿（肩关节 ✓） |
| `legFL2` / `FR2` | legFL1 / FR1 | ±10,11,−72 | 各 1 | 前腿小腿（膝 ✓） |
| `pawFL` / `FR` | legFL2 / FR2 | ±10,2,−72 | 各 4 | 前爪 + 3 只爪尖 |
| `legBL1` / `BR1` | body9 | ±9,21,40 | 各 1 | 后腿大腿 |
| `legBL2` / `BR2` | legBL1 / BR1 | ±11,10,40 | 各 1 | 后腿小腿 |
| `pawBL` / `BR` | legBL2 / BR2 | ±11,2,40 | 各 4 | 后爪 + 3 只爪尖 |

**波动怎么摆**（这条龙最要紧的一件事 ✓）：`body1…body12` 每节给一个 **y 轴**旋转
（y = 转身 = **横向**摆 ✓），因为是父子链，角度会累加 ⇒ 一串小角度就是一条平滑的蛇形 ✓。
例：`+4 +4 +4 +2 +2 0 −2 −2 −2 −4 −4 −4` ⇒ 一个完整的 S，尾端回到 0 ✓
（`docs/dragon_pose_example.json` 里用的就是这组，幅度放大到了 ±6～14 ✓）。

## 三、每根骨头往哪转是什么效果

正面 = **−Z** ✓、+Y 朝上 ✓。绕 **+X** 的方向对"方块在 pivot 前／后"是**相反**的 ✗
（天使那次栽过 ✓），下表都是**在预览里试出来的** ✓：

| 部位 | 效果 |
|---|---|
| `neck1`/`neck2` | **+x = 抬头** ✓（方块在 pivot 前方 ⇒ 正号抬起 ✓） |
| `head` | **+x = 吻部上抬** ✓（−x = 低头咬 ✓） |
| `jaw` | **−x = 张嘴** ✓（+x 会把下颌顶进颅骨 ✗） |
| `body1…12` | **y = 横向摆**（蛇形波动就用它 ✓）；**x = 上下起伏**（飞的时候拱背 ✓）；z = 侧翻（少用 ✗） |
| `tail1…5` | y = 甩尾 ✓；**−x = 尾尖上抬** ✓（+x 下垂 ✓） |
| `tailFin` | z = 鳍面摆动 ✓ |
| `antlerL/R`、`antlerL2/R2` | 小幅转动即可（角基本是硬的 ✓）；镜像时右边取反 ✓ |
| `whiskerL/R`、`whiskerL2/R2` | y = 前后飘、z = 上下翘 ✓（右须取反 ✓） |
| `mane` | −x = 往后飘得更开 ✓；z = 左右晃 ✓ |
| `legFL1`/`FR1`（前大腿） | −x = 往前迈 ✓；`legFL2`/`FR2` **+x = 回折**（蹲 ✓） |
| `legBL1`/`BR1`（后大腿） | +x = 往后蹬 ✓；`legBL2`/`BR2` **−x = 回折** ✓（和前腿符号相反 ✗） |
| `pawFL`/`FR`、`pawBL`/`BR` | −x / +x 微调脚掌贴地 ✓ |

**一个能用的"舞龙"姿势**（见 `docs/dragon_pose_example.json` ✓）：身体 S 形 y 波 ±6～14、
脖子 +18/+12、头 −6、下颌 −24、鬃 −8、须 y∓12 + z±8、尾巴 y −6～−10 + x −4、
前腿 −18/+30/−12、后腿 +20/−26/+10 ✓。

## 五、改颜色 / 加细节

* **颜色**：`tools/gen_dragon_model.py` 顶部 7 行 ✓ —— `SCALE`（朱红）/ `SCALE_HI`（鳞片金边）/
  `SCALE2`（隔节的深色）/ `BELLY`（金色腹甲与金箍）/ `FIN`（背鳍·鬃·尾焰）/ `BONE`（角须牙爪）/ `EYE`（眼）。
  想换青龙：`SCALE` 改墨绿、`SCALE_HI` 改浅青、`BELLY` 改米白 ✓。
* **加方块**：`left_bones()` 里 `B("骨骼", "父", (pivot), [cube(中心x,y,z, 宽,高,深, "材质", rot=(x,y,z))])`
  加一行 ✓ —— **不用手写 UV** ✓（装箱自动 ✓，512 还空着 65% ✓）。
* **加骨骼**：就在同一个列表里加一行（父写在前面 ✓）；名字里带大写 `L` 的会自动生成右边那一半 ✓
  （pivot 与方块 x 取负、旋转 y/z 取反 ✓）。
* **要更长**：把 `sizes` 那个数组多写几节（比如 16 节）✓，或者把每节的进深 16 调大 ✓。

## 六、要进游戏还差什么（说一声我就接）

现在只有**模型 + 贴图**（还没注册实体 ✗）。要做成怪/boss 还差：

1. **实体类**：`Monster implements GeoEntity` ＋ 控制器（`idle` 呼吸起伏 / `fly` 蛇形波动 +
   背鳍抖动 / `roar` 抬头张嘴 / `attack` 咬 / `death` ✓）；
2. **三处注册**：实体类型 ＋ `TNNpcAttributes`（**漏了属性 = 生成即崩** ✗）＋ 客户端渲染器 ✓；
3. **hitbox 与剔除**：这模型**长 23 格** ✗ ⇒ 碰撞箱建议 2.5 × 2 格（只包住身体前段 ✓，
   整条龙都进碰撞箱的话会卡墙 ✗），并且**必须自己撑大** `getBoundingBoxForCulling()` ✗
   （不然抬头只看一段时会整条消失 —— 天使/雕像那两个都踩过 ✓）；
4. **动画**：`idle` / `fly`（12 节 y 波 + 尾巴 / 鳍 / 须同步 ✓）/ `roar` / `attack` / `death`
   —— 我可以照天使那套写成 `tools/gen_dragon_animation.py` ✓。
