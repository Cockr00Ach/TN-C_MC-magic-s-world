## 二、贴图：光明龙（`tools/retexture_dragon.py`）

改配色就改脚本顶部那 9 行 ✓：

| 材质 | 用在哪 | 颜色 |
|---|---|---|
| `SCALE` / `SCALE_HI` / `SCALE2` | 身体/脖子/尾巴的主节（隔节换深浅 ✓） | 珍珠白 + **金边** + 很淡的虹彩（`SHEEN` ✓） |
| `BELLY` | 腹甲 | 奶白 + 金色横缝 ✓ |
| `FIN` | 背鳍 / 鬃 / 尾焰 / 金眉 / 耳 | **亮金**，外缘渐白 ✓ |
| `BONE` | 鹿角 / 长须 / 獠牙 / 鼻角 | 白金 + 金色环纹 ✓ |
| `CLAW` | 爪 | 浅金 ✓ |
| `EYE` | 眼 | 白热核心 + 金虹膜 + 竖瞳 ✓ |
| `hoop` | 节与节之间的金箍 | 亮金 ✓ |

**每个方块归哪个材质**由 `classify()`（骨头名 + 形状 ✓）判断，规则和模型当初怎么建的一致 ✓：

| 判据 | 材质 |
|---|---|
| 骨头名 `antler*` / `whisker*` | bone |
| 骨头名 `mane` / `tailFin` | fin |
| `head` 里：`w==3` → 眼；`w==2` → 獠牙；`4×6×4` → 鼻角；`6×3` / `4×6×6` / 宽≥12 且高≤4 → 眉/耳/头顶鬃；其余 → 鳞 |
| `jaw`：大块 → 鳞，小块 → 鳍（颌下胡） |
| 身体/脖/尾：**z 很扁**（d≤4）→ 金箍；**x 很扁**（w≤2）→ 背鳍；**矮而宽**（h≤5）→ 腹甲；其余 → 主节（隔节 `SCALE`/`SCALE2` ✓） |

> ⚠️ 想更像"光"：以后实体渲染器如果用 `RenderType.entityTranslucentEmissive(...)`（光翼/天使那套 ✓），
> 贴图里这些**亮金和白热像素会真的发光** ✓ —— 现在这张贴图的亮度就是按那个前提配的 ✓。

## 三、动画：`dash` 向前冲刺（`tools/gen_dragon_animation.py`）

| 片段 | 时长 | 循环 | 用途 |
|---|---|---|---|
| **`dash`** | 1.00 s | ✓ | 向前冲刺：身体**向后传播的波** + 前压的冲刺姿态 ✓ |
| `idle` | 2.40 s | ✓ | 悬停：同样的波、幅度很小、头抬着 ✓（附赠 ✓ 实体总得有个待机 ✓） |

### 冲刺到底是怎么 k 的（东方龙的关键就这一条 ✓）

给第 i 节身体一个**正弦**：

```
y = A_i · sin(2π·t/T − i·Δ)        # y = 转身 = 横向摆动 ✓
A_i = 1.5 + 0.5·i                   # 越靠尾巴幅度越大 ⇒ 前段绷直、尾巴甩 ✓
Δ   = 0.62（每节相位差 ✓）
```

* 骨头是**父子链** ⇒ 一串小角度自己会累加成一整条平滑的波动 ✓（不用逐节算位置 ✓）；
* 相位差让波**朝尾巴方向走** ⇒ 看起来就是"身体在往后推水、往前冲" ✓
  （蛇游动的原理 ✓；反过来波朝头走就变成"倒退" ✗）；
* 尾巴再叠一层更大的摆动（幅度 9→17° ✓）和尾鳍张合（`scale` 1.0→1.08 ✓）。

### ★ 一个必须记住的坑：静态角度要**反着补** ✗

模型里脖子带了 **+14°/+10°** 的静态抬头、尾巴每节 **−2°**（微微上扬 ✓）——
所以 `dash` 里脖子写的是 **−8/−6**、尾巴写 **+1.6** ✓：**先抵消静态姿态**，
龙才会是"低头、平直往前冲" ✓。第一版我直接写正数，结果整条龙是**昂着头往上拱** ✗
（预览里一眼就看出来了 ✓ 所以定型前一定先看预览 ✓）。

### 其它姿态细节

* `body1` 额外 −3°（整体略低头 ✓）、身体 x 通道有小起伏（±0.9° ✓）；
* 头颈：前伸压平、下巴微张（`jaw` −7 −3·sin(2φ) ✓、会动 ✓）；
* 鬃毛 −22°（被风往后吹直 ✓）、长须 y ±9 / z ±7（拖在身后 ✓）、鹿角 −4°（被风压后 ✓）；
* 四条腿收在身下（前腿 +28/−40/+18、后腿 −24/+34/−14 ✓，各带 ±2° 抖动 ✓）。

**要调节奏/幅度**：脚本里 `period`（1.0 s ✓）、`A_i`（`1.5 + 0.5*idx` ✓）、
`delta`（0.62 ✓）、尾巴幅度（`9.0 + 1.6*j` ✓）四个数就够了 ✓。

## 四、预览

```bash
G=src/main/resources/assets/tnc/geo/entity/dragon.geo.json
A=src/main/resources/assets/tnc/animations/entity/dragon.animation.json

# 静态四视图（自动取景 + 自动按 box-UV 采贴图真实颜色 ✓）
python tools/preview_geo_anim.py $G - bind --times=0 --views=face34,side,top,face \
    --fit --size=520 --front=-Z --out=docs/previews/dragon_model.png

# 骨骼图（黄点 = pivot ✓ 青线 = 父子链 ✓）
python tools/preview_geo_anim.py $G - bind --times=0 --views=side,face34 \
    --bones --fit --size=680 --front=-Z --out=docs/previews/dragon_bones.png

# 冲刺的波（顶视最能看出波在往后走 ✓；侧视看姿态 ✓）
python tools/preview_geo_anim.py $G $A dash --times=0,0.2,0.4,0.6,0.8 --views=top \
    --fit --size=470 --front=-Z --out=docs/previews/dragon_dash.png
python tools/preview_geo_anim.py $G $A dash --times=0,0.5 --views=side \
    --fit --size=760 --front=-Z --out=docs/previews/dragon_dash_side.png
```

> `--front=-Z` 不能省 ✗（这条龙正面朝 −Z ✓）；`--fit` 也不能省 ✗（23 格长，不自动取景会出画）。
> `face` / `face34` 就是"站在龙头正前方/前方 3/4"的视角 ✓。

预览文件：`dragon_model.png`（四视图）/ `dragon_detail.png`（大图）/ `dragon_bones.png`（骨骼）/

## 五、要进游戏还差什么（说一声我就接）

1. **实体类**：`Monster implements GeoEntity` + 控制器（`idle` ✓ / `dash` 移动时 ✓ /
   以后再加 `roar`、`attack` ✓）；
2. **三处注册**：实体类型 + `TNNpcAttributes`（**漏了属性 = 生成即崩** ✗）+ 客户端渲染器 ✓；
3. **hitbox 与剔除**：23 格长 ⇒ 碰撞箱建议 2.5 × 2 格（只包身体前段 ✓），
   且**必须自己撑大** `getBoundingBoxForCulling()` ✗（不然抬头只看一段时整条会消失 ——
   天使/雕像那两个都踩过 ✓）；
4. **发光**：想让它"真的在发光"就用 `RenderType.entityTranslucentEmissive(texture)`
   （光翼/天使那套 ✓），贴图现在就是按这个前提配的亮度 ✓。
