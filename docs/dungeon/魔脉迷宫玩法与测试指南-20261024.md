# 魔脉迷宫：双视界探险

这份说明对应本轮代码。安装、测试结果以文末验收记录为准。入口仍是主世界的四座野外大门，跨入传送区进入独立地下城维度；每个主题30层，每5层为一个保存进度的挑战段。

## 基本流程

进入大门 → 入口大厅备战 → 选择已解锁的1／6／11／16／21／26层 → 探索随机连接的房间 → 每5层击败守关者并保存。单人每段一次倒地自救；多人可反复倒地，只能由队友救起，全员倒地才失败。失败保留装备与背包，损失本段尚未结算遗币的20%。

战斗房全队集合后封门，清场开门。机关奇遇允许先离开，回来继续；缺药或缺镜子不会卡死整层。完成机关才获得奖励与FTB任务进度。背包满时机关奖励保存在地下城邮件中，腾出格子后自动补发。

F8逐玩家切换，队友的视界不会改变你的相位桥碰撞。普通视界辨认建筑和实体，魔力视界寻找危险、供能路径、机关目标。强光闪灵会惩罚一直盯着它的魔力视玩家，因此观察后需要适时关闭F8。

## 战斗房与四种生态魔物

母巢与供魔灵石真实存在于房内。F8可见灵石到母巢的供能动脉。用武器左击灵石，或火／冰魔法命中灵石，可以断流：停止后续母巢出怪，并把该房关联魔物的移速和攻击减半。向灵石使用古怪废液会让魔物以低生命、无护甲状态出场；狂躁透支药水会引发短暂过载，随后产生不破坏建筑的爆发。

| 魔物 | 识别与应对 | 带回家的用途 |
|---|---|---|
| 拟态魔晶蟹 | 普通视界像宝匣，F8看见红色核心；废液可瓦解外壳，也能正常击败 | 可在低血量时尝试缩水捕捉 |
| 噬魔幽浮 | 隐身、吸附玩家并汲取法力；F8才能可靠击中，往脚下泼火系魔药可驱离 | 捕捉遵循同一窗口与笼子规则 |
| 强光闪灵 | 暗紫石像鬼；F8直视其胸核会致盲5秒，转开目光或用立柱挡住视线 | 作为危险的魔物生产与收集对象 |
| 源晶吞噬虫 | 笨重液态腹囊，攻击弱；直接杀死会爆发且没有正常战利品 | 血量降至25%以下，缩水魔药打开10秒窗口，再用空拘束笼捕捉；拘束罩每次有效采集48M星界魔力 |

捕获的是服务器记录的同一只动物，复制笼子的物品NBT不能复制活体电池。圈养后清除地下城供能与临时缩小状态。

## 怪物美术与可编辑源文件

28种常规魔物按10个家族重做独立轮廓：哥布林尖耳、长鼻与獠牙；兽人宽肩、重甲和巨刃；骷髅肋骨、头骨与分职装备；触手怪八条分节触腕与吸盘；蜥蜴长吻背棘；蜥蜴人长枪与鳍冠；蛤蟆后肢及背疣；恶魔角、翼骨与尾；史莱姆液核及属性器官；宝箱怪开合箱盖、舌头与齿列。

Blockbench源文件在 `model-source/dungeon/*.bbmodel`，每只附嵌入贴图。游戏Java模型在 `assets/tnc/dungeon_models/`，纹理在 `assets/tnc/textures/entity/dungeon/`。4种生态魔物另有独立骨架与渲染，不覆盖队友制作的其他地下城实体。

## 测试入口与验收

管理员可用 `/dungeon enter desert`、`crypt`、`tide`、`astral` 进入对应大厅。普通玩家可用 `/dungeon` 查看说明，`/dungeon leave` 清场后撤离；重连确认用 `/dungeon resume`。自然大门位置可用 `/dungeon locate <主题>` 寻找。

新FTB页为《魔脉迷宫·双视界探险》，只新增这一章。23种机关任务由服务器在真正解开机关时授予对应进度。
