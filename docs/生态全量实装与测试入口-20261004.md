# 魔法生态、异兽牧养与工坊：本轮实装说明

2026-10-04 已安装到实际 PCL 实例。此页记录可运行内容；2026-10-03 的“只有9株和1只羊”记录是旧版本快照。

## 从哪里开始测试

打开原来的「元素觉醒1.4.3-魔改版-20260915」。按 E，从原生 FTB 任务书进入「休闲分类」，新增三页：**花园与魔法植物、异兽牧养与伙伴、魔导工坊**，共62个说明与收集节点。原「远行与耕作」保留27个节点、布局、任务标识和进度身份，更新了9处相关说明。新页不把农业、养殖设为强制剧情门槛。

想一次拿齐测试用品，在允许指令的测试世界切换创造模式，然后按需输入：

```mcfunction
/function tnc:ecology_plant_kit
/function tnc:ecology_animal_kit
/function tnc:ecology_workshop_kit
```

每包分别提供29种种源、24种动物测试蛋及牧养工具、工坊部件及试用产物。建议留出背包空间并分次领取；不清空玩家背包。函数只给创造模式玩家物品，不会自动运行、施工、催熟或发放生存奖励。

植物在普通野外就能栽培。自购天空岛田地也能种，公共镇区及别人的产权区域遵循保护。普通植物空手右键取产，留根继续长；瓶装产物要手持对应数量的真实空瓶。空手右键尚未可收获的植株可看到当前状态和缺少的条件。剪刀或植株采样夹可在对应自然环境研究种源；首次十次有效采样保底，旧地图不需要重铺。

动物先用刷怪蛋看形体，**手持牧养册右键动物**查看喜食、年龄、储量和用途。用喜食食物照料三次，每次有效照料间隔60秒建立主人；牧务杖选动物后点自己的标记、托盘或工作地块。正常生存通过相应群系寻找野生个体，刷怪蛋不作为收集任务要求。幼体至少两游戏日长大，不用睡觉跳时无限催熟。

## 可以围绕什么生活

不是把每种作物收一遍就结束。可以选择以下相互连接的经营路线：

- **花园与远行**：发现种源、布置不同生境，收获星露果和远照果备战；保留种子扩培，用防雨种匣带出门，调查页保留地点、署名与纹样。稀有植物的黎明、睡醒、授粉、花灵回归要真正发生。
- **牧场与料理**：肉食异兽提供六种专属肉材与副产物，做六种不同效果的料理；留养动物供卵、角、胶、羽、鳞等。可以把收获留作自己的旅行物资，或卖给商行、交酒馆订单。
- **魔力与工坊**：成熟翠脉枝可见且实际供魔，成年凝露浮鲸蓄魔；瓶装魔力用于自己补魔、向炉/发电座注入、魔瓶座脉冲供能。鸣线蜥以真实电量参与工艺。资源不能同时被领取和输送两次。
- **伙伴与有限自动化**：负兽和邮鹭搬运实际货物；筑狸修补已登记围栏缺口并消耗材料；犀开垦主人批准的田地；夜蛾访花助长，枕光貂耗魔跟随照明。没有替玩家无限生资源的全自动牧场。
- **经营与归属**：商行现有60项农畜收购品，新增32项原创农产及动物产物；酒馆委托栏增加28项料理/供货需求。赚钱沿用现有银行、工资、买房和家具消费。花礼、早餐、茶也接入居民礼物数据。

## 工坊与魔力电

锻炉仍是**3×3×3占位，其中26个部件和一格空炉膛**。测试包给了搭建札记；先按三层图搭，不是九格小炉。

- 炉芯界面：四输入、一输出、一升级槽；完整结构、材料与魔力满足才加工。保留注魔、烧制、完成特效。
- 余热椒油十次成功作业、冷凝壳二十次成功作业，工作快20%；暂停不扣次数，拆卸保留余量。
- 发电座、导线、蓄能匣、工作灯、魔导纸机沿用实际扣魔/扣FE与同主人网络。电不能逆变成无限魔力。
- 工作灯聚光片把实际光12升15；节能晶芯按十分钟有效亮灯寿命，把每四刻1FE改为每八刻1FE；均可拆卸并存余量。
- 魔瓶座每次红石上升沿向邻接同主人设备供最多5魔力。节律继电器按所选音高响应真实声音，输出十刻红石，五秒冷却；可以驱动魔瓶座。
- 登山绳12格，天幕长绳24格，放出真实可攀爬绳段；按保存身份回收，玩家后来替换的方块不删除。

已通过：**217/217服务端GameTests、109/109单元测试、生产构建和成品校验**。真实开发客户端也完成资源加载：23个新增动物渲染器、155个相关物品模型、608个植物状态模型，无缺失项。成品1247个TN-C JSON均解析成功，三个测试函数已在游戏服务器实际加载。
