# 灯下委托、家庭时光、魔焰药学与远征备战

这版把接委托、准备补给、地下城冒险、回家团聚连成了一条实际可玩的生活循环。沿用 TN-C 深色旧铜星仪界面，新增自己的委托页面和魔焰药学；家庭关系仍由真实的凡家物语 MCA 管理。

## 先这样测试一圈

1. 进入世界后出现人物档案：实际玩家模型、攻击、生命、护甲、速度、法力和七系亲和。输入名字。之后可用 `/character` 重开。
2. 找艾琳登记冒险者，在酒馆委托栏点一张纸接取。击杀目标或通过指定地下城楼层，进度自动记录；回到栏前领奖。无需把纸拿到背包。
3. JEI 搜索“魔焰炼药釜”“焰蕊盐”，制作并摆放釜体。放三种配方材料、玻璃瓶、焰蕊盐，再点火。先试“凝泉饮”。
4. 进入野外地下城大门，到入口大厅选一个五层段。先打开远征备战，把杂物暂存，把常用药放进四格携行栏。全员确认后，由队长再次选择同一段启程。
5. 关掉容器界面后按默认 `H` 饮用第一种可用携行药。也可以拿在手中正常饮用。
6. 宝藏房中使用原来的魔力视按键，默认 `F8`，找回声隐匣；喝回声显影剂可扩大隐匣显现距离。
7. 已经真正结婚的玩家，回到与伴侣一起居住的地方。潜行右键伴侣或 `/family` 打开家庭页，带两份同种食物试共餐。普通右键仍是 MCA 原有互动。

管理员快速取测试物品：

```mcfunction
/give @s tnc:spellflame_cauldron
/give @s tnc:ember_blossom_salt 16
/give @s tnc:elixir_spring 8
/give @s tnc:elixir_bloom 8
/give @s tnc:elixir_echo 8
```

## 委托栏

同一时间最多接三份。所有操作在酒馆真实委托栏附近办理；进度跟随玩家保存在世界账本中，死亡不会把接单记录丢掉。每份交付后按现实时间冷却三十分钟。钱进入现有冒险者钱袋，经验和声望进入原有成长系统，原有 FTB 委托里程碑继续累计。

## 魔焰炼药釜

合成：两个铜锭、三个铁锭、一个原版炼药锅。摆法在 JEI 可查。

```text
铜  空  铜
铁  锅  铁
空  铁  空
```

焰蕊盐：暖椒 + 木炭 + 荧石粉，无序合成四份。每份提供 1200 游戏刻、即正常速度六十秒的实际炼制燃时；停工不白烧。炼制不要求接入魔力科技。

釜界面左边四格是材料区，现有每个配方只需要三种材料，各一份，顺序无关。另一格留空；不能额外塞第四种材料。右侧放空玻璃瓶和取成品，下方放焰蕊盐。界面右边可浏览全部配方及用途。

点火有三种方式：

- 燧石或火焰弹右键釜体，产生普通火。
- 学会任意火系法术后，点界面的点火按钮，花五点个人法力产生魔焰。
- 用已接入的 TN-C 火系火弹命中釜体附近，产生魔焰。

普通火炼制用时为魔焰的 1.5 倍。点火不会在附近方块上引起火灾。工作时有与药液颜色对应的发光药液、旋转环、悬浮材料、向釜心汇入的光粒与焰火；完成有收束光粒和声音。

邻接自己有使用权限的 TN-C 魔力装置时，每秒可抽取一点真实魔力，额外推进十刻炼制。这是可选的借热辅助；没有网络、供能中断时，仍按植物药焰工作。

拆釜会掉落携带库存、燃时和进度的釜，重新放下继续；重新放置产生的新方块不会继续授权旧容器界面。产物满格时暂停，不吞材料或燃料。奶桶、蜂蜜瓶等材料保留正常容器返还。

## 远征备战与魔力视隐匣

备战在地下城入口大厅进行。二十七格私人暂存长期保存在世界数据中，跨重登保留，不是临时删除背包。收纳按钮只搬主背包，快捷栏、穿戴和副手保留；也能逐格挑选带什么。暂存内容不带进战斗，需回大厅取用。

四格携行栏只接收魔药，按从左到右取第一种可用药。默认 H，可在控制设置修改。容器界面打开时不允许快捷饮药，避免两份库存状态互相覆盖。快捷饮药和普通饮药使用同一个冷却，空瓶正常返还。

所有队员需要到齐、选择同一段并确认。改变段数、改动准备物品、队伍变化、离开大厅或重登都会使旧确认失效。生成完成时再次检查退出状态；有人已经离开则取消本次启程，不把退出者强拉回去。

每层一个既有宝藏房中设置一只回声隐匣。普通视觉下不显示模型和选择框，开启魔力视才出现旋转显影。基础显现距离二十四格，显影剂提高到五十二格。仍需实际靠近并清场后右键领取。

每位玩家每只隐匣只能领一次，奖励为两份主题材料和一瓶凝泉饮；满背包保留领取资格。它是本轮魔力视的新用途。Boss 隐身追踪、黑暗元素搜寻和墙面符文尚未实装，后续可接到同一显影入口。

## 家庭怎样与冒险关联

取消 MCA 默认开局命运房间、角色/地形选择和村庄传送，换成 TN-C 人物命名页。姓名同步到玩家显示名及 MCA 家谱记录。实际能力仍取已有系统，不额外随机送属性。

送礼、好感、求婚、婚姻、生育继续使用 MCA。必须是真实已婚关系；订婚不算结婚。普通右键仍打开原版 MCA 互动，潜行右键伴侣才打开 TN-C 家庭时光。

| 实际事件 | 新反应 |
|---|---|
| 接取委托后遇见伴侣 | 武运昌隆、一路平安、记得带药等随机台词 |
| 完成委托后一起回家 | 询问任务、关心疲劳、邀请吃饭 |
| 外出连续二十四千游戏刻后回家 | 想念、留灯等重聚台词 |
| 真正死亡重生，或地下城团灭返回 | 询问伤痛、劝休息；倒地但获救不会冒充死亡 |
| 家中有真实加载、存活且在附近的家谱孩子 | 出现孩子相关的归家和共餐台词 |

台词在聊天和短暂的小型黑底白字浮层显示，至少间隔三十秒。归家识别使用已买且交付的住房，或伴侣实际 MCA 住处；需要玩家和伴侣在住处附近。每次回家都会结束当前离家计时，许多短途出门不会累加成“好久没回来”。此时间随世界运行计算，离线没有缺席惩罚。

家庭页“把这里当作家”调用现有住房与 MCA 迁居逻辑，需要有可交付的自有房屋。共餐需要两份相同、饱食度至少四的食物，可以分在不同格，如两碗蘑菇煲。餐具返还；玩家补饱食并获得十秒再生，伴侣恢复四生命。每二十四千游戏刻可共餐一次。没有强制回家、扣好感或挨饿惩罚。

## FTB、可修改入口与队友更新

任务书仅新增 `tnc_alchemy.snbt`，标题“魔焰药典”，生活与魔导分组下，共二十二个节点。顶部原创药釜插画，下接燃料、药釜、四条各四种魔药的路线，以及借热、备战、回家。每种药写明投入物、用途和炼制时间。旧页、玩家写的剧情和布局均不重新生成。

源文件：

- 委托定义：`src/main/resources/data/tnc/commissions/*.json`。数据包可覆盖或增加同结构文件，用 `/reload` 重载。
- 魔药配方与效果：`src/main/java/com/tnc/tnc/alchemy/Elixir.java`、`ElixirItem.java`，当前为 Java 枚举，修改需重建 JAR。
- 燃料、釜合成：`src/main/resources/data/tnc/recipes/`。
- 模型、图标：`src/main/resources/assets/tnc/models/`、`textures/`；本轮药瓶有五种瓶形和不同装饰，不是统一换色。
- 家庭台词、时机：`src/main/java/com/tnc/tnc/journey/FamilyLife.java`。
- FTB 页：`questbook/ftbquests/chapters/tnc_alchemy.snbt`。运行包对应 `config/ftbquests/quests/chapters/tnc_alchemy.snbt`。
- 新物品及任务资源生成器：`tools/build_life_expedition_assets.py`。它只生成本轮新增章节，编辑此页后不要无意重新运行覆盖它。

委托数据格式示例：

```json
{
  "title": "路灯下的脚步",
  "story": "清理路边6只僵尸，让晚归的人安心。",
  "kind": "kill",
  "target": "minecraft:zombie",
  "count": 6,
  "level": 1,
  "coins": 75,
  "xp": 80,
  "cooldown_seconds": 1800
}
```

`kind` 目前支持 `kill` 与 `floor`。击杀目标填写真实实体注册 ID；楼层目标为 `desert`、`crypt`、`tide`、`astral` 或通配 `*`。新增怪物先注册实体，再引用其 ID。不是任意文本事件都已实现。

本轮队友补丁是 `work/life-expedition-update-20261020.zip`，包含自制 TN-C JAR、唯一新增 FTB 页、清单与安装脚本，不新增第三方模组。解压后关闭游戏，在 PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\apply_life_expedition_update.ps1 -Pack '自己的版本文件夹'
```

脚本校验哈希、备份原 JAR 和完整任务书，只追加新页；MCA 配置仅合并关闭开局命运界面和传送的两个选项。直接使用旧的队友通用补丁生成器不会自动带上本轮新页，请使用此专用包。只 pull 仓库可看到源码和新页，运行游戏还需同步编译的 TN-C JAR，或使用已经更新好的完整版本压缩包。

安装与验证记录在 `release/life-expedition-install-20261020.json` 和 `release/life-expedition-validation-20261020.json`。只使用独立测试世界验证，不修改现有存档、天空岛模板及装修。

最终版同时合并了队友的土系竞技场保护与接近触发、石枪骑士美术、风将模型以及两阶段火山巨龟；不会用本轮旧构建覆盖这些协作成果。最终 JAR 和队友更新包统一以安装记录中的 SHA-256 为准。

插画为本轮 ImageGen 原创生成：深色旧铜魔法药釜、蓝绿色药液、植物与星仪，未使用其他整合包美术。发布资源为 `assets/tnc/textures/guide/alchemy_banner.png`；药瓶、燃料与方块纹理由本仓库生成器绘制，三维模型和动画由本仓库代码实现。
