# 玩家风球与风元素兵器

接入现有风球／风灵召唤链，沿用施法入口、档位、持续时间和伤害倍率。

* T1：三个聚风核心，每个核心有四片实体风刃环绕。
* T2：五个聚风核心，每个核心有六片风刃环绕。
* T3：风灵携带风剑，发射风剑攻击。
* T4：三只风灵携带风剑和风枪，发射风枪攻击。
* T5：五只风灵携带风剑、风枪、环刃，轮换发射三种兵器。

模型使用薄荷青、白色棱边、浅蓝半透明风体与发光晶核。聚风核心外层有不同倾角的旋转气环，以及向内收束的气环。兵器沿发射方向自转，不改变飞行朝向。环绕刃片与护卫兵器只复用烘焙模型，不生成额外实体。

风球攻击时对附近可见敌人施加轻微的三维牵引，指向风球中心。攻击伤害由实际飞行兵器命中承担；发射时不另加一次瞬间伤害。投射物做扫掠碰撞检查，遇墙停止，32 tick 后自动消失，施法者消失后清理；每个施法者最多同时存在 16 个投射物。沿用原来的玩家排除规则。

发布采用当前安装包作为基底，只替换本次涉及的风球／风灵类和六个新模型，逐项证明其他 JAR 条目字节不变。测试与开发预览类不装入游戏包。

六个模型均已在真实客户端完成烘焙渲染检查，无缺失模型或贴图。实际预览见 [模型截图](previews/wind_arsenal_actual_20261018.png)。环绕动作使用插值时间；长存档的旋转角先取模再转换为浮点数，避免大角度损失精度。

验证：247 项单元测试通过；4 项风系游戏内测试覆盖实际命中、墙体阻挡、三维牵引、每玩家 16 个投射物的上限、消失清理，以及五档模型选择和攻击姿态同步。相邻游戏测试的墙体曾干扰射线夹具，已将数量测试移至独立高度。

完整游戏内测试 302 项中通过 301 项；唯一失败项是已有的植物生长夹具 `nightgourdavoidsdaylightandgrowsinshadeandreedrequireswetshore`，与本次风系改动无关。独立模型预览不代表完整整合包的帧率实测。
