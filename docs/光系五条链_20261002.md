## 二、飞行怎么并进光耀的

| 项 | 现在的行为 |
|---|---|
| 判据 | 身上有**光耀链任一档 buff**（`light_radiance`/`light_holy`/`light_divine`/`light_descent`/`light_mercy` ✓）⇒ 可飞 ✓（`graceBuffed` 直接照 SPELLS 表查 ✓） |
| 飞行时长 | = 该档 buff 时长：**t1 12s / t2 14s / t3 16s / t4 18s / t5 20s** ✓ |
| 谁给 | ① 释放那一刻立刻给（`grantGraceFlight` ✓，**队友也一起给** ✓ 范围法术 ✓）；② 每 tick 由 `tickGraceFlight` 续/收 ✓（走 `TnSpellMechanics.tickPlayer` + `TNLightWingsEvents` 两条已证活着的路 ✓） |
| 翅膀 | 同一时刻点亮 `LIGHT_WINGS` 标记 ⇒ 客户端照旧画那对光翼 ✓ |
| 创造/旁观 | 不动 ✓（收回飞行时跳过 ✓） |

> ⚠️ 老存档里如果玩家身上还挂着 `tnc:light_flight` 等已删除的 buff：原版会**直接忽略未知效果** ✓
> 不会崩 ✓（学过的旧法术 id 会留在 `learned` 里，但法杖是按目录装配的 ⇒ 不会出现 ✓）。

## 三、新增的第五条链「光龙」（`LIGHT_DRAGON`）

主角是那条**东方光明龙**（作者手改的 `dragon.geo.json` ✓ 23 格长 / 41 骨骼 ✓、
贴图 `dragon_bedrock.png`（光明龙配色 ✓）、动画 `dragon.animation.json` 的 `dash` ✓）。

> ★ 作者同日第二版：**"不要做成召唤物啊，我要释放出一条巨龙往前冲，触碰造成伤害"** ✓
> ⇒ 龙**不是宠物** ✗：放出去就**直线往前冲**，路上碰到谁伤谁，撞墙/到点爆开消失 ✓
> ★ 第三版：**"我要的龙不是怪，你把他怪给我删了，我要的是跟雷球一样，扔出去，一条龙冲出去"** ✓
> ⇒ 龙**也不是怪** ✗ —— 它是和**雷球（`TNThunderOrbEntity`）同一类**的**投射物实体** ✓：
> `extends Entity` ✗（不是 `Monster`/`Mob` ✗）、`MobCategory.MISC` ✓、**不注册属性** ✓、
> 没有任何 AI/goal/寻路 ✓、打不到推不动 ✓；`TNNpcAttributes` 里**故意没有它** ✓。

| 档 | 法术 | 名字 | 做什么 | 冷却 |
|---|---|---|---|---|
| t1 | `light_dragon_breath` | 光龙吐息 | 向前一道**粗金白光柱**（复用光线链的实体光柱，尺寸 ×1.8 ✓ 会自己索敌）+ 龙吟 | 30 |
| t2 | `light_dragon_scales` | 光龙鳞甲 | 自己 + 10 格内队友：**减伤 50% / 速度 +20% / 光伤 +30%**，20 秒 | 60 |
| t3 | `summon_light_dragon` | **光龙出击** | 放 **1 条**（0.30 倍 = **6.9 格长**）往前冲 **≈45 格**，撞到 **24 伤** | 90 |
| t4 | `light_dragon_dive` | 光龙俯冲 | **2 条**（0.90 倍 = **20.7 格长** · 左右各偏 7°）冲 **≈60 格**，撞到 **34 伤** + 小圣光 | 130 |
| t5 | `light_dragon_descend` | 光龙降世 | **3 条**（3.00 倍 = **69 格长** · 扇形 ∓16°）冲 **≈75 格**，撞到 **44 伤** + 大圣光天降 | 180 |

> ★ 个头倍率是作者 2026-10-02 定的：**t3 = 1 倍 / t4 = 3 倍 / t5 = 10 倍** ✓
> （以 t3 的 0.30 为 1 倍 ⇒ 0.30 / 0.90 / **3.00** ✓，模型原长 23 格 ⇒ 6.9 / 20.7 / **69 格** ✓）。
> **比例图**：`docs/previews/dragon_scale.png` ✓ —— 三档同一个视角，画面里那个**蓝色方块是玩家大小**
> （1.8 格高 ✓）：t3 里它差不多有半条龙长，t5 里它只剩一小条 ✓ 一眼就能看出 69 格有多夸张 ✓。

**数值只有一处** ✓：`light/TNLightDragonChain` 的 `DRAGONS` 表（一行一档：条数 / **个头倍率** / 撞伤 /
速度 / 飞多久 / 扇形角 ✓）＋ 脚本 `tools/gen_light_dragon_spells.py`（冷却/蓄力/粒子 ✓）。
飞行距离 = `speed × ticks`（1.45×62 / 1.65×74 / 1.85×84 ✓）。

### 龙的行为（`light/TNDragonEntity`）—— 一颗"龙形的投射物" ✓（和雷球一个写法）

* **基类是 `Entity`** ✓（**不是生物** ✗）：位置**自己每 tick 算**（直接 `setPos` ✓，雷球就是这么写的 ✓），
  不受重力、不受方块碰撞 ✓；客户端只负责画（GeckoLib 模型 + `dash` 动画 ✓）；
* **放出来就往前冲** ✓：方向 = 准星方向（多条按扇形散开 ✓），位置 = 施法者正前方
  **8 格 ＋ 体长的 1/4** ✓（t5 就是 25 格外 ✓ —— 不然 69 格的龙会把自己和玩家一起包进去 ✗）；
  多条时**横向也按体长错开** ✓（不然两条 21 格的龙完全重叠 ✗）；朝向每 tick 对齐飞行方向 ✓；
* **碰到就伤** ✓：每 tick 用一条**按体长给的判定盒**扫一遍 ⇒ 7 / 21 / **69 格长**的龙身扫过去 ✓，
  每个敌人**整次冲刺只挨一下** ✓（命中有击退 + 金光爆开 ✓），伤害记在施法者头上 ✓；
  ★ 69 格的盒子太宽 ✗ ⇒ 大龙（个头 ≥ 1.0）**隔 tick 扫一次** ✓（它每 tick 才走 1.85 格，漏不掉谁 ✓）；
* **撞墙/到点就散** ✓：判的是**龙头**的位置（原点前方约 10.5×个头 格 ✓）——
  所以是"头撞到山就炸"✓，而不是身体中心撞到 ✓；飞满时长也自己爆开 ✓；
* **不是怪** ✓：打不到它（`isPickable`/`isAttackable` 都 false ✓）、推不动 ✓、没有 AI ✓、
  不参与刷怪/驯服/刷怪蛋那一套 ✓、属性表里也没有它 ✓；
* **只打敌对生物** ✓：不打玩家（含施法者）、不打天使/别的龙、不打阿波罗 ✓。

`/summon tnc:light_dragon` 出来的那条没有参数 ⇒ 会沿它自己的朝向按默认值冲一段 ✓
（不然原地不动，看着像坏了 ✗）。

### 尺寸相关的两个坑（已在代码里处理 ✓）

* **碰撞箱只给身体那一段**（2.5 × 2 格 ✓）—— 69 格全进碰撞箱会卡墙 ✗；
* **剔除盒按体长自己撑**（`getBoundingBoxForCulling` ✓）—— 不然抬头只看一段时整条龙会突然消失 ✗
  （天使/雕像都踩过 ✓）；渲染缩放由法术写进实体 ✓（t3 0.30 / t4 0.90 / t5 3.00 ✓）。
