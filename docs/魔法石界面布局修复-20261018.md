# 魔法石界面布局修复 · 2026-10-18

用户截图中的问题来自两处：页签按钮与点数文字占用了同一行；1254px 装饰外框的顶部被整个横向拉伸，圆形星仪因此变扁。另有部分法术使用 32px 贴图，旧绘制参数只取到了左上四分之一。

本次调整：

- 魔力、点数、页签、法术列表分开排布，学习按钮增高，16px 法术图标完整放入按钮。
- 魔法石使用独立的外框绘制：直边平铺、角饰和顶部圆形装饰保留比例。其他页面继续使用原样式。
- 配键页的「清空」移到左侧，与「切页」并列，避免压住元素筛选。长名称截短，完整内容可悬停查看。
- 面板在矮窗口中整体缩放，点击坐标同步换算；悬停说明在真实窗口坐标中绘制，避免提前跳位。
- 法术贴图取完整 UV，同时支持现有 16px 和 32px 图标。保留用户的亲和力水晶及点位。

验证入口：`./gradlew.bat test build runClient -PmagicStoneUiAudit -Dnet.minecraftforge.gradle.check.certs=false --offline`。

隔离客户端使用 `run-client-ecology-audit`，检查四种窗口尺寸（1600×900、2495×1039、854×480、1920×720）的学习/配键两页，共八张原生截图，使用真实鼠标坐标点击页签、元素筛选和键位，并检查按钮重叠及越界。

安装脚本：`python tools/install_magic_stone_ui.py --live "<PCL版本目录>" --apply`。仅在游戏关闭且构建、原生截图验证通过后替换 TN-C JAR。安装前备份原 JAR，校验运行目录、镜像目录与构建产物哈希一致，并校验 FTB 任务文件完全不变。不修改存档或天空岛蓝图。

实际结果：268 项单元测试通过；8 个原生截图场景、12 次实际坐标点击、50 帧指定位置悬停渲染通过，按钮重叠和越界均为 0。JAR 内部引用、安装一致性、281 个模组检查及任务链/对话检查通过。42 个 FTB 任务文件哈希保持不变。
