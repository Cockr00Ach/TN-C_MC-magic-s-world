# Conquest 材质兼容修复

用户报告启用官方 Conquest 1.6.2 后原版树叶出现紫黑缺失模型。检查发现该 JAR 包含 `assets/minecraft/blockstates/oak_leaves.json` 等全局覆盖，使用非常规旋转，并替换原版树叶模型与贴图。启用它补齐酒馆家具时，同时改变了整包外观。

本次从官方 1.6.2 制作本地兼容副本：以 Minecraft 1.20.1 `client-extra.jar` 的资产目录为依据，移除 Conquest 对已存在原版资产的覆盖及 OptiFine CTM 覆盖，包含内置可选资源包中的对应条目。保留新增非原版依赖资产、所有 Conquest 自身资产、数据和 Java 类，未保留条目的内容全部逐项验证与原文件一致。原版方块再次由原有材质包及原版资源接管。

移除 32,984 个条目，保留 161,324 个条目；原版 10 类树叶的 blockstate 覆盖全部移除，`conquest:round_barrel` 家具资产保留，ZIP 完整性检查通过。工具为 `tools/prepare_conquest_furniture.py`。这是本地兼容构建，不能称为未修改的官方 JAR。

已安装 `ConquestReforged-forge-1.20.1-1.6.2-TNC-no-vanilla-overrides.jar`，SHA256 为 `a2b261804fd6a95388979c12355fbc3086f90d5a327ea726258a59f2bc2a2201`。原官方文件移至 `work/install-backups/conquest-furniture-20261011-195713/`，mods 中只保留兼容版，避免重复 mod ID。

没有改动 options、外部材质包列表或玩家存档。完整记录与被移除的资产清单位于 `work/conquest-furniture-20261011/`。安装前确认没有 Java 游戏进程，安装后校验哈希。需重新启动游戏确认树叶画面；本次未完成正式整合包实机验收。此修复不修复 Conquest 自身命名空间中其他已存在的复杂植物模型错误。
