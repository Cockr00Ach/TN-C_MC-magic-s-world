# 传统植物盘点与四季安排

2026-10-06 · 本地实际运行包静态盘点＋季节设计稿。季节为游戏设计标签，不是现实农学结论；尚未写入游戏。

盘点覆盖实际 PCL 的 281 个 JAR，以及现有 TN-C 植物清单。扫描标签、方块状态、中文语言与部分作物类。证据见 `design/ftb-routes-20261006/`。没有启动游戏导出完整注册表，因此不能把资源文件存在等同于生存可获得/可栽培已验证。下面区分明确作物、模组特色植物、普通花木和装饰。

## 一、四栏怎么展示

春：绿叶、嫩菜、早花，强调第一份收成。夏：水稻、瓜果、热带果，强调新鲜餐与饮品。秋：谷物、果园、葡萄，强调储粮、酿造和加工。冬：耐寒根菜、卷心菜、冰葡萄，强调热餐与越冬。每栏允许出现多季品种的链接图标，首次收集进度共用，不能同一物品领四份奖励。

全年植物设一个底部横带，异境植物设另一个小横带；不要为了四栏好看就编造“地狱疣冬天死亡”。普通树和花作为旁侧“林园”分组，不把家具和果酱锅当作种植任务。

图标用实际物品；方块 ID 用于生长规则，任务检测用真实种源/产物 ID。表中写方块 ID 不代表它就是可交任务的物品 ID。幼苗、成熟株、架上变体和果实方块共享品种进度。
