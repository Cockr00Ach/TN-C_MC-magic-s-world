# RouchNao：接下来怎样让世界更有生活感

当前先把钱、房屋、家具、生产和居民接起来。后续内容围绕「远行有理由，回来有牵挂」扩充，每次做完整的一小段经历。

## 开场视频制作稿（尚无最终素材）

建议75秒，可跳过、可在世界介绍页重看。

|时间|画面|内容|
|---|---|---|
|0–15秒|陌生天幕、散落的旧物、主角醒来|只提出主角的处境，沿用作者原有世界观与角色设定，不另造一个取代原剧情的主角|
|15–32秒|天空岛的灯逐渐亮起，云层间浮现道路|天空岛传来注视，邀请玩家找到一处归处|
|32–50秒|酒馆灯光、窗边读书人、田地、匠人工作|让玩家先感到这里有人生活，不在片中解释全部银行规则|
|50–65秒|法杖、远处遗迹、回家的门|魔法、冒险与生活相互连接|
|65–75秒|小镇名字与一扇半开的门，画面交回游戏|短句：「远行之后，也有一盏灯为你留下。」|

原剧情台词与人物背景由作者的任务书决定。制作视频时另交最终MP4、字幕与使用授权说明；随后再接一次性播放标记、跳过和重看入口。本轮没有用文字弹窗冒充视频。

## 新玩家第一段经历

出生读「归」→天空岛邀请→抵达RouchNao→酒馆见Self→艾琳登记→第一次制杖/铁匠下单→认识织夏与米洛→看一两套房→接一份委托或卖一次农产品→购买房屋/土地→买床和灯→第一次在自己的房间过夜。

房屋、农田、冒险是可以交错的支线。不要强迫玩家结婚、生育、借贷或掌握所有元素才准继续剧情。开局现金不要直接白送整栋房；工资、委托、经营三种路径都有用。

## 一段可重复的生活节奏

出门给作物补种，向居民打招呼；把收成卖到32号；酒馆看一份适合当前装备的委托；远行采到想摆进家里的纪念品；回镇领取匠人的成品，添一把椅子。玩家不喜欢经营时也可以靠委托与工资置家，喜欢安静生活时也不必连续刷Boss。

当玩家已经有家，下一轮最值得做的是**一个完整的返乡事件**：航路补给失踪，镇里的人担心；玩家调查路标、找到营地、完成一次危险行动；回来后织夏的商店出现新的摆件，酒馆的人有一句新话。剧情改变可见的生活，而不只是弹一次奖励。

## 已实装：归航札记三条生活剧情

在41号酒馆与艾琳登记后，点「归航札记」。每条三章，自愿接取、没有期限、可并行。普通委托仍走旁边的Bountiful原生栏，银行与商店各自独立。

|故事|三章实际目标|结局|
|---|---|---|
|酒馆的一桌晚餐|普通小麦8+胡萝卜8 → 熟牛肉4+烤马铃薯4 → 交流两位不同成年邻居、交牛奶1+鸡蛋4|返还空桶；合影纪念页；商店解锁团聚长桌；居民记得晚餐|
|带回远方的见闻|接取后岛外探索三种实际群系 → 交纸3+墨囊1 → 交流三位不同成年邻居|远方盖章札记；商店解锁远方航灯；不要求Boss击杀|
|为自己点一盏灯|实际拥有已交付住宅 → 屋内放普通床、光源、沉浸家具 → 完整在自家床睡过一夜|含自己门牌的归处纪念页；商店解锁六格纪念柜|

三条故事合计400铜、680冒险经验，分章一次结算。纪念页可放展示框；特色家具仍要花钱购买。命名材料不收，满背包不扣，结尾不能重复领奖，离线与重启不丢进度。六位镇民在23、31、37号住宅，使用凡家物语原生交流与婚恋，札记不会替玩家决定婚姻。

32号朝夕商行每天推荐一种农牧产品，实际收购价150%，所有玩家当天相同。推荐按真实日轮换（北京时间08:00），离线跨天照常更新；时钟倒退不重抽。额度仍按实际收入计算，未改成无限收购。居民每天有简短招呼，故事完成后会回应玩家的经历。

开场视频、航路营地调查、节庆、家庭出游和茶灯会馆小游戏仍是后续内容，没有冒称已完成。下一轮先做真实游玩与内饰协作，避免再用文档条目代替交付。

## 高阶灾变委托的制作标准

普通补给、食材、巡猎继续走酒馆Bountiful原生委托栏。灾变讨伐做成少量特别行动：「收集线索→准备物资→远征→实际击杀→带证据归来→小镇回应」。高级目标只开放一次首杀剧情奖励；日常委托不能把重复Boss击杀变成最优赚钱方式。

接入前从实际3.31模组注册表核对目标实体、所在维度、结构、掉落和召唤方式，逐个做多人参与与击杀证据测试。当前已有普通讨伐统计，但不能把到达遗迹/阅读页面当作Boss击杀，也不能凭印象写实体ID。
