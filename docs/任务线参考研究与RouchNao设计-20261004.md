## 原创任务骨架

主线仍由主策编辑：歸的世界观 → 天空岛注视 → 到RouchNao → 酒馆Self交代 → 制杖/铁匠/银行/休闲四支 → 第一次外出委托 → 返镇交付 → 后续遗迹与大型委托。

生活任务单独四页：远行引导、魔法花园、异兽牧养、魔导工坊。每页先一条短的体验流程，再分经营方向，最后给自由收藏的图鉴。全种齐、全养齐、所有机器都做齐不作为主线门锁。

花园：采样夹 → 一份实用收获 → 餐桌/收纳/供货三分支 → 可选19品种与巨藤、翠脉。牧养：牧养册 → 食槽窝点 → 自选牧场 → 肉食餐桌/活取提灯/魔力储运/伙伴工作四分支 → 23个体图鉴。

工坊：札记 → 四材料炉 → 发电座 → 导能线 → 第一盏灯；炉旁分耗材升级，电路分电池/压纹机、声音/瓶座、动物电晶。节点以短距离连续阅读，图鉴收拢为列，不再让每颗图标跨很大的空白。

## 检测与奖励的边界

本轮新玩法页的“持有成果”节点检测背包真实物品，不消耗；操作体验手动确认，文字明确说明。没有把持有种子宣称成亲手种植，把持有托盘宣称成已完成运输。现有酒馆委托、商行交易与银行继续由实际系统结算，图鉴不给无限铜币奖励。

将来如要严格记录“第一次认养、第一次植株采收、第一次完整搭炉、第一次供货”等，可以接服务端进度事件，再把对应手动节点换为advancement检测；未接检测的内容不能写成已经自动验收。本轮先改引导和资料页，不虚构检测能力。

## 本轮实际应用

已经修改自有的花园、牧养、工坊三章：补起步和产物分支、加入内部依赖、收紧布局、纠正旧环境限制与旧炉结构说明。安装会按节点ID合并，已有节点的人工位置、大小和图形若被修改则保留。主策的世界观、主线、法器、装备等页不由这次安装重写。
