# 生态第二轮修改方案（2026-10-04）

按作者本轮六条反馈直接修改并实装，不改天空岛模板、装修存档和作者的任务排版。

1. 动物：23套模型保持独立，重新区分主色、腹色、附属器官和可辨认的斑纹。浮鲸、犀、负兽、山貘适度放大，并同步碰撞体和渲染尺寸。飞行参考包内冰火传说羽蛇的空中目标、平滑运动、碰撞换向逻辑，自写适合牧养动物的空中巡游和升降。
2. 炉：底层9砖，中层7砖+前方炉口+中央核心，顶层8砖+中央排烟口，共24砖和3个特殊部件。炉口负责GUI、投料、成品、注魔和有限漏斗自动化。说明书、配方、测试和指南同步。
3. 界面：结构状态独占一行，左右分别为制作与配方，升级槽、材料槽、进度条和库存互不重叠；配方名称截断后可以悬停查看，选择区域与绘制区域一致。
4. 植物：栽培植株可种普通土、草地、耕地、泥和苔藓，无生物群系、光照、温度、海拔、邻接装饰要求。野生分布保留各自栖境；长高植物仍需要实际空位，避免吞建筑。花灵夜游、授粉、睡醒等特性保留为互动，不阻止植株基本成长。
5. 协作：合并origin/main并保留已实装生态及天空岛修复，实际编译验证；写清仓库不包含的第三方模组、启动环境、资源包与存档如何交给新同伙。
6. 编辑材料：导出法杖与穿戴装备Blockbench工程、贴图和路径映射；另写可修改的玩法路线文档，逐项列出植物、动物、锻造、电学的进入方式、操作、产物用途及作者细调栏。

验证：真实GameTests覆盖四部件结构、漏斗、供魔、栽培解除限制、飞行升降与障碍；单元测试、资源检查和生产构建。实装时备份jar与改动覆盖层，确认游戏未运行，保护用户存档与任务布局。
