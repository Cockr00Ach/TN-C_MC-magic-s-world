# 火球链 现状（火系 · BALL 链）

> 2026-10-05。本文所有数值都是从**源码里读出来的**，不是凭记忆写的。
> 数值的唯一出处是 `FireSpellRules`（火球链）与 `TNScorch`（焚身）—— 要调手感改那两个文件。

---

## 一、火系一共有 3 条链

同一元素下**按"链"（Chain）分**，每条链各 5 档（t1~t5）：

| 链 | 说明 | 5 档 |
|---|---|---|
| **RAY** 火射线 | 本次没动 | 火射线 / 粗火射线 / 三条火射线 / 爆炸射线 / 巨大爆炸射线 |
| **BALL** 火球 | ✅ **本次重做的就是这条** | 火球术 / 大火球术 / 熔岩火球 / 熔岳天倾 / 陨星坠 |
| **BURN** 燃烧 | 本次没动 | 火附着 / 初级燃烧 / 中级燃烧 / 高级燃烧 / 完全燃烧 |

下面全部是 **BALL 链**（下称"火球链"）。

## 二、五档总览

伤害公式：**实际伤害 = 系数 × 5.0（绝对基准）× 施法者火法强**
（下表"伤害"按**火法强 = 1.0** 算，实际按你的火法强等比放大）

| 档 | 名字 | 法术 id | 系数 | 伤害 | 射程 | 冷却 | 前摇 | 行为 | 外观 |
|---|---|---|---|---|---|---|---|---|---|
| t1 | **火球术** | `fireball` | 1.0 | 5 | 40 | 1.5s | 0.5s | 直线火球 | 彗星焰尾 |
| t2 | **大火球术** | `great_fireball` | 2.4 | 12 | 40 | 3.0s | 0.7s | 直线火球（更大）| 彗星焰尾 |
| t3 | **熔岩火球** | `lava_fireball` | 3.2 | 16 | 44 | 5.0s | 0.9s | 直线火球 + **落点留熔岩地** | **不规则岩块 + 随机岩浆**（Voronoi）|
| t4 | **熔岳天倾** | `molten_skyfall` | 3.4×N | 每发 17 | 64 | 12.0s | 1.2s | **目标头顶开法阵**，每 0.5 秒砸一发，共 10 秒 | 法阵 + 落下的岩块火球 |
| t5 | **陨星坠** | `meteor_fall` | 6.0 | **30** + 目标**最大生命 10%** | 24 | 20.0s | 1.5s | **目标脚下开巨型法阵** → 2 秒后天上砸下大陨石 | 巨型法阵 + 大陨石 + 4 颗装饰小陨石 |

> **t5 原名「炎葬」**，2026-10-05 改名并**重写了机制**（不是单纯改名）。
> 旧的 `tnc:flame_burial` 已失效 —— 旧存档里学过的要重新学 `tnc:meteor_fall`。

## 三、两条副产物机制

### 焚身（`tnc:burning_body`）

**触发**：任何火系法术**命中**时自动挂上。

| 等级 | 显示名 | 每秒伤害 | 持续 | 谁会挂 |
|---|---|---|---|---|
| I | 焚身 | **实际命中伤害 × 10%** | 5 秒 | t1 / t2 / t3 / t4 |
| II | 焚身 II | **实际命中伤害 × 20%** | 10 秒 | **t5 陨星坠**（含范围内所有生物）|

三条规则（都在 `TNScorch.decide()` 里，有单元测试覆盖）：

1. **同级不刷新** —— 已经挂着同级或更高，直接跳过（不是"重置时间"）
2. **II 可以顶 I，并且重新计时** —— 低级被高级覆盖
3. **基数用"实际打出的伤害"** —— 暴击/减伤之后的值，不是面板系数

按上表伤害算，I 级焚身额外总伤：`t1 2.5 / t2 6 / t3 8 / t4 8.5`；
t5 的 II 级是 **6/秒 × 10 秒 = 60**。

### 熔岩地

**触发**：熔岩火球（t3）与陨石（t5）**落地**后，在落点下方留一块。

| 项 | 值 |
|---|---|
| 每秒伤害 | 那一发火球的伤害 × **10%** |
| 持续 | 5 秒（100 tick） |
| 半径 | 3 格 |

⚠️ **和焚身是两条独立结算，会同时跳** —— 这是明确要的效果，不是 bug。

## 四、两座法阵（都是**几何体**，不是粒子）

明确否定过「不要就一圈火焰粒子代表法阵」，所以用 `TNSigilRenderer` 一笔一笔画：

```
外圈：粗主环 + 外侧细环 + 一圈扇贝缺口 + 符文刻痕
内圈群：3~5 层同心环
六芒星：六个顶点「隔两点连一次」
卫星圆：3 个，沿 120° 分布、带内部花纹、缓慢公转
中心：圆 + 两股反向螺旋
```

金白发光、走自发光通道；法阵**水平**放置（法线朝上）。
在此之上**再叠加火焰粒子**（外圈一圈 + 盘面火星）凸显"火系"。

| 法阵 | 归属 | 半径 | 复杂度 | 位置 |
|---|---|---|---|---|
| 普通 | 熔岳天倾 t4 | 3 格 | 18 条符文 / 16 扇贝 | **选定目标头顶**，固定不动 |
| **复杂** | 陨星坠 t5 | **7 格** | 28 条符文 / 24 扇贝 / 双层三角 / 顶点小环 | **选定目标脚下的地面**，固定不动 |

## 五、命中判据（很重要）

**火球能打中"所有活着的生物"，唯一的例外是施法者自己** —— 没有任何白名单。

这意味着以下**全部会被打中**：

- 其他玩家 → **法术可以 PVP**
- 队友 → 不看 `isAlliedTo`
- 自己的召唤物 / 宠物
- 村民、动物

（演进：最初抄水系的"必须是敌对怪"→ 试验假人打不中；改成"不是自己人就能打"；最终要求改成"所有生物"。）

## 六、进游戏怎么验

```
/tnc affinity set fire 6
/tnc points add 200
/tnc wand
```

学法术（**`/tnc learn` 不会绕过解锁门槛**，得先有法强与点数）：

```
/tnc learn tnc:fireball
/tnc learn tnc:great_fireball
/tnc learn tnc:lava_fireball
/tnc learn tnc:molten_skyfall
/tnc learn tnc:meteor_fall
```

其它有用的命令：

```
/tnc fire rules                火系规则速查
/tnc fire scorch [heavy]       手动挂焚身（heavy = II 级）
/tnc progress set fire ball 3  直接改火球链进度
/tnc forgetall                 全部忘掉
```

## 七、代码地图（要改什么去哪个文件）

| 文件 | 管什么 |
|---|---|
| `magic/fire/FireSpellRules.java` | **所有数值的唯一出处**：系数 / 射程 / 半径 / 爆炸 / 熔岩地 / 陨石参数 / 命中判据 |
| `magic/fire/TNScorch.java` | 焚身：规则判定 + 每秒结算 + `/tnc fire` 命令 |
| `magic/fire/TNFireBoltEntity.java` | 飞出去的火球与陨石：位移、命中、爆炸、拖尾、成形阶段 |
| `magic/fire/TNSkyfallEntity.java` | 熔岳天倾的头顶法阵（砸哪、何时砸） |
| `magic/fire/TNMeteorFallEntity.java` | 陨星坠的地面法阵 + 放陨石与小陨石 |
| `magic/fire/TNLavaFieldEntity.java` | 熔岩地 |
| `client/TNSigilRenderer.java` | 两座法阵长什么样（几何体） |

## 九、两个已知的坑（不是在火球链里，但会互相影响）

1. **水球有同样的实体位移写法**（`TNWaterBoltEntity` 客户端也在自挪实体），
   所以水球应该也有同样的顿挫 —— 火球链已修好，水系的建议照同样方式处理。
2. **陨石落地那一刻粒子量约 400+ 颗**。单个法术没问题；
   多个陨石同时落地（多人同时放）时低配机可能掉帧 ——
   各层数量都集中在 `TNFireBoltEntity.meteorImpactBurst` 一个方法里，好调。
