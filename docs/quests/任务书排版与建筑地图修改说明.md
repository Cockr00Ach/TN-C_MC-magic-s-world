# TN-C任务书：排版与建筑地图修改

本次已生成原生FTB任务书数据，地图不是另一个网页。游戏内画面尚未逐页人工验收；提供的排版预览是按真实节点坐标绘制的示意，不能当游戏截图。

## 页面顺序和文件

FTB文件在版本目录的 `config/ftbquests/quests/chapters/`。工作仓库的源文件在 `questbook/ftbquests/chapters/`。

| --- | --- | --- |

## 手动改排版

先退出游戏，再复制需要修改的章节文件做备份。可用文本编辑器打开这些文件：本项目生成的是FTB可读的JSON形式SNBT。改节点的`title`、`description`、`icon`、`x`、`y`、`size`、`shape`即可。`x/y`决定任务书平面位置，`dependencies`列前置任务ID。

**已有章节、任务、任务项的`id`不要改。** 改ID会影响旧存档进度。玩家已经拿到的玩法目标不能改成阅读勾选；阅读节点可以保留`checkmark`，真正做过的行为使用`advancement`，物品收集使用`item`。个人钱币报酬在委托系统结算，不给FTB重复加钱。

每张元素法器节点使用真实物品图标，如`tnc:fire_wand_3`；原版物品如`minecraft:iron_chestplate`。法器进阶线不意味着自动学会法术，研习节点单独检查真实学习。光系普通战斗法术尚未实现，所以光列没有虚构的研习任务。

重新进入游戏打开任务书检查。若使用游戏内FTB编辑界面，先在副本/测试存档操作，并保存导出结果，退出游戏后核对上述文件再同步回仓库。不同FTB版本的编辑入口可能不同，本说明不依赖未核验的聊天命令。

## 改建筑用途

图是天空岛原始结构与当前景观覆盖层的俯视图，坐标是相对天空岛原点的局部坐标，**不是你存档的绝对坐标**。41组是建筑/入口编号：18、20属于同一训练场两门；北侧连体楼按分区入口编号，需要你后续确定具体房间。不能理解成41栋完全独立可售房屋。

现在明确安排：19归航银行，28炉石铁匠铺，29潮生制杖屋，34茶灯会馆，40已开放住宅，41酒馆Self/协会/原生委托栏。23、31、37的居民住宅保留。其他紫色编号只是待售候选，尚未出售，也不会自动清空内饰。

你可以直接发“17改某用途、26玩家住宅、34改某玩法”等编号意见。源数据由 `tools/map-town-buildings.py` 中用途提案生成，41个节点在 `tools/gen-main-atlas.py` 生成；生成后的用途清单为 `work/revision2/town-map/建筑用途提案.csv` 与 `建筑编号.json`。

如果只想改文字，编辑图鉴节点的`title/description`即可。如果要改地图底图或圆圈位置，修改地图生成脚本、重新生成底图，然后重新运行图鉴生成器。背景资源为 `tnc:textures/guide/town_atlas.png`，章节图片宽44.6、高40.1；其节点与像素到任务坐标换算统一。换成尺寸或裁切不同的图片，需要一起调整宽高和坐标换算，否则圈号会错位。

## 重新生成与安装

在仓库根目录依次运行：

```powershell
python tools/map-town-buildings.py
python tools/revise-town-guide.py
python tools/finalize-revision-guide.py
python tools/gen-onboarding-quests.py
python tools/gen-town-progression.py
pwsh -NoProfile -File tools/gen-ftb-guide.ps1
python tools/gen-main-atlas.py
```

生成器会覆盖其负责的源文件；若直接手动改了章节，要先把修改合回生成器再重跑。安装使用 `tools/install-playable-update.ps1 -LivePack '你的版本目录'`，先加`-CheckOnly`预检。脚本仅安装TN-C拥有的文件、先备份并校验SHA256；Minecraft运行时会拒绝安装，不编辑存档。改Java功能或jar内图片后需先重新构建jar。地图图片在jar和KubeJS资源两处同步，避免资源覆盖造成看到旧图。
