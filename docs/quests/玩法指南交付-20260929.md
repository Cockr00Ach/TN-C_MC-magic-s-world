# 玩法指南：原生 FTB 任务书交付

## 实际入口与本批范围

启动原来的 PCL 魔改实例，进入世界，按 **E**，点击背包左上角任务书，在章节列表展开 **TN-C - 玩法指南**。

这是 **FTB Quests 2001.4.22** 的原生章节，不是另开的界面。实际 jar 的 `assets/ftbquests/sidebar_buttons.json` 将按钮指向 `ftbquests:open_gui`，对应处理调用 `ClientQuestFile.openGui()`。旧交接文档中“FTB方案废弃”是剧情专题当时的决策，不等于用户要求的背包任务书入口不存在。

本轮初稿接错入口，曾做过独立指南界面；用户纠正后已撤销所有新界面、G键和剧情拦截器。**没有把错误初稿安装到正式实例**，也没有修改第三方 jar。

## 已接入

九章按用户要求排列：世界与魔法、法杖与匠人、魔法师成长、冒险者职称、酒馆委托、钱袋与交易、田园与餐桌、买房与家庭、初来乍到。

共52个阅读节点。节点详情包含原始玩法设想和首版数值，分组/章节/节点/阅读任务共114个固定编号。所有阅读节点无奖励、无前置锁；勾选只代表读过说明，绝不代表已升级、买房或完成委托。

武器章展示5张原创32×32透明像素图标，并为五档概念分别提供说明。神杖叫“傲慢的水龙王”；没有注册无配方的新装备，也没有替换现有法杖。

房屋明确需要购买、交付空内饰、玩家自行装修；小型5银、标准25银、大宅1金50银。币值100铜=1银、100银=1金，钱袋余额死亡保留。上述规则已定稿，机制仍待实现。

## 同伴怎样引入

1. 拉取 Git。
2. 使用 PowerShell 7，在仓库运行 `tools/install-guidebook-update.ps1 -LivePack "自己的整合包实例绝对路径"`。游戏与开发Java进程必须先关闭。
3. 重启游戏，从E背包任务书进入。此批不要求重新编译TN-C模组，图标由KubeJS资产目录加载。

自有章节放在 `questbook/ftbquests/chapters/`，不把基础包整份config提交。正文单一来源是 `src/main/resources/assets/tnc/guide/gameplay.json`；改正文后运行 `tools/gen-ftb-guide.ps1` 生成原生SNBT，再重新安装。图标生成器是 `tools/gen_guide_weapon_icons.ps1`。

安装器只合并自己的分组、覆盖自己的九份章节与五张图标，预先备份，验证SHA256，失败回滚；不会删原来的章节，不改FTB/Whispering的存档进度。
