## 一、这个角色是什么（先对齐，别写偏）

| 项 | 设定（出处） |
|---|---|
| 身份 | **大光魔法师**，**最初魔法协会的成立者**；后来**激流勇退、隐居山林**（`一周目_第一纪正史.md` §115 / `剧情背景_挥戈反日.md` §62） |
| ★ 与主角的关系 | **就是"激活归的魔法石"的那个人** —— 当年就看出归与众不同，但**不说**（同上） |
| ★ 与衍的关系 | **衍小时候见过他**；后来衍在探寻路上与他交流，发现认知相同，**一起去探寻**（同上） |
| 名字 | **庄周（坐望）** —— **旁观者**（同上） |
| 性格（台词实测） | 「**我不算，我看。**」「**说了，你们也不改。**」「**看了一辈子，总要付一次看钱。**」（`第二段` §165-181、`第三段` §92-102） |
| 结局 | 开门送四人进黑暗深处 → **耗尽自己**给归换一个瞬间 → 最后**手里留着四块石头**（`主线概要.md` §38-49） |
| 元素 | **光 6 / 暗 0**（满档光 ✓） |

**一句话人设**：他一辈子在旁边看，看懂了也不说，直到**不说不行**的那一刻 —— 然后他付账。

> ⇒ 所以这条任务链的**唯一主题就是"看"** ✗ 不要写成"打怪交材料" ✗ —— 每一环都该是
> **"你让他看见了一件他没见过的事"** ✓，或者**"他终于开口"** ✓。

## 二、任务链总览（章节《坐望》· 5 环）

位置建议：**第二段（黑暗潮）主线里找到他之后** ✓ —— 也就是四人组第一次进他那间屋子、他问"你们为什么要来"之后 ✓。

| # | 任务名 | 一句话 | 类型（按任务书能显示的三种 ✓）+ 触发 |
|---|---|---|---|
| 1 | **看痕** | 他要你先去把边城东墙那道痕**看清楚**，回来告诉他"是什么" | 交互/考察（走到点）✓ 触发：与他对话完第一章 ✓ |
| 2 | **说不出口的那句** | 他会问你"你们为什么要来" —— **任务不给你选项**，只要求你真的**带来一样东西**证明 | 收集（3 件：路上捡的/打到的，见下）✓ |
| 3 | **坐三年** | 他三年没动过手。要他动手，你得先把**这座城的潮**清干净 | 击杀（潮汐怪 N 只）✓ |
| 4 | **照一下** | ★ 他出手：**用光把某处照明白**（一场演出＋一次"照亮"交互）| 剧情/交互 ✓ |
| 5 | **付看钱** | 他交出东西、然后转身回去坐着 | 交付/收尾 ✓ |

> **交互 / 收集 / 击杀** 设计 ✓，若某环不支持就改成相邻的类型（文案不动 ✓）。

## 三、每一环的细节

### 环 1 · 看痕（教学环：让他知道"你会看"）
- **开场台词**（他坐着，不抬头）：「东墙那道痕，你们看过了吧。」
  「**再去看一次。看清楚了，回来告诉我它是什么。**」
- **目标**：到指定坐标（边城东墙，用**交互点**或"走到即完成"✓）看一次
- **交付**：回来与他对一次话，**他考你**（对话题给 3 个选项 ✓ 只接受 1 个 ✓）
  - 正确答案：**"那是有人从里面划出来的。"**（＝印证他三年前的判断 ✓）
  - 错误答案：不惩罚 ✗，他会说「**你还没看清。**」并把任务退回去 ✓（可以无限重试 ✓）
- **奖励**：**光亲和力点数** ＋ 一句评价（「你比他们肯看。」✓）
- **设计意图**：第一次让玩家体会"这个人只认'看清楚'" ✓，同时把**东墙那道痕 = 衍的手法**这条主线线索钉死 ✓

### 环 2 · 说不出口的那句（收集环：他问"为什么"，任务不给答案）
- **触发**：环 1 完成后他主动开口：「**我不算，我看。**你们来的路上死了几个人、在哪条河边歇过、你那面盾上磕了几道口子，我都看得出来 —— 但我看不出来你们为什么要来。」
- **目标（收集 3 件"证明你走过"的东西 ✓）**：
  1. **一片烧焦的潮壳**（击杀黑暗潮怪掉落 ✓）
  2. **一块被水泡过的旧布/旧木牌**（在河边遗迹拾取 ✓）
  3. **一面磕出豁口的盾**（把**槐**的那面盾拿去给他看 —— 用现成 NPC 的交互 ✓）
- **交付**：交完他**不评价**，只说一句：「**东西我收下了。话说回来，你们还是得自己说。**」
- **奖励**：**光系法术权限（若光系做进法术链）** 或 **魔力上限 +** ＋ 一张可阅读纸（正史残页 ✓）
- **设计意图**：把"收集"做成**叙事道具**而不是刷怪 ✗；也让**槐**在这条链里有位置 ✓（小队关系铺垫 ✓）

### 环 3 · 坐三年（击杀环：逼他动手的前置）
- **台词**：「我三年没动过手。**你们把它清干净，我再考虑要不要动。**」
  「我不劝人，也不拦人 —— 但潮进城了，**再松下去，拆的就不只是一座边城**。」
- **目标**：在边城范围内清 **N** 只潮汐怪（建议 **12~20** ✓，数值你定 ✓）
- **额外条件（建议加 ✓）**：**不能让他出手**（他全程被"保护"✓）→ 用一个不可完成的"护送"文案表达即可 ✓
- **奖励**：**光亲和力 ＋** ＋ 解锁环 4 ✓
- **设计意图**：他不是打手 ✓ —— 他动手是**代价**，不是服务 ✓；所以这一环必须由玩家付 ✓

### 环 4 · 照一下（演出环：整条链的高光）
- **场景**：黑暗潮的核心处 / 一处"照不进去"的黑
- **台词**（照他 §92-102 的原台词 ✓）：
  「我这一身剩下的不多，只够**照一下**。我给你把那半口气照出来 —— **只有一瞬间。**」
  「**看了一辈子，总要付一次看钱。**」「别看我。**看前面。**」
- **目标**：跟着他走到位 → 触发一次"照亮"演出（**光柱/白屏/全场点亮** ✓ 客户端表现 ✓）
- **奖励**：**明牌**（把敌人某处弱点/黑暗深处入口显形 ✓）＋ 光系强化 ✓
- **设计意图**：把"付账"第一次演出来 ✓ —— 为第三段的结局埋钩子 ✓（那时他付的是命 ✓）

### 环 5 · 付看钱（收尾环：他把东西给你，然后回去坐着）
- **台词**：「拿去吧。**路上别再问我为什么。**」
  「（最后一句，很轻）**留一块石头给我就行。**」← ★ 与结局"只有他手里留着四块石头"呼应 ✓
- **目标**：交付/收尾（对话即完成 ✓）
- **奖励**：**四块石头之一**（道具 ✓，纯叙事物 ✓）＋ 章节《坐望》标记 ✓
- **设计意图**：这一句是全链的**记忆点** ✓ —— 玩家到第三段才会明白他说的是什么 ✓
