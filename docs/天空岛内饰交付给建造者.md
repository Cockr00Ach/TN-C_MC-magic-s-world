# 天空岛装修与回收模板

推荐直接把专用装修存档给建造者。无需换种子，也无需重建整座岛。

1. 使用当前同一版整合包，新建启用作弊的存档，名称例如“天空岛内饰母版”。正常触发上岛，等建筑、传送阵和地景全部生成完。管理员可用 `/tnc skylandscape status` 查看地景整修状态；未完成前不要施工。
2. `/gamemode creative` 后在现有天空岛装修。创造模式允许修改城镇保护区，不需要关闭保护，也不要删除天空岛生成数据。
3. 保存退出游戏。备份原存档，再把整份存档文件夹压缩交给建造者。同整合包版本和模组列表一起交付，尤其要保留用到的家具模组。别只发 region 文件或地图截图。
4. 建造者在这份存档内修改，尽量保留外墙、出入口、楼梯及传送阵。酒馆41号已有 Self、艾琳与委托栏；其余岗位为19号银行、28号铁匠、29号制杖屋。可以重新布置柜台，但注明挪过的位置，NPC及委托栏最终由开发者重新绑定。
5. 完工后保存退出，压缩整个存档返还。附建筑编号、修改范围和坐标；例如“41号酒馆两层，改柜台和桌椅，北侧委托栏移到某坐标”。截图用于核对外观。

箱子、柜子内不要放玩家私人物品。固定陈设、模组家具、告示牌文字可保存；画、展示框和盔甲架属于实体，需要单独说明，不能当作普通方块自动导出。不要靠玩家物品展示维持关键装饰。NPC刷怪蛋和玩家数据不会复制到正式模板。

## 开发者接收后的处理

保留返还存档的只读备份，读取 `data/tnc_sky_island_v5.dat` 得到岛原点。已有 `tools/read_tnc_sky_island_data.py` 可读取该数据；已有 `tools/export_town_structures.py` 可按世界坐标边界分片导出方块状态及方块实体，分片最大48格，不导出玩家或NPC实体。

导出以岛原点为基准的相对位置，核对家具所需模组、箱子内容、告示牌和入口，重新安排 NPC 与委托栏。现有导出工具跳过空气；若删除了原有墙面或家具，必须额外记录删除位置，否则简单叠加会留下旧方块。不要把当前导出产物直接塞进 manifest 就宣称完成。

当前酒馆外形还受 `SkyLandscapeUpgrade` 地景增量层控制。内饰需与该层的生成顺序一起接入并测试，避免之后的地景层覆盖装修。母版保存后再制作这一层，当前尚未收到装修产物，不会假定其完成。

随后用两个不同种子的新存档检查岛生成、柜台交互、NPC唯一性、委托结算和容器。验证后发布新模板，所有之后生成的新天空岛使用它。已有存档需要独立迁移：按修改前后对比仅更新匹配旧模板的位置，有玩家改建或储存内容的区域保留并报告冲突；不整岛强制覆盖。

你只需交回装修存档；导出、相对坐标、模板接入与验证由开发者完成。
