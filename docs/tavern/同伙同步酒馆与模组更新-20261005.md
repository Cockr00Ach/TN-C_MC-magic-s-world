# 同伙同步酒馆与模组更新

Git 仓库保存了酒馆内饰补丁、地下室、NPC、音乐及相关源码。运行用的 `mods/tnc-1.0.0.jar` 被 Git 忽略，因此仅执行 `git pull`，游戏仍会加载原来的旧模组。压缩包也只是打包那一刻的快照。

## 更新步骤

1. 完全关闭游戏，备份需要保留的存档。
2. 在自己的仓库目录执行 `git pull origin main`；有本地修改时先提交，再合并，保留自己的装修。
3. 使用 Java 17。首次配置或缺少编译依赖时，运行 `powershell -ExecutionPolicy Bypass -File tools/fetch-libs.ps1 -PackDir "你自己的实际整合包目录"`。该目录需要含完整模组，以及运行整合包后生成的 Connector 缓存。
4. 执行 `.\gradlew.bat build`，得到 `build/libs/tnc-1.0.0.jar`。
5. 执行 `powershell -ExecutionPolicy Bypass -File tools/install-to-pack.ps1` 安装到脚本识别的运行包。先核对脚本显示的 target 路径；也可以手动备份并把新 JAR 复制到自己实际运行包的 `mods`，替换同名旧文件。
6. 启动游戏。已有天空岛和以后生成的天空岛按酒馆升级逻辑安装内饰；旧存档首次升级时先离开酒馆，让施工检查安全通过。无需复制整个天空岛或导入别人的世界。

这一轮入口整片十个坐垫不安排常客；SELF 在吧台后方一格。酒馆音乐覆盖门口、厨房、地下室和所有楼层，进入后十秒开始，连续放完整首再随机下一首，离开后恢复普通音乐。

## 容易混淆的两件事

- 同伙在地图里装修的存档文件，不会自动变成生成模板；需要交付存档，再提取并更新酒馆补丁。本次已提取的内饰补丁在仓库中。
- 本仓库不包含所有第三方模组。新同伙仍需要完整运行包压缩包作为基础，再用 Git 同步源码、资源和配置，并重新编译安装 TN-C。
