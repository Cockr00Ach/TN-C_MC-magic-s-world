# 墨龙地面版远景显示（2026-10-20）

## 范围与实现

本次保留地面观察模式，不恢复飞行、巡游或攻击。修订只覆盖墨龙，不修改全局视距、实体距离和区块票据。

- 真实体的渲染距离和视锥判断改为完整龙身边界，不只看头部锚点。
- 服务端每秒向玩家发送附近地面墨龙的轻量外观快照；距离按完整龙身计算，最多 512 格。
- 客户端失去真实实体时通过世界渲染事件显示同一网格，不创建世界实体，不碰撞、不攻击、不提供跨区块交互。
- 低视距时只给远景模型绘制延长投影远裁面，随后恢复原矩阵和排序；地形视距不变，远景墨须使用独立缓冲提交。
- 真实体重新同步后不再绘制远景，避免重叠；死亡、删除、换维度、离线及停止收包后清理。
- 区块卸载只保留本次服务器会话里确认过的静止外观，不加载或持续运算卸载区块。每维度最多缓存 128 条，每玩家最多发送最近 16 条；重启服务器后需要真实区块至少加载过一次才有远景记录。
- 飞行或战斗中的墨龙不使用静止外观缓存，避免未来恢复战斗后远景位置过期。
- F3 增加 `Ink dragon: tracked=..., distant=..., cached=...`，分别表示客户端真实体数量、本帧绘制的远景数量、收到的外观记录数量。
