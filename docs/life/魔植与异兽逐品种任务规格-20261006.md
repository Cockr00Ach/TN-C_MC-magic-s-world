## 一、魔植页：每株独立的一列

列内四层固定为：**带回种源 → 看见特性 → 收获 → 使用/加工**。上层显示品种原图标和物品名，下层分两支：生活用途、工坊/远征用途。委托不是列的强制前置，任何方式合法获得种源都能开始。

每带最多六列；列距建议 4.5 个任务坐标单位，层距 2.8。正常缩放品种图标大小 1.8，产物/用途 1.2；文字只作短标题，细节在点击后的描述。魔植按生活作用分带，不按元素、季节或逐级等级锁定。

建议五带：归途与旅行（6）；厨房与补给（6）；织造与记录（6）；伴生与景观（6）；储魔与巨藤（5）。实际顺序可按下面品种表调整，确保同一品种只建一列，跨带用途用链接。

### 种源标记

- **果种**：产物可直接种。成熟右键留株；成熟挖掉同样保证拿到至少一份可种果。首次野采建议两份，让玩家能吃一份、留一份。两次动作不能在同一成熟状态重复领产物。
- **种＋产**：成熟挖掉给种子和产物，至少返一份种子；未熟挖掉返一份种子。取消强制采样夹。第一版保留普通挖收，后续可选镰刀批量收。
- **根/芽**：右键收独特产物，普通剪刀取繁殖芽并让母株回再生阶段；挖根返可种源。液体、棉絮和纸皮本身不能直接冒充种子。

所有人工株都用魔法土/源和流动魔力；自然株按野生生态生成。表中“地点”是拟设探索提示与生成方向，实施前对照实际群系标签，不指向唯一固定结构。

## 四、异兽页：上方教学，下面逐只展开

顶部五节点：看笼级 → 长按捕获 → 安置窝点 → 喂食 → 第一份活取/工作。材料旁边链接到魔力炉，不强迫玩家在这页重做一整遍工坊。

每个品种列显示：动物图标＋笼级 → 喜食/窝点 → 产物/行为 → 食品、材料或助手用途。动物图标使用独立模型的清晰小像，不用同一个蛋换颜色。特殊动物区域有大幅栖居示意，比普通列至少多留一倍横向空间。

## 六、特殊动物独立下区

### 蓄魔鲸：养一个会呼吸的魔库

展示大鲸图、露天窝 9×9×9、食槽、集息器与蓄池的小场景。三条向下支线：瓶装带走、联网调峰、照料与育幼。捕获前要准备 III 笼，喂西瓜，并保持 8 秒稳定视线；安置点空间不足时先提示，不强行放出卡在地里的鲸。

拟把当前小额 96 容量/48 日蓄的鲸重新定位为大型储魔伙伴，采用主方案的 16,000 储量；不是旧行为和新库同时叠加。抓进笼保留现有储量但暂停工作，释放恢复，不作为无限离线充电箱。

### 纸帆魟：养一条真的飞行路线

滑翔回路放在 9×9×9 窝内，玩家设置两根栖架，它自行绕行；建筑阻断路线时停工并显示原因。要有俯仰、转弯、滑翔与落架动作，不是贴地走的魟鱼。风翎与供魔工作两条用途都可以选。

### 鸣线蜥：储雷，不引回 FE

独立介绍雷雨蓄能、真实转移和雷鸣晶。同一份能量采成晶体后必须从蜥身上扣掉；晶体放回只返同量。天雷高产但不可靠，平常可以从网络给它充能，作用是移动储备和展示，不靠人工雷击放大能量。

### 新提案：曳彩角羚

III 级；拟喜食蜜粉，地面晶靶庭院。外形是短身高腿羚羊、分叉棱晶角、暖白/栗色体毛，晶角映出绑定色；与原鹿和犀完全不同骨架。喂食后用染料色靶建立安抚目标，短暂观看三次无伤彩炮后可捕获。

任务：准备匹配色靶 → 看见一发实际能量炮 → 接收并存入池 → 供给灯/炉。炮不伤地形，不伤实体。产物拟“棱彩脱角片”，用于色靶和透镜；消耗产物不能再返出它生产时未扣的同份魔力。

### 新提案：鼓腹砂獭

II 级；拟喜食根菜，地面滚坡院。体型圆鼓、宽掌、短尾，沙金/深褐条纹，腹部矿纹；不能用雾腹水獭改名。捕获前手喂，等它完成一次安全自然翻滚，进入安抚状态。

任务：造安全滚坡 → 设置起终点 → 实际跑满一趟 → 收集脉冲供能。产物拟“砂纹腹绒”，用于护垫和防滑层。坡道必须在批准范围，无岩浆、尖刺或深坑；受伤停工。不靠无限坠落刷功率。
