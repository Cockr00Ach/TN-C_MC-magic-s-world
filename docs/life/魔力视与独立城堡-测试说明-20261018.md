# 魔力视、晶纤与赫萝斯堪德界域

本轮保留玩家已有存档、天空岛蓝图和手写任务，只更新 TN-C 运行 JAR 与魔导工坊章节。

## 晶纤

青辉、霞金、虹星三个等级分别保持 8 / 32 / 128 M 每秒。每段最多两个接口，支持直线、转角与竖直连接；相邻第三条支路不会得到隐藏的连接。先接好的两个端点会优先保留，拆掉一个端点后会重新选择邻近目标。独立分流阀仍可分配多路，折光镜仍负责远距离传输。

实际传输与模型共用接口判断，非供能机器作为线路终点，不再靠机器本体充当隐形线路。不同主人的设备不混接。

## 魔力视

默认 F8 开关，可在按键设置中修改。关闭时保留原来的微弱粒子；开启后能看到实际发生的注能、植物或动物取魔、晶纤与镜子传输，以及自然环境中的流动色带。新版加入七色元素魔流、三股螺旋上升的元素旋涡、空中的宽幅极光带和漂浮光点；实际传输使用更亮的定向流束。特效在世界中绘制，并受地形遮挡，关闭立即恢复普通视野。自然色带用于表现环境，不增加任何可收集魔力；实际能量仍由来源产量、缓冲和线路带宽决定。

## 赫萝斯堪德

新生成的主世界堡垒位置改为界门入口。右键赫萝斯堪德界门进入独立维度 `tnc:heroskand`；入口平地上的同名方块负责返回，返程位置随玩家保存，死亡重生后也保留。创造物品栏的功能方块分类可直接取界门测试，生存配方为五紫水晶碎片、一末影珍珠、三黑曜石。

独立界域边长 1024，完整建筑与原有地景使用同一份整套蓝图，按区块原生生成。这里不再尝试把整座城堡压进普通主世界随机地形。旧主世界已经生成的建筑保持原样。

## 其他

赌场覆盖整个建筑，进入先停止原音乐，十秒后循环播放新增曲目；离开停止赌场音乐，交回普通音乐逻辑。

38 种魔植的种下模型与各生长阶段重新制作，各有独立配色；背包物品图标保留。灵纹铁、曜纹金、星髓改成不同轮廓的立体材料。酒馆闲聊采用紧凑黑底白字，近邻气泡避开。魔导工坊保留阶段流程、减少旁支依赖线。

## 星仪风格界面

炼金炉、炉体搭建说明、魔导机器、制杖屋、铁匠铺、银行、房产、商行、归航札记、魔法石、行囊、种匣和牧场设施共用深色旧铜星仪主题。按钮保留原有点击、禁用与键盘操作，服务入口仍由各自 NPC 打开。物品槽保持真实槽位，容器界面在小窗口下等比缩放，鼠标和 JEI 边界同步换算，提示文字在真实窗口坐标下排版。原有生命、饥饿和魔力 HUD 保持。

背景纹理与完整生成提示词见 `art/arcane-ui-20261018/README.md`。中央星仪由原生 GUI 绘制，可以随游戏时间转动，物品和状态仍由游戏实时显示。实际客户端的界面与魔力视截图随验收结果保存，不将概念图当作实装截图。

## 完整城堡校验

实际专用服务端已生成全部 2,160 个区块，并逐块核对 3,617 片蓝图中的 9,043,448 个非空气方块。缺失片段 0、异常方块 0。689 株导入灌木按项目既有规则转为永久杜鹃树叶，避免原装饰作物因支撑规则消失；该明确转换也参与比较，其他差异不能通过。

## 同伙同步

本轮已合并远端风法、暗系巨兽人模型、水法视觉与启动依赖污染修复。Git 继续管理源代码与配置；`git pull` 后需按 README 编译并安装新的 TN-C JAR，或使用作者重新打包的完整实例。不要从旧压缩包覆盖新 JAR。新版背景、植物模型、独立维度与音乐均随本轮 TN-C JAR 分发，不需要额外添加一个 GUI 或魔力视模组。
