# 墨鹤 V5：体型、连扫、实际俯冲和山水景物

2026-10-18

- 本体渲染比例 0.42 → 0.84，碰撞体同步翻倍；发射位置、身周墨光同步上移。
- 鹤影追击、巨大俯冲鹤影、墨螭虚影同步翻倍。attack2 背后巨影保持原来的绝对尺寸。
- 墨球半径由最高 4.02 变为 12.06，法阵和聚墨拖尾同步扩展；伤害和爆炸判定半径未额外加大。
- attack2：仰天长啸、巨影成形之后，左—右—左连续三次横扫。每个目标每次横扫最多受伤一次。保留作者原始 attack2、attack3 动画作为参考，不覆盖原稿。
- attack3：本体上升，锁定目标脚下地面，实际俯冲到法阵；抵达后才启动聚墨和墨球。结束后停留在落点。中断、死亡和存档重载会恢复重力，不留悬空状态。
- 水墨维度增加黑白灰山峰、裂纹山石和弯干层冠松。保留书法平地和出生点空地。只补充已加载区块，不主动加载远处区块；全维度每 tick 最多处理 384 个景物方块。发现已有、不符合生成图案的方块时保护该整列。
- 景物使用独立 V1 保存标记，旧存档已经画好的 V6 地板也可补充景物；无需重开世界。靠近后分批出现。
