# 墨龙批量顶点提交与水墨天空高度修复

用户确认开启光影时，不释放技能的墨龙也明显掉帧；随后反馈在 ink 地面看天空发黑、飞高变亮，并明确授权验证后直接安装。

## 已确认的热点与处理

重读旧 JFR 时只筛选 `jdk.ExecutionSample`，避免导出整份事件 JSON。其游戏主线程在录制中仍标为 `main`，不能仅按 `Render thread` 名称筛选。3620 个主线程样本跨越启动和三阶段演出；其中 `InkDragonBufferedMesh.draw` 的栈内采样 1463 次，`BufferBuilder` 的 Iris 顶点扩展、元素遍历、切线计算均有明显采样。它们是热点证据，不是正式整合包 FPS 或“静止龙占用比例”。

新的 `InkDragonBulkSubmit` 通过可选 MethodHandle 调用 Embeddium 0.3.31 的 `VertexBufferWriter.tryOf/push`。顶点按标准 `NEW_ENTITY` 36 字节格式成批写入，由 Oculus 1.8.0 已注册的序列化器生成其额外实体属性和切线。不使用私有扩展格式、不替换 GL 着色器、不关闭阴影。

每次提交最多 512 个角点，保证包装器使用 LWJGL 栈复制时不会申请数 MB 栈内存。批次直接缓冲区复用，位置、颜色、光照、法线、有效 UV 和覆盖纹理属性完整保留。没有兼容批量 API 或消费者不支持时，回退原逐顶点通道。

本次不修改模型、BBModel、动画、LOD 规则或墨龙技能。近景保持 **152306 个三角面、326748 个提交角点、110531 个需动画变换的共享顶点**；阴影仍按此前轮廓 LOD 保持 36630 个三角面。

## 天空为什么在地面发黑

MC 客户端 `ClientLevelData.isFlat` 并不按每个自定义维度的区块生成器决定。普通主世界存档中的自定义超平坦 ink 会沿用普通世界客户端值：地平线 63、虚空颜色缩放 0.03125。但 ink 实际地面在 -59，触发了地平线下黑色天空盖层，以及低高度背景色变暗。

`InkSkyHeightMixin` 仅对 ink 把地平线改为本维度最低高度 -64、颜色缩放改为正常超平坦值 1。未改其他维度、天空配色或全屏后处理。源码和 SRG 两套方法名均指定，原生客户端已实际应用；正式 jar 采用重混淆后的类。

开光影和关闭光影分别在地面、高空检查并截图；实际读取地平线 -64、缩放 1，失败列表为空：`work/ink-sky-height-20261024-native-report.json`。截图在 `work/ink-dragon-bulk-client-audit/screenshots/`，包括龙近景和两种模式的地面／高空天空；已实际查看模型、阴影和无光影天空。测试对光影的临时开关只改工作区独立测试客户端，未改正式配置。
