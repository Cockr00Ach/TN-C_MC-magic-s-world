# 墨龙恢复飞行与独立绘制（2026-10-21）

用户反馈 v5 在正式整合包中退后三四十格仍会消失，并要求恢复 Boss 动作；用户确认该维度最多这一只 Boss，允许更积极的局部加载。

## 修改范围

- 默认恢复飞行、身体行波、自动索敌和原有喷墨/俯冲。旧地面观察存档通过 `InkMotionVersion` 自动迁回飞行，并解除旧展示模式的 `NoAI`；新版本显式保存的地面调试模式和 AI 标记仍可保留。
- v5 只在客户端没有真实实体时绘制远景，无法覆盖“真实实体还在，但被普通渲染通道过滤”的情况。本版真实体和远景统一在世界事件中绘制，并按 UUID 去重；普通实体渲染入口不再承担墨龙本体的世界绘制。
- 世界事件直接调用墨龙专用绘制入口，不经过普通实体绘制入口或依赖“清除裁剪标记”来保持显示。这是针对代码缺口的修订，不代表已在完整整合包中确认某个优化模组就是根因。
- 远景快照由静止模式改为每 5 tick 同步位置、朝向、飞行/地面状态、攻击阶段及目标点。远景位置和转向插值；实际伤害始终由真实服务器实体结算。
- 仅在水墨维度、有玩家在 Boss 龙身 512 格范围内时，给最近的一只墨龙保活一个随动区域：region-ticket 距离 4，最多 9×9 个 FULL 区块，其中中心 5×5 达到实体运算级别。不保活全维度，不写永久强加载数据。
- 玩家离开维度、远离范围、Boss 死亡/删除或服务器退出时释放。票据另带 60 tick 超时兜底，正常每 5 tick 刷新。
- 卸载后的外观停止播放正在进行的攻击，避免缓存法术无限停留；再次加载后以服务器最新状态为准。
- F3 显示 `tracked / drawn / distant / cached`，区分真实体存在、真实体已独立绘制、远景绘制和快照数量。

模型网格、体型、其他 Boss、正式游戏的全局视距及优化模组配置均未改变。
