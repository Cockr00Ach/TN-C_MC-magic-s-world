# 黑杆毛笔与水墨特效重做

用户修正：毛笔采用书法名笔气质，黑漆长杆；放弃最初粗糙旧木扫描外观。最终模型为程序建模的原创版本，未包含下载扫描的几何或贴图。

## 模型及使用

- 黑漆修长笔杆、银灰流水嵌线、玉白笔箍、细尾绳和挂环。
- 饱满长锋，上浅下黑，尖端浓墨；模型 11002 三角形，高约 9.3 格。
- 实体 `tnc:ink_brush_boss`，900 生命，基础寻敌、移动、近战和独立血条。独立召唤，不加入原鹤、虎、龙三阶段流程。
- 重启后使用 `/summon tnc:ink_brush_boss ~ ~ ~`。
- 移动时笔杆倾斜，在脚下留下约 2–3 格宽的黑墨笔画，带淡墨边缘和飞白；静止后逐渐淡去。只在落地时采样，瞬移清空旧路径，最多 64 个路径点，不修改地面方块、不持久写入世界。

模型源：`tools/build_black_ink_brush.py`。

可查看模型：`model-source/ink-calligraphy-brush/black_ink_brush.glb`。

预览：`model-source/ink-calligraphy-brush/black-brush-preview.png`。

最初研究的模型来自 artsmia / Minneapolis Institute of Art，公开记录 https://zenodo.org/records/10286824 ，Sketchfab 元数据确认 CC0；保留原件和元数据作为研究资料，最终安装包不含该扫描。

## 共用水墨表现

Ink Wash 是后处理光影，没有可直接导入的粒子系统。本次借用宣纸晕染、浓淡和断笔的表现方式，在普通实体渲染中实现；不要求开启光影。

- 鹤、虎、龙共用墨气汇聚：向心弯曲的断续墨丝、零散墨滴、少量飞白。
- 墨球爆开：散墨碎片、三层不规则地面晕染；原有爆炸后山云虚影保留。
- 鹤影/翼虎等共用拖尾中的墨点改成朝向镜头的碎笔锋。
- 龙喷墨落点使用同一晕染系统，减少密集的烟雾片层。
- 装饰碎墨随原版粒子设置减量，没有持续粒子实体、全屏后处理或新雾层。

满粒子设置下，单次地面晕染由原 1148 个双面四边形减到最多 144 个；龙喷墨落点由约 3214 个减到最多 872 个。该数字只表示这些特效的几何预算，不代表整合包帧率提升比例。球体、法阵、山水图片及原有 Boss 模型均保留。
