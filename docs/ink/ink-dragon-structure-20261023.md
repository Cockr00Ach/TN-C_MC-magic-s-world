# 龙结构优化与界面显示修复（2026-10-23）

用户确认：Complementary 开启时卡顿，不开启则流畅；上轮 LOD 删掉太多可见细节。另报告进入 ink 立即全屏黑白、物品栏图标不可见。

## 不再用删近景细节减负

- 近处恢复原版全部 152,306 个三角面，包含身体鳞片、龙角、须鬃。身体/尾部按完整身体包围盒计算近距，不能只因离龙头远就退化。
- 模型资产 SHA256 仍是 `98969AD9C9BAC777D19CFC784701327E2E681AB824AE22987E9E699FE8D97C82`。没有重写作者 BBModel/GLB、动画或网格文件。
- 结构缓存按精确位置位模式和 RGBA 焊接共享属性顶点，不移动或四舍五入任何原始坐标。
- 只把相邻 `(a,b,c)+(a,c,d)` 配成真正四边形，保留原始对角线。70,619 对成功配对；不做任意跨面合并或删面。测试逐个还原所有 LOD 的原始顶点、颜色及三角面。
- 标准实体顶点通道保留；不用此前与光影冲突的自定义 GL 着色器。1×1 白纹理的 UV 具有有效导数，避免全顶点相同 UV；纹理接口现在返回实际 PNG，而非 `.mesh` 文件路径。

| 完整近景模型 | 旧三角面包装通道 | 新结构 |
| --- | ---: | ---: |
| 真实三角面 | 152,306 | 152,306 |
| 发送角点 | 609,224 | 326,748 |
| 需计算摆动/位置变换的属性顶点 | 456,918 | 110,531 |

相较**旧完整模型通道**，发送角点减少约 46.4%，重复位置计算减少约 75.8%。这些不是帧率提升比例，也不是与上轮砍细节版本的直接 FPS 对照。

## 光影阴影单独处理

通过本地 Oculus 1.8.0 的 `ShadowRenderingState.areShadowsCurrentlyBeingRendered()` API 识别阴影通道，使用可选反射，不增加必需模组依赖。光影不存在时正常降级。

阴影仅画 36,630 三角面的轮廓；不在阴影里再绘制巨大透明虚影、墨气拖尾、喷吐、爆炸等技能层。玩家看到的近景仍画完整细节。隔离实机记录 516 次摄像机模型绘制、516 次 Oculus 阴影绘制，确认分支实际生效。

## ink 常驻黑白与物品栏

旧 `InkScreenEffects` 在正常进入维度后，于 `RenderGuiEvent.Pre` 执行全屏后处理；没有完整还原深度/混合状态。入维度立即去色是这条常驻逻辑，并非龙攻击判定。

本轮移除此常驻效果及 GUI 前处理。水墨地形依靠自身材质和天空效果呈现，不再过滤玩家和物品栏。龙的 `ink_dragon_dread` 状态仍按原设计在完整画面末尾短暂去色，并恢复之前的混合因子、混合开关、深度函数、深度写入和深度测试开关。移动/施法减速机制未改。

这是针对已确认后处理状态风险的修复，不推断用户正式存档的物品是否曾被删除；本轮不更改正式玩家数据。
