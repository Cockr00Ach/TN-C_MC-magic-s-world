### 4.3 `sync.cmd` 只增不删，而且是双向的

| 命令 | 行为 |
|---|---|
| `push` | 只覆盖已存在且工作区较新的文件；**不删除**目标端多出来的文件 ✗ |
| `pull` | 会把游戏端多出来的文件**同步回工作区** ✗ → 删掉的东西会"复活" |

**所以删任务章节必须两边都删**：工作区删 + 游戏实例删。只删一边迟早出问题。

```
0. 先读 剧情总纲.md（§6.2 单条任务结构 / §6.3 术语表 / §6.4 红线）；有缺口就回去问编剧系统 AAA

   · 新章节挂到分组：改 chapter_groups.snbt（建议新增 &6TN-C · 元素觉醒，见 剧情总纲 §6.1）
2. 需要 NPC 对话触发 → 在 ftbq_bindings.json 加一条 <对话节点> : <任务 id>
   ⚠️ 任务 id 必须真实存在于某个章节里，否则就是悬空引用（这次删章节踩到了）
3. 同步：cd D:\ModTest\modpack ; .\sync.cmd push
4. 重启游戏（任务数据在启动时读；/reload 不一定重读任务）
5. 进游戏按 J 打开任务界面，逐条核对标题/描述/目标/奖励
6. 回报：把"实施结果 + 遇到的问题"写进本文或交接段；数值/机制类需求写「需求单」给对应专题
```

**口径基准**（编剧系统 AAA 定）：任务标题 ≤12 字人话、描述 2–4 句讲"为什么"、
**NPC 不解释系统**（不要说"需提升亲和力到 6"，要说"你身上的火还没烧透"）、
术语统一用**魔法石 / 亲和力 / 魔法点数 / 链 / 勇者级 / 领域魔法**。

### 8.3 🔴 「帅气模型」的可行边界（别重复走弯路）

用户想要"帅气的骑士模型"，实测下来**只有三条路**，代价差很多：

| 路 | 效果 | 可行性 |
|---|---|---|
| **皮肤**（现在用的）| 一般 —— 还是原版人形，靠贴图 | ✅ 5 分钟，已模板化 |
| **皮肤 + 真盔甲层** | ★ 有立体感（肩甲/头盔凸出来）| 🟡 要额外写一层盔甲渲染 |
| **GeckoLib 自定义模型** | ★★ 最帅、完全自主（作者给伊蕾娜/酒狐走的路）| ❌ **要 Blockbench 建模** —— 本环境没有；手写 `.geo.json` 只能做粗糙方块人 |

**另外查过、但走不通的**：
- `tlm_custom_pack` 里两个模型包共 **13 个模型**（`tnc_pet` 3 + `touhou_little_maid-1.0.0` 10），
  **全是东方女仆系角色，没有骑士/男性模型** → 借不到。
- 皮肤站点（minecraftskins.com / skinsmc.org / planetminecraft）的皮肤**默认版权归作者**，
  这个项目一直避免直接用 → 不能抓。

⇒ **结论**：想要真"帅气"，得**用户在 Blockbench 里导出 `.geo.json`**（或提供一张自己有权的皮肤 PNG）。
功能与外观是解耦的，**换外观不用动任何逻辑**。

### 8.4 位置怎么定（锚点机制，换存档自动跟岛走）

- 登记存 `<存档>/data/tnc_npc_placements.dat`，内容是 **`{锚点, dx, dy, dz}`**，不是世界坐标。
- 锚点来自天空岛：`CENTER` / `ARRIVAL` / `ORIGIN` / `GROUND_PORTAL`（读法见 `SkyIslandAnchors`）。
- **新存档自动采用默认登记**（`NpcPlacementDefaults`，由 `seedDefaults()` 注入；已存在的不覆盖）。
- 命令：
  ```
  /tnc npc here <id>          站在想要的位置登记（自动选最近的锚点）
  /tnc npc status             诊断：登记的应然坐标 + 实体实际坐标/距离/Y差
  /tnc npc list | respawn | purge <id|all> | remove
  /tnc npc place <id> <锚点> <dx> <dy> <dz>     （锚点写 ABSOLUTE 则用世界坐标）
  ```

**踩过的坑（都修了，别再犯）**：
1. **贴地逻辑覆盖了用户指定的 Y** —— 用户站 179 登记，NPC 被高度图抬到 200（差 21 格，
   看起来"人不见了"）。现在只做**最小必要修正**：站得住就原样用。
2. **跨模块取数据绕 NBT 会静默失败** —— 第一版用 `readTagFromDisk` 读天空岛数据，
   运行时既没成功也没进 catch、连日志都没有。现在改成**请那边开公开访问器**（`anchorPos`）。
3. **每开一个存档都要手敲命令** —— 原设计把登记按存档存却没默认值。现已加默认登记。
