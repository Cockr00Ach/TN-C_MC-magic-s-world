## 1. 三条路线怎样一起玩

探索发现种源、异兽 → 家园栽培与照料 → 收获食物/材料/能源 → 制作远征补给、工坊器件或给朝夕商行供货 → 用铜币购买家具、房屋与土地 → 继续探索与收集。

农业、牧养不是推进剧情的必经考试。它们提供持续生活玩法：玩家可经营赚钱，也可只养几株补魔植物、做几份远征餐、留下喜欢的伙伴。委托、食品、魔力电和收藏都使用这些产物。

## 2. 植物路线：种植、互动、产物

### 开始与通用规则

1. 在天空岛之外找野生植株，采样或收取种源；持采样夹对合适自然方块调查也能发现品种。调查保底在十次有效样本内给首次种源。
2. 将种子带回，右键普通泥土、草地或耕地种植；十九种新植物还接受泥巴、苔藓。镜潭莲额外支持静水面，岩函蕨额外支持石面。
3. 栽培株不受群系、光照、昼夜、冷热、支架、盐盆、讲台等环境门槛限制。树藤仍需实际空间，不能长穿房屋。特殊采收互动见下表，它们是成熟后的玩法。
4. 十九种新植物成熟后右键采收，保留根继续生长；瓶装产物带足空瓶。栽培株每三次采收额外给一份种子。野生株首次采收给两份种源，不伪造委托所需的野采证据。
5. 普通生长用世界实际运行时间；睡觉、`/time set`不能无限催熟。区块卸载再加载只补记允许的基础成长，不生成离线魔力、授粉或花灵回归。关掉单机游戏后世界刻不流动，不能当银行的现实时间计息理解。

### 野生生成与栽培的区别

野生植物按新探索区块的实际群系、落点土壤、稳定的水边/遮阴/海拔条件稀疏生成；不要求生成那一刻恰好下雨或处在某个时间。已有人活动、建筑引用、带方块实体的位置、小镇和已有地块会跳过，生成只用空位。不会为了刷植物强行加载未加载的区块，也不向既有内饰插植物。

带回种源后使用栽培规则，野生的环境标签用于探索辨识，不是家园种植的强制门槛。普通书、遮棚纹样、音符等仍能带来互动或不同产物记录。

### 植物加工的四个方向

- 远征食品：星露果/星露饮补魔，暖椒汤与霜椒餐防寒，晨蜜早餐与蜜簇糕补给。
- 安全探索：远照果临时照明，缓降布缓降，折叠雾帐产生30秒雾区，实体藤与绳提供攀爬。
- 调查收藏：岩纹拓页、影纹卡、路线页都保存实际采样者、位置或纹样；调查档案夹存署名页，不能用普通纸伪造档案。
- 工坊材料：晨蜜、雾棉、盐墨、帆纤维、纸皮等进入配方；翠脉枝提供少量持续魔力。收获可自用、制作或按商行收购清单出售。

## 3. 动物路线：认养、窝点、繁育和工作

### 第一只动物怎么养

1. 用牧养册对动物右键，直接查看喜食、主人、栖居问题、库存和剩余时间。
2. 用它喜欢的食物照料三次，每次有效照料至少间隔60秒；同一位照料者完成认养。快速连点不会消耗饲料，也不会刷认养进度。
3. 野外准备合适窝点，放栖居标记。牧务杖先右键选中动物，再右键自己的栖居标记设置窝点。
4. 食槽有四类真实饲料槽、共64份饲料，桶水另记16份。动物走近才吃；不凭空领饲料。产物满库存时不会堆无限离线收益。
5. 用剪刀、木刮片、空瓶、暖息罐或空手取相应产物。搬迁笼保留动物个体、主人、货物与状态；不要用创造蛋代替生存运输。

动物仍保留不同窝点需求，这是牧养特色；本轮取消环境门槛针对的是栽培植物。若也想简化动物窝点，在下面对应栏修改即可。

### 四个牧养经营方向

**肉食牧场**：选石垒豪豕、暮炭野豕、潮背鳄螈、星茸耳兔等，先留繁殖对，再处理成年个体。肉与配料做热锅、暖炖、水行浓汤或远行卷，形成“饲料→繁育→食材→远征餐/交易”的循环。不要把所有动物都设计成杀死才能有用。

**活取牧场**：鹿、蜗、邮鹭、夜蛾、羊长期留养。落角作灯油替代，壳胶作收纳，镜鳞作镜片，响绒作旅毡；成熟周期与收购价格可以独立调整。

**元素牧场**：浮鲸采魔→瓶装储运→锻炉/发电座/枕光貂；鸣线蜥从真实FE或雷雨充电→取晶→储运电；炉鳃山貘暖息、水獭泉浓液、纸帆魟风翎各有实际用途。

**助手牧场**：负兽和邮鹭运输；犀翻地；筑狸修栅栏；浣兽收种与换种；螳螂巡逻；蹄兽坐骑；貂耗魔陪伴照明。先让一只助手完成一条真实小路线，再扩大设施，避免只是养在那里交任务。

## 4. 炼金炉路线：四种材料的3×3×3

总材料：耐火炉砖24、炼金炉口1、魔力炉核1、排烟顶1。不需要刻铜炉框、专用输入砖/输出砖或后方注口。

下面俯视图上方是后、下方是前；“前”由炉口朝外的一面决定。

```text
底层          中层          顶层
砖 砖 砖      砖 砖 砖      砖 砖 砖
砖 砖 砖      砖 核 砖      砖 烟 砖
砖 砖 砖      砖 口 砖      砖 砖 砖
```

1. 完成底层九砖，中层中心放炉核、前方中心放炉口，其余七砖；顶层中心放排烟顶、其余八砖。
2. 右键炉口开界面，右上“搭建说明”有分层图。状态条和27格诊断显示结构问题。
3. 选择工艺；四个材料格的示意物说明需要什么，投入真实材料。
4. 点“注魔＋25”，扣玩家实际魔力；也可用魔力瓶、蓄魔根芯右键炉口。翠脉枝种在炉口前一格可以慢速供魔。
5. 炉子工作时有注能、制作与排烟效果。缺部件会暂停并保留库存；修好可继续。
6. 中层左右两侧的中心炉砖可接漏斗投料；炉口正下方的底层炉砖下接漏斗取成品。同一种砖承担端口，不增加搭建材料种类。
7. 升级格放预热油或冷凝壳，剩余次数用完即停；不是额外建造部件。

旧结构需要按新三层图重搭。旧端口物品保留注册以免读档丢失，它们不属于新结构的必需材料。

## 7. 可直接复现的测试顺序

新测试世界开作弊，创造模式，清出足够背包空位后分别执行：

```mcfunction

/function tnc:ecology_animal_kit

```
