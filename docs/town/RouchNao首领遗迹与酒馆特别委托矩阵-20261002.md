# RouchNao 首领、遗迹与酒馆特别委托矩阵

日期：2026-10-02　更新：2026-10-03。状态：**前三份已接入酒馆的基础特别委托；完整分阶段剧情仍是设计稿**。没有新生成首领或修改天空岛。

## 一、在正史中的位置

本矩阵填入归、让、槐出城后「很多年接委托、平定盘踞一方的家伙」的中段。玩家从 41 号酒馆接到有姓名、有委托人的特别行动，调查的对象各有自己的生态与问题；完成后有人收下调查记录、有人因此改变镇上的供应或说法。它们让远征和 RouchNao 的田地、餐桌、铁匠炉发生联系，但不要求玩家为了种地或买房必须打首领。

**正史边界**：黑暗潮是大量小怪攻城，没有大首领；公孙衍（迷失）的决战在黑暗深处，随后归在时间间隙面对 Chiller Lynn 并失败。不能把 Chiller Lynn 放进可重复的酒馆讨伐，也不能把中段任何模组首领写成幕后真凶。中段交回的线索只指向「各地出现不合常理的损坏、失序与旧记录」，玩家直到正史指定时刻才知道其因果。

**已接入的基础版玩法**：玩家先在 41 号酒馆委托栏潜行右键备案（普通右键继续使用 Bountiful 纸张），达到 15/20/35 级后分别可接上述三份。接单后亲自参与对应首领的真实击杀，在同维度、目标 64 格内且最近 60 秒内对其造成伤害；服务端给参与者记一次个人证明。回同一委托栏潜行右键领取一次性铜币、经验和声望。目标模组未安装时不发新单；已经取得的证明仍可交付。当前**不检查击杀发生在指定遗迹、不要求调查与回访 NPC，也没有解锁铁匠新服务**，下文详细的五阶段剧情仍是下一阶段制作基准。

## 三、每份委托的可玩流程

### 01　炉门里的人：学会退一步

- **发布人**：28 号炉石铁匠铺。铎恩收到一块无论怎么加热都不软的炉壁碎铁，请玩家查明它为何会自己移动。
- **阶段**：酒馆领纸 → 找铎恩拓下炉纹 → 到真实 `mowziesmobs:wrought_chamber` 寻回同纹碎片 → 准备一份耐久料理与修理包 → 击败 `mowziesmobs:ferrous_wroughtnaut` → 回铁匠铺对照纹路，再到酒馆结案。
- **证据**：服务端记录接单玩家在该结构实例内参与实际击杀，再发一次性的「炉纹拓片」（**拟议新任务物品**）。模组战利品表中的 `mowziesmobs:wrought_axe`/`wrought_helmet` 可供玩家收藏，不要求上交稀有武器。
- **生活联系**：铁匠解锁「旧炉金属修补」服务；田地可提供耐久料理用的谷物/蔬菜，成功不是靠交成吨原版小麦。
- **回应与重复**：铎恩承认这道炉纹不是他铸的，并在店里挂上拓片。剧情奖励每人一次；以后可在别的实例再挑战，普通战利品照旧，不重复领第一次的声望和解锁。

### 02　庭院里的蜕皮：第一次跨世界调查

- **发布人**：酒馆登记员艾琳。商队带回一片陌生鳞，委托队伍辨认来源，并记录原地生态。
- **阶段**：辨认鳞片 → 找到暮色森林 `twilightforest:naga_courtyard` → 记录庭院外一处植物及安全返回路线 → 击败 `twilightforest:naga` → 携带记录返镇。
- **证据**：结构实例内的实际击杀记录为主；模组现有 `twilightforest:naga_scale`、`twilightforest:naga_trophy` 可作为收藏展示，不以持有物品单独冒充首杀。
- **生活联系**：解锁「暮色土样」调查订单（**拟议**），给喜欢收集的人一种带回家研究的异世界纪念；后续温室设计可使用土样进行适种实验，不把暮色原模组作物直接改名当原创。
- **回应与重复**：艾琳把跨世界路线写入酒馆地图。剧情首报一次；普通冒险可重打，只有不同真实遗迹实例才可产生新的调查记录。

### 03　沙下的旧名：并非所有遗迹都要掏空

- **发布人**：庄鹊让从旧籍里找到一张缺页的沙漠地契；一支测绘队失联。
- **阶段**：酒馆领测绘单 → 带水、遮阳食品和纸张 → 找 `cataclysm:cursed_pyramid` → 找到测绘队的最后一个标记 → 击败 `cataclysm:ancient_remnant` → 把拓录和人员消息带回，珍贵文物由玩家自行处置。
- **证据**：真实击杀与发现标记分别记录。`cataclysm:remnant_skull` 在模组战利品表里存在，可当可选展示品；不可单用它替代击杀证明。
- **生活联系**：给农业线一份「干旱土样」（**拟议物品**）；未来可拿它试培耐旱魔法植物，卖给商店的是可再生产的植材，不是文物本身。
- **回应与重复**：让读出地契上被刮去的一行字，只确认这里的旧文明也试过保护聚落，不提前说出终局真相。首份报告一次；后续沙漠探险有常规战利品，无反复高额首通奖。

### 04　不肯落下的季节：原创可培育生态的入口

- **发布人**：镇上种植者送来一筐同枝却处于四季的果子，请调查来源。
- **阶段**：尝试保鲜失败 → 找到**新建**季外温室 `tnc:seasonless_conservatory` → 观察四块不同生长期的试验田 → 用灌溉/遮光而非纯伤害破除「季节循环」 → 击败**新做** `tnc:seasonless_coronet` → 带回未受损的「节候种壳」（**拟议物品**）。
- **证据**：结构实例内的多阶段交互与真实击杀均记入服务端。温室探索本身不能算击杀。
- **生活联系**：首次交回后，种壳**可保留并育种**；成熟产物一部分卖店、一部分是季节料理与家园盆栽材料、一部分可作为后续酒馆医药/补给委托。玩家保留第一株的后代，形成收集线，而不是一次性交掉所有种子。
- **回应与重复**：镇里开出「试种记录」页，邻居会评论玩家首次收成。首报一次；种植与多代选种是长期玩法。建筑、植物和 Boss 均为原创提案，当前世界无此温室或实体。

### 05　没有下班的工厂：锻造炉的失控范例

- **发布人**：铁匠铺与商店联名。远地废厂还在消耗矿料，机器却无人值守。
- **阶段**：取商会的耗料账本 → 找 `cataclysm:ancient_factory` → 记录两台不同用途的机器 → 准备绝缘/恢复用品 → 击败 `cataclysm:the_harbinger` → 回镇提交「停机报告」。
- **证据**：模组结构模板存在 `harbinger` 数据标记；任务判定仍以真实击杀与该实例 ID 为准。掉落表有 `cataclysm:witherite_block`，是可选收藏，不当唯一证明。
- **生活联系**：引出自家「魔法锻造炉」的安全规范：魔力输入有上限、过载会停机、红石只能开关/设定而不能白嫖魔力。第一阶段只解锁炉的手工模式；自动化是后续项目，不把灾变现成机器当自己的原创发明。
- **回应与重复**：铎恩拿停机报告改造自己的炉门；首报一次。工厂后续可探宝，但不做每天刷先驱者卖钱的主收入。

### 06　灰烬点名：最难的是把人带回来

- **发布人**：酒馆收到一份下界失踪名单。进入 `cataclysm:burning_arena` 的人最后都只留下物资袋。
- **阶段**：核对名单 → 准备冷却料理、应急水（仅出发地使用）与回程锚点 → 到燃烧竞技场追踪行迹 → 击败 `cataclysm:ignis` → 回收可辨认的遗物 → 把名单交回委托人。
- **证据**：真实击杀加实地发现记录。模组掉落表有 `cataclysm:ignitium_ingot`；TN-C 现有八类珍馐也包含 Ignis 的独立料理素材。剧情遗物单独记录，避免把料理素材吃掉导致无法交差。
- **生活联系**：料理作战准备可来自玩家的肉、蛋、调味与魔法植材；铁匠基于调查完成一次耐热订单。不会让普通农业必须闯下界才解锁。
- **回应与重复**：酒馆把失踪名单上的确认者挨个划回，留下未解的名字。首通一次；后续杀怪只按模组掉落与首领珍馐规则，不给可刷爆的高额剧情金。

### 07　海底的空钟：带回一种活的样本

- **发布人**：渔夫说深海的潮汐变得不按天数来，他的网里捞到沉城的刻字铜片。
- **阶段**：访渔夫 → 准备水下生存餐与救援绳 → 找 `cataclysm:sunken_city` → 记录三处不同深度的水流/植被 → 击败 `cataclysm:the_leviathan` → 将调查图交回。
- **证据**：水下结构内真实击杀为主；现有掉落表中的 `cataclysm:abyssal_egg`/`tidal_claws` 不强制上交。TN-C 现有 Leviathan 珍馐素材与报告分离。
- **生活联系**：渔业、盐腌、温室海水种植成为可选长期经营；第一次允许带回「潮生孢囊」（**拟议新物品**），孢囊能在可控盐度的水槽中繁育，而不是从 Boss 身上无限刷作物。
- **回应与重复**：渔夫能据调查图恢复航线，商店出现限量海产采购单。首报一次；之后水产交易可重复，首领击杀不成为日常最高收益。

### 08　冻土来信：冬季畜牧的理由

- **发布人**：偏远牧场的信到得太晚，字迹在封口下面结冰。庄鹊让请队伍先查牧场，再查雪原监狱。
- **阶段**：救回失联牲畜/核对牧场名册 → 制作保温饲料与热餐 → 到 `cataclysm:frosted_prison` 寻找相关囚牌 → 按模组原有交互唤起并击败 `cataclysm:maledictus` → 把牧场与监狱两份记录一并交回。
- **证据**：标注为**设计**的唤起步骤，具体触发物及机制需游戏里核对 3.31 版本；只以真实击杀记录结案。`cataclysm:cursium_ingot` 是已有可选战利品，不能代替本单证据。
- **生活联系**：解锁可反复制作的「保温饲料」（**拟议**），让异世界畜牧不只是喂麦子：低温时改善产奶/产毛稳定性，但不凭空复制动物产物。
- **回应与重复**：失联牧民返乡或留下消息，镇里有一次安静的欢迎。首报一次；饲料经营可长期持续，首领战不设每日高额悬赏。

### 09　钟声错一拍：原创非数值碾压战

- **发布人**：有人在旧教堂听见四声钟，回程只走了三声。庄鹊让要一份可复验的记录。
- **阶段**：带纸、墨与三枚可识别铜片 → 到现有 `tnc:gothic_cathedral` → 找三处报时装置并抄录先后顺序 → 面对**新建** `tnc:misbeat_bellkeeper`：听音辨方向，敲回缺失的一拍才能解除护甲，反复三次后胜出 → 返镇交调查本。
- **证据**：新战斗脚本记录三次正确解谜和真实击杀；单靠一支高伤法杖秒怪不能算完成。任务证明为服务端记录，可领纪念钟舌（**拟议**）。
- **生活联系**：玩家可制作节律钟控制手工锻造炉的投料节拍，红石只负责节律信号，不产生免费魔力；也可作为住宅钟饰由商店销售。
- **回应与重复**：让说「钟坏了，还能调；人忘了什么，就未必」，只作人物情绪，不揭终局时间魔法。首报一次。教堂结构现有，但当前大型建筑施工代码没有首领放置逻辑；本战斗完全未实装。

### 10　门的另一面：公孙衍（迷失）

- **发布方式**：严格在正史「黑暗潮→周坐望开门」之后由 Self 交出唯一世界特别行动；**不作为 Bountiful 普通轮换纸张**。
- **阶段**：防御无大 Boss 的黑暗潮 → 找望确认入口 → 准备粮食、药与同行者 → 进入黑暗深处，清理沿途小怪 → 与已注册的 `tnc:yan_dark` 交战 → 按 `剧情/第三段_黑暗深处.md` 演出槐、让、望的结局与得石真相 → 触发 `剧情/第四段_挥戈.md` 的时间间隙场景。
- **建筑**：建议把现有 `tnc:abyss_citadel` 的巨坑、城堡作为抵达深处的地表入口与前厅，但必须先与合伙人确认视觉场景；当前结构只负责生成，不会自然生成衍，也未绑定剧情。真正深处战斗区与时间间隙是**需新建或单独实例化的剧情场景**。
- **证据**：实际参战记录和战斗结束事件推进主线。得石剧情记录不可作为可交易战利品；世界重置/二周目逻辑不得被一次普通死亡误触发。
- **生活联系**：临行前可利用自己的农场、畜栏、厨房和锻造炉准备物资；没有房产或家庭的玩家也能靠委托、商店与NPC补给出发。玩家的生活选择体现为返回时有哪些人等他，不阻止主线。
- **回应与重复**：按正史一次性推进；**不可循环讨伐**、不给每日刷新高奖。Chiller Lynn 的初战属于之后的固定叙事，尚无注册实体与可玩战斗，不列入本十单。

## 四、共通验证与制作边界

### 额外原创首领候选：让遗迹有自己的玩法

十份精选单是第一纪中段的建议节奏，原创首领不必都塞进同一条必经战斗线。以下两位是**可替换其中模组首领的支线候选**，并非当前已注册内容；是否进入正式十单，取决于建筑和机制能否做得比重复打怪更有意思。

|候选|地点与委托|战斗以外的动作|带回小镇的变化|
|---|---|---|---|
|守卷城主 `tnc:archive_warden`|现有 `tnc:stonecrest_fortress` 中的独立书库房间；庄鹊让委托找一份被锁的借阅记录|先用苇纹纸拓下三页顺序，战斗中移动书架会遮住法术，按记录开窗才可命中；书库与首领锚点均待制作|不是掉一把更强的剑，而是给镇上图书/抄录员开放一批可读的旧路资料；不提前揭露正史得石真相|
