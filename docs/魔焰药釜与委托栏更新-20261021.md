# 魔焰药釜与委托栏

## 委托栏在哪

在天空岛酒馆，协会接待员艾琳旁边。现在是旧铜边框、贴着四张纸签的板子，右键直接打开委托页。接单、记录进度、交付均无需把纸放进背包。

具体世界坐标随天空岛位置变化。相对于天空岛原点，委托栏为 `(432, 91, 285)`。以之前艾琳在 `(816, 180, 666)` 的世界为例，委托栏约在 `(812, 181, 665)`。

已有酒馆的原 Bountiful 板会移到紧邻空位，保留旧纸交付和库存。普通右键附近旧板也打开新委托页；只有拿着旧委托纸，才进入旧交付流程。没有安全空位时保留原实体，但右键仍使用新委托页，避免覆盖装修。

## 炼药操作

1. 放下 **魔焰炼药釜**，水桶右键倒水。一桶水能炼三剂。
2. 把配方的三种材料各一件丢进锅口，也可以手持原料右键加入。同种材料不会吞下一整组；无关物品不会被接收。
3. 加入 **焰蕊盐**。原料为暖椒、木炭和荧石粉。
4. 对准锅身施放 **火球等真正的火系法术**。燧石、普通火焰、火焰弹物品和界面按钮都不能点火。
5. 按提示空手或持 **铜枝搅拌棒** 右键。浸润、融合、凝结各搅拌一次；会看到棒子和药材旋动。停手时暂停，不会烧毁材料。
6. 凝结后用空玻璃瓶右键盛取，一剂消耗一个真实空瓶。未取走药液之前，药釜不会再吞下一批材料。

持书右键打开只读药典。潜行空手右键可取回未完成的材料，也能取回旧版本留在内部的瓶子和成品。剩余焰蕊盐燃时留存；中途耗尽可以补盐并再次使用火法。

新手测试第一剂：**雨笺莓 + 糖 + 海带 = 凝泉饮**，饮用恢复30法力。配方与完整效果在魔焰药典 FTB 章节中。

## 可见反馈

- 投药：实际材料浮在液面，随搅拌旋转，融合时逐渐沉入药液。
- 加水：蓝色水流落入锅中，水位显示实际剩余量。
- 火焰：釜底蓝绿药焰夹着暖色火心；普通火不能冒充魔焰。
- 恢复类：花粉微光溢出，附近空闲野生动物可能靠近。
- 法力类：上方出现旋转星团、汇入釜中的微光；高阶配方范围更大。
- 战斗类：碎晶火花、短时焰冠；轻盈类：上升蒸汽与泡沫微光。
- 完成：一次明显的光尘迸发，随后留下等待装瓶的药液。

异象不修改天气、世界时间或周围方块；动物不会传送、改主人或改窝点。独立药焰可工作，邻接自己的魔力装置只作辅助，不会绕过点火和搅拌。
