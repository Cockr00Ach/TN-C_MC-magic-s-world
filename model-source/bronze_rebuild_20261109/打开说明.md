本次是独立几何与材质重建，采用明确的立体结构与像素纹饰。五把武器共用一张 512×512 贴图，人偶使用另一张 512×512 贴图，逻辑 UV 均为 128×128。每张为一帧，无逐帧几何副本。编辑预览每个工程为一个材质；实际 draw call 和 Minecraft FPS 未测量。

## 运行资源的使用

“导出/assets/tnc/models/item”提供 Minecraft Java 1.20.1 物品模型，使用旧版单轴 0/±22.5/±45° 旋转；贴图引用已指向同一导出目录中的资源。四件基础武器保留原来的文件名。双刃附 `bronze_twin_main.json`、`bronze_twin_off.json` 与成套排版 `bronze_twin_pair.json`；前两个文件属于同一件双持武器，不注册成两个可单用物品。

当前项目的 `BronzeTwinRenderer` 不读取 `element.rotation`。这些重建模型包含旋转体块，接入前需要让该渲染器支持旋转，或者使用正确的原生模型烘焙路径。`bronze_twin_pair.json` 的原生 Display 截图是整套模型的排版显示；实际双手位置由现有自定义渲染器负责。主、副刃独立导出时握持中心已归一到 `[8,8,8]`，长刀尖在局部 +Y 方向。

人偶运行数据位于 `导出/assets/tnc/puppet/bronze_puppet_parts.json`，保留 `head/hat/body/right_arm/left_arm/right_leg/left_leg` 原生骨架和枢轴。贴图按现有加载器命名为 `textures/entity/bronze_puppet.png`。这份数据应放在 `puppet/`，不是 GeckoLib/Bedrock 的 `geo/` 模型。人物动作继续由现有战士连招系统驱动。

“导出/参考代码/BronzePuppetRebuildModel.java”是 Blockbench 原生 Mojang mappings 导出，供对照骨骼和坐标；接入项目时使用现有 Humanoid 数据加载器，不能把这个参考类直接覆盖原模型类。

本次交付为独立模型文件，尚未替换或安装游戏内资源。攻击、强化、合成、蓄力投掷、召唤与冷却代码均未改动。
