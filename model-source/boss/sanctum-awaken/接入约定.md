# 守曦天使一转二面部资源

## 坐标和锚点

坐标沿用原 SCM2，单位为格，正 Z 朝玩家。新面部片段的根骨取名 `awaken_face`，在原 `head` 最终矩阵上绘制，根偏移为零。子骨分别对应 `head_shell`、`head_oculus`、`head_jaw` 和左右 `head_plumage`。子骨上的枢轴已内置，不叠加原 `head_oculus` 或 `head_jaw` 的旧唤醒缩放。

作者原稿去除父骨变换后的参考头部坐标为 `(0,48.660662,0.575866)`。实际渲染以现有 `head` 矩阵为准。以下枢轴值相对于 `head` 并与运行中 SCM2 一致。

| 原骨骼 | X | Y | Z |
|---|---:|---:|---:|
| head_shell | 0 | 2.879329 | 0 |
| head_oculus | 0 | 4.318994 | 1.957944 |
| head_jaw | 0 | 0.287933 | 0 |
| head_tears | 0 | 3.455195 | 2.591396 |

闭嘴中央唇线约在 `(0,1.330,2.548)`。完全张开后，上唇中央约为 `(0,1.891,2.421)`，下唇中央约为 `(0,0.530,2.611)`。两侧开口末端约在 `X=±2.58`。

## 时间线

| Tick | 面部事件 |
|---:|---|
| 0–22 | 保持第一阶段闭眼和合唇 |
| 24–31 | 上睑先沿一侧眼角松动，星瞳从缝后显露 |
| 32–52 | 上下睑向眼眶外缘回卷，侧眼稍后打开 |
| 46–58 | 一侧嘴角先牵动，另一侧随后跟上，中央只有暗缝 |
| 58–70 | 唇缘退开，首先看见口腔深处，再从唇后露出部分牙尖 |
| 70–82 | 两侧裂笑达到最终幅度，交还现有第二阶段静态面部 |
| 72–114 | 继续使用原 `head_tears` 和现有沿脸颊展开的渲染 |

原 `head_tears` 无需替换、重新定位或缩放。面部片段和现有 SCM2 使用同一张 `sculpture.png`。

## 文件与层替换

- 替换帧在 [`src/main/resources/assets/tnc/models/sanctum/awaken`](../../../src/main/resources/assets/tnc/models/sanctum/awaken)。每个采样含近距版和 `_view` 远距版，确切路径、顶点面数和 SHA-256 见 `frames.json`。
- 0–23 刻使用 000，24–81 刻每刻一帧。若单刻帧尚未预取，可回退至同距离档最接近的已载入前帧，偶数帧可优先预取。到 82 刻交回游戏内既有的二阶段静态面部。082 也随包提供，可用来核对切回的边界。帧之间的眼口裁边会改变拓扑，应调度采样帧，不能按顶点编号插值。
- 绘制片段时跳过原模型中 `replaceLayersOf` 列出的层提交。保留这五根骨的矩阵与子骨遍历。特别是两侧 `head_plumage`，其子骨承载独立羽毛，把父骨设为不可见会一起丢失。
- 原血泪所在的 `head_tears` 槽及透明合成顺序照常运行，72–114 刻继续由现有裁切逻辑展开。牙齿始终以整牙相对牙床运动，露出的部分由当前的唇缘裁切。
- 建议沿用已加载的近远距选择，只预取当前模型需要的距离档。当前加载器的固定键列表不会自动认识这些新文件，接入需为帧目录提供单独的加载入口。
