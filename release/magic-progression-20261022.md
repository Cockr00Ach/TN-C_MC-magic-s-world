## 给伙伴同步

Git main提供源码、配方、模型、任务和工具；编译JAR不存入Git。伙伴可使用同一基础整合包并应用本次 `magic-progression-update-20261022.zip`，不要只pull任务页而继续使用旧JAR。

更新包解压到一个临时目录。完全退出游戏，用 PowerShell 执行：

```powershell
./apply_magic_progression_update.ps1 -Pack '你的PCL版本文件夹绝对路径'
```

脚本校验manifest哈希与文件白名单，先备份再更新；不会遍历删除文件、覆盖作者其它章节或改存档。需要自行构建时，JDK17执行 `./gradlew.bat test jar --offline`，把产物与上述四个章节同步进同一实例。不能把源码目录直接当运行包。
